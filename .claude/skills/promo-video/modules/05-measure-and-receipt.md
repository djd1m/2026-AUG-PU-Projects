# Модуль 05: замеры и квитанция

Эталоны: [`promo/remotion/n6/MEASUREMENTS.md`](../../../../promo/remotion/n6/MEASUREMENTS.md) (среда, прогон, мутация
стража), [`promo/remotion/n2/MEASUREMENTS.md`](../../../../promo/remotion/n2/MEASUREMENTS.md) (цена в кадре по готовым mp4),
[`promo/remotion/n2/ITERATIONS.md`](../../../../promo/remotion/n2/ITERATIONS.md), [`promo/remotion/n6/ITERATIONS.md`](../../../../promo/remotion/n6/ITERATIONS.md),
[`promo/remotion/n2/README.md`](../../../../promo/remotion/n2/README.md); сводка серии — [`promo/RESULT-SERIES.md`](../../../../promo/RESULT-SERIES.md).
Замечания Codex к замерам — [`VERIFY-SERIES-CODEX.md`](../../../../promo/VERIFY-SERIES-CODEX.md) §4.

## Input

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `logs/receipt.txt` | файл вне git | да | строки `TIME … MEMPEAK … watchdog=… host_load1=…` на шаг, `✅/❌` стража |
| `logs/*.txt` | журналы операций | да | `install`, `bundle`, формат; нужны при коде 1 |
| журнал попыток | заметки исполнителя | да | время, что не сработало, категория, правка, минуты |
| README записи и `record-log-*.json` | модуль 03 | да | платные вызовы, тайминги |

## Process

1. **Что мерить — раздельно** (поправка Codex пилота №1: границы «времени рендера» у двух инструментов различались на
   ~10 с сборки):
   - **сборка бандла** — отдельный контейнер `promo-<proj>-bundle`, кэш webpack выключен;
   - **рендер каждого формата** — отдельный контейнер `promo-<proj>-<fmt>` из готового бандла;
   - **`npm ci`** — вне замера (сеть bridge), записать отдельной строкой.
   Время — bash `time` ВНУТРИ контейнера (wall / user / sys); ожидание блокировки в замер не входит.
2. **Память** — `/sys/fs/cgroup/memory.peak` контейнера: пик всей cgroup (Node + Chromium + компоновщик + ffmpeg +
   файловый кэш), **не RSS процесса** — так и писать. Нет файла — `MEMPEAK bytes=null (нет memory.peak)`, не ноль.
3. **Нагрузка хоста** — `host_load1` (1-минутный load из `/proc/loadavg`) на каждый шаг. Время при занятой машине —
   **измерение этой машины в эту минуту**, не «верхняя оценка» и не свойство ролика (Codex §4: N6 16:9 — 380 с при load
   9–11,7 против 317 с у повтора того же файла). Серия: сборка 16,2–25,9 с, рендер одного формата 178–380 с, пик
   2,74–2,97 ГиБ при load 5–13 на 8 ядрах ([`RESULT-SERIES.md`](../../../../promo/RESULT-SERIES.md)).
4. **Сторож хоста** — `watchdog=clean` или `HIT` на шаг (журнал `/var/log/crypto-watchdog/watchdog.log` только читается).
   `HIT` = замер недействителен, переснять.
5. **`MEASUREMENTS.md`** — разделы по эталону N6/N2:
   - *Среда*: ревизия и `dirty_files` из квитанции, digest образа, версии инструмента, лимиты, блокировка, кодирование,
     чем мерили время и память, сторож.
   - *Прогон*: таблица шаг / wall / user+sys / пик памяти / `host_load1` / размер / sha256.
   - *Страж*: итог `probe.sh` по каждому файлу + отдельный `ffprobe -show_streams` на отсутствие аудио (пока `probe.sh`
     его не проверяет — модуль 04, ограничение 8).
   - *Воспроизводимость*: sha256 16:9 и повтора; при различии — PSNR и названная причина.
   - *Привязка к исходникам* (Codex §4 и обязательная правка 3): sha256 `project.config.ts`, всех использованных записей,
     файлов шрифтов; если `dirty_files > 0` — `git diff | sha256sum` грязного состояния или хеш бандла. «Потом
     закоммитил без изменений» без хеша — не доказательство (N1, N4).
   - *Запреты в кадре* — модуль 02 п. 5.
   - *Мутация стража* — п. 7 ниже.
   - *Что не удалось / не проверено*.
6. **`ITERATIONS.md`** — одна таблица на весь проект (часть A **и** часть B, одним итогом — Codex §4: у N1/N2/N4/N5 части
   считались раздельно, общий бюджет не доказывался):
   - столбцы: № · время UTC · что · что не сработало / что узнал · **категория** · правка · минуты;
   - категории — закрытый список: **инструмент** (Remotion/ffmpeg/Playwright/шаблон) · **среда** (хост, образ, соседи,
     сторож, песочница агента) · **исполнитель** (свои ошибки и решения);
   - **попытка = запуск, после которого пришлось что-то менять**; успешные проверки считать отдельной строкой итога,
     не в «попытках» (иначе N6 «8», N4 «3» несравнимы с лимитом ≤ 8 — Codex §4);
   - итог: попыток с правками по категориям, активные минуты, ожидание блокировки и рендера отдельно, платных вызовов
     (число и что именно считалось — запросы к провайдеру или действия в UI).
7. **Страж испытан на падение** ([`guard-must-be-able-to-fail`](../../../rules/guard-must-be-able-to-fail.md)) — один раз
   на изменение шаблона или `probe.sh`, и записать обе строки:
   ```text
   мутация:        из RENDER_FLAGS убран --color-space=bt709 -> render.sh <proj> 1x1 -> код 1
                   (pix_fmt=yuvj420p, ожидалось yuv420p · color_range=pc · color_space=bt470bg)
   восстановление: git checkout shared/render.sh -> код 0, 1x1.mp4 побайтно тот же
   ```
   Отдельно — код 2: несуществующий проект, формат `4x3`, отсутствующий mp4 у `probe.sh`. Эталон — N6 `MEASUREMENTS.md`.
   Мутацию делать в СВОЁМ worktree и восстанавливать до коммита; шаблон в чужом worktree не трогать.
8. **`README.md` проекта** — одна команда повтора (`REPRO=1 bash promo/remotion/shared/render.sh <proj>`), где результат,
   что в папке, таблица «сцена каркаса → сцена шаблона → файл по формату → куски записи», как исключены запреты,
   отклонения от `SCENARIO.md`. README не должен противоречить конфигу: каждое число таймингов и кадрирования — из
   конфига (N2: README «QR в 9:16 без обрезки» против `tall.crop` в конфиге — Codex §3).
9. **Коммиты** `feat(promo): …` / `docs(promo): …` по-русски; mp4 (кроме `promo/dist/`), записи, `node_modules` — не в git.

## Output

- `promo/remotion/<proj>/MEASUREMENTS.md`, `ITERATIONS.md`, `README.md` (+ `SCENARIO.md` актуален).
- Копия `receipt.txt` → `logs/receipt-final.txt` (вне git; путь — в `MEASUREMENTS.md`).
- Файловая квитанция исполнителя в TRACE_PATH (модуль 06 §5).

## Quality Gate

| Проверка | Как | Слой | Блокирует |
|---|---|---|---|
| у каждого шага отдельные wall/память/`host_load1`/`watchdog` | `grep -c 'watchdog=clean' receipt.txt` = число шагов | 1 | да |
| sha256 всех mp4 и конфига в `MEASUREMENTS.md` совпадают с файлами | `sha256sum` против таблицы | 1 | да |
| мутация стража записана (код 1 + восстановление 0) | раздел «Мутация стража» | 3 | да при изменении шаблона |
| у каждой попытки категория из закрытого списка | `ITERATIONS.md` | 1 (grep) | да |
| платные вызовы ≤ лимита, названо, что считалось | `ITERATIONS.md` + README записи | 3 | да |
| README ↔ конфиг без противоречий | выборочная сверка чисел | 4 | нет, но находка Codex = правка |

## Dependencies

- Модуль 04 (REQUIRED): без `receipt.txt` мерить нечего; `render.sh` → 2 — замеров нет, это не «0 секунд».
- `guard-must-be-able-to-fail` (правило, REQUIRED для п. 7).

## Reusability

Структура `MEASUREMENTS.md` (среда → прогон → страж → воспроизводимость → привязка к исходникам → мутация → не
проверено) и закрытый список категорий попыток годятся для любого сравнительного испытания инструмента на этой машине.
