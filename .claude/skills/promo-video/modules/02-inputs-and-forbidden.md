## Process

1. **Инвентарь** — одна строка в формате `05_project_inputs.md` (поля: фраза, стенд, экраны без входа, сценарий,
   токены, лого, ЦА/канал, «Нельзя»). Каждое значение — со ссылкой `файл:строки`:
   - **Экраны без входа** — из маршрутов (CLAUDE.md, `app/` роуты); экран за входом помечать сразу — он потребует
     фикстуру (модуль 03 п. 7) или выпадает.
   - **Токены** — `--paper`/`--ink`/`--accent` из `globals.css` темы по умолчанию (`#rrggbb`; шаблон принимает только
     этот вид). Если акцент на фоне продукта не читается — фон ролика берётся из другого токена продукта (N4:
     `--dark #1b1523` как фон, потому что `#ffc531` на `#fbf8f2` не читается) — и это записывается в README.
   - **Шрифт** — продукта, если его файл есть в проекте (TTF + лицензия OFL); системный шрифт продукта → Onest из образа
     (N2, N5). Шрифт через `next/font/google` без локального файла — сначала найти TTF, иначе Onest с записью «фирменный
     шрифт потерян» (N1: Bricolage/DM Sans → Onest, Codex принял как обоснованный fallback).
   - **Адрес стенда** — из квитанции развёртывания; голый IP (`*.sslip.io` с IP, N3) в финал и в адресную строку кадра не идёт.
2. **Список «нельзя показывать»** — закрытый набор классов; каждый класс проверить для проекта и либо назвать способ
   исключения, либо записать «не применимо, потому что …». В `SCENARIO.md` — таблица, первый столбец = id класса
   (`цены` … `вымышленное`), по строке на класс: так её проверяет ворота (Quality Gate), а не чтение:

   | Класс | Примеры из серии |
   |---|---|
   | `цены` — цены, тарифы, оплата | N2 «План: Free — 990 ₽» в кабинете и в герое лендинга; N1/N4 тестовый магазин; N5/N6 оплата off («Pro скоро») |
   | `бренды` — чужие бренды и продукты | скриншоты Senja/NiceJob/Birdeye/Podium/Cal AI/Opus в `docs/discovery/screenshots` — не брать никогда |
   | `фикстуры` — служебные фикстуры и чужие учётки | N6 демо-бот `/b/pekarnya-kolos-…`, `ui-fixture.json`; N2 «Кофейня Артель» (обращение ушло бы владельцу) |
   | `незавершённое` — незавершённые фичи | N1 вкладка видео, `/partner`; N2 партнёрка; N3 F3 в HEAD; N4 Telegram Mini App |
   | `адреса` — голые IP и внутренние адреса | N3 `212.192.0.33.sslip.io`; локальный адрес съёмки не в кадре |
   | `секреты` — ключи, `.env`, секреты, личные чаты | `.secrets/`, `.env.n5-demo`, личный Telegram владельца N2 |
   | `числа` — неверные числа | N4: синонимы стенда вели «яйцо варёное» → Butter, «гречка» → Oats — в кадр только позиция, прошедшая сверку |
   | `вымышленное` — вымышленные данные без пометки | N1 отзывы, N2 «Пекарня на Речной», гость `anna@example.com` |

3. **Способ исключения — назвать механизм**, по порядку предпочтения:
   1. не снимать (выбор маршрута, `page.route(...).abort()` на запрещённые запросы — N6 `/claim`, `/share`, `/api/auth/*`);
   2. снимать другую раскладку (N2: кабинет 9:16 из mobile, потому что desktop в 9:16 показывается целиком);
   3. кадрирование — **только с запретной зоной** (п. 5): шаблон показывает всё окно, в которое вписан `crop`, а не
      сам `crop` (модуль 04 п. 4, «crop ≠ маска»); видимое окно считает `gate-config.sh`, не исполнитель на глаз;
   4. CSS-скрытие в браузере записи — слабее всего: не исключает вспышку до применения стилей (Codex §2, N1/N5).
4. **Демонстрационные данные — постоянная пометка** на всё время, пока они в кадре (урок N1: пометка «пример» была только
   последние 2 с сцены 4 — Codex «нет»). До появления поля `footnote` в шаблоне (DEC-S-02) — пометка внутри записи
   (подвал страницы-примера, N1 «Вымышленный сайт для демонстрации виджета · пример») **в той части экрана, которая
   остаётся видимой во всех трёх раскладках** — подвал внизу страницы исчезает при кадрировании. Какая часть видна,
   считает `gate-config.sh` (модуль 04 п. 4, строки `VISIBLE`). Интервалы ГОТОВОГО ролика с вымышленными данными — в
   `promo/remotion/<proj>/demo-intervals.tsv` (строки `6-17`); на них модуль 07 требует `видна` на каждом листе.
5. **Запретные зоны записи — `promo/remotion/<proj>/forbidden-zones.tsv`** — для всего, что исключается кадрированием
   (способ 3): прямоугольник в пикселях ИСХОДНОЙ записи и интервал файла, TAB:
   ```text
   # файл	x0	y0	x1	y1	from	to	причина
   owner-create-desktop.webm	0	296	1920	517	0	9.4	блок «План: Free — 990 ₽» до создания точки
   inbox-mobile.webm	0	1272	780	1688	0	5.5	«План: Free» в кабинете до перехода к списку
   ```
   Координаты — с кадра записи (`ffmpeg -ss <t> -frames:v 1`, модуль 04 п. 3). `gate-config.sh` отказывает (код 1),
   если видимое окно любого куска задевает зону (модуль 04 п. 4). Проверено на N2: три настоящие зоны → 0; зона
   `inbox-mobile` продлена до 20 с → 1 «tall 33.50-39.00 с: видимое окно … задевает запретную зону»; строка не из 8
   полей → 2.

## Output

- Строка инвентаря (дополнение `05_project_inputs.md` — через координатора, это общий файл).
- Раздел `SCENARIO.md` «Нельзя показывать → как обойдено» — таблица класс / способ / чем проверяется.
- `promo/remotion/<proj>/forbidden-zones.tsv` (если есть способ 3) и `demo-intervals.tsv` (если есть вымышленные данные;
  интервалы уточняются после монтажа).

## Quality Gate

| Проверка | Команда / способ | Порог | Блокирует |
|---|---|---|---|
| Все 8 классов — строки таблицы «Нельзя → как обойдено», id класса в первом столбце, способ или «не применимо, потому что …» | команда ниже | пустой вывод, код 0 | да: пропуск → дописать до модуля 01 |
| Для каждого запрета «кадрированием» есть строка зоны | `test -s promo/remotion/<proj>/forbidden-zones.tsv` | код 0, если способ 3 применён | да |
| Токены — `#rrggbb` со ссылкой на `globals.css:строки` | чтение; шаблон падает на не-hex | — | да |
| Контраст названия к фону ≥ 4,5:1 | формула WCAG по двум hex | ≥ 4,5 | да (N1) |
| Шрифт покрывает кириллицу и «—» | контрольный кадр с «ё» и тире в `stills` (модуль 04 п. 5) | глифы на месте | да |

```bash
miss=0; for c in цены бренды фикстуры незавершённое адреса секреты числа вымышленное; do
  command grep -qE "^[|] *.?$c.? *[|]" promo/remotion/<proj>/SCENARIO.md || { echo "нет класса $c"; miss=1; }
done; [ -s promo/remotion/<proj>/SCENARIO.md ] || miss=2; echo "rc=$miss"   # 2 — файла нет, проверка НЕ выполнена
```
На SCENARIO.md серии 29.09 (без id классов) команда падает: N2 — нет 8 из 8 строк-классов (классы описаны прозой).

Честная разметка: «цены нет в кадре» не доказывается здесь — это модуль 07 (раскадровка готовых mp4, слой 4 с
детерминированной декларацией). Здесь — полнота списка и зоны, которые проверит `gate-config.sh` до рендера.

## Dependencies

- Инвентарь `05_project_inputs.md` (OPTIONAL как вход: нет строки — создать по п. 1).
- Образ `promo-render` (REQUIRED для кадров записи, по которым снимаются координаты зон).

## Reusability

Таблица классов запретов — общая для любого публичного материала о продукте (скриншоты для лендинга, карточки
в соцсети, презентация); файл запретных зон с проверкой видимого окна — для любого кадрирования записи экрана.
