# Модуль 02: инвентарь входов и «нельзя показывать»

Эталоны: [`docs/research/promo-videos/05_project_inputs.md`](../../../../docs/research/promo-videos/05_project_inputs.md)
(инвентарь шести проектов), [`promo/remotion/n2/SCENARIO.md`](../../../../promo/remotion/n2/SCENARIO.md) («нельзя → обход»),
[`promo/remotion/n2/MEASUREMENTS.md`](../../../../promo/remotion/n2/MEASUREMENTS.md) §«Цена в кадре» (доказательство по готовым mp4).

## Input

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `project_dir` | путь | да | README, CLAUDE.md, `apps/*/…/globals.css`, `layout.tsx`, `public/` |
| `stand_url` | URL | да | выданный адрес |
| `inventory_row` | строка таблицы | нет | если есть в `05_project_inputs.md` — сверить, не переписывать |

## Process

1. **Инвентарь** — одна строка в формате `05_project_inputs.md` (поля: фраза, стенд, экраны без входа, сценарий,
   токены, лого, ЦА/канал, «Нельзя»). Каждое значение — со ссылкой `файл:строки`:
   - **Экраны без входа** — из маршрутов (CLAUDE.md, `app/` роуты); экран за входом помечать сразу — он потребует
     фикстуру (модуль 03 §4) или выпадает.
   - **Токены** — `--paper`/`--ink`/`--accent` из `globals.css` темы по умолчанию (`#rrggbb`; шаблон принимает только
     этот вид). Если акцент на фоне продукта не читается — фон ролика берётся из другого токена продукта (N4:
     `--dark #1b1523` как фон, потому что `#ffc531` на `#fbf8f2` не читается) — и это записывается в README.
   - **Шрифт** — продукта, если его файл есть в проекте (TTF + лицензия OFL); системный шрифт продукта → Onest из образа
     (N2, N5). Шрифт через `next/font/google` без локального файла — сначала найти TTF, иначе Onest с записью «фирменный
     шрифт потерян» (N1: Bricolage/DM Sans → Onest, Codex принял как обоснованный fallback).
   - **Адрес стенда** — из квитанции развёртывания; голый IP (`*.sslip.io` с IP, N3) в финал и в адресную строку кадра не идёт.
2. **Список «нельзя показывать»** — закрытый набор классов; каждый класс проверить для проекта и либо назвать способ
   исключения, либо записать «не применимо, потому что …»:

   | Класс | Примеры из серии |
   |---|---|
   | цены, тарифы, оплата | N2 «План: Free — 990 ₽» в кабинете и в герое лендинга; N1/N4 тестовый магазин; N5/N6 оплата off («Pro скоро») |
   | чужие бренды и продукты | скриншоты Senja/NiceJob/Birdeye/Podium/Cal AI/Opus в `docs/discovery/screenshots` — не брать никогда |
   | служебные фикстуры и чужие учётки | N6 демо-бот `/b/pekarnya-kolos-…`, `ui-fixture.json`; N2 «Кофейня Артель» (обращение ушло бы владельцу) |
   | незавершённые фичи | N1 вкладка видео, `/partner`; N2 партнёрка; N3 F3 в HEAD; N4 Telegram Mini App |
   | голые IP и внутренние адреса | N3 `212.192.0.33.sslip.io`; локальный адрес съёмки не в кадре |
   | ключи, `.env`, секреты, личные чаты | `.secrets/`, `.env.n5-demo`, личный Telegram владельца N2 |
   | неверные числа | N4: синонимы стенда вели «яйцо варёное» → Butter, «гречка» → Oats — в кадр только позиция, прошедшая сверку |
   | вымышленные данные без пометки | N1 отзывы, N2 «Пекарня на Речной», гость `anna@example.com` |

3. **Способ исключения — назвать механизм**, по порядку предпочтения:
   1. не снимать (выбор маршрута, `page.route(...).abort()` на запрещённые запросы — N6 `/claim`, `/share`, `/api/auth/*`);
   2. снимать другую раскладку (N2: кабинет 9:16 из mobile, потому что desktop в 9:16 показывается целиком);
   3. кадрирование — **только если посчитано ВИДИМОЕ окно**, а не `crop`: шаблон показывает всё окно, в которое вписан
      `crop` (модуль 04, «crop ≠ маска»). Для каждого куска записать в комментарий конфига диапазон видимых `y`;
   4. CSS-скрытие в браузере записи — слабее всего: не исключает вспышку до применения стилей (Codex §2, N1/N5).
4. **Демонстрационные данные — постоянная плашка** на всё время, пока они в кадре (урок N1: пометка «пример» была только
   последние 2 с сцены 4 — Codex «нет»). До появления поля `footnote` в шаблоне (DEC-S-02) — пометка внутри записи
   (подвал страницы-примера, N1 «Вымышленный сайт для демонстрации виджета · пример») плюс в `SCENARIO.md`.
5. **Доказательство исключения — по ГОТОВЫМ mp4, раскадровкой с шагом**, не «контрольными кадрами»:
   ```bash
   # внутри promo-render, --network none: кадр каждые 0,25 с на интервале сцены, лист 8 колонок
   ffmpeg -nostdin -loglevel error -ss 6 -to 17 -i /out/16x9.mp4 \
     -vf "fps=4,scale=480:-2,tile=8x6" /o/pc-16x9-s2-%d.png
   ```
   Все три формата, все интервалы с риском (кабинет, лендинг, переходы и первые 0,5 с каждой записи). В
   `MEASUREMENTS.md`: интервалы, шаг, число кадров, sha256 проверенного mp4, путь к листам (устойчивый, не scratchpad —
   например `/home/dz-projects-2026/.promo-assets/<proj>/out/final/proof/`). Эталон N2: 228 кадров, шаг 0,25 с;
   Codex всё равно отметил «между кадрами остаются интервалы» и «листы в scratchpad без привязки к хешам» — поэтому
   путь и sha256 обязательны.

## Output

- Строка инвентаря (дополнение `05_project_inputs.md` — через координатора, это общий файл).
- Раздел `SCENARIO.md` «Нельзя показывать → как обойдено» — таблица класс / способ / доказательство.
- Раздел `MEASUREMENTS.md` «Запреты в кадре» — интервалы, шаг, sha256, путь к листам, вывод «слой 4 (просмотр)».

## Quality Gate

| Проверка | Как | Блокирует |
|---|---|---|
| Все 8 классов пройдены, у каждого способ или «не применимо, потому что» | чтение таблицы | да |
| Для классов «цены», «фикстуры», «вымышленные данные» есть раскадровка готовых mp4 с sha256 | `MEASUREMENTS.md` | да |
| Токены — `#rrggbb` со ссылкой на `globals.css:строки` | чтение; шаблон падает на не-hex | да |
| Контраст названия к фону ≥ 4,5:1 | формула WCAG по двум hex (любой калькулятор) | да (N1) |
| Шрифт покрывает кириллицу и «—» | контрольный кадр с «ё» и тире (загрузка шрифта этого не доказывает — Codex §5) | да |

Честная разметка: «цены нет в кадре» — слой 4 (глаз), в образе нет OCR; детерминированно проверяется только
декларация (таблица заполнена, путь и sha256 существуют).

## Dependencies

- Инвентарь `05_project_inputs.md` (OPTIONAL как вход: нет строки — создать по п. 1).
- Образ `promo-render` (REQUIRED для раскадровки).

## Reusability

Таблица классов запретов — общая для любого публичного материала о продукте (скриншоты для лендинга, карточки
в соцсети, презентация): способы 1–4 и доказательство по итоговому файлу переносятся без изменений.
