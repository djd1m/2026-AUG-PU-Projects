# promo-video — промо-ролик под наши проекты

## Назначение

Сделать для продукта из `projects/*` короткий ролик из **живых экранов стенда**, воспроизводимый одной командой
и честный: титр не обещает того, чего нет в кадре; в кадре нет цен, чужих брендов, служебных фикстур и выдуманных
данных без пометки. Инструмент выбран и не пересматривается навыком: **Remotion 4.0.529** на общем шаблоне
[`promo/remotion/shared/`](../../../promo/remotion/shared/README.md) (выбор — [`promo/RESULT.md`](../../../promo/RESULT.md),
[`docs/research/promo-videos/04_decision.md`](../../../docs/research/promo-videos/04_decision.md)).

## Входы

| Вход | Откуда | Обязателен |
|---|---|---|
| Проект `projects/<NN-slug>/` | README «простыми словами», CLAUDE.md (маршруты), `globals.css` (токены), шрифт | да |
| Выданный адрес стенда | квитанция развёртывания / README проекта | да (без него — только сцены-заголовки, ролик не делается) |
| Строка проекта в инвентаре | [`05_project_inputs.md`](../../../docs/research/promo-videos/05_project_inputs.md) — экраны без входа, «Нельзя» | да; нет строки — модуль 02 её создаёт |
| Решения владельца | стиль, адрес в финале, музыка (по умолчанию нет), лимит платных вызовов | да, спросить до модуля 03 |
| Образ `promo-render:2026-09-29` | [`promo/render-image/`](../../../promo/render-image/README.md) | да для модулей 03–05 |

## Роли

| Роль | Кто | Что делает | Чего не делает |
|---|---|---|---|
| **Координатор** | Claude (основной сеанс) | модуль 01 (каркас), выдаёт постановку, держит журнал серии, решает спорное по правилам, собирает страницу владельцу, зовёт Codex | не пишет в worktree исполнителя; не правит продукт |
| **Исполнитель, часть A** | агент Claude в своём worktree | модули 02–03: инвентарь, сценарий, запись экранов, квитанция записи | не монтирует; не правит шаблон и продукт |
| **Исполнитель, часть B** | тот же агент после сигнала «шаблон готов» | модули 04–05: конфиг, рендер, замеры, квитанции | не переснимает записи без решения координатора |
| **Проверяющий** | Codex (другое семейство, read-only) | модуль 06 §6: титры ↔ кадр, запреты, единообразие, замеры, шаблон, вердикт | не рендерит; его «нет» не отменяется исполнителем |
| **Владелец** | человек | стиль, адрес, музыка, лицензия Remotion, учётки, публикация | — |

Один исполнитель на проект: у ролика одна пара «записи ↔ конфиг», делить её между агентами — два писателя в одном файле.

| Фаза | Зависимость | Путь / как проверить | Required | Зачем |

| 03–05 | образ `promo-render:2026-09-29` | `bash promo/render-image/check.sh` → `0` | REQUIRED | ffmpeg/ffprobe, Onest, Chromium, Node 24 для рендера и раскадровки |
| 03 | Playwright 1.60.0 | образ `mcr.microsoft.com/playwright:v1.60.0-noble` + `playwright@1.60.0` с lockfile в `promo/capture/<proj>/` | REQUIRED | запись экранов |
| 04 | Remotion 4.0.529 | `promo/remotion/package-lock.json` (общий) | REQUIRED | сборка и рендер |
| 06 | Codex CLI | `node "<codex-plugin>/scripts/codex-companion.mjs" setup --json` → `"ready": true` | OPTIONAL | независимая проверка другим семейством |

**Fallbacks:**
- `frontend-design` нет → держаться раскладки шаблона как есть (она фиксирована) и токенов продукта; в отчёт — «вкус не проверялся».
- `brutal-honesty-review` нет → самопроверка по чек-листу ниже, пункт за пунктом, с ответом в `SCENARIO.md`.
- `promo-render` нет или `check.sh` ≠ 0 → **остановиться** (`render.sh` сам отдаст код 2): собрать образ `bash promo/render-image/build.sh`
  только с разрешения владельца (диск: образ 3,46 ГБ, [`render-image/README.md`](../../../promo/render-image/README.md)); рендер на хосте запрещён.
- Playwright-образа нет → запись НЕ выполнена (код 2 в README записи с причиной); сцены-заголовки без экранов роликом не считаются.
- Codex не готов → проверка вторым семейством НЕ выполнена: так и записать в итог; заменить её Claude-ревью можно только
  с пометкой «одно семейство», вердикт «готово к публикации» тогда не выносится ([`codex-invocation-local.md`](../../rules/codex-invocation-local.md)).

## Критерий готовности (из [`promo/SERIES.md`](../../../promo/SERIES.md) + правки после вердикта Codex)

1. Три mp4 — `ffprobe`: 45,000000 с, 1350 кадров, `yuv420p`, tv/bt709, 30/1, H.264 High; повтор 16:9 побайтно совпал (`REPRO=1`).
2. `SCENARIO.md` — титры сцен для правки владельцем + раздел «что титры НЕ обещают» + таблица «нельзя → как обойдено».
3. `README.md` — одна команда повтора, адреса и тайминги записей, отклонения от сценария.
4. `MEASUREMENTS.md` — сборка и рендер отдельно, `memory.peak`, `host_load1`, sha256 всех mp4 **и** конфига; проверка запретов по
   раскадровке ГОТОВЫХ mp4 с шагом (не «контрольные кадры»).
5. `ITERATIONS.md` — каждая попытка с категорией инструмент / среда / исполнитель; части A и B одним итогом; платные вызовы.
6. Ни одного титра без кадра-доказательства; демонстрационные данные помечены постоянно, пока они в кадре.
7. Бюджет исполнителя — 120 мин активной работы, ≤ 8 попыток с правками; превышение — остановиться и отчитаться.

## Чек-лист самопроверки (перед сдачей координатору)

- [ ] Каждый титр: назван кадр (файл записи + секунды), где сказанное ВИДНО. «Гость сканирует QR» без сканирования в кадре — дефект (N2).
- [ ] Каждая строка титра ≤ 45 знаков, не больше двух строк; первый титр — одна мысль, не три блока (N4).
- [ ] Финал: имя продукта + адрес, подтверждённый владельцем; контраст названия к фону ≥ 4,5:1 (N1 был ≈ 1,9:1).
- [ ] Список «нельзя показывать» пройден построчно; для каждой строки — способ и доказательство по готовым mp4.
- [ ] Вымышленные данные помечены весь показ, а не последние 2 с (N1).
- [ ] Числа в кадре здравые (N4: синоним «яйцо варёное» → Butter; снимали только позицию, прошедшую сверку).
- [ ] Платные вызовы посчитаны по ЗАПРОСАМ к провайдеру, не по действиям в UI (N5, N6); остаток лимита записан.
- [ ] README ↔ конфиг не противоречат по таймингам и кадрированию; спор решается журналом `record-log-*.json` (N6, N2).
- [ ] `probe.sh`/`render.sh` испытаны на падение (мутация → 1, восстановление → 0, тот же sha256).
- [ ] Остановлено только своё: контейнеры `promo-<proj>-*`, никаких `pkill -f`.
- [ ] Фикстура-учётка не удалена; `.fixture.env` — 600; в git — ни одного `.env`, пароля, `.state-*.json`.

## Известные ограничения навыка

- Проверен на пяти проектах одной машины (VPS 8 vCPU / 11 ГБ, без GPU); перенос на другую машину — пересчитать лимит CPU под её сторожа.
- «Проверка запретов по раскадровке» — слой 4 (глаз): в образе нет OCR, детерминированного «цены нет» не существует.
- Правки шаблона из вердикта Codex (раздел 5) на 29.09 **не внесены** — перечислены в модуле 04, §«Известные ограничения шаблона».
- Музыка и озвучка — вне навыка (решение владельца); лицензия Remotion при команде от 4 человек — открытый вопрос владельцу.
