# Project work companion

For project-work preparation, readiness, pause/resume, delivery evidence, or
telemetry diagnosis, read
[project-work-companion](../skills/project-work-companion/SKILL.md).

Run the repository complexity ROUTE before PLAN and repeat the substantive ROUTE
before IMPLEMENT. Run the companion's read-only readiness preflight immediately
before actual E2E, not as a universal precondition for implementation; docs-only
or not-yet-E2E work records an explicit `not_applicable` reason. A mechanical result
is a lower bound; preserve the calling command's stricter requirements,
approval/checkpoint contracts, and telemetry ownership. Product artifacts and
evidence stay in the selected project. This local adapter does not authorize
external actions or replace vendor workflows.
