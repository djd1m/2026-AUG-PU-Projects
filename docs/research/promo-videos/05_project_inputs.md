## Общее

- Ни в одном проекте не записан канал показа именно для промо. Есть упоминания каналов роста: N1 — Product Hunt
  (PRD S1); N4 — Telegram, VK Клипы, YouTube, Дзен (`product-discovery-brief:13`); N6 — Telegram-канал маркетолога
  (`brief:55,154`).
- Файла логотипа нет ни у кого, кроме N1 (иконки). OG-картинок нет. У N4 есть динамическая карточка 9:16
  (`app/c/[cardId]/image/route.ts`).
- Скриншоты в `docs/discovery/screenshots` у всех проектов сняты с **чужих** продуктов (Senja, NiceJob, Birdeye,
  Podium, Rewardful, Cal AI, Opus) — в ролик не брать.
- Каталог `03a-affiliate-rewardful` — не цель; цель — `03-affiliate-rewardful`.

## Следствия для выбора инструмента

1. Живые экраны есть у всех шести без входа — ось B (живой интерфейс в кадре) решающая, скринкаст через Playwright
   реален для каждого.
2. Логотипов почти нет → ролики строятся на типографике и токенах (ось G): у каждого проекта свои цвета и шрифт
   (Bricolage/DM Sans, системный, Rubik, Unbounded/Onest, system-ui, Onest).
3. Каналы показа не записаны → вопрос владельцу: 16:9 для лендинга/YouTube и 9:16 для Telegram/VK Клипов —
   инструмент обязан давать оба формата из одного исходника.
4. Ограничения съёмки: не создавать нагрузку на платные вызовы (N4, N6), не показывать оплату (N1/N4 тест, N5/N6
   off), не показывать чужие бренды и голые IP (N3), не выдавать демо-данные за настоящие.
