# «Не-код» сервисы (для контраста): Canva, Descript, HeyGen, Runway, Veo/Vidu

Проверено: 2026-09-29. **Выбывают по классу продукта; цены и возможности API не проверялись** (круг 2). Для Canva и
Descript прямых источников нет. Оговорка: у части сервисов есть API, и вызов API можно хранить в коде. Но рендер
остаётся облачным (ось C = 0 по определению), а результат генеративных моделей не детерминирован — поэтому класс
выбывает независимо от наличия API.

| Сервис | Класс | Почему выбывает |
|---|---|---|
| Canva (canva.com) | GUI-редактор шаблонов | **A=0**: ролик живёт в облачном редакторе, не в git; правка = ручные клики. **C=0**: рендер в облаке. |
| Descript (descript.com) | монтаж по транскрипту, GUI | **A=0**, **C=0**; сильный в монтаже говорящей головы, не в показе веб-интерфейса. |
| HeyGen (heygen.com) | ИИ-аватары и озвучка, облако | **A=0**/**C=0** как редактор. Та же компания делает HyperFrames — её облачные голоса доступны из HyperFrames опционально. [1] |
| Runway / Google Veo / Vidu (ShengShu) | генерация футажа моделью | **C=0** (только облако/GPU), **A≈0** (результат недетерминирован); интерфейс продукта модель не покажет — нарисует похожий. [2][3] |

**Вывод.** Все выбывают по A и/или C (условия задачи, а не пожелания). Опционально могут дать **материал** (голос,
фоновый футаж) для кодового движка — это ось I; для промо реальных интерфейсов риск «пластикового» вида высокий.
