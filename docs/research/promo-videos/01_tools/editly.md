# Editly

Проверено: 2026-09-29. Всё без ссылки — «не проверено».

**Что это.** «Slick, declarative command line video editing & API»: ролик описывается JSON5-спекой (клипы → слои),
Node + FFmpeg склеивают видео, изображения, титры, переходы, музыку. Автор — Mikael Finstad (`mifi`). [1]

**Версия.** Стабильная npm `latest` **0.14.2 от 2022-12-23**; `next` 0.15.0-rc.1 от 2025-01-19. Последний push
2025-05-12. ≈5,5 тыс. звёзд. Фактически в режиме минимальной поддержки. [2][3]

**Лицензия и цена.** MIT, бесплатно. [1][3]

**Движок и требования.** Node, FFmpeg/FFprobe в PATH; слои `gl` требуют headless-gl, на Linux без графики известны
сбои инициализации GL. ESM-only. GPU не нужен, но GL-переходы — риск в контейнере. [1]

**Живой интерфейс.** Только готовые видео/изображения (записи и скриншоты Playwright). Слои `canvas`/`fabric` —
рисование кодом, не DOM. [1]

**Русский TTS/субтитры.** TTS нет. Слои `title`/`subtitle` с текстом есть; автоматических субтитров нет. Микс
аудио, ducking, нормализация — есть. [1]

**Форматы.** `width/height` в спеке; три формата — три спеки (или генерация спеки скриптом).

**Агентопригодность.** JSON-спека проста для LLM; но мало примеров анимации и типографики, нет навыков для агентов.

**Минимальный пример (из README [1]).**

```json5
{
  outPath: 'output.mp4',
  width: 1920, height: 1080, fps: 30,
  clips: [
    { duration: 4, layers: [{ type: 'video', path: 'clip.mp4' }] },
  ],
  audioFilePath: 'music.mp3',
}
```

**Воспроизводимость (круг 2).** Умолчания случайны: `defaults.transition.name` = `random`, цвета заливок и
градиентов — «default: randomize». JSON в git сам по себе не даёт того же ролика: переходы, цвета и эффекты нужно
фиксировать явно. [1] Что переходы реализованы на GL (gl-transitions) и headless-gl нужен уже в базовом сценарии —
не проверено.

**Ограничения.** Стабильный релиз 2022 года; бедная типографика и моушн; хрупкий headless-gl; случайные умолчания.
