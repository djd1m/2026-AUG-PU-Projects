# Motion Canvas

Проверено: 2026-09-29. Всё без ссылки — «не проверено».

**Что это.** TypeScript-библиотека анимаций на Canvas с генераторами (`yield*`) и редактором в браузере для
предпросмотра. Ориентирована на объясняющие ролики с голосом. Сообщество, репозиторий `motion-canvas/motion-canvas`
с 2022-08. [1][2]

**Версия.** `@motion-canvas/core` **3.17.2** от 2024-12-14 — последний релиз; последний push в репозиторий
2026-07-02. ≈19,2 тыс. звёзд. Новых релизов почти два года. [2][3]

**Лицензия и цена.** MIT, бесплатно. [2][3]

**Движок и требования.** Рендер запускается **кнопкой RENDER в редакторе** в браузере: кадры сохраняются как
PNG/JPEG/WebP-последовательность, видео собирается FFmpeg отдельно (или плагином). Официального headless/CLI-рендера
на странице Rendering не описан (круг 2: это не доказывает его отсутствие во всём продукте — не проверено). Если
его нет, на VPS без дисплея придётся автоматизировать редактор через Playwright — обходной путь, не проверено. [4]

**Живой интерфейс.** Сцены рисуются на Canvas; экраны продукта — как изображения или видео-клипы (записи
Playwright). Способ встроить DOM/React-компоненты не найден — не проверено (страница Rendering этого не касается). [1]

**Русский TTS/субтитры.** Аудиодорожка подключается файлом («set up audio» в документации). [4] Встроенный TTS и
готовый путь к субтитрам по времени **не найдены — не проверено**: страница Rendering не каталог возможностей.
Внешний Piper/Whisper доступен так же, как всем.

**Форматы.** Размер задаётся в настройках проекта; несколько форматов — несколько проектов/настроек (не проверено).

**Агентопригодность.** Типизированный TS-API, документация есть; официальных навыков для агентов не найдено.

**Минимальный пример (стиль документации).**

```tsx
import {makeScene2D, Txt} from '@motion-canvas/2d';
import {createRef} from '@motion-canvas/core';

export default makeScene2D(function* (view) {
  const title = createRef<Txt>();
  view.add(<Txt ref={title} text="Тарелка" fill="#fff" fontSize={120} opacity={0} />);
  yield* title().opacity(1, 0.6);
  yield* title().scale(1.2, 0.4);
});
```

**Ограничения.** Headless-рендер в просмотренной документации не найден; редкие релизы; путь встраивания DOM не найден.
