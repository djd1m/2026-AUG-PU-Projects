## Измеренный результат

- Единственная мутация: exact-ID BuildKit prune, immutable/private/type=regular/until=24h, без all и broadpolicy.
- Удалено **14 из 26** разрешённых cache records; **12** оставлены BuildKit. Причина каждого пропуска CLI не раскрыта; повторных prune и расширения набора не было.
- Docker сообщил logical reclaimed **3.587GB**; реальная прибавка доступного места по statvfs **2,896,752,640 байт ≈ 2.90 GB (2.70 GiB)**.
- До: 1,079,144,448 байт; после: **3,975,897,088 байт ≈ 3.98 GB (3.70 GiB)**. Разность включает конкурентные записи других процессов; logical bytes могут пересекаться со слоями образов.
- Исчезнувшие ID точно совпали с отчётом prune и входят в разрешённые 26.
- Сохранены все **140 rows образов/тегов**, **57 контейнеров** с прежними start/restart/running/health состояниями, **70 томов** и **29 сетей**. Браузер сохранил состояние. Env, секреты и полные inspectconfigs не читались.
- Все семь обязательных postchecks: **PASS**. Heavylock удерживался от preflight до проверки; N8/coursepromo получили сообщение release.
