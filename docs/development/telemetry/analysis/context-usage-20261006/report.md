# Анализ расхода контекста — 2026-10-06

Окно 1М само по себе не означает отправку 1М токенов в каждом запросе. В локальной выборке связь с ростом недельного расхода **не установлена**: все выбранные usage-события сообщают окно 258400, максимум входа одного запроса — 236692 токена. Нет датированного изменения на 1М и сопоставимых недельных данных до/после.

Отдельный read-only исполнитель `gpt-6.1-sol/high` проверил метаданные локальных сессий. Итоговая выборка: восемь неизменных файлов за 3–6 октября, 3199 наблюдений запросов после удаления 181 повторного снимка. Медианный вход — 114509 токенов; cached/input — 97,93%. Это выбранная, нерепрезентативная выборка; возможное включение дочерних расходов в родительские исключает суммирование в общий счёт. Полный обезличенный результат: [auditor-report.md](auditor-report.md).

Наблюдаемые факторы нагрузки: длинные истории, многочисленные запросы, Astra/high и повторные попытки. В N7 зафиксировано 55 попыток, включая 18 неудачных; это записи процесса, а не биллинговые запросы. У N7 нет числовых полных usage/cost в журнале, поэтому точный вклад проекта и процент экономии неизвестны.

Официальная документация связывает расход Codex с моделью, сложностью, контекстом, reasoning, инструментами и кэшированием. API-тарифы нельзя напрямую переводить в недельный лимит подписки: [Codex pricing](https://learn.chatgpt.com/docs/pricing). Текущая опубликованная стоимость кредитов Astra выше Sol; это не измерение расхода нашего аккаунта.

Применяем компактные передачи между стадиями, ограниченные чтения файлов/логов и сохранение больших доказательств на диске. Ревью получает только нормативный пакет планировщика и замороженный код, без истории автора. Не меняем глобальное окно или пороги compaction. Более раннюю compaction следует оценивать отдельно: изменение префикса может уменьшить повторное использование кэша ([Prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching)). Обязательные проверки и критерии приёмки сохраняются.

Ограничения измерения: фактическая конфигурация основного хоста, полный недельный биллинг и момент изменения окна неизвестны. Максимальная поддерживаемая ёмкость модели отличается от фактически переданного входа ([Model documentation](https://developers.openai.com/api/docs/models/gpt-6.1-sol)).
