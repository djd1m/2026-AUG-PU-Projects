## Модели, длительность и расход

Профиль `compact-quality-first-v2`, содержательный тир M при механическом S.
ROUTE — requested Terra medium; PLAN — Astra high; IMPLEMENT и исправления —
Sol high; независимые semantic/review/recheck — Astra high. CLI объявлял
запрошенные модели; response-level actual не подтверждён. Это разные поколения
одного поставщика, не vendor separation.

По UTC-границам [паспорта](run.json) elapsed — **209.7 мин**, включая паузы и
координацию; активное время неизвестно. Это не прогноз похожей задачи.
Времена стадий — наблюдения координатора, возможна задержка регистрации;
они не доказывают latency модели. Частичный CLI usage сохранён в
`*-host-usage.json`. Полный расход, стоимость и недельный остаток неизвестны.
Размер многократно повторяемых diff в CLI не использовался как счётчик токенов.
Экономия не установлена.

## Diagnose и постоянный урок

[Извлечение текущей телеметрии](diagnose-extraction.json) обнаружило неполный
интервал `implement-launch-1`: неуспешная инициализация CLI не получила запись
начала. Поэтому analyzer вернул exit 2. Это раскрытый пробел измерения, не
провал приёмки навыка; неизвестное время не восстановлено по памяти.

| Наблюдение | Вывод и действие | Проверка эффекта |
|---|---|---|
| Небольшое дополнение выросло в объёмный валидатор и несколько проходов | Координатор недостаточно ограничил объём и время исполнителей. Владелец подтвердил неприемлемую задержку. | Бюджет попытки и время до первого проверяемого результата на следующей сопоставимой задаче. |
| После зелёных тестов продолжались уточнения, инструкции перечитывались | Ограничить корректирующий проход конкретными находками и точным контекстом. | Число проходов и время до приёмки при сохранении качества. |
| CLI -o перезаписал первый подробный receipt кратким итогом | Следующие вызовы сохраняют сам финальный terminal receipt без двойной записи. | Доля корректных receipts с первой попытки. |
| Независимое ревью нашло два дефекта при зелёных тестах | Сохранить независимую проверку и повторять её по затронутым инвариантам. | Пропущенные дефекты; без обещаний предотвращённых инцидентов или сэкономленных часов. |

По прямому запросу владельца урок сохранён в
[постоянной памяти AGENTS.md](../../../../AGENTS.md#память-ограничивать-объём-и-длительность-работы).
Это инструкции будущим сессиям, не автоматический таймер. Одной сменой модели
текущего чата организационную причину задержки устранить нельзя.
