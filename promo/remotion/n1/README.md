## Решения по оформлению

- **Токены** (`apps/web/src/app/globals.css`): фон `--ink #1e0a3c`, текст белый (`--surface #ffffff`), акцент
  `--accent #6701ef` (полоса титра). Контраст акцента к фону 2,43 : 1 — поэтому название в финале с круга правок 1
  набрано `--accent-tint #eee0ff` (`titleColor`, 14,38 : 1).
- **Шрифт — Onest, а не Bricolage Grotesque + DM Sans.** У продукта оба шрифта подключены `next/font/google` с
  `subsets: ['latin', 'latin-ext']`; в CSS стенда (`.next/static/css/*.css`) `unicode-range` ни одного `@font-face` не
  включает U+0400–04FF — кириллицы в них нет, русский текст на самом стенде рисуется запасным шрифтом. Титры ролика
  русские, поэтому шрифт продукта их не отрисует; взят Onest образа, как у остальных проектов серии.
- **Иконка `brand/icon.svg`** в финал не вставлена: шаблон не поддерживает логотип (финал = название, подзаголовок, адрес).
- **Пометка «Отзывы демонстрационные»** (круг правок 1): поле шаблона `footnote` на пяти сценах с отзывами, на всю
  сцену, все форматы. С круга правок 2 — строкой в полосе титра у края кадра, запись не перекрывает; интервал с
  вымышленными отзывами — `demo-intervals.tsv` (9,5–39 с), проверка — `gate-verdict.sh` навыка `promo-video`.
- **Метка тарифа «Бесплатный» не в кадре** (круг правок 2): бейдж у названия проекта в кабинете исключён кадрированием
  (`forbidden-zones.tsv`, проверка — `gate-config.sh`); 9:16 — кусок `links-mobile` после прокрутки.
- **9:16, тег `<script>` целиком (круг правок 2D):** `snippet-mobile` снят заново — поле кода плавно прокручивается по
  горизонтали до `data-slug="primer-coffee" async></script>`; продукт не менялся (`promo/capture/n1/README.md`).
- **Сцена 1 — запись, а не заставка**: по `SCENARIO.md` боль показана пустой стеной `wall-empty-*` с титром.
