# N1 «Proofwall» — сценарий ролика 45 с (текст титров для правки владельцем)

Каркас серии (`promo/SERIES.md`): боль → шаг 1 → шаг 2 / результат → распространение → финал. Без голоса,
без музыки. Шрифты продукта: Bricolage Grotesque (заголовки) + DM Sans (текст) — `apps/web/src/app/layout.tsx`.
Токены (`apps/web/src/app/globals.css:13–35`): фон `--ink #1e0a3c`, акцент `--accent #6701ef`, подложка
`--accent-tint #eee0ff`, поверхность `--surface #ffffff`. Иконка — `apps/web/public/brand/icon.svg`.

Источник смысла — README «Простыми словами»: ссылка довольному клиенту → отзыв без регистрации → вы решаете, что
показывать → стена и блок на ваш сайт одной строкой. Записи — `/home/dz-projects-2026/.promo-assets/n1/`, тайминги
внутри файлов — `promo/capture/n1/README.md`.

**Честность кадра.** Кофейня «Пример» (`primer-coffee`) и все пять отзывов — вымышленные примеры, созданные для
ролика учёткой-фикстурой. На всех сценах, где видны отзывы (форма, модерация, стена, блок кода, сайт кофейни — 9,5–38,5 с
ролика), постоянная сноска «Отзывы демонстрационные» (поле шаблона `footnote`). С круга правок 2 она стоит строкой ВНУТРИ
полосы титра у внешнего края кадра (9:16 и 1:1 — справа вверху, 16:9 — справа внизу) и не перекрывает запись: прежняя
плашка над записью закрывала часть кнопки «Отправить отзыв» в 9:16 и 1:1 (находка Codex №4 второго круга).

## Чего титры НЕ обещают (и почему)

- **Видео-отзывы** — не упоминаются: приём видео на стенде выключен, вкладки «Записать видео» в кадре нет.
- **«Бесплатно» / тарифы / снятие знака оплатой** — не упоминаются: оплата — тестовый магазин (инвентарь, «Нельзя»).
  Блок «Тариф» в записи кабинета скрыт стилем записи (см. `promo/capture/n1/README.md`).
- **«Виджет проверен на чужом сайте»** — не утверждается: сцена 4 показывает виджет на странице, поднятой ВНУТРИ
  контейнера записи (`http://127.0.0.1:8099`), это другой origin, но не настоящий сайт клиента. Титр говорит о том,
  что видно: строка кода → отзывы на странице.
- **«Импорт с площадок»** — не упоминается: его нет в продукте.

## Сборка на шаблоне (часть B) — чем кадр отличается от таблицы выше

Тексты титров — в `project.config.ts`; при правке менять там. Титры сцен 2–3 разбиты на две строки-фазы:
«Отправьте клиенту одну ссылку.» → «Отзыв за минуту — без регистрации.»; «На стену попадает только то, что вы
одобрили.» → «Нажали «Опубликовать» — отзыв уже на стене.»; сцена 1 — одной строкой «Клиенты вас хвалят. А показать
на сайте нечего.»

- **Круг правок 2.** Сноска перенесена в полосу титра (см. выше), кнопка «Отправить отзыв» и заголовок формы открыты во
  всех трёх форматах (контрольные кадры и раскадровка — `MEASUREMENTS.md`). Бейдж тарифа «Бесплатный» у названия
  проекта убран из кадра сцены 2: 16:9 и 1:1 — окно ниже бейджа и заголовка проекта (`forbidden-zones.tsv`), 9:16 — кусок `links-mobile`
  3,0–5,5 с (страница уже прокручена) вместо 0,8–4,5 с. Метка тарифа — класс «нельзя показывать» (модуль 07 навыка).
- **Пометка постоянная (круг правок 1).** Плашка «Отзывы демонстрационные» стоит на всей длительности каждой сцены с
  отзывами во всех трёх форматах; прежний титр последних 2 с сцены 4 снят — там теперь «Одна строка кода — и отзывы на
  вашем сайте.» до конца сцены.
- **Название в финале — `#eee0ff`** (`--accent-tint` продукта, 14,38 : 1 к фону) вместо акцента `#6701ef` (2,43 : 1).
- **Финал без иконки и не Bricolage Grotesque.** Шаблон не выводит логотип; шрифт всего ролика — Onest, потому что
  Bricolage Grotesque и DM Sans продукта подключены без кириллицы (subsets latin/latin-ext). Подзаголовок финала:
  «Отзывы клиентов — на стене и на вашем сайте.»
- **Кнопка «Choose File / No file chosen»** (headless Chromium) видна в сцене 2 до прикрепления фото — ≈ 1 с ролика.
- **В 9:16 отзыв отправляет Олег Т., в 16:9 и 1:1 — Марина С.** (разные отправки формы в записях mobile и desktop).
- **1:1, конец сцены 4 (круг правок 1):** кадрирование как в 16:9 — карточки виджета целиком, текст отзывов мелкий.
- **9:16, сцена 4:** тег `<script>` уходит за правый край блока кода — так в mobile-записи; исправить — нужна пересъёмка.
