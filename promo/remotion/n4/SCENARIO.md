# Сценарий ролика N4 «Тарелка» — 45 с

Каркас серии (`promo/SERIES.md`): боль → шаг 1 → шаг 2 / результат → распространение → финал. Без голоса и музыки,
титры по-русски шрифтами продукта (заголовок Unbounded, строка Onest), токены `apps/web/app/globals.css`:
`--paper #fbf8f2`, `--ink #17121c`, `--accent #ffc531`, `--dark #1b1523`, `--ok #1f7a48`.
Главная раскладка — mobile (продукт — PWA на телефоне); desktop — запасной материал для 16:9.
Записи — `promo/capture/n4/README.md`, файлы в `/home/dz-projects-2026/.promo-assets/n4/`.

Текст титров — из README проекта, раздел «Простыми словами». Правило: титр не обещает того, чего нет в кадре.

## Оговорки для монтажа

- Сцена 4: на снятой карточке бейдж — плашка «Тарелка» с логотипом, а не текст «распознано в Тарелке»,
  поэтому титр его дословно не обещает. Картинка карточки целиком — `card-image.jpg` (1080×1920).
- Сцена 3: титр «Ошиблась порция — поправьте» ставится только на отрезок, где в кадре нажатие «плюс 50 г» и
  изменение плиток. После правки появляется плашка расхождения «Оценка по фото: 104 · Из базы: 130» — честно,
  но не задерживать. Строка степпера на телефоне обрезана («прим…») — дефект вёрстки продукта, кадр короткий.
- Запасной материал: `diary-mobile.webm` («в дневник» → итог дня и стрик) — если сцена 3 короче 13 с.
- Не показывать: `/pro`, оплату, кабинет партнёра, ссылки `/r/…`, вход (в записи эти адреса заблокированы).
  Верхняя строка главного экрана содержит ссылку «кабинет» — это надпись навигации, не экран кабинета.
- Фото в кадре — свободное CC0 (Wikimedia Commons, «Red apple on a plate», автор Fructibus), источник и лицензия — в
  `promo/capture/n4/README.md`.
