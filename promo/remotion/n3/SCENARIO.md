# Сценарий ролика N3 «Круг» — 45 с, 5 сцен, вариант A «кабинет владельца»

Для правки владельцем. **Решение владельца 29.09:** ролик только по одному, самому зрелому варианту — A (разбор зрелости:
14/15 против 11 у C; вариант A — единственный, где цикл «правила → реестр → утверждение → отметка выплаты» закрыт без
кнопок лаборатории). Интерфейсы B, C, D в ролик не входят.

Источник смысла — `projects/03-affiliate-rewardful/README.md` («Простыми словами»), экраны — интерфейс A по выданному
адресу **`https://reward.aicoding.space/`** (ADR-003, выкладка `bridge-901f0a6` 29.09 ~18:55 UTC). Запись — один
непрерывный файл на раскладку (`a-tour-desktop.webm`, `a-tour-mobile.webm`) и один демосеанс на раскладку
(`promo/capture/n3/README.md`).

Токены (`projects/03-affiliate-rewardful/shared/ui/style.css:3`): фон `--pale #f0f8ff`, текст `--ink #353e44`, акцент
`--blue #0087ee`. Шрифт — **Rubik** продукта (`shared/ui/rubik-{regular,bold}.ttf` + `OFL.txt`; 600 нет — берётся bold).
Контраст: `--blue` к `--pale` 3,43 : 1 (< 4,5 — название финала им не красится), `--ink` к `--pale` 10,18 : 1 →
`titleColor = #353e44`. Без голоса и музыки.

**Все данные в кадре синтетические** (демо-seed стенда: партнёры Анна и Илья, оплаты за август 2026). Сцены 1–4 несут
постоянную сноску шаблона `footnote: «Данные демонстрационные»` во всех трёх форматах.

## Как смонтировано

- 16:9 и 1:1 — desktop-запись с `crop` ниже служебной полосы «Лаборатория Круг» (окна — `config-inspect.tsv`, зоны —
  `forbidden-zones.tsv`); 9:16 — mobile-запись целиком, куски взяты после прокрутки полос за край.
- Сцена 3 — 4 куска одной записи (подготовка, утверждение, форма, сохранение): набор текста поручения (56–62 с desktop)
  вырезан стыком внутри одного файла, без затемнения.
- Сноска «Данные демонстрационные» — поле `footnote` шаблона на сценах 2–4 (6–39 с), во всех трёх форматах.
- Экран «Обзор» записан (0–14 с), но в ролик не вошёл: сцена 1 — типографская по каркасу серии.

## Что титры НЕ обещают (и почему)

- **Оплата клиента не показывается как действие.** Событие оплаты в демо создают только кнопки лаборатории — их показывать
  нельзя. Титры говорят о правилах, реестре и приглашении — о том, что делает владелец и что видно в кадре.
- **«Перевод» — не банковский.** В кадре отметка оператора; продукт сам пишет «Не подтверждает зачисление в банке». Титр —
  «отметьте ручной перевод», не «платите».
- **«Одной кнопкой»** — это кнопка «Подготовить реестр» в кадре; утверждение и отметка — отдельные шаги, титр второго
  куска их называет.
- **Приглашение — предпросмотр текущего демосеанса** (так пишет сам экран): титр не говорит, что партнёр уже вступил.
- **Не показываются:** «Тариф» (цены), CSV-выгрузка, кнопки лаборатории, служебные полосы стенда, вход `/account` (F3).
