45 с, без голоса и музыки, 16:9 + 9:16 + 1:1 из одного конфига. Сценарий и «нельзя → обход» — [`SCENARIO.md`](SCENARIO.md),
записи — [`../../capture/n3/README.md`](../../capture/n3/README.md), замеры — [`MEASUREMENTS.md`](MEASUREMENTS.md),

## Воспроизвести одной командой

```bash
REPRO=1 bash promo/remotion/shared/render.sh n3     # три формата + повтор 16:9 со сверкой sha256
```

Результат: `/home/dz-projects-2026/.promo-assets/n3/out/final/{16x9,9x16,1x1}.mp4`, квитанция — `logs/receipt.txt`;
опубликованные копии — `promo/dist/n3/`. Записи (вне git) — `/home/dz-projects-2026/.promo-assets/n3/a-tour-{desktop,mobile}.webm`.

## Как исключены запреты (кратко; полностью — SCENARIO.md)

- Служебные полосы стенда (вход F3, «Лаборатория Круг · Новый сеанс») — окна `crop` ниже них в 16:9/1:1; в 9:16 куски
  mobile выбраны после прокрутки полос за край; обе меры проверяет `gate-config.sh` по `forbidden-zones.tsv`.
- «Тариф», CSV, кнопки лаборатории, `/account` — не открывались и не нажимались (журналы записи).
- Адрес — только домен `reward.aicoding.space` (сторож кадра `address_visible` пуст; в финале — адрес из ADR-003).
- Синтетические данные — сноска шаблона на сценах 2–4 во всех форматах.

## Отклонения от сценария

- Экран «Обзор» записан, но в ролик не вошёл (сцена 1 — типографская по каркасу).
- Mobile-куски сцен 2 и 4 замедлены (×0,63 и ×0,58), потому что после круга правок 1 их концы укорочены до начала
  прокрутки к служебным полосам.
- Desktop-доказательство отметки — строка «Отправлено вручную» (блок «Отмечено оператором» у нижнего края записи);
  mobile показывает блок целиком.
