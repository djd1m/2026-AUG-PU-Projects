## Кадрирование (пиксели исходной записи desktop 1920×1080)

- **2а:** 16:9 — карточка формы целиком (x 360–1560, y 110–630); 1:1 — правая половина формы: файл, галочки, кнопка.
- **2б:** 16:9 — заголовок выпуска, блок хода, «Ваши клипы» (y 180–740); 1:1 — левая часть (шаги и подпись хода).
- **3:** сначала сетка трёх карточек 90 / 88 / 86 с меткой `clipmkr.ru/c/…`; последний кусок — зум на низ первой карточки
  (оценка 90 из 99, строка «Цепкость · Самодостаточность · Длина», начало раскрытого объяснения). **Раскрытое
  объяснение на desktop уходит за нижний край записи** — 16:9 и 1:1 показывают только его начало («Цепкость · 29/33» и
  текст), все три строки целиком — только 9:16 (mobile).
- **4:** сначала метки и кнопки трёх карточек со строкой «Ссылка скопирована»; затем страница клипа `/c/ECY8LH`
  (заголовок, «Сделать свои клипы», кадр клипа с меткой).
- **9:16** — записи целиком (правило серии), `allowTallCrop` не задан.
