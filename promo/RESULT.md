## Проверка Codex (`VERIFY-CODEX.md`): «да с поправками», качество пилота C

Главное: (1) 16:9 под 2,5 CPU у обоих практически равно (287–296 против 293–297 с); (2) границы «времени рендера»
различаются (HyperFrames собирает HTML до замера, Remotion собирает бандл внутри — ~10 с в пользу HyperFrames);
(3) размеры файлов сравнивать нельзя — разные CRF/пресеты; (4) счёт итераций у обоих смешивает вину инструмента,
среды и исполнителя; (5) предварительно предпочесть **Remotion** за побайтно совпавшие повторы при равном времени.
Три обязательные поправки перед окончательным выбором: единый `render.sh`-режим (2,5 CPU все форматы, отдельно
сборка/рендер), одинаковое кодирование (CRF/preset/цвет) и общий контрольный монтаж, единый учёт попыток.

## Что пилот НЕ доказал

- Скорость под 6 CPU: хостовый сторож (`crypto-miner-watchdog.sh`, наследие 26.08) перезапускает контейнер с CPU > 300 %
  по мгновенному замеру; 2,9 CPU тоже сработал. Быстрее — только с исключением по имени `promo-*` (решение владельца).
- Ролики целиком глазами не смотрели ни исполнители, ни координатор — только контрольные кадры (по 5 на формат).
- Музыка и озвучка — вне пилота по решению владельца.
- Причина невоспроизводимости HyperFrames (гипотеза — выбор кадра VP8 при перемотке `<video>`).

## Уроки роя

- Общие шаблоны имён (`render.sh` у обоих) + `pkill -f` = убитый сосед. Правило: останавливать только по PID/полному
  пути/имени контейнера с префиксом инструмента.
- Хостовые сторожа надо инвентаризировать ДО протокола замеров: лимит CPU в протоколе был невыполним на этой машине.
- Тихие умолчания под cgroup (кэш по памяти хоста, цветовое пространство) ловятся только `ffprobe`/OOM — страж на
  формат результата обязан быть в `render.sh` (у обоих теперь есть).

## Рекомендация координатора

Оба инструмента годятся; различие — в природе, а не в скорости:
- **Remotion** — детерминизм (одинаковый файл при одинаковом коде) и предсказуемое поведение; цена — лицензия при
  «компании от 4 человек» и три явных флага под контейнер.
- **HyperFrames** — Apache-2.0, быстрее вход (первый рендер с первой попытки, `snapshot --at` за 40 с), но pre-1.0 с
  расходящейся документацией и без побайтной воспроизводимости.

Предлагаю: **Remotion как основной** для шести роликов (воспроизводимость важнее для ×6 правок текстов), HyperFrames —
запасной; решение владельца по лицензии (юрстатус) может перевернуть выбор — тогда HyperFrames без потери качества.
Перед серией — выполнить три поправки Codex на пилоте N6 (≈ 1–2 ч) и посмотреть оба ролика глазами.
