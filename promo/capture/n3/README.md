## Блокер записи (решение владельца)

1. **Выданный адрес не отвечает.** `https://n3-{a,b,c,d}.212.192.0.33.sslip.io/` → `TLS alert internal error`:
   машина сменила адрес, общий прокси `ai-hub-tls-proxy` обслуживает n3 как `n3-*.194.85.249.105.sslip.io`.
2. **По действующему адресу интерфейсы не открывают сеанс.** API держит список origin, зашитый в код
   (`shared/contracts/deployment.mjs` → только `…212.192.0.33…`), и на новом адресе отвечает
   `403 ORIGIN_DENIED` «Источник запроса не разрешён» — все четыре интерфейса показывают «Доступ к кабинету
   отклонён». **Для посетителей стенд N3 сейчас не работает.** Чинится только пересборкой/перенастройкой стенда,
   что постановкой запрещено (и в HEAD лежит незавершённый F3).
3. **Заплатка съёмки.** Чтобы снять неизменённый продукт, скрипт выполняет запросы страницы к `/api/*` через
   `route.fetch` с заголовком `Origin` выданного адреса (тот же сервер, те же ответы; продукт, стенд и данные не
   меняются). Это видно в шапке `record-n3.mjs`. Если владелец считает такую съёмку недопустимой — две годные
   записи тоже снимаются с монтажа.
4. **Лимит демосеансов исчерпан.** Каждое открытие интерфейса создаёт fixture-арендатора, а их число на стенде
   ограничено **200 без очистки** (`shared/application/index.mjs`, `maxDemoRuns`). На 08:12 UTC стенд отвечает
   `429 DEMO_LIMIT` «Достигнут лимит независимых демосеансов» — **«Новый сеанс» перестал работать для всех**.
   Мой вклад: **17 демосеансов** (разведка 14: 6 + 6 + 2; запись 3), то есть до меня было ≥ 183. Скрипт теперь
   останавливается на первом `DEMO_LIMIT`/`RATE_LIMIT` и не повторяет запрос.

Варианты для владельца: (а) очистить fixture-арендаторов стенда N3 (или поднять `maxDemoRuns`) и добавить
действующий адрес в список origin — затем повторить запись одной командой ниже (нужно 6 сеансов:
`STEPS=overview,rules,partner,registry LAYOUTS=mobile` + `STEPS=partner,registry LAYOUTS=desktop`);
(б) собрать ролик из двух годных записей и типографских карточек для сцен 3–4 (титр сцены 3 без кадра нарушил бы
правило «не обещать того, чего нет в кадре»); (в) отложить N3 до выкладки F3 с постоянным доменом.

## Как повторить

```bash
cd promo/capture/n3
free -g   # если available < 2 ГБ — подождать (sleep 60, до 10 раз)
docker run --rm --name promo-n3-capture --memory=1500m --cpus=2 \
  -v "$PWD:/work" -v /home/dz-projects-2026/.promo-assets/n3:/assets -w /work \
  mcr.microsoft.com/playwright:v1.60.0-noble \
  bash -c "npm ci --no-audit --no-fund && node record-n3.mjs"
```

Без публикации портов. `STEPS=overview,rules,partner,registry` и `LAYOUTS=desktop,mobile` сужают прогон; каждая
запись — один новый демосеанс стенда. Код возврата `1` — есть сбой записи или голый IP в кадре.
