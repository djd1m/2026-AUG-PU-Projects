## Блокер: лимит демосеансов (нужна операция координатора/владельца)

Прогон 18:56:42 UTC (`LAYOUTS=desktop`): `POST /api/demo` → **`429 DEMO_LIMIT`** «Достигнут лимит независимых
демосеансов» через 0,75 с после старта файла; арендатор НЕ создан (отказ до вставки). Скрипт остановился, mobile не
запускался. Неудачный файл — `failed-2026-09-29T18-56/`. Сторож хоста: `gate-watchdog.sh promo-n3-capture` → 0.
**Для посетителей `reward.aicoding.space` вариант A сейчас не открывается вообще.**

Документированной процедуры сброса или увеличения лимита нет (искал: `docs/f2-operations.md`,
`docs/runtime-contract.md`, `docs/ADR.md` ADR-003, `scripts/*`, `apps/api/server.mjs`):

- лимит — константа кода: `shared/application/index.mjs:22` `options.maxDemoRuns ?? 200`; `apps/api/server.mjs` его не
  передаёт; переменной окружения нет — поднять без правки кода нельзя;
- очистка fixture-арендаторов не описана, а удаление упирается в триггеры неизменяемости `immutable_fact_guard`,
  `sent_allocation_guard` и внешние ключи десяти таблиц на `tenants(id)`; `docs/f2-operations.md` прямо называет
  удаление истории ради обхода ограничений недопустимым.

Поэтому исполнитель ничего не выполнял. **Решено 29.09 ~19:05 UTC координатором по решению владельца** (вариант 1
ниже): лимит вынесен в `N3_MAX_DEMO_RUNS`, на стенде 400, API на образе `n3-api:bridge-38bed68`. **Предложенная
минимальная операция:** одна строка в ветке `n3/reward-domain`
(релизная линия ADR-003) — `apps/api/server.mjs`: `createApplication({ mode, …, maxDemoRuns: 400, database: … })`
(или чтение `N3_MAX_DEMO_RUNS` с проверкой целого 1…10000, которую уже делает `createApplication`), пересборка только
`n3-api` новой меткой и выкладка одной командой API из `docs/f2-operations.md`; откат — метка `bridge-901f0a6`.
Схема и данные не меняются. Для ролика нужно ровно 2 сеанса.

## Как повторить

```bash
free -g   # available < 2 ГБ — не запускать
T0=$(date '+%Y-%m-%d %H:%M:%S')
docker run --rm --name promo-n3-capture --memory=1500m --cpus=2 --shm-size=1g \
  -v "$PWD/promo/capture:/work" -v /home/dz-projects-2026/.promo-assets/n3:/assets -w /work/n3 \
  -e LAYOUTS=desktop mcr.microsoft.com/playwright:v1.60.0-noble \
  bash -c 'set -e; npm ci --no-audit --no-fund && node record-n3.mjs'
bash .claude/skills/promo-video/scripts/gate-watchdog.sh promo-n3-capture "$T0"
# затем то же с -e LAYOUTS=mobile; каждый запуск — один демосеанс стенда
```

Без публикации портов. Код `1` — сбой записи или адрес в кадре; на `DEMO_LIMIT`/`RATE_LIMIT` скрипт не повторяет запрос.
