## Как повторить

```bash
free -g   # available < 2 ГБ — не запускать
T0=$(date '+%Y-%m-%d %H:%M:%S')
docker run --rm --name promo-n3-capture --memory=1500m --cpus=2 --shm-size=1g \
  -v "$PWD/promo/capture:/work" -v /home/dz-projects-2026/.promo-assets/n3:/assets -w /work/n3 \
  -e LAYOUTS=desktop mcr.microsoft.com/playwright:v1.60.0-noble \
  bash -c 'set -e; npm ci --no-audit --no-fund && node record-n3.mjs'
bash .claude/skills/promo-video/scripts/gate-watchdog.sh promo-n3-capture "$T0"
# затем то же с -e LAYOUTS=mobile; каждый запуск — один демосеанс стенда
```

Без публикации портов. Код `1` — сбой записи или адрес в кадре; на `DEMO_LIMIT`/`RATE_LIMIT` скрипт не повторяет запрос.
