## Круг правок 2D: пересъёмка `snippet-mobile` (2026-09-29 16:18 UTC)

Находка Codex трёх кругов подряд: в 9:16 тег `<script … data-slug="…">` уходит за правый край поля кода в самой
mobile-записи. Замер в записи: у `pre.snippet` `scrollWidth 732` при `clientWidth 310` CSS px и `overflow-x: auto` — тег в
2,4 раза шире поля. Из трёх способов выбран первый по порядку постановки — **горизонтальная прокрутка поля кода в
кадре**: продукт сам делает поле прокручиваемым (как пальцем у пользователя), стиль страницы не меняется. Прокрутка
плавная (2,6 с, ease-in-out, `el.scrollLeft` через `requestAnimationFrame`) от начала строки до `scrollLeft 422` (конец),
затем пауза 1,6 с на хвосте тега `data-slug="primer-coffee" async></script>`, затем прежнее выделение. Зритель видит
строку целиком за 2,7 с; кадры 4 / 6 / 7 / 8,6 / 10,5 / 12,4 с просмотрены. Масштаб страницы и более широкий viewport
не понадобились (при масштабе, вмещающем 732 px в 310, моноширинный шрифт ≈ 5 CSS px — нечитаемо в 9:16).

Как снято: `STEPS=setup,snippet ONLY=mobile` (новая переменная `ONLY` — одна раскладка), тот же контейнер и HiDPI-рекордер
390×844 @2, контейнер `promo-n1-capture-2d`; вход той же фикстурой (`/api/auth/login` → 200, 1 вход), отправок, импорта,
модерации — 0, платных вызовов — 0. Журнал `record-log-2026-09-29T16-18-33-276Z.json` с `video.start`/`video.saved` и
`t_file_s` у каждого события: `gate-log.mjs` → 0 («1 файлов, 5 событий с t_file_s»). Прежняя запись сохранена как
`snippet-mobile-old.webm` (вне репозитория). sha256 новой записи `a0e4c79cc60102f7edd97e7b4095df7ce94557b1da62fc2d930eee6c260dea0c`;

## Что НЕ снято и почему

- **`/f/demo` и `/w/demo`** не сняты: у демо-проекта на стене пробные записи (пустые тексты, снимок без подписи) и

- **Главная `/` с регистрацией** не снята: в форме видна служебная почта фикстуры.
- **Отзыв с внешней площадки** (есть в demo-script) не снят: сценарий 45 с его не вмещает, а DoD фичи не закрыт.
- **Кнопка «Choose File / No file chosen»** на форме — по-английски: так рисует headless Chromium, в браузере
  пользователя подпись локализована. В кадре 1–2 с до выбора фото.

## Как повторить

```bash
docker run --rm --name promo-n1-capture --memory=1500m --cpus=2 --shm-size=1g \
  -v "$PWD/promo/capture:/src:ro" -v /home/dz-projects-2026/.promo-assets/n1:/assets \
  mcr.microsoft.com/playwright:v1.60.0-noble \
  bash -c "mkdir -p /work && cp /src/hidpi-recorder.mjs /work/ && cp -r /src/n1 /work/n1 && cd /work/n1 && npm ci --no-audit --no-fund && node record-n1.mjs"
```

Без публикации портов; `node_modules` остаются внутри контейнера. `STEPS=…` — выборочные шаги
(`setup,wallempty,links,seed,form,moderate,approveall,wall,snippet,site`). Повторный прогон входит той же
учёткой; `form` пропускается, пока счётчик отправок 2 из 2; `seed` не импортирует повторно. `wallempty` и `links`
после публикации отзывов покажут уже не пустое состояние. Перед запуском `free -m`: свободной (available) памяти
было 4,8–5,2 ГБ (колонка `free` — 0,5–0,7 ГБ: остальное — кэш страниц; ориентир — `available`).

- Ответ `POST /api/auth/register` (201) не читается после клика: форма сразу уводит на `/dashboard/<slug>`, и
