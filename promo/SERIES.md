## Общие правила серии

- **Один шаблон, один сценарий-каркас:** 5 сцен по 45 с — (1) боль клиента, (2) шаг 1 продукта, (3) шаг 2 / результат,
  (4) распространение (виджет / ссылка / QR / карточка), (5) финал: название + адрес. Без голоса, субтитры Onest
  (у N1 — Bricolage Grotesque/DM Sans, у N4 — Unbounded/Onest, у N3 — Rubik: шрифт продукта, если он есть в проекте,
  иначе Onest). Токены — из `globals.css` проекта (`05_project_inputs.md`). Музыки нет (решение владельца).
- **Среда и замеры:** образ `promo-render:2026-09-29`, `--cpus=2.5 --memory=4g --network none`, рендер под
  `flock /home/dz-projects-2026/.promo-assets/render.lock`, контейнеры `promo-<proj>-*`, останавливать только своё.
  Кодирование одно у всех: H.264 High, `--crf=20`, `yuv420p`, bt709, 30 fps; `--offthreadvideo-cache-size-in-bytes=512MB`,
  `--concurrency=2`, Chromium из образа. Время рендера в квитанции — отдельно сборка, отдельно рендер.
- **Записи:** по ВЫДАННОМУ адресу стенда, desktop 1920×1080 + mobile HiDPI-рекордер (`promo/capture/hidpi-recorder.mjs`),
  файлы в `/home/dz-projects-2026/.promo-assets/<proj>/`, вне git. Что нельзя показывать — по `05_project_inputs.md`
  (оплата, чужие бренды, служебные фикстуры, незавершённые фичи, голые IP в кадре).
- **Платные вызовы — минимум и по счёту:** N6 предпросмотр 1 + ответы ≤ 4 (уже есть); N4 — ≤ 3 распознавания
  (реальные фото еды из свободных источников CC0 или своё фото тарелки — не чужие снимки); N5 — ОДНА запись ≤ 3 минут
  (свободный CC0-подкаст/речь) → расшифровка + выбор фрагментов ≈ несколько рублей; N1, N2, N3 — платных вызовов нет.
  Каждый агент пишет в квитанцию число вызовов.
- **Экраны за входом:** там, где сцена невозможна без кабинета (N6 установка, N1 модерация, N5 экран клипов,
  N4 дневник), исполнитель создаёт ОДНУ учётку-фикстуру `promo-fixture-<proj>@example.com` с паролем из
  `openssl rand`, хранит в `/home/dz-projects-2026/.promo-assets/<proj>/.fixture.env` (600), помечает в квитанции; аккаунт
  не удаляет (владелец решит). Никаких чужих учёток, `ui-fixture.json` не трогать.
- **Стенды не перезапускать, код продуктов не менять.** Если для съёмки нужна правка продукта — записать в квитанцию
  как «не снято, нужна правка», а не править.
- **Критерий готовности исполнителя:** 3 mp4 (`ffprobe`: 45,000 с, 1350 кадров, yuv420p, 30 fps), `README.md` (как
  воспроизвести одной командой, адреса и тайминги записи), `MEASUREMENTS.md` (сборка/рендер/память/sha256 повтора 16:9),
  `ITERATIONS.md` (честно: инструмент / среда / исполнитель), `SCENARIO.md` (текст титров сцен — для правки владельцем).
  Бюджет — 120 минут активной работы, ≤ 8 итераций.
