# Бриф проверочного ревью серии из пяти роликов (OpenAI Codex, gpt-6-astra, medium)

Ты — независимый проверяющий из другого семейства моделей. Пилот (`promo/RESULT.md`, `promo/VERIFY-CODEX.md`) уже
принят владельцем: инструмент — Remotion, серия собрана на общем шаблоне. Прочитай `promo/SERIES.md` (правила серии,
критерий готовности, журнал), `promo/CAPTURE-BRIEF.md`, `promo/remotion/shared/README.md` и `render.sh`, инвентарь
«что нельзя показывать» `docs/research/promo-videos/05_project_inputs.md`, затем пять проектов
`promo/remotion/{n6,n4,n5,n1,n2}/{SCENARIO,README,MEASUREMENTS,ITERATIONS}.md` + `project.config.ts` и записи
`promo/capture/{n4,n5,n1,n2}/README.md` (N6 — `promo/capture/README.md`). Видеофайлы недоступны — суди по документам,
конфигам и коду. N3 отложен решением владельца — не оценивай.

Задача — найти, что мешает отдать ролики владельцу как готовые:
1. **Текст титров** (`SCENARIO.md` + `project.config.ts` каждого): по-русски, без опечаток и канцелярита, 1–2 короткие
   строки на сцену; титр не обещает того, чего нет в кадре по описанию сцены; каркас 5 сцен «боль → шаг 1 →
   шаг 2/результат → распространение → финал» соблюдён; финал называет продукт и адрес.
2. **«Нельзя показывать»:** по инвентарю и README записей — цены/оплата, чужие бренды и учётки, служебные фикстуры,
   незавершённые фичи, голые IP, ключи. Где исполнитель заявил «исключено» — назван ли способ и доказательство
   (например, проверка по готовым mp4 кадрами у N2). Где нет доказательства — назови.
3. **Единообразие серии:** три формата из одного исходника, одно кодирование (`render.sh`: CRF, yuv420p, bt709,
   30 fps, 1350 кадров), одна среда (`promo-render:2026-09-29`, 2,5 CPU, 4 ГБ, без сети), повтор 16:9 sha256 — у всех
   пяти? Расхождения между проектами в конфиге/сценах/шрифтах — законные (токены продукта) или случайные.
4. **Достоверность замеров** (`MEASUREMENTS.md`): чем мерили сборку/рендер/память, есть ли у каждого отдельное время
   сборки и рендера, число платных вызовов по лимитам `SERIES.md`, число итераций с разбором «инструмент / среда /
   исполнитель» в `ITERATIONS.md`.
5. **Шаблон** `promo/remotion/shared/`: что в нём хрупко (переполнение текста, кадрирование записей под 9:16 и 1:1,
   сегменты записей, шрифты), какие правки нужны перед тем, как из него делать навык.
6. **Вердикт для владельца:** ролики можно отдавать (да / да с поправками / нет) — по каждому из пяти одной строкой;
   3 обязательные правки перед публикацией; оценка серии A/B/C/D.

Формат: markdown по-русски, разделы 1–6, каждая находка — «файл: утверждение → что не так → довод». Не пересказывай.
