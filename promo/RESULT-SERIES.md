## Решения координатора (автономно, по правилам серии; владелец может отменить)

- **DEC-S-01.** Титры, обещающие не снятое (N6 сцена 4, N5 сцена 4, N2 сцена 3), — нарушение правила серии «не
  обещать титром того, чего нет в кадре», правятся без ожидания владельца: N6 → «Окно бота — на вашем сайте, без
  переделки страниц»; N5 → «На каждом клипе — метка с короткой ссылкой на КлипМейкер»; N2 → «По QR — три способа
  оставить отзыв». Стилистика (N4 первый титр, «разнос» у N2) — вкус владельца, правится по его слову.
- **DEC-S-02.** N1: пометка «отзывы демонстрационные» — постоянной плашкой на сценах с отзывами (шаблон получает
  поле `footnote` на сцену); контраст финала — цвет названия из токенов продукта с контрастом ≥ 4,5:1.
- **DEC-S-03.** Противоречия README ↔ конфиг (N6 тайминги ответов, N2 кадрирование QR и «Отправлено») — сверить по
  журналу событий записи; исправлять документ, если кадр верен, и монтаж, если нет.
- **DEC-S-04.** Правки шаблона из раздела 5 — в фазе 4 (навык), не в этом круге: круг правок использует шаблон как
  есть плюс минимальное поле `footnote`; иначе пять проектов перерендериваются дважды.
- **DEC-S-05.** После правок — второй, узкий круг Codex по диффу (не полный), критерий выхода задан заранее:
  закрыты ли три обязательные правки, не сломано ли соседнее.
