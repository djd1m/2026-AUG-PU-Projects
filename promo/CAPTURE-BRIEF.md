# Постановка исполнителя проекта в серии (часть A — съёмка и сценарий; часть B — сборка на шаблоне)

Обязательные документы: `promo/SERIES.md` (правила серии), `docs/research/promo-videos/05_project_inputs.md` (твой
проект: экраны без входа, сценарий, токены, ЧТО НЕЛЬЗЯ), `promo/capture/README.md` + `record-n6.mjs` +
`hidpi-recorder.mjs` (образец записи: явный `recordVideo.size`, HiDPI-рекордер для mobile, журнал событий с
таймингами, счётчик платных вызовов), README и CLAUDE.md твоего проекта (маршруты).

## Часть A (сейчас)

1. **Сценарий** `promo/remotion/<proj>/SCENARIO.md`: 5 сцен по каркасу серии (боль → шаг 1 → шаг 2/результат →
   распространение → финал), титры по-русски, 1–2 короткие строки на сцену, из README «простыми словами»; для каждой
   сцены — какой экран и какое действие в кадре, длительность (сумма 45 с). Не обещать титром того, чего нет в кадре.
2. **Запись** `promo/capture/<proj>/record-<proj>.mjs` (+ `package.json` с `playwright@1.60.0`, lockfile) по ВЫДАННОМУ
   адресу стенда, две раскладки (desktop 1920×1080; mobile 390×844 @2 через HiDPI-рекордер), тема продукта по умолчанию,
   человеческие паузы, плавный скролл; файлы — `/home/dz-projects-2026/.promo-assets/<proj>/*.webm` (вне git) +
   `record-log-*.json`. Контейнер: `mcr.microsoft.com/playwright:v1.60.0-noble`, `--rm --memory=1500m --cpus=2`, без
   портов; перед запуском проверь `free -g` — если свободно < 2 ГБ, подожди (`sleep 60`, до 10 раз).
3. **Фикстура-учётка**, только если сцена невозможна без кабинета: `promo-fixture-<proj>@example.com`, пароль
   `openssl rand -hex 12`, в `/home/dz-projects-2026/.promo-assets/<proj>/.fixture.env` (600); регистрация через
   обычную форму стенда; в README — что создано. Чужие учётки, `ui-fixture.json`, `.env` стендов — не трогать.
4. **Платные вызовы** — по лимитам `SERIES.md`; каждый — в счётчик и в README. Ничего не гонять в цикле.
5. `promo/capture/<proj>/README.md`: таблица ffprobe записей, адреса и тайминги событий, платные вызовы, что НЕ снято и
   почему, что показывать нельзя (из инвентаря) и как это обойдено.
6. Коммит `feat(promo): запись экранов <proj> …` + `docs(promo): сценарий <proj>`, по-русски, без Co-Authored-By; видео
   в git не класть (`promo/.gitignore` уже есть).

После части A — отчёт координатору и ожидание сообщения «шаблон готов» (не бездействуй в цикле: заверши ход отчётом).
