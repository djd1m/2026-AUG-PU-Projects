## Что не удалось / не сделано

- **Побайтная воспроизводимость:** два рендера 16:9 различаются в 993 кадрах из 1350 (только участок с `<video>`,
  PSNR 50,7 дБ); причина не установлена — см. `MEASUREMENTS.md`.
- **Сцена 4 показывает не установку:** экран `<script>` не снят (нужен вход), в кадре окно чата предпросмотра с
  бейджем, а титр «Одна строка кода — и бот на вашем сайте» остался по постановке — кадр и титр расходятся.
- **Музыки нет.** CC0-трек не подбирался.
- **`hyperframes check`** (браузерный гейт layout/contrast) не запускался — использованы `lint` и `snapshot` + просмотр
  кадров глазами. Официальный skill/plugin HyperFrames и `--docker` режим не пробовались.
- **Codex** не вызывался (нужды в проверке API не возникло).
- Композиция 16:9 из desktop-записи оставляет много пустого поля по бокам окна чата — кадрирование «пилотное».

## Где документация расходится с поведением (находки)

1. **`doctor` возвращает 0 при проваленных проверках** (Chrome не найден, `/dev/shm` мал). Для агента это худший
   вид ответа: код возврата говорит «всё хорошо». Проверено: `hyperframes doctor; echo $?` → `0`.
2. **Качество по умолчанию:** `dist/docs/rendering.md` — «draft, standard, high (default: standard)»;
   `render --help` — «draft, looks, delivery, or standard/high … (Default: looks)». Верить надо `--help`.
3. **Воркеры:** `rendering.md` — «Parallel workers 1-8 (default: auto)», «4 workers is usually the sweet spot».
   На деле при лимите cgroup 4 ГиБ включается low-memory режим и **auto = 1 воркер** (в журнале
   `workerCount: 1`, `forceScreenshot: true`) — об этом пишет только `--help` (`--low-memory-mode`, авто при ≤ 8 ГБ).
4. **`dist/docs/examples.md`** обещает шаблоны `title-card` и `video-edit`; в пакете есть только `blank`,
   `from-file`, `warm-grain`.
5. **Шаблон `blank` и `docs/gsap.md` грузят GSAP с jsDelivr** (`gsap@3.14.2` и `gsap@3` без пина). Под
   `--network none` это молча даёт страницу без таймлайна; обязательный пин версии в `_shared/CLAUDE.md` касается CLI,
   но не GSAP.
6. **Регистрация таймлайна:** `_shared/CLAUDE.md` велит `window.__timelines = window.__timelines || {}`, шаблон
   `blank` пишет `window.__timelines["main"] = tl` без инициализации. Линтер при этом видит регистрацию **только
   во встроенном `<script>`** — вынос в файл даёт ложную ошибку `missing_timeline_registry`.
7. **Финал рендера:** «Screenshot capture (slower): BeginFrame did not run. Needs chrome-headless-shell» — хотя
   передан именно `chrome-headless-shell`. Причина не выяснена (вероятно, low-memory режим форсирует screenshot);
   на результат не влияет, на скорость — да.
8. **Телеметрия:** `HYPERFRAMES_NO_TELEMETRY=1` уважается (`hyperframes telemetry status` → `disabled`,
   `Source: HYPERFRAMES_NO_TELEMETRY`); адрес отправки в коде — `https://us.i.posthog.com`. Все рендеры шли с
   `--network none` — уйти ей было некуда в любом случае.
