# Ролик N6 «Суфлёр» на HyperFrames (пилот `promo/PILOT-N6.md`)

Один исходник — три формата: 16:9 1920×1080 и 1:1 1080×1080 из desktop-записей, 9:16 1080×1920 из mobile-записей.
45 с, 30 fps, H.264, без звука (музыки нет — см. «Музыка»).

## Одна команда

```bash
bash promo/hyperframes/n6/render.sh               # npm ci → сборка → lint → 16:9, 16:9 повтор, 1:1, 9:16 → ffprobe
SKIP_INSTALL=1 bash promo/hyperframes/n6/render.sh
```

Всё исполняется в образе `promo-render:2026-09-29`; на хосте ничего не ставится, портов нет. Сеть — только у
`npm ci`; сборка, lint и рендер — `--network none`, `--cpus=2.9 --memory=4g` (сторож CPU > 300 %). Замеряемые рендеры идут под
`flock /home/dz-projects-2026/.promo-assets/render.lock`. Результаты:
`/home/dz-projects-2026/.promo-assets/n6/out/hyperframes/{16x9,9x16,1x1}.mp4`, журналы — `renders/logs/` (вне git).

## Устройство

```
src/template.html   разметка ролика (сцены, клипы, субтитры) с местами {{W}} {{H}} {{FORMAT}} {{SRC}} …
src/scene.css       токены N6, Onest, размеры по формату
src/scene.js        GSAP-таймлайн: «камера» над записью (точка + масштаб на формат), появление титров
build.mjs           → build/{16x9,1x1,9x16}/ — три самостоятельных проекта HyperFrames (index.html со вставленными
                    CSS/JS, vendor/gsap.min.js, fonts/Onest-*.ttf из образа, media/*.webm из /assets)
scripts/            install · lint-all · render-one (замер) · probe (ffprobe + проверка протокола, 0/1/2) · snap · sheet
```

Почему три каталога, а не три файла: `hyperframes lint` требует ровно один корневой `index.html` в проекте
(`multiple_root_compositions`), а `lint`/`check` не умеют `-c`. Записи `.webm` вставлены как `<video>` напрямую —
перекодировать в mp4 не понадобилось; обрезка — `data-media-start` + `data-duration` у клипа.
