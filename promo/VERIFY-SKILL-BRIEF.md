# Бриф проверки навыка `promo-video` (OpenAI Codex, gpt-6-astra, medium)

Ты — независимый проверяющий из другого семейства моделей. Прочитай `.claude/rules/skill-interface-protocol.md`,
затем `.claude/skills/promo-video/SKILL.md` и все `modules/0*.md`; для сверки фактов — `promo/SERIES.md`,
`promo/RESULT.md`, `promo/RESULT-SERIES.md`, `promo/VERIFY-SERIES-CODEX.md`, `promo/remotion/shared/README.md`,
`render.sh`, `scripts/probe.sh`, `promo/capture/README.md`.

Найди, что мешает применить навык к новому проекту без координатора-автора:
1. **Протокол:** frontmatter, секции модулей (Input/Process/Output/Quality Gate/Dependencies), зависимости с fallback,
   ссылки на существующие файлы — нарушения назови по файлу и строке.
2. **Достаточность:** сможет ли исполнитель по модулю 03 записать экраны, а по 04 — собрать и отрендерить ролик, не читая
   переписку серии? Чего не хватает (команды, пути, порядок, критерий «готово»)?
3. **Достоверность:** цифры и утверждения (лимиты CPU, память, время, коды возврата, флаги кодирования) совпадают с
   квитанциями серии и кодом шаблона? Расхождения — по строке.
4. **Уроки серии:** вошли ли твои же находки по серии (титры без обещаний, постоянная пометка демо-данных, crop ≠ маска,
   раскадровка готовых mp4, preflight сегментов) — как ворота (Quality Gate), а не как совет?
5. **Ворота, которые не могут упасть:** какие Quality Gate сформулированы так, что проходят всегда (нет порога, нет
   команды, нет кода возврата)?
6. **Вердикт:** навык годен к применению на новом проекте (да / да с поправками / нет); 3 обязательные правки; оценка A/B/C/D.

Формат: markdown по-русски, разделы 1–6, каждая находка — «файл:строка: утверждение → что не так → довод». Не пересказывай.
