# Какие модели питают продукты курса

Ответ на вопрос «можно ли свести всё к одному провайдеру и сэкономить».
Исследование роем из четырёх агентов, данные на **26.08.2026**, 40+ источников.
Детальные разборы: [`/research/openai-footprint/`](../research/openai-footprint/).

> Речь о моделях **внутри продуктов**. Claude Code как инструмент разработки — отдельная
> история, он в этот расчёт не входит.

---

## Короткий ответ

**Свести к одному провайдеру нельзя, но footprint сокращается с восьми разных до двух.**

| | |
|---|---|
| **OpenAI** | закрывает 7 проектов из 8 |
| **Self-hosted Stable Diffusion + ControlNet** | только проект 08 |
| **Бесплатный OpenRouter** | ❌ не годится как бэкенд продукта — см. §3 |

И главное открытие: **деньги здесь вообще не проблема.** Весь AI на объёме курса стоит
десятки долларов, а не тысячи. Экономить было не на чем — но проверить стоило, потому что
попутно нашлись две вещи, которые сломали бы проекты.

## 2. Три находки, которые важнее экономии

### 🔴 Проект 08: у OpenAI нет контроля геометрии

Аналога ControlNet и depth-карт **не существует**. Единственные инструменты — маска
в эндпоинте `edits`, которую **сама документация OpenAI называет «entirely prompt-based»**
(то есть без гарантии контура), и `input_fidelity` для точечных деталей вроде лица
или логотипа, доступный только на модели, уходящей 23.10.2026.

Для Interior AI это **потеря ключевого требования**, а не деградация по краю: генерация,
переставившая окна, считается браком по определению — по ней ничего не построишь.

**Вывод:** проект 08 остаётся на self-hosted Stable Diffusion с ControlNet-depth.
GPU-VPS от $0.13–0.8/час, генерация 3–9 секунд на кадр.

### 🔴 Проект 05: таймкоды есть не у всех моделей

| Модель | Таймкоды |
|---|---|
| `whisper-1` | ✅ уровень слов и сегментов (`verbose_json`) |
| `gpt-4o-transcribe-diarize` | ✅ сегменты + спикер |
| `gpt-4o-transcribe`, `mini` | ❌ в документации не найдено |

Без таймкодов нарезка клипов **невозможна в принципе**. Модель для проекта 05 выбирается
не по цене и не по качеству, а по одному признаку — отдаёт ли она временные метки.
Ошибка выбора вскрылась бы при попытке нарезать первое видео.

Бонус: `gpt-4o-transcribe-diarize` даёт **диаризацию из коробки** — разделение по спикерам.
Для подкастов это ровно то, что нужно; self-hosted путь потребовал бы отдельного
pyannote-пайплайна.

### 🔴 Проект 06: pgvector не проиндексирует вектор больше 2000 измерений

Жёсткий лимит HNSW и IVFFlat — упирается в размер страницы Postgres.

| Модель | Размерность | Индексируется |
|---|---|---|
| `text-embedding-3-small` | 1536 | ✅ |
| `text-embedding-3-large` | 3072 по умолчанию | ❌ **нет** |

Ловушка в том, что **на десяти документах всё работает** — вектора складываются, поиск идёт
перебором. Отказ приходит при попытке построить индекс, то есть на объёме, где уже больно.

Обход: `halfvec` (лимит 4000) либо явное урезание параметром `dimensions` при вызове API.
OpenAI официально подтверждает, что усечённый вектор новой модели может превосходить полный
вектор старой — так что `3-large` с `dimensions=1536` легитимен, а не компромисс.

**Рекомендация:** по умолчанию `text-embedding-3-small` — чтобы не наступать вообще.

## 3. Бесплатный OpenRouter: почему не подходит

Проверяли всерьёз — для курса это сняло бы барьер входа студентам. Не вышло, по трём
независимым причинам.

### Дыры в модальностях — не обходятся

- **Нет ни одной бесплатной модели распознавания речи.** Нужна проектам 01 и 05.
- **Нет ни одной бесплатной модели генерации изображений.** Нужна проекту 08.

Обе коллекции на OpenRouter полностью платные.

Эмбеддинги бесплатные есть (`nvidia/nemotron-3-embed-1b:free`), текстовая генерация есть,
часть vision-задач закрывается — но три проекта из восьми упираются в отсутствие модальности.

### 🔴 Приватность и бесплатность взаимоисключающи по конструкции

Ключевой факт: чтобы бесплатные модели **вообще заработали**, в настройках аккаунта нужно
включить **оба** тумблера — «может тренироваться на данных» и «может публиковать промпты».
Иначе бесплатные эндпоинты возвращают 404 «нет моделей, подходящих под политику».

То есть выбрать «бесплатно и приватно» технически невозможно.

Прямое подтверждение от самого провайдера (NVIDIA, на странице бесплатной мультимодальной
модели): **«Avoid uploading confidential information, personal data, voices, or faces»**.

Через наши продукты идут ровно они: **голоса** клиентов (01), **лица** и еда людей (04),
документы бизнеса (06), контакты для рассылки (07).

### Надёжность

Официальная документация OpenRouter **прямо называет бесплатный уровень непригодным
для продакшена**. Лимиты: 20 запросов в минуту, 50 в день (1000 при пополнении счёта на $10+).

### Где всё-таки годится

| Сценарий | Годится |
|---|---|
| Демо на занятии, на своих тестовых данных | ✅ да |
| Прототип без персональных данных | ✅ да |
| Бэкенд продукта, который показывают людям | ❌ нет — ни по приватности, ни по надёжности, ни по модальностям |

## 5. Честные пробелы

Что агенты не смогли подтвердить и пометили явно:

- Точный WER для русского языка — цифры из стороннего агрегатора, не из первоисточника
- Поддержка таймкодов у `gpt-transcribe` — в документации не найдено ни подтверждения,
  ни опровержения
- Официальный лимит длительности аудио (лимит размера — 25 МБ, длительность не указана)
- Стабильность `diarize` в продакшне — есть открытые issues на Azure SDK
- Качество усечения эмбеддингов именно до 1536 — в документации есть только пример с 256
- Оценка CPU-времени для self-hosted `large` — экстраполяция, не измерение
