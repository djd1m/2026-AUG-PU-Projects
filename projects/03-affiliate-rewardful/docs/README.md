# Документация N3 — Круг

Первый продуктовый приоритет: работающая цепочка «рекомендация → подтверждённая регистрация в SaaS → оплата → комиссия». После неё выполняется одобренный этап подтверждения email, восстановления пароля, Yandex ID и инструкций платёжных провайдеров.

Рабочие кабинеты: [A](https://n3-a.212.192.0.33.sslip.io/account), [B](https://n3-b.212.192.0.33.sslip.io/account), [C](https://n3-c.212.192.0.33.sslip.io/account), [D](https://n3-d.212.192.0.33.sslip.io/account). Общий backend и реальные аккаунты; начальные CJM-страницы на `/` используют синтетические данные. Статус выкладки новой воронки указан в F3 completion.

Сборка и изолированные проверки не доказывают подключение боевого магазина. Для реальных платежей нужны выделенные credentials N3 и проверка конкретного merchant-сценария. Выплаты партнёрам остаются ручными, по реестру до 5-го числа следующего месяца.
