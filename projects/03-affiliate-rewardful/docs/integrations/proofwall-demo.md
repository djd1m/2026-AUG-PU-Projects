# Демонстрация: покупка в Proofwall → комиссия в N3

Обновлено 9 сентября 2026. Связка развёрнута на публичных стендах. Используется существующий **тестовый магазин ЮKassa проекта 1**, по согласованию владельца. Proofwall создаёт платёж и получает уведомление; N3 независимо проверяет этот платёж и начисляет комиссию. Между backend проектов — публичный HTTPS, общей сети контейнеров и доступа к чужой БД нет.

## Подготовка

Оставьте кабинет партнёра открытым: https://n3-a.212.192.0.33.sslip.io/account

Для покупателя откройте отдельное приватное окно браузера. Нужен **новый аккаунт Proofwall и доступный почтовый ящик**, отличный от почты владельца и партнёра N3: самореферал отклоняется. Открывайте письмо подтверждения в том же приватном окне, где зарегистрировались. Старый аккаунт Proofwall, созданный до перехода по ссылке, не получает атрибуцию задним числом.

## Сценарий на 5–10 минут

1. В приватном окне откройте именно партнёрскую ссылку:
   https://n3-a.212.192.0.33.sslip.io/r/cb8662f3-8deb-494a-a220-e27fbbebf354
2. Вы попадёте на https://proofwall.aicoding.space/ . Служебные параметры исчезнут из адреса; атрибуция сохранится в защищённой cookie. Создайте аккаунт: почта, пароль, название проекта и свободный адрес проекта.
3. В кабинете найдите **«Партнёрская покупка»**. Нажмите **«Отправить письмо подтверждения»**. Откройте ссылку из письма в том же приватном окне и явно нажмите **«Подтвердить»**. Простое открытие письма/ссылки не подтверждает почту.
4. Вернитесь в кабинет. Дождитесь сообщения **«партнёрская регистрация сохранена»**. Обычно доставка занимает один цикл worker — около 5 секунд; при временном отказе следующий повтор начинается через 60 секунд.
5. Нажмите **«Оплатить 30 дней»**. Проверьте сумму **990 ₽**. Завершите оплату на странице тестового магазина ЮKassa, используя тестовые реквизиты из кабинета/инструкции провайдера. Не вводите настоящую банковскую карту.
6. Вернитесь в Proofwall. Должны появиться **«Оплачено до»** и **«Тестовая оплата подтверждена»**. Возврат со страницы оплаты сам по себе не активирует тариф — требуется подтверждённое уведомление.
7. В обычном окне обновите кабинет N3, выберите вашу организацию с ролью **«партнёр»** и нажмите **«Обновить данные»**. При текущей ставке 20% новая покупка добавит **198 ₽ тестовой комиссии**. Если в программе уже были тестовые покупки, смотрите прирост, а не абсолютный итог.
8. Покажите участникам, что **доступная к выплате сумма не выросла**: тестовые комиссии видны отдельно и не попадают в реестр реальных выплат. Обновите страницу и при необходимости снова выберите роль партнёра — начисление сохраняется на сервере.

## Дополнительный показ возврата

В кабинете тестового магазина ЮKassa выполните частичный возврат **495 ₽** по этой покупке. После подтверждения и доставки в N3 комиссия именно этой покупки станет **99 ₽**. Повторное уведомление не снимает её второй раз. Proofwall показывает **«Срок тарифа требует ручной проверки»**: возврат не выдаётся за автоматически пересчитанный срок тарифа.

## Если цепочка остановилась

| Что видно | Что проверить |
|---|---|
| Письмо не пришло | Спам, правильность адреса; сообщение об ошибке доставки в UI. Не создавайте новую оплату до подтверждения. |
| Ссылка подтверждения отклоняется | Откройте её в том же браузерном сеансе; после выхода/смены пароля запросите новое письмо. |
| Почта подтверждена, регистрация ещё не сохранена | Дайте worker выполнить повтор; оператор проверяет очередь и действительность ключа. |
| Оплата отменена | Снова нажмите оплату, затем используйте предложенное действие новой покупки после подтверждённой отмены. Не сбрасывайте ключ вручную при сетевой ошибке. |
| ЮKassa показывает успех, тариф не обновился | Проверить доставку на существующий webhook Proofwall `https://proofwall.aicoding.space/api/webhooks/payment`; не менять его на webhook N3. |
| Тариф активирован, комиссии ещё нет | Обновить N3 и дождаться worker; оператор сверяет outbox, ответ API и магазин. Не оплачивать повторно ради появления комиссии. |
| Видна другая организация | Выберите нужную организацию и роль партнёра в рабочем кабинете. |

## Что проверено, а что остаётся подтвердить вручную

- Изолированный браузерный E2E прошёл всю цепочку на настоящем коде Next/worker/N3: регистрация, подтверждение, оплата, 198 ₽, дубли, возврат до 99 ₽, мобильный интерфейс. **Resend и ЮKassa в этом прогоне имитировались.**
- После развёртывания прошли 49 публичных UI-проверок A–D, публичный переход по указанной ссылке и проверка защищённой cookie на desktop/mobile.
- Настоящий Proofwall backend проверенно обращается к публичному N3 HTTPS API с установленным ключом. Тестовый магазин настроен; ключи не попадают в браузер/GitHub.
- **Доставка настоящего письма и законченная покупка через настоящий TEST API ЮKassa ещё не подтверждены этим прогоном.** Именно шаги 3–8 выше завершают такую приёмку. Это не объявление готовности к боевому приёму денег.
