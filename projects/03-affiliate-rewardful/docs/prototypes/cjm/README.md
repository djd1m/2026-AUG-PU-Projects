# Четыре HTML CJM — checkpoint до PRD

Откройте **index.html** в браузере или любой вариант отдельно:

- variant-a.html — владелец запускает программу, проверяет начисление и выгружает ручной реестр.
- variant-b.html — клиент рекомендует продукт и получает бонус на подписку.
- variant-c.html — партнёр видит условия, личные начисления и дату ручного перевода.
- variant-d.html — личный агент готовит реестр; владелец проверяет версию и продолжает вручную, агент партнёра запрашивает только личный статус.

Каждый HTML автономен: CSS, JavaScript и Rubik встроены, сеть и установка пакетов не нужны. Рабочее имя — «Круг», визуальная основа — Rewardful. Все оплаты, события и суммы демонстрационные. CSV и файл выбора скачиваются локально; никакой регистрации, рассылки или денежных операций нет.

Кнопки A/B/C/D переключают сценарии. Нижняя карта позволяет открыть любой из шести экранов; это режим просмотра, не production onboarding gate. «Сравнить» показывает различия, оценки, выбор варианта и составление сочетания. JSON выбора не отправляется автоматически — передайте его или назовите вариант в беседе. Цена, комиссия, credits и сроки удержания — гипотезы. Ручные выплаты за прошлый месяц до5-го — решение владельца.

## Сборка и проверка

Исходники в assets/. Сборка без зависимостей:

```sh
python3 scripts/build.py
node --check assets/app.js
node --check assets/data.js
node --check assets/agent-flow.js
```

`tests/browser-check.js` — браузерный сценарий для исполнения через WebDriver execute/sync после свежей загрузки. Проверяет 24 экрана, overflow, состояние повторного платежа после возврата, ставку и ссылку вступления, opt-in, однократное применение бонуса, роли и выбор. Выбор после теста очищается. Это проверка поведения прототипа, не платёжной интеграции.

`tests/mobile-harness.html` создаёт iframe с реальным CSS viewport390×844: media queries работают относительно390px. Использован из-за минимального размера outer window Firefox500px. Это responsive проверка в desktop Firefox, не испытание Safari/Android.

Лицензия Rubik — assets/OFL.txt. Собственная реализация UI, чужой CSS не включён. Источники и измерения — ../../source-product-profile.md. PRD не создан, ожидается решение владельца.

Агентный вариант D — новый способ доступа к тем же возможностям, а не отдельный сегмент. MCP/A2A отражены в сценариях, работающих серверов протоколов нет. Обоснование: ../../discovery/agent-interface-cjm.md.

`tests/agent-check.js` проверяет ограничение/отзыв/истечение доступа, запрет выгрузки неутверждённой версии, перенос исправленного реестра в ручной UI, актуальность объяснения, личный scope и отмену задачи. Итог:31 проверки на desktop и31 на mobile. `four-cjm-*-results.json` — текущая регрессия всех24 экранов,91 проверка на каждом viewport. Старые73-check файлы оставлены как исторический baseline первой версии.
