# Вариант C — Кабинет партнёра

Рабочий F1: условия до согласия, личная ссылка, история собственных комиссий по историческим правилам и статус ручной выплаты. [PRD](docs/PRD.md) · [CJM](prototype/index.html) · [Приёмка](../../docs/features/c-partner/05_completion.md).

Публичный UI: https://n3-c.212.192.0.33.sslip.io/ — без SSH. [Сценарий демонстрации](https://n3-c.212.192.0.33.sslip.io/demo.html). При запуске сначала общий backend, затем `docker compose -f variants/c-partner/docker-compose.yml up -d --build --wait` из корня N3. Перед запуском проверить свободные порты корневым скриптом. БД без host ports, отдельная internal-сеть только backend.

Обычный кабинет работает без merchant-полномочий. Операторская лаборатория открывается явно и только в полном fixture-сеансе. Она может имитировать отметку отправки; реального перевода и подтверждения зачисления нет. Все данные синтетические.
