# Вариант D — поручение агенту

D работает с общим API: ограниченная делегация на 10 минут, повторяемые задачи, отзыв/истечение доступа, отмена и поздний ответ, пересчёт реестра после возврата и продолжение в A. Владелец отдельно утверждает точную версию и скачивает CSV; деньги не отправляются.

[Сценарий демонстрации MD](docs/demo.md) · [HTML](docs/demo.html) · [Как открыть UI через SSH](../../docs/demos/index.md) · [PRD](docs/PRD.md).

UI: http://127.0.0.1:13034/ после SSH-туннеля. Инструкция: http://127.0.0.1:13034/demo.html. Перед показом нажмите «Новый сеанс». Для каждой роли начинайте свежую ветку; переход D → A сохраняет тот же серверный артефакт.

Из корня проекта: `docker compose -f variants/d-agent/docker-compose.yml up -d --build --wait`. Перед запуском проверьте порт13034. Нужны уже работающие общие API/БД и сеть n3-frontend. БД не имеет host ports и не подключена к frontend-сети.

Приёмка: 10 критериев, 13/13 Firefox-тестов (12 сценариев), desktop1440/mobile390, независимое ревью. Общий итог A–D49/49. F1 runner детерминированный: реальные LLM и MCP/A2A wire здесь отсутствуют, usage:null. [Подробные результаты](../../docs/Completion.md).
