# Вариант B — Бонус клиенту на подписку

Рабочий стенд F1: добровольное участие после публикации демовиджета, личная ссылка, история бонусов и резервирование для счёта. Реальные платежи не проводятся.

[PRD](docs/PRD.md) · [Исходный CJM](prototype/index.html) · [Приёмка и тесты](../../docs/features/b-customer/05_completion.md).

На VPS интерфейс: https://n3-b.212.192.0.33.sslip.io. Для просмотра с компьютера: `ssh -L 13031:127.0.0.1:13031 -L 13032:127.0.0.1:13032 <ваш-VPS>`, затем открыть https://n3-b.212.192.0.33.sslip.io. Лаборатория встраивания: https://n3-a.212.192.0.33.sslip.io/_fixtures/embed-host.html.

Сначала запустите общий backend из корня проекта, затем `docker compose -f variants/b-customer/docker-compose.yml up -d --build --wait`. Перед запуском обязательна проверка свободных портов корневым скриптом. БД без опубликованных портов и доступна только backend; frontend подключён к отдельной сети.

Кнопки в лаборатории оператора создают только fixture-события в явном merchant-контексте. Неизвестный результат биллинга сохраняет резерв; подтверждённый отказ освобождает его, успех применяет к счёту.
