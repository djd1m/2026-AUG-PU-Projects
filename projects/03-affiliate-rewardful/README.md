# 03. Партнёрская программа за 15 минут

> **Неделя 03** · `партнёрка` · референс: **Rewardful (2800+ бизнесов)**

## Что делаем

Аналог Rewardful: трекинг рефералов по cookie, вебхуки оплаты, авто-расчёт рекуррентных комиссий, дашборд партнёра.

**Целевой стек:** трекинг по cookie, вебхуки оплаты (Stripe/ЮKassa), дашборд партнёра

## Механики роста (обязательный блок)

Главный продукт — не прототип, а **рост**: аудитория и выручка. В требования закладываем на этапе дизайна, а не после.

| Драйвер | Гипотеза для этого проекта |
|---|---|
| **Виральность** | Продукт САМ является механикой роста: каждый клиент запускает партнёрку, а его партнёры видят наш брендированный дашборд. Классический B2B2C-loop. |
| **Партнёрка** | _заполняется по итогам `/research/GROWTH-MECHANICS-REQUIREMENTS.md`_ |
| **Блогеры / люди с аудиторией** | _заполняется по итогам `/research/GROWTH-MECHANICS-REQUIREMENTS.md`_ |
