### P1 — предел 5 отправок в час с адреса на проект

Проверено живьём: 1–5-я отправка → 201, **6-я и 7-я → 429**. Весь зал сидит за одним NAT, то
есть под одним адресом. Если предложить «оставьте отзыв со своего телефона по Wi-Fi» — пройдут
первые пятеро, шестой получит красную ошибку.

Репетировать не больше трёх раз; зрителям предлагать мобильный интернет, а не Wi-Fi зала.

### P1 — партнёрскую программу показать нечем

Партнёрских кодов, комиссий и атрибуций в базе **ноль**. Страница `/partner` открывается и
просит ключ доступа, которого не существует. Не открывать.

### P2 — оплата это заглушка, и она видна

`PAYMENTS_STUB=true`, реквизиты ЮKassa пусты. `POST /api/checkout` честно отвечает
`{"stub": true}` с несуществующим адресом. Кнопки оплаты в кабинете нет вообще. Про платный
тариф говорить словами.

### P2 — кириллическое название даёт мусорный адрес

Транслитерации нет: «Демо Проба» превращается в слаг `f5q`. В боевой базе виден живой след той
же грабли — проект `https-projects-aicoding-space`. **Вводить латинское название**, тогда адрес
получится читаемый на экране.

### Подготовить заранее — иначе сюжет не покажется

- **Файл со снимком отзыва** на машине показа: JPEG, PNG или WebP до 5 МБ. Годится настоящий
  скриншот любого отзыва — свой, из мессенджера, с карты. Без файла шаг 2:45 придётся делать
  только ссылкой.
- **Ссылка на реальный отзыв** у площадки, скопированная в буфер: проверяется хост, `http` и
  чужой домен будут отклонены с названием причины.

### ⛔ Чего НЕ делать

- **Не запускать `docker compose up` / `npm run up`** — поднимется `caddy` и упрётся в занятые
  порты 80/443 чужого прокси, стек упадёт посреди показа. Стенд обслуживает внешний
  `ai-hub-tls-proxy`; если перезапуск всё же нужен — только с demo-оверрайдом.
- **Не показывать получение письма** восстановления — см. риск R-2.
- **Не открывать** `.env` и файл с учётными данными демо-аккаунта.
- **Не утверждать, что виджет проверен на чужом сайте** — проверен на чужом Origin в заголовке.
- **Жёстко перезагрузить каждую вкладку** (Ctrl+Shift+R): вкладка, открытая до пересборки,
  молча роняет кнопки «Создать проект» и «Опубликовать».

## Прогон · часть 2 — техника, 10–12 минут

Сквозная мысль: **дефект живёт в стыке, а не в модуле.** Четыре худших дефекта этого проекта
имели одинаковую форму — каждая часть по отдельности правильная, а ломалось допущение, которое
одна часть делала о другой и которое нигде не проверялось. Юнит-тесты зелёные, контейнеры
здоровы, дефект в проде.

### 1. «Оплата не применялась НИКОГДА» (2 мин, сильнейший сюжет)

Обработчик вебхука ЮKassa ставил заявку на `event_id` **шагом 2**, а перезапрашивал статус у
провайдера **шагом 3**. Перезапрос — это и есть подтверждение подлинности: у ЮKassa **нет
подписи уведомления**, тело запроса не источник истины.

Недоступность провайдера выражалась **возвращаемым значением**, а не исключением. Колбэк
транзакции завершался штатно — и транзакция **коммитилась вместе с заявкой**. Дальше: маршрут
отдавал 500, ЮKassa честно повторяла уведомление, повтор упирался в **уже занятый** `event_id`
и коротил в «дубликат» с кодом 200.

> **Деньги списаны, тариф не повышен, повторить нечем.** Не «иногда», а всегда, когда провайдер
> недоступен в момент первой доставки.

**Лечение — одна строка:** `throw` вместо `return`, потому что откат транзакции освобождает
заявку.

**Что показать:** шапку файла роута (строки 1–13) — **файл нарушал инвариант, записанный в его
собственной шапке**. Комментарий не исполняется.

```bash
git log -1 --format=%B 0501766
```

**Чем доказано:** пять новых тестов, из них три — стражи по исходнику; испытаны на способность
падать: **с возвращённым дефектом `2 failed | 35 passed`, после починки `37 passed`». Ни один из
408 тестов проекта этого раньше не покрывал.

### 2. Страж, который стережёт свойство КОДА, а не один прогон (1 мин)

Тест **читает исходник** роута, срезает комментарии и утверждает три свойства текста:
`return 'provider_unavailable'` не встречается; ветка недоступности провайдера бросает; индекс
`status: 500` больше индекса `catch` — то есть 500 физически отдаётся снаружи транзакции.

Плюс тест-инвентаризация: число `AbortSignal.timeout(` не меньше числа `await fetch(` — у
каждого внешнего вызова есть верхняя граница ожидания. Найдено ложной посылкой в документах:
проверка утверждения «письмо будет первым внешним вызовом проекта» вскрыла, что у вызовов к
ЮKassa таймаута не было **вообще** — при том что вызов происходит **внутри транзакции** и
удерживает соединение общего пула.

Такой приём применён в **14 файлах тестов**.

### 3. BASE_URL: у внешнего адреса нет права на дефолт (1,5 мин)

Переменная лежала в `.env`, но **compose её не пробрасывал**. Дефолт `http://localhost:3000`
сработал — приложение стартовало, 408 тестов зелёные, все страницы открывались, — и **каждая
выданная владельцу ссылка** (форма, стена, сниппет виджета, ссылка бейджа) вела на машину
посетителя. Петля роста была разомкнута на публичном экземпляре. **Нашёл владелец продукта, а
не проверка.**

Правило, выросшее отсюда: значение, определяющее то, что продукт отдаёт **наружу**, дефолта
иметь не должно. Разумный дефолт превращает «неправильно настроено» в «молча неверно» — снимает
единственный дешёвый сигнал, падение при старте.

Разбор собственного промаха, записанный в коммит: UI-проверка запускала контейнер через
`docker run -e BASE_URL=…`, то есть **в обход compose** — проверялась своя команда, а не
конфигурация, которая идёт в дело. Лечение — сквозной скрипт по пути клиента, где ключевая
проверка не «ссылка есть», а **«ссылка ведёт сюда»**.

```bash
bash scripts/check-cjm.sh https://proofwall.aicoding.space   # 18 шагов, все зелёные
```

### 4. Пустая маска CIDR читалась как «принимать любой адрес» (1 мин)

`"1.2.3.4/"` — опечатка, но `Number('')` равен нулю, то есть без проверки такая запись означала
бы префикс `/0`, а `/0` — «пускать всех». **Одна опечатка в списке = выключенная аутентификация
вебхука.**

Вторая ловушка того же модуля: `185.71.76.0/27` покрывает `.0–.31`, но **не** `.100` — хотя
строковый префикс совпадает. Сравнение строкой недопустимо.

Третье решение того же класса: список сетей **зашит в код**, не в переменную окружения —
вынесенный наружу, он однажды приедет пустым, а пустой allowlist читается как «фильтра нет».

### 5. Обходимый rate limit: дефект в стыке (1,5 мин)

Caddy **дописывает** адрес пира в конец `X-Forwarded-For`, поэтому доверять можно только
последнему элементу — **код был верен**. Но compose **публиковал порт** `web`, значит прокси
можно обойти и прислать свой единственный заголовок — «последний элемент» становится значением
атакующего.

Воспроизведено на живом контейнере: **с ротацией заголовка прошли 7 запросов при пороге 5**; с
одним адресом — 5 и затем 429.

Ни код, ни конфигурация по отдельности не были сломаны. Лечение структурное: `expose:` вместо
`ports:`, а условие теперь не подразумевается, а проверяется скриптом — и скрипт проверен в обе
стороны.

### 6. Двойной CORS: curl подтверждает работоспособность сломанного (1,5 мин)

`Access-Control-Allow-Origin` ставили **оба** — и Caddy, и приложение. Браузер отвергает ответ с
двумя такими заголовками **целиком**: виджет не грузился ни на одном чужом сайте, петля роста
была разомкнута.

**Обнаружено только в браузере.** `curl` показывает оба заголовка и выглядит нормально, потому
что политику CORS не применяет вовсе.

```bash
curl -sI -H "Origin: https://example.com" \
  "https://proofwall.aicoding.space/api/widget/config?slug=demo" | grep -i access-control
# сейчас: ровно один
```

**Честная деталь как остаточный след:** комментарий в коде роута до сих пор утверждает «Caddy
ставит тот же заголовок в проде» — это неправда с момента починки. Комментарий разошёлся с
конфигурацией молча. Ещё одна иллюстрация к тезису «комментарий не исполняется».

### 7. Граница FTC, закреплённая тестом (1 мин)

Правило FTC 16 CFR Part 465 (в силе с 21.10.2024) прямо запрещает отзывы, сгенерированные ИИ;
штраф до **$53 088** за нарушение.

Граница проведена **архитектурно**: сервис расшифровки — единственный, получающий ключ OpenAI;
`web` и `worker` его не получают вовсе. Контрактный тест утверждает: зарегистрирован **ровно
один** маршрут, он принимает только `video_url`, а постороннее поле `text` **отвергается**
strict-схемой, а не игнорируется молча.

То есть «переписать отзыв нейросетью» физически некуда отправить — граница не в документе и не
в промпте, а в тесте.

```bash
cd services/transcribe && npx vitest run   # 9 passed, 0,6 с
```

Воркер стартовал раньше миграций, падал на `relation "testimonials" does not exist` и **лежал

## Опорные формулировки

### Открывающая история (60 секунд)

> «Клиенты вас хвалят — в переписке, голосом, письмом. Похвалы разбросаны: скриншот в
> мессенджере, письмо в почте, комментарий в соцсети. А на сайте пусто, и новый посетитель не
> понимает, можно ли вам доверять.
>
> Владелец получает ссылку и отправляет её довольному клиенту. Тот переходит и оставляет отзыв —
> ничего не устанавливая и нигде не регистрируясь. Владелец решает, что показывать. Одобренное
> складывается в публичную стену и в блок, который вставляется на чужой сайт одной строкой.»

**Для кого:** инди-хакер с одним SaaS — запуск на Product Hunt через неделю, успех — стена
отзывов на лендинге за вечер. Вторично — агентство с 5+ клиентами.

### Главная мысль

> «Фича, которую видят только твои пользователи, не растит продукт. Растит та, которую видят
> чужие.»

Отсюда несущая конструкция — **петля бейджа**: виджет живёт на сайте клиента, каждый посетитель
этого сайта видит наш бренд, часть приходит к нам и ставит виджет у себя. Это единственный
канал, работающий **вообще без нашего трафика**.

Практическое следствие: бейдж — часть тарифной архитектуры **с первого дня**, а не фича на
вторую неделю. И решение о нём принимает **только сервер**: виджету поле тарифа не передаётся
вообще — иначе бейдж снимался бы из devtools, и канал ломался бы в первую же неделю.

### Про цену — говорить честно

**Числа нет.** Цена платного тарифа — открытое решение владельца, в дорожной карте висит как
`blocked`. В коде есть дефолт 990 ₽, но это конфигурация, а не принятая цена. Ориентир рынка: у
референса Senja Free $0 → Starter ~$29 → Pro ~$59; дно категории — $9.

### Метрика недели

**Число установленных виджетов на внешних доменах, цель 10 за неделю.** Интерпретация задана
заранее: меньше 5 — петля не запустилась; 5–20 — рабочий диапазон; больше 20 — проверить на
накрутку, прежде чем радоваться. Число названо честно как **гипотеза, а не расчёт**.

Считаем **сайты, а не людей**: один владелец с пятью сайтами даёт впятеро больше показов, чем
пятеро с одним.

## Возражения

**«Зачем это, если есть Senja за $19–29?»**
Прямой ответ: **как бизнес — незачем, и в документах это написано открытым текстом.** Разведка
называет категорию red ocean с дном цены $9 и делает вывод: клон-в-лоб конкурирует ценой и
проигрывает. Решение — не конкурировать ценой вообще, а конкурировать **скоростью до первого
виджета**. Дальше то, ради чего проект делался: это учебный прогон конвейера. Ценность в том,
что за неделю от разбора чужого продукта до работающего стенда с петлёй роста проходится
воспроизводимо.

**«Отзывы легко подделать»**
Три разных страха — три разных ответа. (1) Генерация отзыва ИИ закрыта архитектурно: в продукте
**нет пути**, где модель порождает текст. (2) Отравленный отзыв как атака на клиента:
экранирование на **рендере**, а не на приёме — текст сохраняется побайтово, а не исполняется.
(3) Демо-данные помечены **в двух местах** — в данных и на экране; пометка привязана к данным, а
не к адресу страницы: уберёшь демо-строки — отметка исчезнет сама.

**«Виджет замедлит мой сайт»**
**2,6 КБ в сжатом виде при бюджете 30 КБ.** Не блокирует рендер страницы-хозяина, p95 отрисовки
≤ 300 мс. Обратную сторону назвать самому: виджет может сломать вёрстку хозяина — ответ на это
Shadow DOM, изоляция **двусторонняя**.

**«А если клиент напишет плохое?»**
Модерация — обязательная часть контура, а не опция. На стене видно только одобренное. Честная
оговорка вслух: правовая рамка «что владелец обещает автору отзыва» пока **не написана** —
решение висит открытым.

**«Чем это лучше скриншотов из телеграма?»**
Скриншот не встраивается · не машиночитаем (на стене рендерится разметка `schema.org/Review`,
которую читают поисковики и AI-движки) · не проверяем (у отзыва есть статус, автор, источник и
журнал модерации) · ничего не растит.

### Честные ограничения — назвать самому

1. **Импорта с площадок нет** — ядро оригинала, за неделю не реализуемо. Цена решения записана
   прямо: без импорта продукт **слабее оригинала по активации**, первый отзыв владелец добывает
   сам.
2. **Цена не решена**, текст ToS не написан, домен для публичных стен — открытый вопрос.
3. **Реальный путь оплаты не проверен на живом магазине** — нет ключей. Проверены заглушка,
   отказ без учётных данных, идемпотентность, апгрейд тарифа.
4. **Аудио уходит третьей стороне** (OpenAI) — назван осознанный размен; маршрут переигровки —
   self-hosted Whisper.
5. **Сценарий без цели**: один проверочный сценарий проверяет функцию, которой нет ни в одном
   требовании — она официально отложена. Нашёл финальный гейт. Проверка, которой нечего
   проверять, выглядит как работающая.
