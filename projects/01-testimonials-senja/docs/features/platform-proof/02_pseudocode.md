# Отзыв с площадки · Алгоритмы

## Добавление владельцем (кабинет, под сессией)

```
POST /api/testimonials/platform      multipart/form-data
  сессия обязательна → account_id; проект резолвится по slug И принадлежности аккаунту
  поля: name, role, text, platform, source_url?, screenshot?

  1. проверить платформу: из закрытого списка, иначе отказ
  2. ссылка, если дана: https + хост из списка этой платформы, иначе отказ С ПРИЧИНОЙ
  3. снимок, если дан: сигнатура содержимого (не расширение и не заявленный тип),
     SVG отвергнуть, размер ≤ 5 МБ
  4. ЕСЛИ нет ни ссылки, ни снимка → отказ: «нужна ссылка или снимок»
  5. снимок в хранилище, тем же путём, что фото автора
  6. INSERT source='platform', status='pending'    # та же модерация, что у всех
```

Порядок несущий: проверки — **до** записи в хранилище. Иначе отвергнутый отзыв оставляет за собой
файл, который никто не удалит.

## Рендер — обе поверхности одинаково

```
карточка отзыва:
    текст
    если screenshot: <img> как СОДЕРЖИМОЕ карточки (не аватар), с открытием в полный размер
    если source='platform':
        подпись «Отзыв с <площадка>»
        если source_url: подпись — ссылка, rel="nofollow noopener", target="_blank"
    автор, роль, аватар (как было)
```

Пометка источника ставится **всегда** при `source='platform'`, даже когда ссылки нет: читатель
обязан знать, что смотрит на перенесённое, а не на написанное здесь. Ссылка делает пометку
проверяемой, но её отсутствие не отменяет обязанности пометить.

## Разметка для поисковиков

У отзыва с площадки в структурированных данных **не указывается**, что он оставлен на нашем
сайте. Утверждать обратное значило бы приписывать себе чужой сбор.
