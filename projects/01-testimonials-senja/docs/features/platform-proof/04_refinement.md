# Отзыв с площадки · Тесты и мутации

| T | Сценарий | Ловит |
|---|---|---|
| P-1 | Полный круг: владелец добавляет отзыв со ссылкой → модерация → виден на стене и в виджете с пометкой | что фича вообще работает |
| P-2 | Ни ссылки, ни снимка → отказ; в базе **ничего не создано** | отзыв без доказательства маскируется под перенесённый |
| P-3 | Ссылка на `http`, на чужой хост, не-ссылка → отказ **до** записи и **до** загрузки снимка | проверка после сохранения оставляет мусор |
| P-4 | Ограничение БД: попытка вставить `source='platform'` без обоих полей **прямым запросом** | защита только в коде |
| P-5 | Обратное ограничение: `source='form'` со ссылкой отвергается СУБД | поля источника у не-переносного отзыва |
| P-6 | SVG под видом PNG отвергнут; тип берётся из сигнатуры | тот же класс, что у фото автора |
| P-7 | Пометка источника видна **и** на стене, **и** в ответе конфига виджета | одна поверхность обновлена, вторая забыта |
| P-8 | Снимок рендерится как содержимое, а не в слоте аватара (страж по разметке) | «переиспользовали photo_url» |
| P-9 | XSS: имя и текст с разметкой не исполняются ни на стене, ни в виджете | экранирование забыто на новом пути |
| P-10 | Ссылка получает `rel="nofollow noopener"` и `target="_blank"` | чужая площадка получает вес и доступ к `window.opener` |
| P-11 | Размер бандла виджета после правки ≤ 30 КБ | бюджет проверен, а не предположен |

## Мутации

## Чего тесты не проверяют

Что ссылка ведёт на отзыв **об этом заведении** — проверить это нечем, публичного API отзывов у
площадок нет. И что владелец имеет право публиковать чужой снимок: это вопрос оферты, а не кода.
