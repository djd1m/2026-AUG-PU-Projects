## Конкурентная проверка (P4)

Идемпотентность обязана держаться **при одновременных** импортах того же файла, а не только
при последовательных. Последовательный тест зеленеет и на проверке-перед-вставкой:

```
два одновременных импорта одного содержимого -> суммарно вставлено ровно N, а не 2N
```

Это то же требование, что `shared-resource-verification.md` ставит третьим пунктом:
последовательный тест не отличает ограничение БД от проверки в коде, а разница между ними —
ровно окно между чтением и записью.

## Соотношение пределов

Отдельная проверка, без которой предел строк существует только на бумаге:

```
MAX_IMPORT_ROWS строк по 200 символов текста и 40 имени обязаны помещаться в MAX_IMPORT_BODY
```

Если не помещаются, до проверки числа строк дело не дойдёт никогда — сработает `413`, и
сообщение будет о размере, а не о числе строк. Владелец не поймёт, что делать.
