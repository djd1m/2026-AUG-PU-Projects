## Принимаемые риски

**1. Приоритет фичи не решён.** `DEC-003` — решение владельца, и оно не принято. Фича
сделана; когда её показывать пользователям — не вопрос этого документа.

**2. Импорт видео и фото не поддерживается.** CSV несёт текст. Файлы требуют второго канала
и отдельной фичи.

**3. Импорт с внешних площадок по API не поддерживается.** Референс умеет 30+ интеграций,
каждая — отдельная работа. CSV покрывает общий знаменатель: выгрузить умеет почти любая
площадка.

**4. Отпечаток строится по имени и тексту.** Два РАЗНЫХ отзыва с одинаковым именем автора и
одинаковым текстом будут считаться одним. Это осознанно: такие строки неразличимы и для
человека.

**5. Формулы в ячейках не обезвреживаются.** Ячейка `=1+1` попадёт в текст отзыва как текст
`=1+1` — на стене и в виджете это безопасно, React экранирует. Опасность возникла бы при
ОБРАТНОЙ выгрузке в Excel, а выгрузки в продукте нет. Записано, чтобы при её появлении
вопрос был задан, а не открыт заново с нуля.
