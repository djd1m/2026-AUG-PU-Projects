# Справочник API

Базовый адрес — значение `BASE_URL`. Все тела — JSON, если не указано иное.

Аутентификация владельца — cookie `pw_session`, `httpOnly`. Токен **никогда** не
возвращается в теле ответа: иначе его прочитал бы любой скрипт на странице.

## Публичные маршруты (без входа)

### `POST /api/auth/register`

Создаёт аккаунт и первый проект, сразу выдаёт сессию.

```json
{
  "email": "owner@example.com",
  "password": "не короче 12 символов",
  "desired_slug": "acme",
  "project_name": "Acme"
}
```

`201`:

```json
{
  "account_id": "uuid",
  "project_slug": "acme",
  "urls": {
    "submission_form": "https://ваш-домен/f/acme",
    "wall_of_love":    "https://ваш-домен/w/acme",
    "dashboard":       "https://ваш-домен/dashboard/acme",
    "widget_snippet":  "<script src=…></script>"
  }
}
```

Адреса в `urls` строятся от `BASE_URL`. Если он не задан, все они укажут на
`http://localhost:3000` — при этом ответ будет `201`, и ошибку видно только по содержимому.

| Код | Причина |
|---|---|
| `400` | Тело не JSON, или поля не прошли проверку (список в `errors`) |
| `409` | Слаг занят |

### `GET /api/projects/slug-available?slug=acme`

`200` → `{ "available": true | false }`

### `POST /api/testimonials`

Отправка текстового отзыва. Принимает `application/json` или `multipart/form-data`
(второе — когда прикладывается фото).

Поля: `slug` (обяз.), `name` (обяз.), `role`, `text` (обяз.), `photo` (файл, только в
`multipart`).

`201` → `{ "public_id": "…" }`

| Код | Причина |
|---|---|
| `400` | Поля не прошли проверку; фото не JPEG/PNG/WebP, больше 5 МБ, или содержимое не соответствует заявленному типу |
| `404` | Слаг не найден |
| `429` | Превышен лимит 5 отправок в час с одного IP |

Текст принимается **как есть**, без вычищения разметки. Обезвреживание — при рендере.
Это сознательное решение: очистка на входе теряет исходный текст безвозвратно и всё
равно не защищает те места, где отзыв выводится в другом контексте.

### `POST /api/testimonials/video`

Только `multipart/form-data`. Поля: `slug`, `video` (файл, до 100 МБ), `name`, `role`,
`text_caption`, `duration_sec`.

`201` → `{ "public_id": "…" }`. Расшифровка ставится в очередь и появляется позже
отдельным полем.

### `GET /api/widget/config?slug=acme&domain=example.com`

Настройки виджета. **`badge_required` вычисляет сервер** по тарифу проекта — параметра,
которым клиент мог бы на это повлиять, не существует.

### `POST /api/widget/badge-click`

Учёт перехода по подписи. Всегда `204`, в том числе при некорректном теле: это счётчик,
он не должен ничего сообщать вызывающей стороне.

### `GET /api/photo/<ключ>`

Отдаёт фото с типом, определённым сервером **по содержимому файла**, и заголовком
`X-Content-Type-Options: nosniff`.

### `POST /api/webhooks/payment`

Уведомление ЮKassa. Тело: `{ "event": "...", "object": { … } }`.

Провайдер **не подписывает** уведомления, поэтому подлинность подтверждается двумя
способами сразу:

1. адрес источника принадлежит опубликованному списку сетей ЮKassa;
2. статус платежа перезапрашивается через API провайдера.

Повторная доставка того же события безопасна: идемпотентность обеспечена уникальным
ограничением в базе, а не проверкой «есть ли уже такая запись» перед вставкой — иначе
две одновременные доставки прошли бы обе.

## Маршруты владельца (нужна сессия)

### `POST /api/testimonials/<id>/moderate`

```json
{ "status": "approved" }
```

Допустимые значения: `pending`, `approved`, `rejected`, `hidden`.

| Код | Причина |
|---|---|
| `400` | Недопустимый статус или недопустимый переход (в тексте ошибки указано, из какого в какой) |
| `403` | Отзыв принадлежит чужому проекту |
| `404` | Не найден, либо идентификатор не UUID |
| `409` | Состояние изменилось между чтением и записью |

### `POST /api/checkout`

```json
{ "slug": "acme" }
```

`200` → `{ "redirect_url": "…", "stub": true|false }`

`stub: true` означает, что включён `PAYMENTS_STUB` и реального обращения к провайдеру
не было. `501` — платежи не настроены, `502` — провайдер недоступен.

### `POST /api/share`

Отмечает, что владелец **подтвердил** намерение поделиться. До вызова этого маршрута
приложение не обращается ни к каким внешним сервисам — это свойство проверяется
отдельным тестом, читающим исходный код компонента.

## Страницы

| Адрес | Что отдаёт |
|---|---|
| `/` | Витрина продукта |
| `/f/<слаг>` | Форма сбора отзыва |
| `/w/<слаг>` | Wall of Love, серверный рендер, разметка `schema.org/Review` |
| `/dashboard/<слаг>` | Кабинет владельца |
