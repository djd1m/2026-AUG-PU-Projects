## Коротко о системе

Распределённый монолит в монорепозитории: Next.js 15, PostgreSQL с изоляцией арендаторов
на уровне строк, MinIO для видео и фото, отдельный сервис распознавания речи. Развёртывание —
Docker Compose за Caddy.

Наружу опубликован только Caddy. Порты хранилищ не публикуются никогда — это архитектурный
инвариант, а не настройка.

## Проверки перед сдачей

```bash
bash ../../scripts/check-port-conflicts.sh .   # БД не опубликована, порты свободны
bash scripts/check-env-wiring.sh               # переменные доезжают до сервисов
bash scripts/check-cjm.sh "$BASE_URL"          # путь клиента проходит целиком
npm test                                       # 408 проверок в 35 файлах
```
