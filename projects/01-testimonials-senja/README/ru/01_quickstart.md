# Быстрый старт

Проект поднимается одним стеком Docker Compose: приложение, воркер транскрипции,
сервис распознавания речи, Postgres, MinIO и Caddy.

## Требования

- Docker + Docker Compose v2
- Node.js 20+ — только для запуска тестов с хоста; само приложение собирается в контейнере
- Свободные хостовые порты (проверяются скриптом, см. шаг 2)

## Пять команд

```bash
# 1. Конфигурация
cp .env.example .env
# заполнить POSTGRES_PASSWORD, MINIO_ROOT_*, S3_*, SESSION_SECRET, BASE_URL, APP_DOMAIN
# пароли генерировать, а не придумывать:  openssl rand -hex 24

# 2. Проверить, что нужные порты свободны — ДО запуска
bash ../../scripts/check-port-conflicts.sh .

# 3. Поднять стек
docker compose up -d --build

# 4. Применить миграции
docker compose exec web npm run migrate --workspace packages/db

# 5. Убедиться, что путь клиента проходит целиком
bash scripts/check-cjm.sh "$BASE_URL"
```

## Обязательные переменные

Без них приложение **стартует**, но ведёт себя неправильно — поэтому шаг 5 обязателен.

| Переменная | Зачем | Что будет, если забыть |
|---|---|---|
| `BASE_URL` | От неё строится **каждая** выдаваемая наружу ссылка: форма сбора, витрина, сниппет виджета, ссылка на badge | Все ссылки укажут на `http://localhost:3000`, то есть на машину посетителя |
| `SESSION_SECRET` | Подпись токена сессии | Сессии владельцев невалидны |
| `POSTGRES_PASSWORD` | Пароль БД | **Не оставлять дефолтным.** Открытая БД с паролем `postgres` уже приводила к компрометации сервера майнером |
| `S3_*`, `MINIO_ROOT_*` | Хранение видео и фото | Загрузки падают |
| `APP_DOMAIN`, `ACME_EMAIL` | Выпуск TLS-сертификата Caddy | HTTPS не поднимется |

`PAYMENTS_STUB=true` (по умолчанию) — платежи симулируются, к ЮKassa обращений нет.
Для локальной разработки так и оставить.

## Порты

Хостовые порты задаются **в `.env`**, а не правкой `docker-compose.yml`:

```
WEB_PORT=3000
HTTP_PORT=80
HTTPS_PORT=443
```

Порты хранилищ (Postgres, MinIO) наружу **не публикуются вовсе** — они доступны только
соседним контейнерам по внутренней сети. Это архитектурный инвариант, а не настройка.

## Тесты

Тесты идут против **живой** Postgres, поэтому им нужен отдельный стек:

```bash
bash scripts/init-test-env.sh          # .env.test со случайными паролями
set -a; . ./.env.test; set +a
docker compose -f compose.test.yml up -d
npm test
```

Тестовый стек публикует порты, но **строго на `127.0.0.1`** и с генерируемыми паролями.
