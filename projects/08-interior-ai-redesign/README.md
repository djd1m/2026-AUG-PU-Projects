# 08. Редизайн комнаты по фото за 25 секунд

> **Неделя 08** · `генерация` · референс: **Interior AI Питера Левелса ($40–45K MRR, >99% маржа)**

## Что делаем

Аналог Interior AI: фото комнаты → редизайн в выбранном стиле за ~25 секунд. 3D Vision сохраняет конструкцию, меняя стиль. Приём оплаты.

**Целевой стек:** Stable Diffusion + depth/ControlNet + приём оплаты
