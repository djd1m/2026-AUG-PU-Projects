## Immutable measured scene

Manual room x=length east/west, z=width north/south, y=height. WallId north/east/south/west. Surface IDs floor, ceiling, wall:north, wall:east, wall:south, wall:west; GLB opaque descriptor surfaces mesh:<mesh-index>:primitive:<primitive-index> (no inferred wall/floor; IDs bound to immutable source/descriptor). All dimensions m canonical decimal strings. Opening id/wallId/offsetM/widthM/heightM/sillM, no overlap/outsidewall.
Object positionM is centerX/bottomY/centerZ; dimensionsM widthX/heightY/depthZ, rotationY radians finite. Immutable catalog IDs and exact stored dimensions. Manual rotated-AABB room/object/opening check labelled bbox_checked/non-engineering; GLB fit unconfirmed. Shell normalization/calibration is fixed measured baseline, not model-writable. Scene shellId/hash material/objects only, no executable/URI/transform fields. Camera orbit transient; before/after same current camera.
Viewer reusable package @n8/viewer may own Babylon rendering +2D fallback without Next/API/SQL; assets resolved by caller. It is one viewer, not a second3D engine. Public SceneViewer props/exports source-bound before feature3 integration. This placement refines Architecture apps/web viewer ownership for user-requested reuse; domain/API behavior unchanged.
