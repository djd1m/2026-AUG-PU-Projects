Прочитан через публичный GitHub Gist API 2026-10-13. Ниже — структурированный пересказ, не дословная транскрипция.

1. Получить реальное пространство: готовый план или обмер сканером; показать черновую 3D-модель без оформления.
2. Собрать желаемый образ: Pinterest-доска/изображения, выделить понравившиеся детали и обсудить пожелания.
3. На основе обмеров и референсов подготовить визуализацию; менять варианты до принятого решения.
4. Найти реальные позиции на локальном рынке: где купить, сроки, альтернативы и экономия.
5. Собрать финальный бюджет и выбрать решение до начала затрат и дорогостоящих переделок.

## Границы интерпретации

- Основной клиент по уточнению владельца — человек, делающий ремонт для себя.
- Scaniverse и Gemini/OpenRouter — новые конкретные вводные владельца, а не доказанные возможности из транскрипта.
- Упоминания стоимости ремонта, экономии и оплаты дизайнеру в транскрипте — иллюстрации говорящего;
  это не проверенные рыночные данные и не обещания продукта.
- Электрика и сантехника объясняют цену ошибок; это не основание обещать инженерный проект автоматически.
- Три HTML-варианта сохраняют эту цепочку и отличаются помощью на шагах, aha и оплатой;
  отдельный CJM для дизайнера или магазинов не является первым продуктом.
- Партнёрские соглашения с магазинами отложены; реальные товарные ссылки могут быть полезны без них.
