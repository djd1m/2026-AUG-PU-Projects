# Component boundary
Network adapter packages/adapters/src/pinterest.ts uses Node HTTPS/DNS with pinned validated IPv4 and exact host/path policy, no generic proxy. Web server reference-pinterest.ts composes owned repository, downloader and existing private uploader; domain has no concrete network dependency. Existing reference schema unchanged; imported images create new rows and preserve source links/history. Client discovery+selection state lives in reusable PinterestReference helper used by DesignReferences. Preview outbound only after authenticated user selects saved link. No credentials required or provider-key changes.
