# N8: что из выбранного CJM работает сейчас

Аудит14.10.2026: независимое сопоставление пользовательского задания/канонического CJM с кодом плюс реальный read-only Chromium обход публичного стенда. Аудировался образ `181590da…058ee`; последний sourcecommit `47c4e6fb` меняет только документацию и шаблон окружения. **Прохождение сокращённой спецификации не равно реализации исходного автоматического CJM.**

## Главный результат

Работает ручной путь: аккаунт → подтверждённая прямоугольная комната / выбранные OCR-размеры / калиброванный GLB → ручные референсы и оформление → ручные карточки товаров → точная условная смета → приватный экспорт/ссылка.

Автоматический путь «план + визуально понятые референсы → подходящий AI-дизайн → найденные реальные товары → актуальный полный бюджет» пока не работает целиком. Основные пробелы — визуальный анализ и рекомендации, автоматический каталог и активированная генерация.

## Фактически проверено на стенде

Открылись все6вкладок, личный кабинет и billing. Подтверждены manual/off,0кредитов у синтетической fixture, сохранённые план/дизайн/смета/экспорт. Пользовательских ошибок в просмотренном пути не найдено.10.678секунд самого Chromium-прогона;20GET, только разрешённый synthetic loginPOST,0завершённых запрещённых мутаций и0внешних запросов.

Открытие «Дизайна» автоматически пытается записать событие первого просмотра. Аудитор заблокировал этот POST до сервера; просмотр продолжил работать. Это аналитическая запись, не признак генерации или изменение проекта.

Этот аудит не повторял save/checkout/liveAI и не доказывает все business mutations. Ранее сохранённые247тестов и browser30/21 — отдельные доказательства с указанными ревизиями.

## Подключение Gemini после аудита

В приватном окружении подготовлены `google/gemini-4-argon`, allowlist, актуальные консервативные rate ceilings, max_tokens4096. Установлены пределы приложения5USD/сутки и0.10USD/запрос; по выбору владельца оставляется провайдерский10USD/неделю.

Обычный completionkey не управляет настройками OpenRouter: `/api/v1/keys` вернул401. Поддержка weekly уже внедрена, прошла независимое ревью и250/250тестов, выложена образом `ea805048…1e886`;153файла совпали с исходниками, новый шестишаговый UI smoke прошёл. Для запуска остаётся включить IncludeBYOKusage в кабинете ключа. Режим live ещё не включён, реальная Gemini-генерация не выполнена. Изменение статуса должно подтверждаться новым source/runtime receipt, а не исправлением исторического аудита.
