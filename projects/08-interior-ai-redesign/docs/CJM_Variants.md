# RoomKind: три пути к первому редизайну

Дата исследования: 2026-10-02. Все варианты — гипотезы продукта, не измеренная конверсия.
CHOSEN_CJM: A — «Моя комната, новый характер». Владелец явно поручил выбрать лучший вариант самостоятельно.
HTML-прототипы будут расположены в `docs/cjm/`; они показывают интерфейс, не доказывают работу GPU.

## Variant A — Моя комната, новый характер · выбран

| Поле | Решение |
|---|---|
| **Aha Moment** | Пользователь двигает разделитель между своим фото и первым качественным редизайном с теми же окнами и стенами. |
| Entry Hook | Владелец или арендатор хочет увидеть новый стиль до покупки материалов. |
| Onboarding → Core Loop → Paywall | Фото → стиль → очередь → проверка результата → сравнение → share → личная галерея → пакет следующих генераций. |
| Growth loop | **content-driven**: результат становится содержанием добровольного поста, новый зритель создаёт свою комнату. |
| FR-GROWTH-001 | CTA «Поделиться до/после» появляется возле первого готового результата; генерация композита за одно действие. |
| FR-GROWTH-002 | Партнёр сохраняется до оплаты в first-party cookie; промокод вводится независимо в paywall. |
| FR-GROWTH-003 | На бесплатном композите видимый RoomKind badge; оплаченный пакет открывает экспорт без него. |
| FR-GROWTH-004 | Код блогера или риелтора связывается с подтверждённой покупкой, не с регистрацией. |
| Микротренды | [Тактильные поверхности и тёплые палитры, Houzz May 2026](https://www.houzz.com/magazine/2026-u-s-houzz-emerging-summer-trends-report-stsetivw-vs~185266615); [Afrohemian Decor, Pinterest 2026](https://business.pinterest.com/pinterest-predicts/). |
| Главный риск | Красивый кадр может нарушить геометрию; такой результат блокируется для публичной галереи и не считается успешной генерацией. |

## Variant B — Объект, который хочется показать · не выбран

| Поле | Решение |
|---|---|
| **Aha Moment** | Риелтор видит готовый брендированный лист до/после для одной комнаты, с явной пометкой виртуального редизайна. |
| Entry Hook | Нужно объяснить потенциал помещения покупателю без реального ремонта. |
| Onboarding → Core Loop → Paywall | Фото объекта → нейтральный стиль → сравнение → брендированный лист → собственная галерея → пакет экспорта. |
| Growth loop | **badge**: получатель листа переходит по подписи RoomKind и пробует инструмент. |
| FR-GROWTH-001 | Поделиться листом после просмотра результата; публикация или отправка только по отдельному действию. |
| FR-GROWTH-002 | Код риелтора доступен на paywall, cookie не является единственным каналом. |
| FR-GROWTH-003 | Бесплатный лист с badge, платный экспорт без него. |
| FR-GROWTH-004 | Один персональный код на партнёра, агрегаты по фактически оплаченным заказам. |
| Микротренды | [Тёплое дерево, Houzz 2026](https://www.houzz.com/magazine/25-home-design-trends-defining-how-well-live-in-2026-stsetivw-vs~184059289); [curved furniture и сенсорные фактуры, Houzz Summer 2026](https://www.houzz.com/magazine/2026-u-s-houzz-emerging-summer-trends-report-stsetivw-vs~185266615). Меняется мебель, не геометрия комнаты. |
| Главный риск | Снятие badge уменьшает распространение; нужен поток профессиональных пользователей, пока не подтверждённый. |
| Причина отказа | Более узкий сегмент и риск расширить scope в listing workflow; оставлен для дальнейшего исследования. |

## Variant C — Два взгляда на дом · не выбран

| Поле | Решение |
|---|---|
| **Aha Moment** | Пользователь показывает знакомому свой первый редизайн; приглашённый создаёт собственную комнату и оплачивает пакет. |
| Entry Hook | Хочется проверить смелый стиль и обменяться идеями с другом. |
| Onboarding → Core Loop → Paywall | Фото → выразительный стиль → сравнение → личная ссылка → оплаченная покупка приглашённого → дополнительный кредит → пакет. |
| Growth loop | **incentivized referral**: один кредит после квалифицированной покупки нового приглашённого. |
| FR-GROWTH-001 | Share CTA только на результате; контактная книга и автоматические рассылки отсутствуют. |
| FR-GROWTH-002 | Атрибуция покупки через cookie или введённый код. |
| FR-GROWTH-003 | Бесплатный экспорт с badge; пакет снимает его. |
| FR-GROWTH-004 | Персональные коды, self-referral и повторные покупки одного клиента не дают награду повторно. |
| Микротренды | [FunHaus и Afrohemian, Pinterest 2026](https://business.pinterest.com/pinterest-predicts/). Смелые узоры и текстиль используются в декоре без перестройки окон. |
| Главный риск | Вознаграждение создаёт накрутку, финансовый учёт и GPU-затраты до подтверждения органического спроса. |
| Причина отказа | Новый финансовый инвариант не нужен для недельного MVP; reward engine не реализуется. |

## Сравнение и решение

| Критерий | A | B | C |
|---|---|---|---|
| Соответствие постановке | Прямое | Частичное: B2B | Частичное: дополнительный бонус |
| Growth unit | Публичный композит | Badge на листе | Квалифицированная рекомендация |
| Дополнительная сложность | Минимальная | Формат листа и профессиональный контекст | Бонусный ledger и anti-fraud |
| Неизмеренная гипотеза | Люди захотят делиться | Получатель заметит badge | Награда увеличит привлечение |

Выбран A: ценность и носитель роста возникают в одном месте. Badge здесь атрибуция контента, а не второй самостоятельный loop. Вторичная тактика без нового кода: вручную подготовить примеры для интерьерных блогеров; отправка сообщений требует отдельного согласия. B и C сохранены полностью.
Цель недели: 12 добровольных share-completed событий от разных пользователей; доля расшаренных генераций — целевая 20% только при ≥30 готовых генерациях. До этого показываются абсолютные числа и знаменатель.
