# RoomKind — Product Requirements

## Product Brief
Проблема: человеку трудно представить новый стиль в собственном помещении. Решение: фото → стиль → редизайн с сохранением конструкции, сравнение и добровольный визуальный share. Первичные пользователи — владельцы и арендаторы; вторичные — риелторы/блогеры. Это гипотезы сегментов, не измеренные доли.
PD-SCOPE-001 принят полностью. PD-CJM-001: CHOSEN_CJM A, альтернативы в `CJM_Variants.md` не удаляются. Бренд RoomKind самостоятельный, точная айдентика InteriorAI не копируется.

## MVP and exclusions
MVP: безопасный аккаунт, фото JPEG/PNG/WebP до 10MB/20MP, 4 стиля, долговечная очередь Postgres, отдельный SD/ControlNet-depth GPU worker, before/after slider, личная галерея, пакет 20 генераций за 900 RUB, branded share, персональные партнёрские коды, opt-in публичная галерея.
Не входят: каталог мебели, 3D, дизайнерская коллаборация, подписки, партнёрские выплаты, reward engine, автоматические сообщения. Пользовательские фото не применяются для обучения.

## User stories and priorities
P0: как владелец комнаты загружаю фото и сравниваю выбранный стиль с исходником; чужие фото недоступны. P0: при оборванном соединении нахожу ту же задачу, повтор не расходует кредит. P0: подтверждённая оплата начисляет пакет ровно один раз. P1: делюсь конкретным результатом и могу отозвать публикацию. P1: партнёр виден в агрегате только при подтверждённой конверсии.

## Success criteria
Качество: исходные окна/двери/стыки стен сохранены по `Specification.md`; реальные GPU evidence обязательны. Скорость warm generation p95≤25s — целевой критерий после ≥30 настоящих запусков, пока не измерен. Рост: 12 уникальных share-completed за неделю; доля≥20% только при n≥30. Данные берутся из нашей БД, не из неподтверждённого охвата соцсетей.

## Authority and risks
PD-MONEY-001: цена — утверждённая для автономной разработки гипотеза, экономика требует фактического замера до live запуска. `decisions-owner.md` фиксирует разрешение 2026-10-02. Новые затраты 0; реальный GPU отсутствует, поэтому полный MVP completion пока заблокирован geometry/performance gate. Локальный demo показывает fixture label и не считается настоящей генерацией.
