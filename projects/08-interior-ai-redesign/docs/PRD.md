# N8 — Product Requirements v0.1

2026-10-13 · AUTO SPARC · статус **Review**, выбранный путь **A**. Владелец разрешил полный цикл без повторного CJM approval. Это спецификация целевого MVP; ни один пункт не свидетельствует о пройденной реализации.

## Product Brief

N8 — помощник для ремонта собственного жилья: измеренное пространство и референсы становятся понятным вариантом, списком конкретных товаров и пересчитываемым бюджетом. Основная польза [H] — принять связанное решение до закупок. Первичная аудитория — homeowner; близкий человек может посмотреть приватный визуальный результат. Дизайнерские агентства, магазины и affiliate-партнёры не отдельные первые продукты.
Исходный фото-redesign scope расширен владельцем; GPU/ControlNet и «25 секунд» не обязательная архитектура/SLA. [project-input](project-input.md) имеет приоритет над исходным промптом. Исследованные [A/B/C](discovery/cjm-design-brief.md) сохраняются как discovery, остановка на выборе A отменена новым разрешением.

## Scope and priorities

| Обязательная локальная способность | Ценность | Feature |
|---|---|---|
| Аккаунт/кабинет и приватный проект | Вернуться к собственным решениям | F1 |
| Ручной измеренный план и GLB upload/calibration, image refs/URL | Подтвердить основу и объяснить вкус | F2 |
| План/3D, оформление, до/после, история | Узнать свою комнату и сравнить изменения | F3 |
| Товарные ссылки/снимки, упаковки/unknown, смета/этапы/замены и owner-only CSV списка | Понять, что покупать и какие расходы ещё неизвестны | F4 |
| Адаптер пакета credits/оплаты, конфигурация off, offline проверка реального контракта | Подготовить монетизацию без фиктивного списания | F5 |
| Watermarked before/after export и отзывная private view | Обсудить образ с близкими | F6 |

Real OpenRouter adapter и ЮKassa adapter входят как capabilities, тестируемые offline. Live inference/платёж отсутствует без ключей/лимитов/merchant и отдельного разрешения; interface явно это говорит. Manual/preset дизайн и ручная закупочная смета должны работать полноценно без этих интеграций. Автоматический scraper не обязательный happy path: проверенные страницы дали 401, API consumer access не установлен.
Вне первой поставки: автоматическое измерение по фото, инженерные чертежи, сложные mesh-конверсии, photorealistic render/video SLA, интернет-магазин/закупка за пользователя, коллаборативный редактор, подписки, public SEO gallery и партнёрские выплаты.

## Canonical journey and UX

1. Зарегистрироваться/открыть проект, выбрать регион; demo-комната отдельно маркирована.
2. Ввести длины/проёмы или загрузить self-contained GLB; подтвердить масштаб/контрольные размеры. До этого концепт нельзя выдавать за проверенный дизайн.
3. Добавить refs изображениями/ссылками и отметить детали. Pinterest не является обязательной интеграцией.
4. Выбрать стиль, материалы/примитивы, посмотреть реальную 3D-сцену/план/до-после, сохранить и согласовать revision. Без AI это реальный редактор, не имитация AI-генерации.
5. Связать элементы с официальными товарными карточками/ручными snapshot; видеть неподобранное, stale/unknown, доступные замены.
6. Из площади/количества, запаса и coverage получить упаковки и бюджет; отделить работы/доставку/резерв и неизвестное.
7. При изменении пожеланий/размеров/цены/наличия вернуться в дизайн, создать новую revision и пересчитать, сохранив историю.
8. Просмотреть состав тарифной возможности, скачать before/after и по собственной воле дать приватную ссылку на изображение.

Ключевые экраны: кабинет, space/calibration, refs, design/version compare, shopping list, budget/diff, billing history/config status, share preview. Предусмотрены keyboard/390px, понятные disabled/error states, 2D fallback. Эмоции/боли в discovery — гипотезы; пользовательские интервью пока не проводились.

## Requirements and acceptance

Единый нормативный набор: [Specification.md](Specification.md) FR/NFR headings и US/SC IDs. [Pseudocode.md](Pseudocode.md) содержит exact REQUIREMENT/REALISES и API, [Refinement.md](Refinement.md) — конкретные suites, [ADR.md](ADR.md) — решения и все growth dispositions. У каждой реализованной фичи нужны per-feature local→GitHub reuse artifact, тесты и независимый anti-drift по точной revision.

| Success metric | Target / status | Source value |
|---|---|---|
| Полный homeowner путь | Все обязательные SC реализованы и проверены локально | ручное измерение: Playwright/интеграционные сценарии по SC |
| Неизменность shell | Ноль принятых mutation-fixtures стен/масштаба/проёмов | наш журнал |
| Расчёт упаковок/unknown | Все граничные fixtures дают ожидаемое значение/статус | ручное измерение: decimal/property tests |
| Unauthorized access | Все cross-owner negative tests отклонены | ручное измерение: DB/API security suites |
| First design/export/share | Наблюдаемые counts, численной бизнес-цели пока нет | наша БД |
| API/200-line budget latency | Предложения NFR-performance-1; ещё не измерены | ручное измерение: 10-client local fixture и perf.now benchmark |
| Delivery time | Ориентир 8h, автономный предел 10h от 20:25 UTC 2026-10-13 | наш журнал |

Рынок/TAM/CAC, готовность платить, экономия, AI качество/стоимость результата неизвестны. Цена пакета задаётся отдельно оператором; default off без выдуманной коммерческой цены. Публичный запуск и платный эксперимент не следуют автоматически из разрешения на разработку.

## Constraints, risks and release

Стек — модульный N6/N5 Next/TS/Postgres donor, isolated local Compose. Чужие секреты/бизнес-сущности не копировать. Изменение измеренной основы инвалидирует downstream; «доверие» показывать по конкретному факту (user-confirmed / geometry unchanged / source dated), не общим зелёным бейджем.
Главные риски: ложная точность, неполный бюджет, приватность планов, повторное начисление/спенд, blocked retail access. Их защиты конкретизированы в FR/NFR; deadline не разрешает ослабить их.
Следующие этапы: независимая валидация шести линз → конкретные исправления → toolkit/feature routing → F1–F6 с независимым ревью → интеграционные/E2E проверки и локальная передача. Статус готовности определяется доказательствами [Completion](Completion.md), не наличием документов.
