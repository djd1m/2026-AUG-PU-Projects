# Варианты CJM — N6b (клон Chatbase)

**Фаза:** 0 · модуль M2.5 `reverse-engineering-unicorn` · **Дата:** 2026-09-30
**Выбор владельца:** ожидается. Ни один вариант не выбран пайплайном; дальше Фазы 0 работа не идёт.
**Прототип:** [`discovery/cjm-prototype.html`](discovery/cjm-prototype.html) — один HTML, без внешних загрузок, вкладки A/B/C,
сравнение, оценка. Палитра прототипа — **фолбэк** (отраслевая, Productivity: slate/orange), потому что облик Chatbase
**НЕ ИЗМЕРЕН** (`no-browser-mcp`), см. [`source-product-profile.md`](source-product-profile.md).
**Входы:** [`product-discovery-brief.md`](product-discovery-brief.md) (M2 сегменты, жалобы, цены), постановка [`00-task.md`](00-task.md).
Ссылки `[src-N]` ниже — список «Источники» в brief.

Варианты различаются **петлёй роста**, а не только экранами: A — значковая (badge), B — content-driven (публичные
демо-страницы), C — поощряемая реферальная через веб-студии. MVP-scope постановки общий для всех трёх; различаются
порядок экранов, место paywall и то, что строится в первую очередь из `FR-GROWTH-*`.

Общее для всех: Aha по постановке = **первый верный ответ со ссылкой на свой документ** (FR-GROWTH-001). Варианты
отличаются тем, **чей** это документ в момент Aha и **кто** этот момент видит.

## Variant A — «Бот на сайте за 10 минут» (growth loop: badge)

| Поле | Содержание |
|---|---|
| **Aha Moment** | владелец задаёт вопрос в песочнице и получает верный ответ со ссылкой на СВОЮ страницу/PDF, затем тот же ответ — в виджете на своём домене |
| **Entry Hook** | С1 «владелец малого сайта», functional job «ответь посетителям за меня»; боль — вопросы ночью и потерянные клиенты |
| **Onboarding** | регистрация → URL сайта + PDF → прогресс индексации «страниц N из M» (задача минут: id задачи выдаётся до начала) → песочница |
| **Core Loop** | вставить `<script>` → посетители спрашивают → счётчик «вопросов на вашем сайте / из них “не знаю”» → дозагрузить документ |
| **Paywall** | не при регистрации; после Aha и установки: лимит ответов Free и «убрать бейдж» — платно (на неделе — кнопка-намерение, оплата вне сборки) |
| **Growth loop варианта** | **Значковая/встраиваемая**: бейдж на каждом Free-виджете → клик → лендинг с ref=bot_id → новый бот |
| **Как ложатся FR-GROWTH** | 001 — CTA «вставить на сайт» в момент Aha · 003 — бейдж в виджете Free, снятие платно · 004 — студия видна только как тип аккаунта (минимум) · 005 — демо-страница как вторичная тактика · 002 — отложен (оплата вне сборки) |
| **Микро-тренды** | «Powered by» как дистрибуция, K≈0.1–0.2 у встраиваемых [src-13]; снятие бренда как платная опция — у Chatbase $99/мес [src-5]; «URL → бот за минуты» [src-7] |
| **Главный риск** | медленная петля: K встраиваемых 0.1–0.2, эффект виден через трафик ЧУЖИХ сайтов; за неделю 15 внешних виджетов — это скорее ручной посев, чем петля. И вопрос 38-ФЗ по бейджу |

## Variant B — «Попробуй на своём сайте без регистрации» (growth loop: content-driven)

| Поле | Содержание |
|---|---|
| **Aha Moment** | посетитель лендинга вводит URL своего сайта БЕЗ регистрации и через минуты получает публичную демо-страницу, где бот отвечает по его сайту со ссылками |
| **Entry Hook** | С1 и С2: «сколько бы это стоило мне?» → «посмотри сам на своём сайте»; боль — недоверие к «ИИ, который врёт» |
| **Onboarding** | URL → анонимная задача индексации (лимит на IP/сутки) → публичная демо-страница `/d/{slug}` → «сохранить бота» = регистрация |
| **Core Loop** | демо-страницей делятся в чатах/соцсетях («смотри, наш сайт отвечает») → зрители демо вводят свой URL |
| **Paywall** | после сохранения: установка виджета бесплатна с бейджем; платно — больше страниц/ответов, без бейджа |
| **Growth loop варианта** | **Content-driven / product-led loop**: результат (демо-страница) сам приводит следующего |
| **Как ложатся FR-GROWTH** | 001 — share-CTA на демо-странице в момент первого верного ответа · 005 становится главным (демо-страница) · 003 — бейдж на демо и в виджете · 004 — студии используют демо как «прототип для клиента» · 002 — отложен |
| **Микро-тренды** | демо «введи URL» у SiteGPT/ChatBot.com [src-7]; дешёвые эмбеддинги — анонимная индексация стоит центы [src-9]; ожидание «до 10 минут до ценности» [src-7] |
| **Главный риск** | деньги и злоупотребления: анонимный посторонний запускает краулинг и ответы (класс `посторонний` в `model-call-cost.md`); индексация ЧУЖИХ сайтов без согласия владельца (robots.txt, авторское право); демо не равно установке — метрика недели (виджеты на внешних доменах) растёт медленнее просмотров |

## Variant C — «ИИ-бот для клиентов вашей студии» (growth loop: incentivized referral через студии)

| Поле | Содержание |
|---|---|
| **Aha Moment** | студия за 10 минут собирает бота на сайте клиента в своём sub-аккаунте, показывает клиенту ответ со ссылкой на его PDF-прайс и передаёт бота клиенту |
| **Entry Hook** | С2 «веб-студия»: functional job «добавь клиенту ИИ-фичу и продай её»; боль — нет white-label и передачи бота |
| **Onboarding** | аккаунт студии → «новый клиент» (sub-аккаунт) → URL+PDF клиента → песочница → «передать клиенту» (приглашение по e-mail) |
| **Core Loop** | каждый сайт клиента = виджет; студия ведёт N клиентов из одного кабинета; клиент видит «собрано студией X» |
| **Paywall** | тариф «Студия» (sub-аккаунты) + вознаграждение студии за платных клиентов — раскрытое клиенту |
| **Growth loop варианта** | **Поощряемая реферальная (односторонняя)**: вознаграждение получает студия; мотион — Partnership-Led |
| **Как ложатся FR-GROWTH** | 004 — главный (sub-аккаунты + перенос) · 002 — атрибуция клиента к студии до платной конверсии (нужна оплата → вне сборки) · 003 — бейдж ко-брендированный «студия X · продукт» · 001 — CTA «передать клиенту» в момент Aha |
| **Микро-тренды** | агентства реселлят white-label ботов по $99–299/мес за клиента [src-12]; affiliate источника платит только за платную подписку, self-referral запрещён [src-6] |
| **Главный риск** | без оплаты петля не замыкается: вознаграждение студии нечем выплатить на неделе; мало студий — мало сайтов; сложнее всех по объёму (роли, передача владения, приглашения) |

## Сравнительная таблица

| | A — Badge | B — Демо без регистрации | C — Студии |
|---|---|---|---|
| Петля | значковая (встраиваемая) | content-driven / product-led | поощряемая реферальная (односторонняя) |
| Совпадение с постановкой | **основной loop BADGE**, демо — вторичная | демо становится основным — **против** постановки | студии — FR-GROWTH-004, но loop иной |
| Вклад в метрику недели (15 внешних виджетов) | прямой: каждый шаг ведёт к установке | косвенный: демо ≠ установка | прямой, но зависит от числа студий |
| Нужна оплата, чтобы петля замкнулась | нет (бейдж работает на Free) | нет | **да** (вознаграждение) — вне сборки |
| Денежный риск (`model-call-cost`) | средний: ответы виджета | **высокий**: анонимный краулинг + ответы | средний |
| Правовые вопросы | 38-ФЗ (бейдж), 152-ФЗ | + индексация чужих сайтов без согласия | + раскрытие вознаграждения |
| Объём MVP | наименьший | средний (анонимные задачи, лимиты на IP) | наибольший (роли, передача) |
| Скорость сигнала за неделю | средняя | высокая по просмотрам, низкая по установкам | низкая |

## Рекомендация исполнителя (не выбор)

**A — Badge**, с двумя заимствованиями без новой петли: из B — публичная демо-страница **сохранённого** бота (вторичная
тактика постановки, без анонимного краулинга чужих сайтов), из C — минимум для студий (sub-аккаунт и перенос бота,
FR-GROWTH-004) без вознаграждения. Почему: только A замыкается без оплаты, прямо кормит метрику недели и совпадает с
постановкой. Что при этом сознательно НЕ пробуем: анонимное демо (B) и денежную петлю студий (C) — их следует вернуть,
если за неделю клики по бейджу окажутся нулевыми.
