Источник: шпаргалка занятия (https://claude.ai/artifact/TNLyfqD57XEDXAiwJS4ujF), раздел «Повторить в соседней папке», шаг 2.

```
/replicate

Строим клон Chatbase: клиент загружает свой сайт и PDF, получает обученного на своих данных
чат-бота и встраивает его виджетом на сайт за 10 минут.
Вся документация проекта — в projects/06b-rag-class/docs/

MVP-scope на неделю:
- источники: URL сайта (краулинг) + загрузка PDF
- индексация в pgvector (text-embedding-3-small, 1536); pgvector — расширение нашего Postgres, не отдельная БД
- чат с RAG-ответами и ссылкой на источник в каждом ответе
- виджет: один <script> тег; Powered-by badge в виджете
НЕ входит: передача оператору, мультиязычность, аналитика диалогов, CRM, обучение на диалогах.
«В базе нет ответа» → явное «не знаю» со ссылкой на контакт; это @security-сценарий.

## GROWTH MECHANICS CONSTRAINTS
Основной loop: BADGE. Вторичная тактика: публичная демо-страница бота.
FR-GROWTH-001: момент ценности = первый верный ответ со ссылкой на свой документ.
FR-GROWTH-003: badge обязателен на free, снятие — платная опция.
FR-GROWTH-004: партнёры — веб-студии (sub-аккаунты, перенос бота).
Каждый FR-GROWTH — три Gherkin-сценария: @happy-path, @edge-case, @security.
Не менее 3 вариантов CJM с разными growth loop, затем ОСТАНОВКА и мой выбор.
Метрика недели: виджеты на внешних доменах с ≥1 вопросом — цель 15.
```

## Условия владельца (30.09)

1. Промпт — ровно этот, показан владельцу до старта.
2. Ключи можно брать из N6, но не выводить их в сессиях, журналах, коммитах.
3. Тестовый домен как у N3/N4: `n6b.194.85.249.105.sslip.io`.
4. Переиспользовать готовые модули N1–N5; код N6 НЕ использовать (иначе повтор не показывает работу пайплайна).
5. Частые коммиты и пуши в ветку `feature/06b-rag-class`.
6. Валидатор — модель Anthropic (Claude Opus), КАЖДЫЙ раз новый агент без контекста кодинга, с контекстом плана:
   постановка, этот файл, документы фаз — и ничего из переписки или рабочих копий исполнителей.

## Объём сборки (из плана, одобрен 30.09)

MVP из постановки: обход сайта и PDF, pgvector, чат с источником и «не знаю», виджет с бейджем, демо-страница, минимум
для студий. Оплата, партнёрские выплаты, удаление аккаунта — вне этой сборки. Остановки у владельца: выбор CJM после
Фазы 0; подъём стенда; фичи тира XL.
