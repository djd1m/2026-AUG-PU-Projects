# N6b «RAG-бот для сайта» - Executive Summary

**Фаза:** 1 · SYNTHESIS `sparc-prd-mini` · **Дата:** 2026-09-30

## Overview

N6b — чат-бот для малого сайта, обученный на его страницах и PDF, который ставится одним `<script>`. Каждый ответ собирается
только из найденных фрагментов и несёт ссылку на страницу сайта или страницу PDF; если фрагмента нет — «не знаю» и контакт
владельца. Рост — бейдж «Работает на N6b» на Free, публичная демо-страница сохранённого бота и подаккаунты студий с
передачей бота клиенту (выбор владельца «A + демо из B + минимум C», PD-CJM-001). MVP — неделя, стенд
`n6b.194.85.249.105.sslip.io`, оплата вне сборки.

## Problem & Solution

**Проблема:** посетители уходят без ответа; боты категории выдумывают, включая ссылки (PD-INSIGHT-002).
**Решение:** граница «знаю / не знаю» и адрес ссылки принадлежат коду (ADR-003), модель только формулирует.

## Target Users

- **Primary:** С1 — владелец малого сайта (PD-SEGMENT-001).
- **Secondary:** С2 — веб-студия (канал, FR-GROWTH-004).

## MVP Features

1. **Ответ со ссылкой на свой документ** — момент ценности (FR-GROWTH-001), доверие к боту.
2. **Виджет одним `<script>` с бейджем** — установка за минуты, петля роста (FR-GROWTH-003).
3. **«Не знаю» + контакт и потолки расходов** — бот не врёт и не разоряет (PD-INSIGHT-003).

## Technical Approach

- **Architecture:** distributed monolith в монорепо: web (Next.js 15), worker, migrate, Postgres 16 + pgvector (ADR-001, ADR-002).
- **Tech Stack:** TypeScript, esbuild-виджет в Shadow DOM, `text-embedding-3-small` + `gpt-4.1-mini` за портом провайдера (ADR-004).
- **Key Differentiators:** цитаты проверяются кодом; разрешённые origin на бота (ADR-007); передача аккаунта клиенту студии (ADR-008).

## Research Highlights

1. Вектор `text-embedding-3-small` — 1536, $0.02 за 1M токенов: индексация сайта ≈ $0.003 (Research T1–T2).
2. `gpt-4.1-mini` — $0.40/$1.60 за 1M: ответ ≈ $0.0015 `[H]` по объёму; деньги жгут ответы посторонним, не индексация.
3. pgvector: HNSW по косинусу, фильтр после скана → итеративный скан (T4, T12).
4. RFC 9309: robots.txt 5xx/сеть — полный запрет, 4xx — можно всё (T8–T9).
5. Главная жалоба на Chatbase — выдумки и ссылки на несуществующие страницы [src-4].

## Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Петля бейджа не даёт 15 доменов за неделю | ручной посев 15 знакомым владельцам и студиям |
| Счёт от посторонних вопросов | потолки числом, атомарно до вызова, отказ старта без них (ADR-010) |
| Неверный порог сходства | калибровка на 30 вопросах до публикации |
| 152-ФЗ / 38-ФЗ | открытые вопросы Q-001, Q-002 владельцу (PD-RISK-001, PD-RISK-002) |
