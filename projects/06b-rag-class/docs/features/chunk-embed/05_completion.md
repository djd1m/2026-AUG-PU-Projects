## Отклонения и границы

1. **Файлы.** Дорожная карта называла `packages/db/migrations/003_hnsw.sql` — не нужен (индекс в 001). Шаг индексации — в
   `services/worker/src/embed.ts`, исполнитель задачи — в новом `index-runner.ts`.
2. **Резерв сверху.** Для английского текста ⌈длина/4⌉ бывает больше точной оценки — резервируется большее; переплата
   резерва ≤ разницы. Провайдер считает свои токены (`tokens_in` журнала), резерв с ними не сверяется.
3. **Потолок итеративного скана.** `hnsw.max_scan_tuples` по умолчанию 20 000: если у ДРУГИХ ботов больше 20 000 фрагментов
   ближе к вопросу, чем свои, top-K может прийти неполным (не чужим). Предел MVP ≈ 200 000 фрагментов на всю БД — риск
   реален на больших объёмах; проверять в performance-наборе (Refinement, NFR-n6b-1).
4a. **План зависит от статистики.** Первый полный прогон показал: при нескольких тысячах строк бота планировщик взял btree
   `bot_id` + точную сортировку, и тест «план через HNSW» упал — а тест изоляции на таком плане зеленел бы и без
   итеративного скана. Поэтому изоляция проверяется на ПРИНУДИТЕЛЬНОМ пути HNSW (`enable_sort=off` в пуле теста), и
   мутация MS1 (снят скан) краснеет. Боевой путь btree точен и безопасен; опасен только путь HNSW.
4. **Окна символов.** Сплошная строка длиннее 125 символов без пробелов режется окнами по 125 кодовых точек без подсчёта
   BPE (квадратичного на такой строке) и без перекрытия; такие части короче 500 токенов.
5. **ord неизменённых частей** не переписывается при изменении документа: порядок нужен только для чтения, ответ его не
   использует.
6. **Извлечение не подключено.** В `main.ts` `extractors: {}` — боевые задачи по-прежнему честно отказывают до фич
   crawl-site / pdf-source; шаг индексации проверен на тестовом извлечении (документы, вставленные фикстурой).
7. **Оплаченная, но не записанная попытка.** Если аренду забрали во время вызова модели, вызов оплачен (счёт по попыткам),
   а части не пишутся; повтор задачи заплатит за них снова. Окно — одна аренда (2 мин), батч ≤ 100 частей.
8. Дорожная карта (`status`) не обновлялась — до ревью. Телеметрия прогона — у координатора.
