# Testing — N6b

Источник: `docs/Refinement.md` → Testing Strategy, `docs/test-scenarios.md` (Gherkin по SC-US), Edge Cases Matrix.

## Уровни и цели

| Уровень | Что | Цель | Где |
|---|---|---|---|
| Unit | нарезка, порог, проверка цитат, вырезание URL, `planOf`, `excluded`, `normalizeOrigin`, `metricHost`, HMAC посетителя, разбор robots.txt, SSRF-фильтр | 80% строк `packages/rag`; 100% ветвей `planOf`, `excluded`, `normalizeOrigin`, SSRF | `*/tests/unit/` |
| Integration | RLS, квоты конкурентно, аренда задач, частичный unique, HNSW-изоляция ботов, передача аккаунта | все SC-US с БД | тестовый compose `name: n6b-test`, пароли `${VAR:?}` |
| Contract | порт провайдера на адаптере `fake`: детерминированные эмбеддинги и JSON, «чужой cited_id», тело запроса несёт `provider` | каждый метод порта | `packages/rag/tests/contract/` |
| E2E | Playwright на РАЗВЁРНУТОМ стенде по выданному адресу: регистрация → URL → прогресс → песочница → публикация → виджет на ЧУЖОМ origin с CSP и враждебным CSS → вопрос → бейдж → лендинг | сквозной CJM | `tests/e2e/` |
| Performance | 200 000 фрагментов синтетики, поиск p95 ≤ 100 мс; ответ p95 ≤ 6 с (20 вопросов) | NFR-n6b-1 | отчёт в `docs/` |

## Правила

1. **Каждый SC-US-nnn-k имеет тест, имя которого содержит идентификатор** (`it('SC-US-012-5: …')`). Сценарий в
   `test-scenarios.md` без теста — не закрытое требование.
2. **Конкурентный тест, а не последовательный**, для всего, что трогает разделяемый ресурс: квоты (50 параллельных при
   остатке 3 → ровно 3 вызова), аренда (два воркера), 6-й подаккаунт, двойной клик источника.
3. **Мусорный вход перечнем**: план `[null, undefined, '', 'PAID', ' paid', 'premium', 0, 1, true, {}, ['start']]` →
   бейдж; origin `null`/пусто/чужой → 403; адреса SSRF списком.
4. **Страж испытан на падение**: вернуть дефект → тест красный (`N failed`), восстановить → зелёный. Обе строки — в
   описании коммита или review-report.
5. **Модель в unit/integration — только `fake`.** Живой `gpt-4.1-mini` — лишь калибровка (ворота выпуска) и E2E на стенде.
6. **Виджет проверяется на ЧУЖОМ origin** (другой порт, например `http://localhost:8099`) под ограничительным CSP и
   враждебным CSS; своя страница — не проверка (`.claude/rules/embeddable-widget.md`). Квитанция — `docs/embed-contract.md`.
7. Полный прогон ВСЕХ наборов перед коммитом фичи, не только своего.

## Калибровка — ворота выпуска (SC-US-006-4)

30 вопросов по тестовому сайту: 20 с ответом, 10 без ответа, но со сходством ≥ `MIN_SIMILARITY`. Проход: 10/10 «не знаю»
и ≥ 17/20 со ссылкой. Артефакт `docs/calibration-report.md`: дата, модель, `MIN_SIMILARITY`, хэш промпта, исход по
каждому вопросу. Повтор обязателен после смены порога, модели или промпта. Не прошло — стенд посетителям не открывается.
