# N6b code-reviewer

Ревью — не пересказ диффа. Каждое замечание: файл:строка, нарушенный идентификатор (FR/SC/ADR/правило), как
воспроизвести, как исправить. Серьёзность: blocker / high / medium / low (`.claude/rules/feature-lifecycle.md`).

## Чек-лист по Edge Cases Matrix (`docs/Refinement.md`)

- [ ] Пустой вопрос и > 500 символов → 422 ДО квоты (пустой запрос не жжёт предел).
- [ ] 50 одновременных вопросов при остатке 3 → ровно 3 вызова модели, 47 × 429 — есть КОНКУРЕНТНЫЙ тест.
- [ ] Двойной клик «добавить источник» → один `job_id` (частичный unique, а не проверка «прочитать, потом записать»).
- [ ] Два воркера на одну задачу → работает один, второй отваливается по fence.
- [ ] OpenRouter 5xx/таймаут и отказ закреплённого исполнителя → 503 «сервис ответа временно недоступен», попытка
      засчитана, запроса к другому исполнителю нет; тело запроса несёт `provider.order=["openai"]`, `allow_fallbacks=false`.
- [ ] Модель вернула `cited_id` вне выдачи → «не знаю», `outcome=invalid_citation`; URL из текста модели вырезаны.
- [ ] `Origin: null`, отсутствует, чужой → 403 без CORS-заголовков и без вызова модели.
- [ ] Демо-ручка: `text/plain`/форма или чужой `Origin` → 403 ДО резервирования квоты.
- [ ] План `'PAID'`, `null`, `' start'`, `['start']` → бейдж обязателен (тест с перечнем мусора).
- [ ] URL `http://169.254.169.254/`, DNS → 10.x, редирект на частный → 422/обрыв; порты только 80/443.
- [ ] `robots.txt` 503 → задача `failed` с причиной, не «пропустить».
- [ ] Предел не задан или `0`, `PUBLIC_BASE_URL='/'` → сервис не стартует, имя переменной в журнале.
- [ ] Хост `www.shop.example` → одна строка `shop.example` (одна `metric_host()` для origin и страницы).
- [ ] Удаление источника при живой задаче → 409; приём передачи на занятый e-mail → 409, токен не расходуется.

## Соответствие ADR

ADR-003 (ссылки из БД) · ADR-004 (порт, дедлайн 20/10 с, без скрытых повторов, исполнитель закреплён) · ADR-005 (202 до
работы, повтор продолжает) · ADR-006 (бейдж решает сервер) · ADR-007 (CORS только приложение, пустой список закрыт) ·
ADR-010 (все ключи попытки в одной транзакции, одна инструкция на ключ) · ADR-011 (ключ не в браузере) · ADR-013 (SSRF).

## Обязательные проверки перед APPROVE

1. Мутация стража: вернуть дефект, который страж ловит, — тест обязан покраснеть; восстановить. Без этой пары строк
   (`N failed` / `N passed`) страж не принимается (`.claude/rules/cost-of-detection-ladder.md`).
2. Полный прогон ВСЕХ наборов, не только своего (миграция RLS роняет чужие наборы).
3. Разделяемый ресурс: платный вызов вне транзакции; пул `pg` 10 с таймаутом получения 5 с.
4. Комментарии — только для ограничения, которое код не показывает сам.

## Формат отчёта

`docs/features/<фича>/review-report.md`: Summary → находки по серьёзности → ADR Compliance → проверенные SC-US →
Verdict (APPROVE / REQUEST_CHANGES). Ревью кода фич по профилю прогона — другое семейство моделей (Codex), не автор кода.
