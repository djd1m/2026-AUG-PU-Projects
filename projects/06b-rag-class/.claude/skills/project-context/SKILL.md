# N6b — контекст проекта

## Что строим

Бот по страницам и PDF владельца сайта: ответ только из найденных фрагментов со ссылкой на источник из нашей БД; нет
ответа — «не знаю» и контакт владельца без вызова модели генерации. Виджет одним `<script>` на чужом сайте, бейдж на Free,
демо-страница сохранённого бота, подаккаунты студий и передача аккаунта клиенту. Оплата — вне сборки.

Повтор проекта N6 на занятии 30.09: **код `projects/06-rag-sales-chatbase` не открывать** (правило владельца №4). Модули
N1–N5 — по `docs/discovery/reuse-inventory.md` (28 строк; «чего нет» — обходчик, PDF, pgvector, RAG — пишется с нуля).

## Факты исследования (`docs/Research_Findings.md`, `docs/Architecture.md` → External Dependencies)

- `text-embedding-3-small`: 1536 измерений, $0.02 за 1 M токенов; через OpenRouter — `openai/text-embedding-3-small`.
- `gpt-4.1-mini`: $0.40 вход / $1.60 выход за 1 M; ≈ $0.0015 за ответ `[H]`; 5 000 платных ответов/сутки ≈ $7.5.
- OpenRouter отдаёт `gpt-4.1-mini` исполнителям Azure и OpenAI; закрепление — `provider.order=["openai"]`,
  `allow_fallbacks=false` (страница provider-selection).
- RFC 9309: robots.txt 5xx/сеть → полный запрет; 4xx → разрешено всё; предел разбора ≥ 500 KiB.
- pgvector: HNSW `vector_cosine_ops`; фильтр `WHERE` после скана → `hnsw.iterative_scan = strict_order`; образ
  `pgvector/pgvector:0.8.6-pg16`.

## Границы объёма

почте, OCR сканов, анонимное демо по чужому URL, вознаграждение студий. Облик источника не снят (`НЕ ИЗМЕРЕНО`,
`no-browser-mcp`) — палитра кабинета помечена фолбэком.
