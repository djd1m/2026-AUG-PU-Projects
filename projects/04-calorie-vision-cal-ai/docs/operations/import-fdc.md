# Импорт USDA FoodData Central — инструкция оператора

Скачивание дампов — шаг ЧЕЛОВЕКА, не скрипта (`FR-source-and-correct-1`): делать сборку
зависимой от доступности стороннего сервиса незачем, а импорт 200+ МБ чужих данных не
принадлежит `docker compose up`.

## 1. Скачать дампы

Раздел [Download Data Sets](http://fdc.nal.usda.gov/download-datasets/) на
`fdc.nal.usda.gov`. Нужны ТРИ набора (полный дамп в формате CSV, «Full Download»
включает файлы всех типов данных):

| Набор | Что содержит |
|---|---|
| Foundation Foods | подробный химический состав отдельных продуктов |
| SR Legacy | наследие USDA Standard Reference — самое широкое покрытие сырых продуктов |
| FNDDS 2021-2023 | готовые блюда и БЫТОВЫЕ ПОРЦИИ (граммы), нужные `default_portion_g` |

Точные URL версионированы по дате релиза и на момент планирования (`03_architecture.md`,
External Dependencies) сознательно НЕ зафиксированы — угаданный адрес был бы непроверенным
значением. Оператор:

1. Открывает страницу Download Data Sets, копирует ссылку на CSV-архив каждого набора.
2. Скачивает файл и записывает его SHA-256: `sha256sum <файл>.zip`.
3. Сверяет контрольную сумму с указанной на странице загрузки (если она опубликована) —
   иначе просто фиксирует сумму скачанного файла в собственном журнале операций.
4. Распаковывает архивы В ОДИН каталог так, чтобы там лежали (имена USDA-дампа):
   `food.csv`, `food_nutrient.csv`, `nutrient.csv`, `food_portion.csv`. При конфликте
   версий файла `nutrient.csv` между наборами используется любой один — идентификаторы
   нутриентов (Energy 1008, Protein 1003, Total lipid (fat) 1004, Carbohydrate 1005)
   стабильны между релизами дампа.

## 2. Запустить импорт

```bash
DATABASE_URL=postgres://n4_migrate:***@localhost:5432/n4 \
  npm run import:fdc -- /путь/к/каталогу/с/дампами --snapshot-date 2026-04-01
```

`--snapshot-date` — дата ПУБЛИКАЦИИ набора (со страницы Download Data Sets), а НЕ
сегодняшняя дата: снимок описывает данные, а не момент, когда их залили. Отсутствие
аргумента или недоразбираемая дата — отказ БЕЗ частичного импорта.

Скрипт печатает: сколько строк принято, сколько отвергнуто (с `fdc_id` и причиной —
обычно отсутствие одного из четырёх значений на 100 г) и итоговое число строк
`food_item` в таблице. Повторный запуск того же дампа — идемпотентен: `id` уже
существующих строк не меняется.

## 3. Применить RU-курацию

```bash
DATABASE_URL=postgres://n4_migrate:***@localhost:5432/n4 npm run seed:food-synonyms
```

Требует, чтобы `food_item` уже был наполнен шагом 2: seed ссылается на `fdc_id`
(`food_item_source_id`), а не на `food_item.id`.
