# Бренд-бейдж на шеринговой карточке — исследование правил

Метод: WebSearch по потребительским share-фичам (Strava, Spotify Wrapped, Nike Run Club,
Duolingo, Untappd/Vivino, watermark/logo-guidelines материалы). Официальной дизайн-документации
у Strava/Nike/Duolingo/Untappd в открытом доступе почти нет — их конкретные пиксельные значения
НЕ НАЙДЕНЫ, помечено явно. Общие правила соцсетей и watermark-практик подтверждены несколькими
источниками.

## 1. Безопасные зоны Stories 1080×1920

- Верх: **~220 px** перекрыты аватаром, именем, полосой прогресса, крестиком закрытия.
- Низ: **~220 px** перекрыты полем ответа, кнопкой отправки, зоной стикеров (опрос/вопрос).
- Итоговая безопасная зона по вертикали: примерно **1080×1420–1440 px**, отступ по 250 px
  сверху и снизу как более консервативная оценка (источники расходятся в диапазоне 220–250 px —
  закладывать больший, 250 px).
- Фон/декор можно тянуть на весь холст 1080×1920; весь читаемый контент (текст, бейдж, CTA) —
  строго внутри безопасной зоны.
- Источники: [Outfy — Instagram Safe Zone Guide 2026](https://www.outfy.com/blog/instagram-safe-zone/),
  [Wavegen — Instagram Story Size 2026](https://wavegen.ai/instagram-story-size),
  [CampaignSwift — Safe Zone Sizes Guide 2026](https://campaignswift.com/blog/instagram-safe-zone-sizes).
- Про Telegram/VK safe zones — данных В ПОИСКЕ НЕ НАЙДЕНО; их UI-оверлеи не документированы так
  подробно, как Instagram. Разумно применять ту же зону 250 px (более широкий оверлей Instagram
  как верхнюю границу требований).

## 2. Расположение и форма бренд-бейджа

- Нижняя треть карточки — стандартное место для бренд-знака: «bottom-right — классическая позиция
  водяного знака, взгляд туда приходит последним и читает знак как подпись, не как заголовок»
  ([logotouse.com](https://www.logotouse.com/post/logo-placement-best-practices)).
- Четыре угла — «естественный дом» для лого: не спорят с сюжетом кадра (обычно фото/герой-число
  занимает центр и верх).
- Соотношение форм по функции:
  - **знак + wordmark в «пилюле»** (скруглённый прямоугольник с подложкой) — когда бейдж несёт
    смысловую нагрузку «сделано в X» и должен читаться как отдельный маленький UI-элемент, а не
    слиться с фото;
  - **строка «логотип + wordmark» без подложки** — когда фон уже тёмный/контролируемый (градиент
    снизу), подложка избыточна;
  - **только знак** — для повторного use на маленьких превью (не для основной карточки 1080×1920).
- Платформенная поправка (актуальна как «худший случай», к которому надо готовиться): для TikTok
  водяные знаки размещают с отступом **не менее 8% от края**, так как правый вертикальный UI-столбец
  занимает крайние ~15% экрана — цифра из другой платформы, но подтверждает практику «минимум ~8%
  от края» как общий ориентир отступа бейджа от рамки кадра.
  Источник: [barnimages.com — Logo Placement Guidelines 2026](https://barnimages.com/blog/tips/adding-a-logo-to-social-media-graphics/).
- Отступ вокруг знака: не меньше половины высоты самого знака с каждой стороны (breathing room).
- Размер относительно холста для Nike/Strava/Duolingo — КОНКРЕТНЫХ % НЕ НАЙДЕНО (официальные
  брендбуки не в открытом доступе). Ориентир из общей watermark-практики: высота бейджа-пилюли
  обычно в диапазоне 3–5% высоты холста (≈60–100 px на 1920 px) — это экстраполяция из общих
  watermark-гайдов, не измеренное значение с реальной карточки, помечать как ГИПОТЕЗУ.

## 3. Читаемость бейджа на любом фото

- Подложка нужна ВСЕГДА, если бейдж лежит поверх фото без контролируемого фона:
  «на busy-фото — полупрозрачная подложка позади лого или тонкая тень/обводка»
  ([enviragallery.com — Watermark guide](https://enviragallery.com/how-to-design-a-watermark/)).
- Контраст: логотип с текстом обязан проходить WCAG 2.1 AA — **4.5:1** для обычного текста,
  **3:1** для крупного (это формальный минимум, не «модный», но именно он и есть проверяемый порог).
  Источник: [logotouse.com](https://www.logotouse.com/post/logo-placement-best-practices).
- Современно (2025–2026) для «стеклянной» пилюли-подложки — glassmorphism-рецепт из практики
  UI-дизайна (не специфично для share-карточек, но применимо):
  - fill низкой прозрачности, **~55–65%** для основной пилюли-бейджа (чтобы текст оставался чётким),
    более лёгкий (~25%) — для второстепенных декоративных чипов;
  - backdrop-blur **20–24px** + небольшой saturation-boost, чтобы цвета фото под стеклом усиливались;
  - тонкая (1px) светлая обводка/хайлайт по верхнему краю — имитация «пойманного света»;
  - мягкая тень, отделяющая панель от фона.
  Источник: обобщение из практики glassmorphism-компонентов, см. подборку
  [CodeFronts — Glassmorphism Pill Badge](https://codefronts.com/snippets/css-tags-chips/glassmorphic/)
  и [designstudiouiux.com](https://www.designstudiouiux.com/blog/what-is-glassmorphism-ui-trend/).
- Что устарело: жёсткая чёрная плашка на 100% непрозрачности через всю ширину карточки, толстая
  белая обводка вокруг текста (эффект «стикер из 2015»), длинная тень (drop-shadow с большим
  сдвигом) — читается как дешёвый watermark, а не бренд-элемент.
- Что современно: короткая мягкая тень (blur без offset), тонкая полупрозрачная обводка, локальный
  затемняющий градиент именно под текстом (а не по всей карточке) — практика «directional scrim»,
  упомянутая в актуальных (2026) материалах по overlay-карточкам.

## 4. Типографика бейджа

- Точных пропорций знак/текст у Strava/Nike/Duolingo НЕ НАЙДЕНО — открытых guideline-документов
  нет в индексируемом виде.
- Общее правило из watermark-практики, применимое напрямую: **тестировать шрифт в финальном
  размере** — тонкие штрихи и мелкие детали теряются при компрессии/растрировании, поэтому для
  бейджа предпочтителен жирный сан-сериф, не тонкое начертание
  ([Zight — Watermark Design Best Practices](https://zight.com/blog/best-practices-for-video-watermark-design/)).
- Практическая рекомендация под это правило и под шрифт Unbounded (переменная толщина): брать
  bold/semibold начертание, не regular/light — тонкие насечки Unbounded Light на растрированном
  1080px JPEG через librsvg могут потерять чёткость.
- Регистр: для короткого бренд-слова в пилюле типовая практика — либо все заглавные с небольшим
  трекингом (создаёт ощущение «печати»/лейбла), либо обычный регистр для более «человечной»,
  некорпоративной подачи (это выбор стиля, а не измеренное правило — оба варианта встречаются).
- Иконка/знак обычно занимает высоту, близкую к высоте строчных букв текста рядом (x-height) или
  чуть выше — это общее правило верстки «иконка + текст в один ряд», не специфика конкретного
  бренда.

## 5. Композиция «премиум»-карточки

- Иерархия сверху вниз (подтверждается общей практикой overlay-карточек и структурой карточки
  в постановке продукта): фото — на весь кадр без рамки; тёмный градиент снизу вверх, затемняющий
  только зону, где лежит текст (а не всю карточку) — практика «directional scrim overlay»
  ([CodeFronts, 2026](https://codefronts.com/design-styles/css-gradient-ui/hero-banner-gradient-overlay/)).
- Число-герой (ккал) — самый крупный элемент текстового блока, задаёт первый взгляд; состав блюда —
  вторая по значимости строка; 3 макроса (Б/Ж/У) — ряд одинаковых по весу маленьких чисел под
  героем, не крупнее подписи блюда.
- Источник (USDA FDC # + порция) — самый мелкий текст, внизу текстового блока, воспринимается как
  «мелкий шрифт доверия», не как часть иерархии для беглого прочтения.
- Максимум элементов на карточке — общий принцип overlay-карточек: не больше одного «героя»,
  одного вторичного блока и одной служебной строки внизу; больше — карточка перестаёт читаться
  за секунду просмотра сторис (это следует из общей практики карточек-обзоров/hero-паттернов,
  не найдено как измеренное число специально для fitness-share-карточек).
- Бренд-бейдж — отдельный, самый нижний слой, физически НЕ сливающийся ни с градиентом текстового
  блока, ни с source-строкой: собственная подложка/пилюля, собственный отступ от нижнего края
  (внутри safe zone, см. п.1).

## 6. Референсы (по словесному описанию найденного)

1. **Strava** — активность-карточки известны как эталон «фото маршрута/активности на весь кадр +
   компактный блок статистики поверх», но именно официального описания бейджа и его пиксельных
   параметров НЕ НАЙДЕНО в открытом поиске (Behance/Dribbble-материалы про иллюстрации бейджей
   достижений, это другая сущность — не бренд-watermark на share-карточке).
2. **Spotify Wrapped 2025** — сильная сторона: единая, но каждый год визуально разная
   «фирменная система» (в 2025 — ретро/аналоговая эстетика, значки-пины, doodle-линии), которая
   делает шеринг узнаваемым БЕЗ отдельного маленького логотипа-бейджа — бренд считывается через
   весь визуальный язык карточки, а не через угловой знак.
   ([spotifynews.substack.com](https://spotifynews.substack.com/p/designing-2025-wrapped-turning-a)).
3. **Nike Run Club** — сильная сторона: типографика лёгкая, много воздуха, акцентный цвет только
   для одного элемента; шеринговые шаблоны различаются по ТИПУ пробежки (обычная/темповая/длинная),
   но «каждый шеринг NRC узнаётся как NRC» — единая система лейаутов и ограниченный набор метрик,
   не перегруженная карточка. Официального описания веса/позиции бренд-бейджа НЕ НАЙДЕНО.

Ограничение честно: по всем трём найдены только общие обзорные материалы (пресс/дизайн-блоги), не
официальные style guide с пиксельными значениями — специфичные числа по этим брендам считать
недоступными, а не «примерно такими же, как везде».

## 7. Антипаттерны — что делает бейдж «убогим»

- Полностью непрозрачная плашка на всю ширину карточки — читается как баннерная реклама, а не как
  элемент бренда.
- Толстая белая/чёрная обводка вокруг текста бейджа («сборка из 2012–2015») вместо мягкой тени
  или тонкой подложки.
- Длинная смещённая тень (offset drop-shadow) — визуально «приклеенная наклейка».
- Бейдж без подложки поверх светлого/пёстрого фото — на части кадров становится нечитаемым
  (нарушение контрастного порога 4.5:1/3:1 из п.3).
- Бейдж, залезающий в зону UI Instagram/Telegram (верхние/нижние ~220–250 px) — обрезается или
  перекрывается интерфейсом соцсети.
- Логотип крупнее или заметнее, чем число-герой (ккал) — переворачивает иерархию: карточка
  выглядит как реклама приложения, а не как результат пользователя.
- Разный шрифт/вес бейджа относительно остальной типографики карточки — визуально «приклеенный
  сверху» элемент, не часть дизайн-системы.
- Бейдж как «наказание» — контрастная рамка/иконка замка/текст вида «АПГРЕЙД, ЧТОБЫ УБРАТЬ» —
  превращает мягкий стимул к подписке в раздражающий барьер; правильная подача — нейтральная
  подпись источника контента («распознано в «Тарелке»»), не императив.
