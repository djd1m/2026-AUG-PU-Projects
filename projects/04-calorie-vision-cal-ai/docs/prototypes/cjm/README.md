# Прототип CJM «Тарелка» — четыре пути

Кликабельный прототип четырёх вариантов CJM (A/B/C/D) из [`../../CJM_Variants.md`](../../CJM_Variants.md).
Выбор варианта **не сделан** — прототип существует, чтобы владелец его сделал.

## Как открыть

Двойной клик по `index.html` — офлайн, с `file://`, без сервера и сборки. Точки входа в
вариант: `variant-a.html` … `variant-d.html`. Состояние в адресе: `index.html#C/4` —
вариант C, шаг 4; такой ссылкой можно делиться.

## Что кликать

| Где | Что делает |
|---|---|
| Вкладки A/B/C/D | переключают вариант; работают стрелками с клавиатуры |
| Рельс из 6 шагов | Вход → Камера → Результат → Дневник → Paywall → Рост |
| Шаг 2, круглая кнопка | «снимает» кадр и переводит на экран результата |
| Шаг 3, степпер «− 1 +» | пересчитывает четыре плитки (ккал и БЖУ) |
| Шаг 3, чип «USDA FDC …» | раскрывает запись открытой базы — откуда взялось число |
| Шаг 3, «показать расхождение» | экран выбора «модель ≠ база», а не тихое усреднение |
| Шаг 4 | B: видимость страницы дня · C: роль клиент/тренер · D: бонус за код |
| ⚖️ «Сравнить варианты» | таблица четырёх вариантов + готовый текст решения |
| 🔧 «Собрать свой» | гибрид: по каждому шагу выбрать вариант-донор |
| 📊 «Скрыть карту» | убирает правую панель для чистого показа |

**Ничего никуда не отправляется и не сохраняется:** решение фиксирует владелец в чате.

## Смоук

```bash
node tests/smoke.cjs
```

Playwright берётся из соседнего окружения — у прототипа зависимостей нет. Проверяются
4 варианта × 6 шагов, обе панели, отсутствие горизонтального скролла на 390px и ошибок
в консоли. Результаты — `tests/*-results.json`, скриншоты — `tests/shots/`.
Числа калорийности и записи дневника — демонстрационные.
