Как ограниченный страж слоя 1 — приемлемо при ручном ревью соответствий.

- [medium] **Контракт `curated_by` приемлем для перезаливки при подтверждённом исключительном владении метками.** Замечание круга 1 закрыто контрактом условно: комментарий не доказывает отсутствие ручных строк под теми же метками. Отсутствия других кураторов недостаточно. **253 ≠ 153 × 2**; число согласуется с гипотезой `100 × 2 + 53`, которую нужно подтвердить историей загрузок.

До запуска потребовал бы такой read-only SQL:

```sql
BEGIN TRANSACTION ISOLATION LEVEL REPEATABLE READ READ ONLY;

SELECT curated_by, count(*) AS rows,
       count(DISTINCT name_ru_normalized) AS names
FROM food_synonym
GROUP BY curated_by
ORDER BY curated_by;

SELECT s.curated_by, s.name_ru, s.name_ru_normalized,
       f.source, f.source_id, s.recipe_parts,
       count(*) AS copies,
       min(s.curated_at) AS first_curated,
       max(s.curated_at) AS last_curated
FROM food_synonym s
LEFT JOIN food_item f ON f.id = s.food_item_id
WHERE s.curated_by IN ('nutritionist-ru-01', 'coordinator-ru-02')
GROUP BY s.curated_by, s.name_ru, s.name_ru_normalized,
         f.source, f.source_id, s.recipe_parts
ORDER BY s.curated_by, s.name_ru_normalized;

ROLLBACK;
```

Результат второго запроса сверить с **ранее загруженными версиями seed**, включая состав рецептов. Необъяснённые строки или варианты содержимого требуют разбора до удаления; одних итоговых счётчиков недостаточно.
