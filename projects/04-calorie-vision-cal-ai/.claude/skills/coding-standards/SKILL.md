# Стандарты реализации N4 «Тарелка»

Сначала прочитать `.claude/rules/coding-style.md` и нужный алгоритм в `docs/Pseudocode.md`. Для
изменений схемы, транзакций, границ доверия и интеграций дополнительно `.claude/rules/security.md`,
`docs/Architecture.md` и применимый ADR.

## Девять обязательных образцов

1. **Внешнее значение разбирается из `unknown` через схему**, а не приводится типом. Это относится и
   к телу HTTP-запроса, и к ответу поставщика модели, и к `initData`.
2. **Диапазоны проверяет наш код после разбора.** Structured outputs гарантируют тип и форму, но не
   `minimum`/`maximum`/`maxItems`. `confidence` 0…1, `mass_g` 1…5000, позиций ≤ 12, кандидатов ≤ 3,
   `model_estimate_kcal` ≥ 0; нарушение — `failed(schema_violation)` с названным полем, а НЕ
   подрезание до границы: `confidence = 7` иначе тихо станет «уверен» и отменит эскалацию.
3. **Число считается из снимка.** `(mass_g / 100) × значение_на_100г` берётся из `Snapshot`, а не из
   живой строки `food_item`. `model_estimate_kcal` читается ровно в одном месте.
4. **Разделяемый ресурс правится одним оператором.** Квота, идемпотентный ключ, захват аренды —
   `INSERT … ON CONFLICT …` и условный `UPDATE … WHERE lease_fence = ?`. Никакого
   «прочитать, потом записать»: две попытки приходят ОДНОВРЕМЕННО, обе не находят строки, обе пишут.
5. **Транзакция не держит внешний вызов.** Аренда закрывается до обращения к модели; ограничение
   создают предикат `leased_until` и fencing, а не длинная транзакция.
6. **Владение резолвится на сервере** по `owner_key`; чужой ресурс отвечает `404`, тем же ответом,
   что и несуществующий.
7. **Закрытые перечисления — union-типы.** Значение вне набора трактуется как самое строгое:
   `failed`, `rejected`, тариф `free`, «нет согласия».
8. **Отсутствие числа показывается как отсутствие.** `unmatched` исключается из итога; нулевой
   знаменатель даёт «не измерено» и «недостаточно данных (n из 30)», а не `0%` и не пустую полосу.
9. **Внешний сервис — за адаптером.** У поставщика модели две реализации: живой клиент и
   детерминированный фейк. Тесты не ходят в интернет; живой режим включается ключом и помечается
   отдельно (DEC-A-009).

## Порядок шагов в маршруте приёма скана

Порядок принадлежит защите, а не удобству. `EnqueueScan`:

```
частота → формат и размер по БАЙТАМ → заявка Idempotency-Key (ON CONFLICT DO NOTHING)
        → CheckAndConsumeQuota(primary): 3 ключа, одна транзакция
        → загрузка оригинала в приватный бакет, photo(expires_on, file_state=present)
        → growth_event(install) при первом скане сессии
        → 202 { scan_id, status: 'queued' }
```

Валидация РАНЬШЕ идемпотентности: мусорный запрос, занявший ключ, сделал бы повтор с исправленным
фото вечным отказом. Квота ПОСЛЕ валидации и ДО модели: мусор не жжёт чужую квоту, а вызов не
делается бесплатно.

`RecognizeScan`: аренда с fence → закрыть транзакцию → presigned-URL ≤ 15 мин → нормализация
(HEIC→JPEG, ≤ 1568 px, ≤ 5 МБ) → Haiku 4.5 по схеме → проверка диапазонов → при `confidence < 0,6`
сначала `CheckAndConsumeQuota(escalation)` и только потом Sonnet 5 → поиск в базе → расчёт →
`Snapshot` → `discrepancy_ratio` → условная запись по своему fence.

## Единицы, время, имена

Граммы и килокалории — целые; макронутриенты — один знак после запятой. Календарные сутки, границы
дня, стрик и потолки — `Europe/Moscow`; `eaten_on` хранится как `date`. Имена сущностей, статусов,
маршрутов и чисел берутся из `docs/canon.md`; переименование фиксируется в плане фичи, а не
вводится молча.

## Миграции

Обычные SQL-файлы в `packages/db/migrations`, по порядку, с описанным откатом. Уникальность и
потолки обеспечивает база, а не код. Частичные индексы под реальные чтения:
`(status, leased_until) WHERE status = 'queued'`, `(owner_key, eaten_on) WHERE deleted_at IS NULL`,
`(expires_on) WHERE file_state = 'present'`, GIN-триграммы по `food_item.name_en` и
`food_synonym.name_ru_normalized` — именно по нормализованной форме, потому что поиск идёт по ней.

## Перед тем как назвать команду

Точные версии, пути workspace и имена npm-скриптов фиксирует фича `foundation` и подтверждает
исходник. До этого команда из документа — предложение, а не факт. Если чего-то нет — сообщить о
пробеле, а не изобрести синтаксис.
