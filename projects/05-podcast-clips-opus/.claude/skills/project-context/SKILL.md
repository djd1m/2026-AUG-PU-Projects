# Контекст проекта N5 «КлипМейкер»

Порядок чтения: `docs/validation-report.md` → `docs/PRD.md` → `docs/Specification.md` → документ по
роли вопроса. Проверенные документы — это планы и контракты. Из их существования не следует ни
приложения, ни маршрута, ни теста, ни развёрнутого стенда: **реализация не начиналась**.

## Продукт и актёры

Нарезка коротких вертикальных клипов из длинной записи. Ведущий загружает подкаст или вебинар,
продукт расшифровывает речь с таймкодами СЛОВ, выделяет 3–8 самодостаточных фрагментов по 20–75 с,
режет их в 9:16 с вшитыми субтитрами и показывает оценку 0–99 с объяснением из трёх компонентов.
Клон Opus Clip; отличает его от источника не обещание точности, а объяснённая оценка и честное
число найденных фрагментов: если самодостаточных нашлось два, показываются два, а не добитые до
трёх.

Клиент один: веб-приложение Next.js на своём домене, мобильная вёрстка обязательна. Контур — Россия
и СНГ, интерфейс русский. Площадки публикации — VK Клипы, Telegram, Rutube, Дзен; публикует
пользователь вручную, автопостинга нет. CJM — вариант **D**: путь A целиком плюс блок «клипы для
гостя» (B-лайт), выбран владельцем 2026-09-21 (OWN-001).

| Актёр | Кто это | Что делает |
|---|---|---|
| **Сергей** | эксперт-подкастер, записывает час в неделю и публикует сам | загружает запись, ждёт клипы, выбирает лучшие, скачивает, копирует ссылку, отправляет гостю |
| **Анна** | гость выпуска, у неё своя аудитория и нечем поделиться после эфира | открывает гостевую страницу без регистрации, скачивает свои клипы, может зарегистрироваться оттуда |
| **Кирилл** | блогер-партнёр с каналом о контенте | раздаёт персональный код, смотрит счётчики в кабинете |
| **зритель чужой ленты** | случайный человек в VK Клипах | видит метку с адресом, переходит по `/c/{code}` |
| **оператор** | держит стенд | смотрит расход по попыткам, отказы по потолкам, свободный диск |

## Что входит в неделю

Загрузка видео до 2 ГБ → транскрипция с таймкодами слов → выделение 3–8 самодостаточных фрагментов
→ кроп 9:16 с вшитыми субтитрами → оценка потенциала с объяснением → экран клипов (плеер, скачать,
короткая ссылка) → метка на free с короткой ссылкой → «клипы для гостя» (галочки, согласие,
гостевая страница без входа) → код блогера при регистрации и кабинет партнёра → потолки минут и
загрузок → экран интереса «Pro скоро» → срок хранения клипов на free.

## Что НЕ входит — и это решение, а не пропуск

Автопостинг · brand kit · командная работа · распознавание лиц и авто-фрейминг · диаризация и
сортировка по спикерам · бонусные минуты за гостя и связанный анти-фрод · **приём денег** (ЮKassa из
клона — спящий код, вторая волна) · выплаты партнёрам · экспорт в NLE · AI B-roll · дубляж ·
шоуноты и посты как публичная страница.

Три требования помечены `Should` и включаются, только если неделя позволит: ссылка на VK/Rutube
(`FR-INGEST-003`), отправка клипа себе в Telegram (`FR-RESULT-003`), вход через Telegram
(`FR-AUTH-002`). Первые два опираются на зависимости со статусом **UNCONFIRMED** и в Phase 3 не
входят, пока статус не изменится. Решение о включении фиксируется в `docs/Completion.md` до релиза,
а не молчаливым пропуском.

## Словарь (термины употреблять как здесь, синонимы не заводить)

| Термин | Значение |
|---|---|
| **запись** (`video`) | исходный загруженный файл: 2–90 мин, ≤ 2 000 000 000 байт |
| **клип** (`clip`) | один вырезанный фрагмент 20,0–75,0 с в 9:16 с субтитрами |
| **метка** | надпись, вшитая в ПИКСЕЛИ клипа на тарифе free: «КлипМейкер · <домен>/c/<code>» |
| **короткая ссылка** (`clip_link`) | `/c/{code}` — лендинг с атрибуцией и счётчиком перехода, НЕ файл |
| **гостевая страница** (`guest_pack`) | приватная по коду подборка клипов гостя, `noindex`, 14 дней от отправки |
| **фенс** (`fence`) | монотонный счётчик попыток НА ВИДЕО; результат принимается только от актуальной попытки |
| **серия** (`series_no`) | набор попыток стадии; кнопка «повторить» открывает новую серию |
| **scope квоты** | один из ШЕСТИ ключей счётчика расхода |
| **probe** | первый шаг стадии `stt` в `worker-stt`: скачивание, `ffprobe`, списание минут |
| **самодостаточный фрагмент** | понятен без контекста выпуска; именно это, а не «интересный», ищет модель |

Три состояния, которые видит пользователь, — `выполняется`, `успех`, `отказ`. Семь значений
`video.status` — внутренние и на экран не выносятся.

## Числа канона — единственный источник

| Параметр | Значение |
|---|---|
| Размер файла | ≤ 2 000 000 000 байт; тип по байтам (MP4/MOV/WebM/M4A/MP3) |
| Длительность записи | 2–90 мин, измеряется `ffprobe` в `worker-stt` |
| Минуты на аккаунт в сутки | **90** — равно максимальной длительности: одна полная запись обрабатывается всегда |
| Загрузки на аккаунт в сутки | 2; анониму — 0 |
| Возвраты слота загрузки в сутки | 2 (`user_upload_refunds`) |
| Вызовы LLM: на аккаунт / всего | 2 / 20 |
| Суточный потолок минут (все аккаунты) | 600 |
| Одновременных тяжёлых задач | 1 на VPS |
| Клипов на запись | 3–8; длина 20,0–75,0 с |
| Оценка | 0–99 = хук (0–33) + завершённость (0–33) + длина (0–33), у каждой фраза объяснения |
| Метка | нижний левый угол, высота ≥ 3,5 % кадра, внутри safe zone сторис, контраст ≥ 4,5:1 |
| Срок хранения клипов free | 3 дня после `done` |
| Срок гостевой страницы | 14 дней от отправки |
| Подписанная ссылка | ≤ 15 мин |
| Попытки рендера | ≤ 2 автоматических, таймаут ffmpeg 15 мин |
| Задача целиком | ≤ 30 мин; ответ на создание — сразу, `202`-семантика |
| Лимит частоты | 30/мин мутирующие, 120/мин чтение, на IP, ДО тела |
| Анти-фрод | 50 применений кода с одного `ip_prefix` за 10 мин → `blocked` |
| Таймзона | Europe/Moscow |

## Метрики недели и что они не значат

| Метрика | Цель | Откуда значение |
|---|---|---|
| Клипов с меткой наружу (≥ 1 внешний переход) | ≥ 40 | наша БД |
| Аккаунтов, выпустивших хотя бы один такой клип | ≥ 10 | наша БД |
| Записей с отправленной гостевой ссылкой / из них открыто | ≥ 30 % / ≥ 50 % | наша БД |
| Показатель i — клипов наружу на активный аккаунт | ≥ 4 | наша БД |
| conv% — переходы по метке → регистрации | ≥ 1 % при n ≥ 30 | наша БД |
| Время до готовности всех клипов, p95 (час записи) | ≤ 20 мин | наш журнал |
| Расход на модели за сутки | ≤ 600 ₽ | наш журнал |
| Читаемость метки на телефоне | 5 из 5 | **ручное измерение**, два человека, экран ≈6 дюймов |

Показатели **i и conv% ведутся раздельно и не перемножаются**: произведение двух оценок выдаёт
догадку за измерение. Удержание D7/D30 и окупаемость привлечения в неделю не закладываются —
горизонт короче их периода, а процент на выборке меньше 30 наблюдений самообман. Порог conv% 1 % —
проверяемая гипотеза, а не обязательство (DEC-A-003).

Сверка расхода с отчётом поставщика требует ОРГАНИЗАЦИОННОГО аккаунта Anthropic и
`ANTHROPIC_ADMIN_KEY` у оператора. Если аккаунт индивидуальный, метрика измеряется вручную по
консоли — и это называется вслух, а не подменяется словами «не измерено никак».

## Нерешённые вопросы и границы знания

1. Доступность имени «КлипМейкер» не проверялась — рабочее, унаследовано от январского клона.
2. Совместимость Cloud.ru Object Storage не доказана: тесты идут на MinIO, ручная приёмка остаётся
   владельцу (DEC-A-005).
3. Найдёт ли модель три самодостаточных фрагмента в настоящем часовом выпуске — не проверено.
4. Читается ли метка на телефоне в ленте VK Клипов — не проверено.
5. Уложится ли часовая запись в 20 минут p95 — не измерено.
6. Восстановления пароля в неделе нет (DEC-A-007): почтового провайдера нет в инвентаре внешних
   зависимостей, и добавить его — отдельное решение со строкой инвентаря.
