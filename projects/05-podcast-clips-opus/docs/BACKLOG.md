## 1. Перенос на другой сервер — чего НЕТ в репозитории

Репозиторий переносит код и документы. Эти вещи живут только на текущей машине, их нужно перенести или
пересоздать отдельно:

| Что | Где сейчас | Что делать |
|---|---|---|
| Секреты и настройки стенда (27 переменных: пароли БД/Redis/MinIO, `SESSION_SECRET`, `OPENROUTER_API_KEY`, `N5_PUBLIC_ORIGIN`, потолки `N5_LIMIT_*`…) | `/tmp/n5-demo.env` (вне git, **/tmp может очиститься при перезагрузке**) | перенести защищённым каналом или создать заново по `.env.example`; пароли — `openssl rand -hex 24`. Смена `SESSION_SECRET` разлогинит всех — это нормально |
| Настройки тестового стека | `/tmp/n5-test.env` | пересоздать по `.env.example` (любые случайные пароли) |
| Данные стенда: база (аккаунты, записи, клипы, партнёрка), файлы клипов и превью, журнал расхода | тома Docker `n5-clipmaker_pgdata`, `n5-clipmaker_miniodata`, `n5-clipmaker_model-spend`, `n5-clipmaker_caddydata` | если стенд нужен со старыми данными — `pg_dump` + копия бакета MinIO; иначе — пустой стенд и новый прогон записи. **Витринный клип `/c/CTDUUG`** (лендинг, ADR-018) живёт в этих томах: без переноса витрина пуста, лендинг покажет 404 видео — пересобрать демо и поправить `SHOWCASE_CLIPS` (`packages/shared/src/showcase.ts`) |
| Тестовые данные прибора вёрстки (учётка UI-фикстуры) | `.responsive-fixture/ui-fixture.json` (вне git, 0600) | пересоздать `scripts/seed-ui-fixture.mjs` на новом стенде (`REPRODUCE.md` §8а) |
| Внешний прокси и TLS для `clipmkr.ru` | общий Caddy соседнего проекта `ai-hub-tls-proxy` на этой машине | на новом сервере — свой Caddy с доменом (`REPRODUCE.md` шаг 7, вариант «Общего прокси нет») и перенос DNS `clipmkr.ru` |

## 2. Требования спецификации, отложенные (`Should`, «при нехватке недели»)

1. **FR-RESULT-003 — «отправить клип себе в Telegram».** Кнопка на карточке кладёт файл в личный чат с ботом
   (публикуют с телефона, делают на компьютере). Рекомендуемый следующий шаг.
2. **FR-INGEST-003 — загрузка по ссылке VK Видео / Rutube.** Зависимость `UNCONFIRMED`: скачивание с площадок не
   проверено. Колонка `video.source_url` в схеме зарезервирована под это.
3. **FR-AUTH-002 — вход через Telegram** (второй способ входа).
4. **Восстановление пароля по почте** — нужен почтовый сервис.

## 3. Ждут решения или данных владельца

5. **RT-005** — контакт оператора на гостевой странице `/g/`: нужен реальный адрес и ответственный.
6. **Приём денег** — ЮKassa: код спящий (ADR-005), маршрут вебхука не зарегистрирован; «Pro» ведёт на экран
   интереса. Включение = правило `incoming-webhooks.md` целиком + тестовый магазин.
7. **Перенос базы в российскую юрисдикцию** (OWN-006) — ОБЯЗАТЕЛЕН до первого реального пользователя: сейчас
   персональные данные в PostgreSQL на VPS в Нидерландах.
8. **Подтверждение почты при регистрации** — до реальных пользователей (сейчас несколько бесплатных аккаунтов на
   одного человека возможны — принятый риск OWN-008).
9. **Cloud.ru Object Storage** — боевое хранилище по замыслу (OWN-004); тесты и стенд на MinIO. Ручная приёмка
   (SigV4, multipart, Range, CORS) — чек-лист в `Completion.md` (DEC-A-005).

## 4. Не проверено (эмуляция и тесты это не доказывают)

10. **Встроенные браузеры Telegram и VK** — скачивание клипа изнутри, лендинг, `/c/`, `/g/` (OWN-016, финальный
    пункт плана mobile-ui). Нужен живой телефон.
11. **Настоящий iPhone** — первый экран с панелями Safari (в эмуляции WebKit панель первой карточки кончается с запасом 51–163 px до низа экрана).
12. **Читаемость метки на телефоне человеком** (FR-GROWTH-005): двое смотрят 5 клипов с руки.
13. **NFR-PERF-001** — час записи ≤ 20 мин p95: одна точка (88,4 мин → 12 мин 39 с), не p95.
14. **Надпись призыва в кадре** — не смотрел человек; не-перекрытие с субтитрами доказано аналитически.

## 5. Технические хвосты

15. Витрина лендинга раздаёт клип ≈ 23 МБ публично; ограничение — только 120 запросов/мин на адрес, облегчённой
    версии клипа нет (`docs/features/landing-demo/05_completion.md`).
16. Модерации адресов призыва нет: вредный https-сайт автора покажется на `/c/` с доменом (фича 27).
17. Рантайм-образы несут devDependencies (Playwright ≈ 32 МБ): `npm prune --omit=dev` в Dockerfile.
18. Прибор вёрстки: R9 на стенде проверяет экран записи только в готовом состоянии (фикстура `done`); мобильный
    WebKit изредка даёт «нестабильный замер» контраста — прибор помечает его предупреждением.
19. Осиротевший аккаунт UI-фикстуры `ui-fixture-1790328187143` на стенде (мусор от первого прогона сида).
20. Модели OpenAI в разработке не используются с 25.09.2026 (OWN-017): фичи 25–29 проверены одним семейством
    (Opus пишет, Sonnet ревьюит). Когда квота вернётся — кросс-семейное ревью фич 25–29 желательно.
