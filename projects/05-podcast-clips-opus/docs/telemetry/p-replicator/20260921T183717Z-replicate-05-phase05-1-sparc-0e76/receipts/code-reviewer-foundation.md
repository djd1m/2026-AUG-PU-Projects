## Находки по серьёзности

**blocker — 2**

* **RV-001** — `ip.ts:6` берёт последний элемент `X-Forwarded-For`. В топологии, записанной в
  `proxy/Caddyfile:1-2` и `docker-compose.yml:142` (внешний прокси машины → петлевая публикация →
  Caddy → web), этот элемент постоянен для всех пользователей. Следствия: ограничитель частоты
  вырождается в ОДНО общее ведро 30/мин на весь продукт (перебор не ограничен, любой посетитель
  закрывает вход всем), `session.ip_prefix` одинаков у всех сессий. Не выполнен именной критерий
  `FR-AUTH-001 @security` («31-й запрос **с одного IP**»), канон §7 и шаг 1 `AuthRegisterAndLogin`.

  приложения. Не выполнен критерий `FR-RENDER-002 @security` («процесс НЕ стартует»). Комментарий
  `instrumentation.ts:4` утверждает обратное; `tests/health.test.ts:11` утверждает 503, живой сервер
  даёт 500 — тест покрывает путь, которого в этом отказе не существует.
