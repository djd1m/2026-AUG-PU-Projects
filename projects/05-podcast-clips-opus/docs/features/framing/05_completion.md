# Квитанция — framing (кадр следует за лицом)

**Решение:** ADR-009. **Требование:** FR-RENDER-004 (`docs/Specification-addendum.md`).
**Коммиты:** `1f13bd8`, `2a6a55d`, `bc5b70c`.

## Путь к решению — три опровергнутых предположения

| Предположение | Замер, который его опроверг |
|---|---|
| Центральный кроп 9:16 годится | для 1280×720 видна полоса ~405 px из 1280; двое по краям не попадают |
| Два этажа по половинам кадра | нижняя панель пуста в 10 замерах из 12 (83 % клипа) |
| Следить за говорящим по каналам звука | каналы совпадают: корреляция громкостей 0,9995, ноль окон с разницей > 3 дБ из 10 611 |

## Что проверено и чем

| Свойство | Чем | Итог |
|---|---|---|
| Без плана два этажа не строятся | `tests/framing.test.ts` | мутация «вернуть слепые этажи» → 1 красный, восстановлено → 9 из 9 |
| Граф двух этажей не путает панели | `tests/framing-media.test.ts`, настоящий ffmpeg, исходник «красное \| синее» | красное сверху, синее снизу |
| Кадр без лица отсутствует | живой прогон, детектор по **готовым** клипам | 384 с, семь клипов, ноль кадров без лица |
| Кадр переключается за камерой | журнал `framing_plan` | 38 переключений против 14 при постоянном пороге |
| Ложное лицо на фоне не уводит кадр | клип 6, секунда 0: лица 0,041 и 0,045 при пороге 0,049 | отсеяны |

## Числа (канон §7)

Шаг замеров 0,5 с · порог размера 0,4 × медиана лиц клипа, не ниже 0,03 · лицо в верхней 0,34 окна ·
смена плана не чаще 1,5 с и при сдвиге ≥ 0,06 · два замера без лица терпимы · два этажа при
присутствии обоих ≥ 0,9 · одиночный план при ≥ 0,5.

## Ошибки по дороге — названы

1. Постоянный порог 0,06, выбранный по одному наблюдению, отсёк большинство участников в клипе общими
   планами (медиана 0,048): кадр перестал переключаться. Владелец заметил.
2. Проверка «кадров без лица — ноль» объявила задачу закрытой, хотя доказывала отсутствие стены, а
   не следование за говорящим. Разные свойства.
3. «Детектор недоступен» откатывался к слепым этажам, «лиц нет» — к центру. Вскрылось в контейнере
   без OpenCV.

## Чего фича НЕ доказывает

- Следование за **говорящим**: кадр идёт за самым крупным лицом. На общем плане обоих это не одно и
  то же. Точное решение — раздельные дорожки звука по участникам.
- Тесты не проверяют детектор на настоящем видео: в тестовом образе нет OpenCV.
- Качество кадра на телефоне — только глазами владельца («теперь всё нормально», 23.09.2026).
