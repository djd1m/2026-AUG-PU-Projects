# Постановка для Codex — фича 21 `pause-compaction`: убрать паузы из клипа

Готовы фичи 1–20, **697 тестов** в образе. Решение владельца — OWN-012 в `docs/decisions-owner.md`.
Разбор и измерения — `docs/proposals/density/00_proposal.md` (§2–§7 обязательны, особенно §5 «Что
ломается»). Образцы, на которых владелец выбрал K, сделаны разовым скриптом
`docs/features/pause-compaction/samples.py` (приложен как образец алгоритма, не код продукта).

## Что построить

### 1. Схема, загрузка, интерфейс
- Миграция `017_compaction.sql`:
  - `video.compact boolean NOT NULL DEFAULT false`;
  - `video.loudness_median_db numeric(6,2)` — медиана огибающей ВСЕЙ записи (лениво, см. п. 2);
  - `clip.cut_plan jsonb` — сохранённый план резов (массив `[start, end]` сохраняемых кусков в
    секундах ИСТОЧНИКА) или `null`;
  - `clip.duration_seconds numeric(6,2)` — фактическая длина файла клипа.
- `video.create`: `compact: z.boolean().optional()`, отсутствие = `false`, повтор ключа с другим
  значением → 409 (как `music`, `teaser`). `Uploader.tsx`: третья галочка «Убрать паузы», по
  умолчанию ОТМЕЧЕНА, в Resume, блокируется при возобновлении; Resume без поля → `false`.
- `ClipCard.tsx`: длина — `clip.duration_seconds`, если есть, иначе прежняя разность границ.

### 2. План резов — детерминированно и один раз
- Константы: `COMPACT_KEEP_SECONDS = 0.05` (K, решение владельца OWN-012), `COMPACT_XFADE_SECONDS = 0.06`,
  `COMPACT_MIN_PAUSE = 0.30`, `COMPACT_MAX_PAUSE = 2.0`, `COMPACT_EDGE = 0.5`,
  `COMPACT_THRESHOLD_BELOW_MEDIAN_DB = 18`, `COMPACT_MIN_SAVING = 0.03`, окно огибающей 20 мс.
- **Медиана записи** — если `video.loudness_median_db IS NULL`, `worker-video` считает её по ВСЕЙ
  записи (моно 16 кГц, RMS по 20 мс, медиана дБFS) и записывает одним `UPDATE … WHERE
  loudness_median_db IS NULL`. Работает и для записей, загруженных до фичи.
- **План** — если `clip.cut_plan IS NULL`: огибающая диапазона клипа, тихие участки ниже
  `медиана − 18`, длиной `[0,30; 2,0]` с, не ближе `0,5` с к краям; каждый ужимается так, что после
  перекрестия остаётся ровно K тишины (`(K + XF)/2` с каждой стороны, как в `samples.py`). Если
  итог < 20,0 с или экономия < 3 % → план = один кусок (весь диапазон), уплотнения нет. План
  сохраняется в `clip.cut_plan` ДО рендера и при повторной попытке ЧИТАЕТСЯ, а не пересчитывается.
- Чистые функции `buildCutPlan(envelopeDb[], median, start, end) → Segment[]` и
  `mapTime(plan, tSource) → tOutput` с тестами. Время внутри вырезанной паузы отображается на
  точку стыка.

### 3. Рендер
- `compact = true` и план из >1 куска → граф: `trim`/`atrim` по кускам исходника + цепочка
  `xfade=transition=fade:duration=XF` и `acrossfade=d=XF` (как `samples.py`), затем ПРЕЖНЯЯ цепочка
  кадрирования → субтитры → приманка → вспышка → метка. Один проход кодирования (RD-001).
- **Всё, что привязано ко времени, пересчитывается через `mapTime`:** слова субтитров (ДО
  `generateSubtitleFile`), планы следования за лицом (`FollowSegment.from`), длительность для музыки
  и пэк-шота (`t0` от ФАКТИЧЕСКОЙ длины), обложка (25 % фактической длины). Заголовок — с `t=0`,
  не меняется.
- Проверка длины: исходный диапазон — как сейчас; фактическая длина ≥ 20,0 с гарантирована планом.
- `clip.duration_seconds` пишется для ЛЮБОГО рендера (и без уплотнения).
- Контракт: при уплотнении добавить `cut_plan` и `compact: 'v1:<K>:<XF>'`; без уплотнения — побайтово
  прежний (эталоны `baseline.json`, `music-only.json`).
- Журнал: `{"event":"compaction","cuts":N,"saved_s":…,"saved_pct":…}` либо
  `{"event":"compaction_skipped","reason":"too_short|small_saving|no_pauses"}`.
- Любая ошибка огибающей/медианы → клип без уплотнения + `compaction_skipped` с причиной; отмена
  (`signal`) пробрасывается.

## ОБЯЗАТЕЛЬНЫЕ правки после VALIDATE (перекрывают текст выше)

Проверка плана (Anthropic): READY WITH FIXES, 4 high.

1. **[high] Кадровая сетка.** Частота кадров уплотнённого рендера фиксирована `COMPACT_FPS = 25`;
   все границы кусков выравниваются по сетке 1/25 с; `COMPACT_XFADE_SECONDS = 0.08` (2 кадра) вместо
   0,06. K = 0,05 с (решение владельца) НЕ меняется: с каждой стороны паузы остаётся `(K + XF)/2`,
   выровненное по кадрам. Offset `xfade` считается по выровненным длинам. Тест: A/V-смещение после
   5 стыков ≤ 1 кадр (вспышка-метка в видео и щелчок в звуке у последнего куска).
2. **[high] Подключение звука.** Граф уплотнения выдаёт метки `[vc]` и `[ac]`. `buildMusicAudioGraph`
   получает метку речи ПАРАМЕТРОМ (сейчас `[0:a:0]` зашит); без музыки — `-map [ac]`. Ветка без
   видео (`color=`) — только `atrim`/`acrossfade`, без `xfade`, и `color=…:d=D'`. RD-001 (один
   `execFFmpeg`) — проверить и на mp3 без видео с `compact`.
3. **[high] Одна плановая длина D'.** `D' = Σ len − (n−1)·XF`, выровненная по кадрам, считается из
   плана ДО рендера и используется ВЕЗДЕ внутри рендера: `color=…:d`, выходной `-t`, музыка
   (`atrim`, `afade`, замер трека), пэк-шот (`t0 = D' − 0,8`), обложка (`0,25·D'`). ffprobe — только
   для `clip.duration_seconds`. Минимальная длина плана — `20,0 с + 1 кадр`.
4. **[high] План под фенсом и при любом пропуске.** В транзакции после `lockRender`:
   `UPDATE clip SET cut_plan=$1 WHERE id=$2 AND cut_plan IS NULL`, затем ПЕРЕЧИТАТЬ и рендерить только
   по значению из БД. При ЛЮБОМ пропуске уплотнения (мало экономии, коротко, нет пауз, ОШИБКА
   огибающей/медианы) записывается план из одного куска `[[start, end]]` — иначе повторная попытка
   уплотнит и получит другой контракт (S3 `412` → вечный `failed`). Отмена `signal` — до записи.
   `getRenderInput` отдаёт `compact`, `loudness_median_db`, `cut_plan`.
5. **[medium] Медиана:** записать (`WHERE loudness_median_db IS NULL`), перечитать и использовать
   ТОЛЬКО значение из БД (иначе первый клип считает по неокруглённой). RMS по всей записи — потоком,
   не держа весь PCM в памяти.
6. **[medium] `mapTime` формально:** смещение куска k = `Σ_{j<k} len_j − k·XF`; точки из
   `[e_{k−1} − XF, s_k + XF]` → середина перекрестия; вне `[start, end]` — зажим к краям; функция
   монотонна (тест на точках внутри перекрытия). Слово, целиком попавшее в паузу, получает
   `start = end` и отбрасывается — это записано и допустимо.
7. **[medium] Нормализация перед `xfade`:** каждый кусок `trim,setpts=PTS-STARTPTS,fps=25,
   format=yuv420p,settb=AVTB`; звук `aformat=sample_rates=44100:channel_layouts=stereo`. Тест на
   источнике с переменной частотой кадров.
8. **[medium] Время в `trim` — относительно `start`** (при `-ss start` перед `-i` метки входа с 0):
   `trim=s−start:e−start`. Следование за лицом: до `planFollow` пересчитать `sample.t` →
   `mapTime(plan, sample.t)` и передать `clipStart = 0`; детектор — на диапазоне источника.
9. **[medium] Субтитры:** 1) отфильтровать слова в шкале источника `[start, end]`; 2) `mapTime`;
   3) `generateSubtitleFile(mapped, 0, D')`.
10. **[low] `duration_seconds`:** пишется в фенсированном `UPDATE` внутри `publishRenderResult`
    (сигнатура `RenderResult` расширяется), длительность — пробой формата; в `screen.ts` и
    `ClipScreen` через `Number(...)`; `null` → прежняя разность границ.
11. **[low] Тест K:** синтетика — тональные вспышки с цифровой тишиной, измерение по сэмплам (окно
    1 мс), допуск ±10 мс; мутант «keep = K без XF» обязан покраснеть.
12. **[low] Прочее:** `compact = true` с планом из одного куска → граф и контракт побайтово прежние;
    `cut_plan` округлён до 1 мс; составляющая оценки «Длина» и её объяснение остаются про ИСХОДНЫЙ
    фрагмент — это решение, записать в отчёт. Уже загруженные записи уплотняются после
    `UPDATE video SET compact=true` и перерендера (делает координатор).

## Тесты

| Страж | Что проверяет | Дефект → ожидание |
|---|---|---|
| план | синтетическая огибающая: паузы 0,2 / 0,5 / 1,0 / 2,5 с, у края 0,3 с → режутся только 0,5 и 1,0 | снять `COMPACT_MAX_PAUSE` → красный |
| K | после рендера тишина на стыке ≈ K (±1 кадр), измеренная по звуку | `keep = K` без `XF` → красный |
| порог 3 % / 20 с | план из одного куска при экономии < 3 % и при итоге < 20 с | снять условие → красный |
| детерминизм | повторная попытка ЧИТАЕТ `cut_plan`; второй рендер побайтово равен первому по аргументам | пересчёт плана → красный |
| mapTime | монотонность, точки стыков, время внутри паузы → стык; слова субтитров не попадают в вырезанное | — |
| субтитры | на настоящем ffmpeg: слово после реза появляется в сдвинутое время (±1 кадр) | без `mapTime` → красный |
| длина | `clip.duration_seconds` = ffprobe файла (±0,05 с); ClipCard показывает её | — |
| пэк-шот | `t0` = фактическая длина − 0,8 | от исходной длины → красный |
| выключено | `compact=false` → эталоны `baseline.json`/`music-only.json` побайтово; медиана не считается | безусловное уплотнение → красный |
| схема | `compact` без поля → false; 409 при расхождении; лишнее поле → 422 | снять `.strict()` → красный |
| интерфейс | галочка отмечена по умолчанию, в Resume, блокируется | default false → красный |

Мутации обеими строками. Прогон — `npx vitest run` по затронутым файлам (Docker недоступен — не
повод для `failed`; полный прогон в образе и мутации делает координатор).
