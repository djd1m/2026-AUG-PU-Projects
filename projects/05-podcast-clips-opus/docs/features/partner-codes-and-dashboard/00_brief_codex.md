Готовы фичи 1–9. **391 тест зелёный** на настоящих PostgreSQL 16, Redis 7 и MinIO.

**Тир XL: фича трогает атрибуцию, то есть чужие деньги в будущем.** Партнёр приводит пользователей и

## Что построить

### 1. `code.apply` — четыре исхода, и они не симметричны

**ADR-007 — сердце фичи. Выпиши все четыре исхода в код явно, а не выводи из условий:**

| Переход | Ответ | Что происходит со строкой `attribution` |
|---|---|---|
| `cookie` → `explicit` | `200` + `replaced_source` | источник заменён: человек назвал код явно, это сильнее следа cookie |
| `explicit` → любой | **`409`** | явный выбор уже сделан и не переписывается |
| `guest_link` → `cookie` | **`409`** | переход по гостевой ссылке не вытесняется пассивным следом |
| недействительный код | **`422`**, строка **НЕ ТРОНУТА** | и **откат к cookie ЗАПРЕЩЁН** — это внедряемый дефект стража |

Последняя строка — не формальность. Если при недействительном коде молча откатиться к cookie,
атрибуция припишется не тому партнёру, и заметить это можно только сверкой выплат.

### 2. Anti-fraud — три правила, все проверяемые

- **50 применений одного кода с одного `ip_prefix` за 10 минут → `partner_code.status = blocked`.**
  Счёт по `ip_prefix` (IPv4 → /24, IPv6 → /64, DEC-A-019), функция уже есть.
- **Самореферал → `attribution.status = rejected`.** Владелец кода не приводит сам себя.
- **Самопереходы владельца по своим ссылкам не считаются** (уже сделано фичей 8 — используй, не
  дублируй).

Блокировка кода — **состояние кода, а не отказ запроса**: заблокированный код перестаёт работать
для всех, и это видно в кабинете.

### 3. Кабинет партнёра

Свои коды, число приведённых, статусы атрибуций. **`403` здесь законен и обязателен**: партнёр
спрашивает про свой код, сервер знает, чей он. Это единственное место в продукте, где `403`
правильнее `404` — и в отчёте назови, почему остальные места остаются на `404`.

Мобильная вёрстка обязательна.

## Тесты, без которых фича не принимается

**Все четыре исхода ADR-007 — четырьмя отдельными тестами**, не одним параметризованным: они
асимметричны, и общий тест скроет, какой именно исход сломан.

| Страж | Внедряемый дефект |
|---|---|
| ADR-007: недействительный код не откатывается к cookie | разрешить откат → красный |
| `explicit` → любой даёт `409` | разрешить перезапись → красный |
| `guest_link` → `cookie` даёт `409` | разрешить → красный |
| `cookie` → `explicit` даёт `200` и `replaced_source` | вернуть `409` → красный |
| 50 применений за 10 мин блокируют код | поднять порог или убрать → красный |
| самореферал отклоняется | засчитать → красный |
| кабинет партнёра отвечает `403` на чужой код | вернуть `404` → красный |

**Конкурентный:** N параллельных применений одного кода на границе 50 — код блокируется ровно один
раз, счётчик не перескакивает порог незамеченным.

Мутации обеими строками.
