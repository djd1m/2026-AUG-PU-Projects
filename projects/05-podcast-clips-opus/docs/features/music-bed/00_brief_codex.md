## Что построить

### 1. Схема и загрузка

- Миграция `014_music.sql`: `ALTER TABLE video ADD COLUMN music boolean NOT NULL DEFAULT false`.
- `createVideoSchema`: поле `music: z.boolean().optional()`; отсутствие = `false`. Схема остаётся
  `.strict()`. Значение пишется в `INSERT` той же транзакции.
- Повтор с тем же `Idempotency-Key` возвращает ПЕРВУЮ строку, как и сейчас; флаг музыки второй
  попыткой не перезаписывается.
- `Uploader.tsx`: галочка «Добавить фоновую музыку», **выключена по умолчанию**, недоступна во время
  загрузки; под ней мелко: «Komiku — Everything is groovy, CC0». Значение уходит в `video.create`.

### 2. Рендер — двухпроходная схема (§4.1)

`getRenderInput` дополнительно отдаёт `v.music`. Если `music = false` — **рендер побайтово прежний**:
тот же граф, те же аргументы.

Если `music = true`:

1. **Проход 1, только звук.** Громкость речи клипа в полосе 300–3400 Гц:
   `-ss start -t dur -i input -map 0:a:0 -af highpass=f=300,lowpass=f=3400,ebur128 -f null -`,
   разобрать итоговое `I:`. Тем же способом — громкость трека на отрезке `[0, dur]` в той же полосе.
   Чистая функция разбора вывода `ebur128` — отдельно и с тестом.
2. **Усиление:** `gain_dB = S_speech − M − S_track`, где `M = 18` — константа `MUSIC_MARGIN_LU` с
   комментарием «оценка, не измерение; заморозить после прослушивания владельцем (В-8)».
3. Если `S_speech` или `S_track` не число либо ниже −70 LUFS — **музыка не ставится**, рендер идёт
   без неё, и в журнал пишется `{"event":"music_skipped","reason":…}`. Отказ рендера из-за музыки
   запрещён: музыка необязательна, клип — нет.
4. **Проход 2 — рендер как сейчас**, плюс второй вход (трек) и звуковой граф:
   `[0:a:0]` речь без изменений; трек → `atrim=0:dur,asetpts=PTS-STARTPTS,volume=<gain>dB,afade=t=in:d=0.5,afade=t=out:st=<dur-1>:d=1`;
   смешение `amix=inputs=2:duration=first:normalize=0` (**`normalize=0` обязателен**: без него речь
   тише на 6,0 дБ — §2 И-2). Никакого `sidechaincompress` (§4.3).
5. Длительность клипа не меняется: `-t` прежний, проверка 20–75 с прежняя.
6. Журнал: `{"event":"music_mix","speech_lufs":…,"track_lufs":…,"gain_db":…}`.

### 3. Контракт неизменяемости (Л-5)

В хеш контракта в `workers/render.ts` добавить `music: input.music ? '<id трека>:<sha256>' : null`
и `margin: MUSIC_MARGIN_LU` при музыке. Без этого перерендер с музыкой отвечает `412`, ветка `HEAD`
признаёт старый объект своим, и музыка молча не доезжает.

### 4. Гостевые и платные клипы

Файл клипа один, поэтому клип с музыкой уходит с музыкой и на гостевую страницу. Это **не** меняет
предмет согласия гостя: у CC0-трека нет лицензиара. Тариф `paid` музыку не отключает — решает галочка.
Ничего в `guest-pack` не править; в отчёте назвать это строкой.

## ОБЯЗАТЕЛЬНЫЕ правки после VALIDATE (перекрывают текст выше при расхождении)

Независимая проверка постановки (Anthropic, 24.09.2026): READY WITH FIXES. Каждый пункт — условие приёмки.

1. **[blocker] Страж RD-001 не трогать.** Он требует ровно один `execFFmpeg` и отсутствие
   `spawn`/`execFile` в `render/ffmpeg.ts`. Замер громкости — в НОВОМ модуле `render/loudness.ts` со
   своей функцией запуска, которая возвращает stderr и принимает `signal`. Без `-v error`: при нём
   итоговый блок `ebur128` не печатается. В `render/ffmpeg.ts` остаётся один проход кодирования.
2. **[high] Хеш без музыки неизменен.** Ключи `music`/`margin` добавлять в объект контракта ТОЛЬКО
   при фактическом смешении; при отсутствии музыки JSON побайтово прежний. Тест: хеш клипа без
   музыки равен константе, снятой с текущего `main` ДО правок.
3. **[high] Хеш — из факта, не из намерения.** `renderClip` возвращает
   `{ music: { track: string, gain_db: number } | null }`; контракт строится из ЭТОГО значения, а не
   из `input.music`. Иначе пропуск на попытке 1 и смешение на попытке 2 дают одинаковый контракт.
4. **[high] Разбор `ebur128`.** На тишине он печатает `I: -70.0 LUFS`, а не `-inf`; покадровые строки
   ТОЖЕ содержат `I:`. Разбирать только блок после `Summary:`; пропуск при `S ≤ −60` LUFS (у речи
   и у трека). Образцы для тестов разбора снять с НАСТОЯЩЕГО вывода ffmpeg из образа/тестового
   контейнера (на хосте ffmpeg 4.4, в образе 8.1 — сверить формат) для `anullsrc` и `sine`, вместе с
   покадровыми строками.
5. **[high] Сквозной тест против вечного пропуска.** `renderClip({music:true})` на заглушке обязан
   дать `music_mix` (а не `music_skipped`) и вернуть `music !== null`; в выходе есть энергия трека
   (громкость вне полосы тона заглушки заметно выше, чем у рендера без музыки). Мутация «разбор
   возвращает NaN» → красный.
6. **[high] Отказ замера не валит рендер.** `FFmpegError` в проходе 1 (нет файла, битый трек) →
   `music_skipped` с `reason:"measure_failed"`, рендер без музыки. Отмена и таймаут (`signal`)
   пробрасываются. Проход 1 стоит ПОСЛЕ `watermarkGeometry` и `probeVideoStream` (SL-008 требует
   ноль вызовов ffmpeg до ошибки геометрии).
7. **[high] Г-3 обязан уметь покраснеть.** Заглушка речи с пиком около −4 dBTP при −17 LUFS (как
   И-5), либо мутация +20 дБ; красная строка мутации обязательна. В коде — потолок усиления
   `MUSIC_MAX_GAIN_DB = 12`; выше → `music_skipped`, `reason:"gain_out_of_range"`.
8. **[medium] Г-2 без тавтологии.** Экспортировать чистую `buildMusicAudioGraph(gainDb, duration)`,
   ею пользуются и `renderClip`, и тест. Уровень заглушки выбрать так, чтобы трек без усиления
   заведомо превышал `S − M + 0,5` — иначе мутация `gain=0` не покраснеет.
9. **[medium] «Выключено = прежнее».** Эталон аргументов ffmpeg снять с текущего `main` в фикстуру
   ДО правок; временные пути (`mkdtemp`, `.ass`) нормализовать; проверять через
   `vi.spyOn(exec,'execFFmpeg')`, как SL-008.
10. **[medium] Граф ffmpeg явно.** Трек — ВТОРОЙ вход `-i`, после исходника, без `-ss`/`-t` (ссылки
    `[0:…]` не сдвигаются); `-map 0:a:0` заменяется на `-map [aout]`; звуковая цепочка присоединяется
    через `;` к тому же `-filter_complex` в ОБЕИХ ветках (`[0:idx]` и `color=`). На обе ветви до
    `amix` — `aformat=sample_rates=44100:channel_layouts=stereo`. Г-1 сравнивать при одинаковом `-ac 2`.
11. **[medium] Идемпотентность и галочка.** Повтор `video.create` с тем же ключом и ДРУГИМ `music` →
    `409`, как расхождение `declared_bytes`. В `Uploader.tsx`: `music` хранится в `Resume`, галочка
    заблокирована, пока для этого файла есть незавершённое возобновление. Тесты на оба пути.
12. **[medium] Каталог трека.** `.dockerignore` исключает `*.md` — тест каталога README не читает.
    Путь через `resolve('apps/worker/assets/music/…')`, как у шрифтов. Тест: sha256 и длительность
    через `ffprobe`. mp3 уже лежит в `apps/worker/assets/music/`.
