# Контекст внедрения и уточнения плана

Источник: уточнение владельца 26.10.2026. Здесь готовится код. Запуск приложения,
подключение счётчика и проверка поступления событий выполняются на будущем
сервере Cloud.ru в РФ. Текущий VPS не становится местом включения аналитики.

Сейчас требуется исходный код, локальные/контейнерные проверки и инструкция
переноса. Создание счётчика в аккаунте Яндекса, его ID и проверка целей в
целевой Метрике — пункты запуска в Cloud.ru. Их статус planned, не pass.
Общее упражнение3.4 не объявляется фактически завершённым по mock-запросам.

Фиксированная связка1-1-1-1: тематическое Telegram-сообщество авторов → Старт
990₽/300кредитов (5часов) → нарезка разговора в вертикальные клипы с русскими
субтитрами → независимый русскоязычный автор еженедельного видеоподкаста.
Канал/спрос/CAC — гипотезы; размещения и покупки не выполняются.

Закрытый tuple пилота: utm_source=telegram, utm_medium=community,
utm_campaign=n5_pilot, utm_content=demo_a. Другие значения и utm_term не
сохраняются/не отправляются. Не использовать raw referrer, query/hash,
имена/ID аккаунтов, видео, клипов и платежей в аналитике.

Ограничения dedupe: одна activation/signup отметка на браузер и пилот сTTL
30дней; paymentintent IDs только локально, максимум20записей сTTL30дней,
не отправлять provider. Визит —30минут бездействия. Это best-effort граница
наблюдений, не exactly-once и не account-level финансовый ledger.
Если storage недоступен, допускается только ограниченная память текущей
вкладки с явно документированным undercount/повторами при перезагрузке.

SDK: на исключённом пути и при отзыве согласия останавливать/разрушать
уже загруженный счётчик, очищать очередь и состояние. Проверить переход
с разрешённой страницы на чувствительную после opt-in; одного direct-entry
теста недостаточно. Network-проверка при тестовых ID полностью перехватывает
provider-запросы: это не доставка в настоящую Метрику.

Конфигурация счётчика приходит runtime с сервера (не секрет). По умолчанию
выключена. Внедрение не меняет auth/provider/billing/DB, текущие тарифы или
кредитный баланс. Окружение/compose правит только integration owner.
