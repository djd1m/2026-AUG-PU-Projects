# Фича 28 `landing-demo` — независимое ревью Opus 5.5

Ревьюер: Opus 5.5, 28.09.2026, от `1f1edb48`. Код не правился. Сверено с `28d48b1f` и текущим деревом:
`packages/shared/src/showcase.ts`, `apps/web/src/server/showcase-file.ts`, `screen-runtime.ts`, `retention.ts`,
`short-link.ts`, `Landing*.tsx`, `AuthForm.tsx`. `tests/landing-demo.test.ts`, `tests/retention.test.ts`,
`tests/short-link.test.ts` — зелёные в общем прогоне 198/198 (контейнер Playwright, без БД).

Стенд `https://clipmkr.ru`, только чтение (без `/c/`: его GET пишет просмотр):
`GET /api/showcase/CTDUUG/thumbnail` → `302` на подпись `X-Amz-Expires=900`, ключ `thumbs/…/46f99d89…-v2.jpg`;
`GET /api/showcase/ABCDEF/file` → `404`; `GET /` → `200`, `data-theme="dark"`, в разметке ровно
`/api/showcase/CTDUUG/{file,thumbnail}`.

## Заявления квитанции, не подтверждённые кодом

- «Мутации 9/9 (включая `-db`)» — `retention-exclusion-db`, `set-membership-db`, `link-code-db`, `done-only-db`
  требуют PostgreSQL; в ревью не перезапускались.
- «Первый экран 375×667: демо 143×253, кнопка низ 542, запас 125 px» — замер исполнителя браузерным набором по
  фикстуре без шрифтов Next и выреза; на устройстве не проверено (записано).
- Подтверждено: ретенция исключает `SHOWCASE_CLIP_IDS` параметром, стирание аккаунта — нет (`retention.ts:7-12`
  стирает префиксы без исключений); `/c/` витрины не объявляется истёкшим, явный `expires_at` соблюдается; перенос на
  другой сервер записан (`BACKLOG.md` §1, `REPRODUCE.md:422-426`).

## Что сделано хорошо

- Витрина — закрытый набор в коде с точным сравнением: код того же формата вне набора не стоит ни одного запроса к БД.
- Найден и закрыт стык до выкатки: ретенция стёрла бы клип 27.09, `/c/` показал бы «срок истёк».
- Право на удаление сильнее витрины — стирание аккаунта клип витрины не щадит.
- `preload="none"` и постер: постоянная нагрузка лендинга — один запрос постера, а не 23 МБ.

GRADE: A
