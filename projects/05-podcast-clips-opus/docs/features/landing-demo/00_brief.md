# Постановка — фича 28 `landing-demo`: лендинг с демо-клипом (шаг 5 плана mobile-ui)

FR-LOOK-007/011, OWN-016 («лендинг с демо-клипом нужен»), выбор демо — владелец 25.09.2026:
«вот этот клип можно поставить на витрину https://clipmkr.ru/c/CTDUUG». Клип пересобран 26.09 (A-2509-06):
заголовок в начале, финальный акцент, надпись «Полный выпуск — по ссылке». Исполнитель — Opus 5.5, проверка —
Sonnet 5 (OWN-017). Методика — `.claude/skills/responsive-ui/SKILL.md` (читать целиком), соглашения фич 24–27.

## Зачем
Посетитель лендинга сейчас не видит результата продукта — только текст и форму входа. Момент ценности
(FR-GROWTH-001 для гостя сайта) — увидеть готовый вертикальный клип из настоящего длинного разговора.

## Что сделать
1. **Витрина — закрытый набор в коде.** `SHOWCASE_CLIPS` в `packages/shared` (сейчас одна запись: короткий код
   `CTDUUG`, подпись «88 мин разговора → 7 клипов», исходная длительность и число клипов — числа, не выдуманные:
   взять из базы стенда при написании — запись `ec8b9021-…`: `duration_seconds` 5305,9 с ≈ 88 мин, 7 клипов).
   Не переменная окружения и не флаг в БД (`honest-configuration`: список разрешений — код).
2. **Публичная раздача ТОЛЬКО клипов витрины.** Новый маршрут (например `GET /api/showcase/{code}/file` и
   `/thumbnail`): код не из `SHOWCASE_CLIPS` → 404; клип не `done` или без объекта → 404; иначе — редирект на
   подписанную ссылку ≤ 900 с (как существующий путь файла клипа) либо отдача тем же механизмом. Остальные клипы
   по-прежнему доступны только владельцу и гостевой странице (`security.md` «Доступ к файлу клипа — ровно два
   пути» — это ТРЕТИЙ путь: зафиксировать в ADR-018 и в `security.md` проекта явно, с обоснованием и границей).
   Лимит частоты — как у чтения (120/мин). Срок хранения: у клипа витрины `expires_at` NULL — проверить, что
   ретенция не удалит его объект; иначе — исключение по `SHOWCASE_CLIPS` и тест.
3. **Первый экран лендинга** (FR-LOOK-011): надзаголовок → H1 (текст владельца не менять) → демо: вертикальный
   плеер 9:16 (`playsinline`, `preload="none"`, постер — кадр витрины, без автозвука; ширина ограничена, чтобы
   на телефоне кадр и действие помещались) с подписью «88 мин разговора → 7 клипов» → действие. На 390×844,
   375×667, 360×740 без прокрутки видны ОБА: демо (хотя бы постер целиком или его верхняя половина — реши и
   запиши число) и основное действие. Основное действие на узком экране — кнопка «Попробовать бесплатно»
   (`.landing-cta`), ведущая к форме входа/регистрации (якорь, фокус в поле почты); форма остаётся на странице
   ниже. На десктопе (≥ 600) форма справа как сейчас, демо — в левой колонке под текстом. Обновить
   `FIRST_SCREEN_ACTIONS` для `/` (селектор основного действия) и добавить R9-проверку «демо в первом экране»
   (селектор `.landing-demo video`), тесты прибора и фикстуры.
4. Ссылка «Смотреть полный выпуск» под демо не нужна (она на `/c/CTDUUG`); под демо — ссылка «Открыть клип»
   на `/c/CTDUUG` (там призыв автора).
5. Тёмная/светлая тема — токенами; видео — `--media-bg`.
