# Постановка — фича 27 `clip-cta`: призыв к действию в конце клипа

Решение владельца 25.09.2026 (OWN-018): «пользователь перед монтажем клипа мог задать, какой action он ждёт
от зрителя по окончании: посмотреть полное видео, или ещё что-то (перейти по ссылке, подписаться туда-то)».
Повод: клип `https://clipmkr.ru/c/CTDUUG` идёт на витрину, но он продвигает ВЕСЬ выпуск
(`https://www.youtube.com/watch?v=ukZyNkgqVho`), а ни в клипе, ни на странице `/c/` ссылки на выпуск нет.
Исполнитель — Opus 5.5, проверка — Sonnet 5 (OWN-017). Закрывает также пункт бэклога «CTA подписаться».

## Модель данных
- Закрытый набор видов призыва `CTA_KIND` в `packages/shared`: `watch_full` («Смотреть полный выпуск»),
  `subscribe` («Подписаться»), `open_link` («Перейти по ссылке»), `none` (без призыва, по умолчанию).
  Надписи — из кода, НЕ свободный текст: текст вшивается в пиксели и уезжает в чужие ленты навсегда
  (та же цена, что у метки, `secrets-management.md` про `N5_PUBLIC_ORIGIN`).
- Адрес призыва `cta_url`: обязателен для всех видов, кроме `none`; только `https:` (разбор `new URL`,
  протокол из закрытого набора, без логина/пароля в адресе, длина ≤ 2048, без пробелов); пустое и
  непригодное — отказ `422` с понятным текстом, а не молчаливое `none` (`honest-configuration`).
- Хранение: миграция `020_clip_cta.sql` — колонки `cta_kind` (CHECK по набору, NOT NULL DEFAULT 'none') и
  `cta_url` у `video` (+ CHECK: `none` ↔ `cta_url IS NULL`). Существующая неиспользуемая `video.source_url`
  относится к FR-INGEST-003 (загрузка по ссылке) — её НЕ переиспользовать.

## Где задаётся
1. **Перед монтажом — в форме загрузки** рядом с галочками: выбор «Что сделать зрителю в конце» (радио
   или `select` из четырёх) и поле адреса, появляющееся для видов кроме `none`. Передаётся в `video.create`
   (Zod-схема, ДО заявки `Idempotency-Key` — порядок из `security.md`), сохраняется в `video`.
2. **Смена у готовой записи** — на экране записи: форма «Призыв в конце» (тот же набор). Сохранение
   запускает пересборку клипов записи тем же механизмом, что смена музыки (ADR-016, `-vN` ключи,
   квота `user_rerenders` — по одной единице на КАЖДЫЙ пересобираемый клип; при нехватке остатка — отказ
   целиком до постановки, без частичной пересборки). Новая процедура tRPC `video.setCta` — это 17-я
   процедура канона §5: обновить канон и все места, где названо «16 процедур».

## Где виден зрителю
1. **В кадре (пиксели)** — на финальных секундах клипа (там же, где финальный акцент, ADR-012; если акцент
   выключен — последние 2,5 с): крупная надпись вида призыва («Полный выпуск — по ссылке», «Подписывайтесь —
   ссылка ниже», «Подробнее — по ссылке») НАД меткой `clipmkr.ru/c/КОД`. Сам внешний адрес в кадр НЕ
   вшивается (длинный, не читается) — путь зрителя: метка → `/c/КОД` → кнопка. Для `none` — ничего. Шрифт,
   размер, безопасная зона — как у заголовка в начале (ADR-013), не перекрывая субтитры и метку.
2. **Страница `/c/{code}`** — главная кнопка = призыв записи («Смотреть полный выпуск →» и т. п.) со
   ссылкой на `cta_url`; под ней видно доменное имя адреса («youtube.com») — зритель видит, куда уходит.
   «Сделать свои клипы» становится вторичной кнопкой. Ссылка — обычный `<a>` с `rel="noopener noreferrer
   nofollow"` `target="_blank"`, НЕ редирект через наш домен (не делать открытый редирект). CSP `/c/` не
   ослаблять. R9 (первый экран): основное действие `/c/` — теперь кнопка призыва, если он задан, иначе
   `.cta` как сейчас; обновить `FIRST_SCREEN_ACTIONS` и тест.
3. **Гостевая страница `/g/`** — не трогать в этой фиче.

## Злоупотребление (назвать в отчёте, как закрыто)
Наш домен начинает показывать ссылку на произвольный внешний адрес — это поверхность фишинга. Минимум:
только `https`, видимый домен назначения, `nofollow`, метка «ссылка автора клипа». Без редиректа через нас.

## Тесты и стражи
- Юнит: разбор `cta_url` (пусто, `http:`, `javascript:`, `data:`, с `user:pass@`, 2049 символов, пробелы →
  отказ; `https://www.youtube.com/watch?v=…` → ок); набор видов закрыт (неизвестный вид → 422).
- Миграция: CHECK отвергает `watch_full` без адреса и `none` с адресом.
- Рендер: фильтр надписи присутствует при виде ≠ `none` и отсутствует при `none` (по образцу тестов
  заголовка/пэк-шота); медиатест пикселей — по образцу teaser-медиа (если в образе нет браузера/шрифтов —
  громко «НЕ ВЫПОЛНЕН»).
- `/c/`: кнопка призыва с `rel`, домен виден, без призыва — прежняя кнопка; экранирование адреса (XSS).
- `video.setCta`: чужая запись → 404; квота `user_rerenders` списывается по числу клипов атомарно, при
  нехватке — отказ без постановки (конкурентный тест по образцу фичи 22).
- Мутации: (1) пропустить проверку протокола → красное; (2) убрать вывод надписи в фильтре → красное.
