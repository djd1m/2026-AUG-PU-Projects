# Постановка — фича 27b `clip-cta`: надпись призыва в кадре и пересборка клипов записи

Продолжение 27a (закоммичена `fc898ab`). Исходная постановка — `00_brief.md` («Где виден зрителю» п.1, «Где
задаётся» п.2); проверка плана Sonnet — `01_validate.md`: правки **2, 3, 4, 5, 6, 7, 10** отнесены к 27b и
ОБЯЗАТЕЛЬНЫ (читать целиком). Исполнитель — Opus 5.5, ревью — Sonnet 5 (OWN-017).

## Что сделать
1. **Надпись в кадре.** Для вида ≠ `none` на финальных секундах клипа — надпись вида призыва из закрытого набора
   (тексты — в `packages/shared/src/cta.ts`, короткие: «Полный выпуск — по ссылке», «Подписывайтесь — ссылка
   ниже», «Подробнее — по ссылке») НАД меткой `clipmkr.ru/c/КОД`. Окно показа — ЧИСЛОМ (правка из 01_validate:
   не путать с 0,8 с пэк-шота; предложение — последние 2,5 с, но не раньше конца заголовка и не дольше клипа).
   Геометрия fail-closed по образцу `watermarkGeometry`/`layoutTeaser`: посчитать зону между субтитрами и меткой
   на 1080×1920, если надпись не помещается — уменьшить кегль до предела, ниже предела — отказ рендера надписи
   с записью в журнал (клип собирается без надписи, а не с наложением на субтитры). Образец фильтра — `teaser.ts`.
2. **Пересборка всех клипов записи** при `video.setCta` с изменением вида/адреса (адрес в пиксели не идёт —
   менять пиксели нужно только при смене ВИДА или переходе none↔не-none; смена одного адреса — без пересборки).
   Цикл по образцу `video-retry.ts:36-40` + логика rerender из `clip-music.ts`: квота `user_rerenders` одним вызовом
   `checkAndConsumeQuota(..., n = число клипов)`; если хоть один клип записи уже пересобирается — отказ целиком 409
   ДО списания; при нехватке остатка — отказ целиком без постановки. Частичный отказ ПОСЛЕ постановки — принять как
   известное ограничение (аналог ADR-016), описать в ADR-017.
3. Текст `limits-contract.ts` для `user_rerenders` — нейтральный («Пересборки на сегодня исчерпаны»).
4. Документы: ADR-017 (из черновика — в принятое, с геометрией и окном), FR-RESULT-006 (addendum), канон (окно,
   кегль), REPRODUCE, 05_completion.

## Проверки
typecheck/lint/build; набор в образе (`--build`, сейчас 904/904); медиатест пикселей надписи по образцу
teaser-медиа (кадр финала содержит надпись; при `none` — нет); конкурентный тест «setCta во время идущей смены
музыки → 409» и «при остатке меньше числа клипов — отказ целиком, списано 0»; мутации: убрать проверку «уже
пересобирается», списывать по одному клипу, убрать fail-closed геометрии, вывод надписи при `none` — красное/зелёное.
Не выкатывать, не коммитить, миграций на стенд не применять. Отчёт — `07b_code_report.md`, последняя строка
`Status: completed|failed` после всех итогов.
