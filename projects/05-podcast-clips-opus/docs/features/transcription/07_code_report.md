# Отчёт Codex: transcription

Реализация фичи 4 подготовлена. **Приёмка не закрыта:** недоступны обязательный контейнерный
интеграционный прогон и ревью Anthropic (OWN-002). Пропуски не объявляются зелёными проверками.

## Реализовано

- `packages/shared/src/transcript.ts`: единые типы слов/сегментов, необязательный `speaker`,
  числа чанкинга и таймаутов, проверка непустых слов с конечными монотонными границами.
  Закрытые перечисления уже существуют в `shared/enums.ts`; новые значения не введены.
- `apps/worker/src/stt/extract.ts`: ffmpeg читает уже скачанный оригинал, потоково пишет MP3,
  моно 16 кГц / 64 кбит/с и одновременно находит тишину. Копия видео и WAV не создаются.
  Вход ограничен протоколом `file`; процесс принудительно завершается при отмене.
- `stt/chunker.ts`: целевая длина 180 с, пауза в окне ±20 с, перекрытие 2 с. При отсутствии
  паузы чанк получает `hardCut`, а воркер пишет событие `stt_hard_cut` с идентичностью видео.
  После кодирования размер проверяется по файлу: максимум **25 000 000 байт**. Чанки создаются
  последовательно, удаляются после обработки; весь каталог удаляет существующий `withSource`.
- `stt/client.ts`: интерфейс `Transcriber`, явный live/fake через конфигурацию, JSON
  `input_audio: {data, format: 'mp3'}`, модель `openai/whisper-large-v3`,
  `provider: {only: ['Together'], allow_fallbacks: false}`. Таймаут 120 с, автоматических
  скрытых HTTP-повторов нет; ошибки поставщика выбрасываются. Fake разрешён только в тестах.
- `workers/stt.ts`: использует начальное списание `acceptProbe`, не измеряет длительность
  повторно. Каждая отправка авторизуется транзакцией; повтор любого уже отправленного чанка
  повторно списывает оба минутных ключа. Максимум три отправки чанка, включая неизвестный
  исход после сбоя. Отказ квоты не возвращает загрузочный слот.
- `stt/spend.ts`: `/work/model-spend.jsonl` на существующем постоянном томе. До вызова пишется
  и синхронизируется событие `phase=attempt`; затем `phase=outcome` с результатом, в том числе
  timeout/provider_error/no_timestamps. Для суммы расхода считать только `phase=attempt`:
  исход — уточнение той же попытки, а не второе списание. Ключи и текст аудио не журналируются.
- `stt/merge.ts`: сдвиг слов и сегментов на смещение; удаление совпадающих слов перекрытия,
  затем обязательная проверка монотонности. Сортировка не скрывает потерянное смещение.
- `packages/db/src/transcription.ts` и новая `006_transcription.sql`: долговечный счётчик
  отправок чанков в `job_attempt`, фенс транскрипта, проверка активной попытки/аккаунта,
  транзакционное сохранение транскрипта, `selecting` и попытки `select`. Публикация в Redis
  происходит после COMMIT; существующий сторож восстанавливает потерянную публикацию.
  Предельное время STT отсчитывается от `job_attempt.started_at`: 30 минут.

## Ревью, расхождения и непроверенное

- Дополнительное независимое ревью Sol выявило отсутствие `-protocol_whitelist file` в
  извлечении. Исправлено в extract/chunker; рецензент повторно прочитал обе строки и подтвердил
  устранение. Остаточных blocker/high не назвал. Это **не** требуемое Anthropic-ревью.
- Anthropic CLI: попытка ограничена 180 с, завершена таймаутом; результата и квитанции модели нет.
- Docker daemon: `permission denied` на сокете. Локальный PostgreSQL 16 также не запущен:
  `runuser: cannot set groups: Operation not permitted`. Обязательный
  `docker compose --project-directory . --profile test run --rm --build test` остаётся
  невыполненным. Ограничения сессии не позволяют запросить повышение прав.
- **Живых вызовов OpenRouter не было**, ключ не читался. HTTP-тесты используют детерминированный
  фейк: успех, отсутствие таймингов, пустое тело, 5xx и отмена/таймаут. Часовой медиатест
  синтетический: живая дикция, музыка, качество границ/распознавания и производительность
  полного часового STT с реальным поставщиком не проверены. Никакого заявления о p95 нет.
- Degradation `hard_cut` явная; при несовместимых перекрывающихся таймингах проверка может
  отказать всей транскрипции, вместо молчаливой склейки неверной шкалы.
- В каноне/ADR/карте переиспользования остались whisper-1/OpenAI: код следует более новому
  DEC-A-022 и пункту 0 брифа. Указанные брифом FR-STT фактически называются
  `FR-TRANSCRIBE-001/002`. Отдельной таблицы `transcript_word` в схеме нет: слова — `transcript.words`
  JSONB, как в Architecture. Перечисления уже ограничены CHECK миграции 001 и существующим
  стражем; миграция 006 добавляет только фенс и долговечный счётчик отправок.
- E2E/CJM и deployment не запускались; готовность стенда не заявляется. МинIO/Cloud.ru,
