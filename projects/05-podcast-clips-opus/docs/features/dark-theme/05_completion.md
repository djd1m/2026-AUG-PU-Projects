## Что сделано
- Тема: тёмная по умолчанию, светлая только по cookie `n5_theme=light`; `themeFromCookie` в
  `apps/web/src/lib/theme.ts` — закрытый набор, мусор/дубли/регистр → `dark`.
- Тема на сервере: корневой layout (`force-dynamic`, `generateViewport` → `themeColor`, `colorScheme`),
  `/c/` и `/g/` из заголовка `cookie`; CSP страниц не менялся.
- Переключатель `ThemeToggle` 44×44 в шапке лендинга и кабинета, `aria-pressed`, имя постоянное.
- Все цвета — токены двух тем в `globals.css` (вне блоков токенов цветов нет — тест); SSR-токены
  дублируются и сверяются тестом; стрелка `select` двумя data-URI, autofill, `accent-color`, `--media-*`,
  `--brand-*`; светлый фокус #9c5e0a (старый 2,68:1 < 3:1).
- H-1 ревью: разделитель под превью клипа (фон кадра в тёмной теме 1,22:1 к карточке).
- Прибор: каждый сценарий в dark и light, предусловие `data-theme` (не применилась → код 2), `theme` в ключе
  дедупликации `summary()`.
