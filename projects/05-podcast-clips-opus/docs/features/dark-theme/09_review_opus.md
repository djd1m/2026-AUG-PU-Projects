## Заявления квитанции, не подтверждённые кодом

- «Прибор по стенду, обе темы — код 0, 194 прохода» (`05_completion.md`) — не перепроверено: прогон прибора по стенду
  создаёт UI-фикстуру (запись в базу стенда), а ревью ограничено чтением.
- «Шапка кабинета на 320 px: 139 → 77 px» — числа из замера исполнителя, автоматического утверждения высоты нет
  (L-1 Sonnet остаётся).
- Остальное подтверждено чтением: закрытый набор `dark|light` и fail-closed разбор (`lib/theme.ts:10-20`, мутация
  «регистр → light» даёт `Failed Tests 3`), `Secure; SameSite=Lax` без `HttpOnly`, токены SSR `/c/`, `/g/` посимвольно
  сверяются тестом с `globals.css` (`theme.test.ts:64-74`), `prefers-color-scheme` не используется. SSR стенда:
  `GET https://clipmkr.ru/` без cookie → `data-theme="dark"`.

## Что сделано хорошо

- Два значения cookie — не выбор, а строгий дефолт: `n5_theme=light; n5_theme=dark` → `dark` (тестом).
- Токены дублируются в SSR-страницах, но расхождение значений — красный тест, а не договорённость.
- Предусловие прибора «тема не применилась» — код 2, а не зелёный прогон в одной теме.
