## 1. Лента стадий вместо панели статуса
Сейчас статус записи — панель с иконкой и текстом + `progress`. Нужно: компактная горизонтальная лента из четырёх
стадий «Загрузка → Расшифровка → Выбор → Монтаж» (закрытый набор, по статусам `video` канона §4). У каждой стадии
три вида — сделано / идёт (с прогрессом «N из M» у монтажа) / отказ; плюс «нет ответа от обработки» (молчание
≥ 5 мин по `updated_at` — не «идёт»). Три состояния задачи (выполняется / успех / отказ) обязаны выглядеть
по-разному и сохраниться: причина отказа и кнопка «Повторить» — как сейчас. Когда всё готово — лента сворачивается
в одну строку «Клипы готовы · N из M» (не занимает первый экран). Доступность: `ol` с `aria-current="step"`,
состояние текстом, не только цветом; на 320 px — без горизонтального скролла (подписи короче или переносятся).
