# Квитанция — transcript-tolerance

**Решение:** ADR-010. **Требования:** FR-TRANSCRIBE-003, FR-SELECT-003, FR-SELECT-004.
**Коммиты:** `2e7f8e7`, `2a6a55d`, `bc5b70c`. Отчёты: `docs/features/transcription/21_fix_report_word_order.md`,
`docs/reviews/15_fix_report_live_findings.md`.

## Пять отказов одной живой записи (88,4 мин, 12 916 слов)

| Что отвергало | Величина |
|---|---|
| строгая монотонность начал слов | откат 0,26 с на слове №98 |
| доля поджатых > 1 % | 5 на 409 слов |
| выход за границы куска | 0,0000205 с |
| один негодный фрагмент отбрасывал все | 7 годных потеряно |
| модели слался весь список слов | 1128 КБ ≈ 385 тысяч токенов; модель вернула пустой список |

## Что проверено и чем

Тесты закрепляют **измеренные** величины, а не синтетические границы: откат 0,26 с, 5 на 409,
превышение 0,0000205 с принимаются; восемь кандидатов с одним негодным дают семь; сообщение модели
на 12 916 словах — 153 412 байт при пороге 200 000. Каждое — мутацией обеими строками
(`scripts/test-live-findings-mutations.mjs`).

Живой прогон после исправлений: расшифровка 7 мин 48 с, 43 поджатия (0,33 % слов), 7 клипов.

## Чего фича НЕ доказывает

- Дефект склейки кусков теперь даст клип со сдвинутой границей вместо отказа. Цена принята владельцем.
- Одна запись — одна точка; другой язык, другая акустика, другой исполнитель могут дать иной профиль
  погрешностей.
