1. **[blocker] Очистка по сроку хранения мертва в проде.** `apps/web/src/server/retention.ts:90`
   зовёт `storage.erasePrefix(`${prefix}/${video}/${clip}`)`, а настоящая
   `packages/s3/src/erasure.ts:8` принимает только каталог записи
   (`^(videos|clips/free|clips/paid|thumbs)/{uuid}/$`) и бросает «Непригодный префикс удаления»;
   шаг глотает ошибку → `object_key` не обнуляется, каждый проход берёт те же 100 клипов, бесплатные
   клипы старше 72 ч остаются в S3 навсегда. Тесты зелёные только из-за заглушки. Правка: отдельная
   `eraseClipPrefix` в `erasure.ts` с ЗАКРЫТЫМ регэкспом `^(clips/free|clips/paid|thumbs)/{uuid}/{uuid}$`
   (без завершающего `/`; uuid фиксированной длины — чужой клип не зацепит; тест на соседний клип с
   общим префиксом записи). Тест, гоняющий НАСТОЯЩУЮ проверку префикса (не заглушку), + мутация
   «вызов прежней `erasePrefix`» → красный.

   Для пересборки вести отметку жизни на попытке (`job_attempt.heartbeat_at` или обновление
   `started_at` в `setRenderDeferred`/на старте воркера) и мерить по ней. Тест: ждала 25 мин, стартовала,
