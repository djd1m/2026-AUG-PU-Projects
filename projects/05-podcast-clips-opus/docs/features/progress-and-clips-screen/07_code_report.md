# Фича 7 — progress-and-clips-screen: отчёт Codex

Реализованы интерфейс и серверные чтения. **Приёмка не закрыта:** настоящие PostgreSQL/Redis/MinIO,
браузерная проверка мобильного размера и обязательное ревью Anthropic недоступны в этом запуске.
`Status: failed` ниже означает незакрытые обязательные проверки, а не отсутствие реализации.

## Что работает по коду и локальным проверкам

- `/` — вход/регистрация через существующие API фичи 1; `/dashboard` — загрузка и список записей;
  `/dashboard/videos/[videoId]` — прогресс и клипы. Кабинет требует настоящую серверную сессию.
  Компоненты лежат в `app/videos`, `app/upload`, `app/clips`, как в брифе; адрес подробностей —
  из `long-job-contract.md`, без дополнительного алиаса `/videos/...`.
- `video.get`, `video.list`, `clip.list`, `clip.markDownloaded` — процедуры из закрытого канона.
  `GET` на существующем tRPC-транспорте поддерживает чтение, `POST` сохраняет создание и retry.
  Чтения ограничены 120/мин, мутации остаются 30/мин, результаты не кешируются.
- Разные текст, значок, CSS и семантика для выполнения, успеха и отказа. Молчание более пяти минут
  выделено отдельно, без индикатора выполнения. Опрос раз в пять секунд, дедлайн чтения 4,5 с,
  отмена при уходе; потеря сети явно видна. Сторож 30 минут переиспользуется из фичи 3.
- Все 17 фактических причин отказа имеют русский текст; пять текстов по потолкам. Для
  `user_upload_refunds` отдельного текста нет. Действия различают другой файл, повтор обработки
  и новую загрузку завтра. Возврат квоты вычисляется от даты отказа, поэтому кнопка не отодвигает
  разрешённый повтор ещё на сутки при каждом чтении.
- Карточки: вертикальное видео/превью, длительность, оценка 0–99, три компонента 0–33 и непустые
  объяснения. Некорректная оценка отвергается; `score=NULL` не подменяется нулём. Меньше трёх
  фрагментов объясняется прямо. Неудачный соседний клип не блокирует готовый.
- `/api/clips/[clipId]/file` и `/thumbnail` — только сессия владельца; чужой, отсутствующий,
  незавершённый, удалённый или истёкший ресурс не подписывается. Файл отдаётся через 302 на S3,
  не проксируется. Подписанная ссылка живёт 900 с; скачивание задаёт безопасный UTF-8 filename.
- Загрузка использует существующий `uploadParts`: прямые PUT в S3, три параллельные части,
  обновление подписей и возобновление тем же Idempotency-Key. `video_id` фиксируется в DOM до PUT.
  Успешные части сохраняются до подтверждения complete, чтобы повторить завершение после обрыва.
- CSS содержит сетки 3/2/1 колонка и мобильную раскладку до 600 px. **Это реализация адаптивности,
  но не доказательство проверки в мобильном браузере.**

## Что осталось непроверенным

**Ни один экран в браузере не открывался.** Chromium отказал до загрузки страницы. Поэтому
мобильные размеры, реальная доступность плеера/скачивания и гидратация не объявляются проверенными.
SSR-тесты проверяют разметку и подписи, но не геометрию на телефоне.

Настоящие PostgreSQL 16, Redis 7, MinIO недоступны: 89 integration-тестов пропущены, включая три
новых SQL/HTTP-теста владения, независимости клипов и событий. Следующий обязательный прогон —
`docker compose --project-directory . --profile test run --rm --build test` после настройки среды
и проверок портов. Cloud.ru/CORS, полный пользовательский путь, latency <1 с / скачивание <3 с,
реальные модели, NFR p95 и читаемость метки людьми не измерялись. Требуется ревью Anthropic.
