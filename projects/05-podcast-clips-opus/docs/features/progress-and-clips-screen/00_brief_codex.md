## Что построить

### 1. Экран прогресса — три состояния, и каждое выглядит ПО-СВОЕМУ

`выполняется` · `успех` · `отказ`. Два неразличимых состояния — это одно состояние, то есть дефект.

- **выполняется:** этап словами («расшифровываем», «выбираем фрагменты», «режем 3 из 7») и
  `video_id` на экране — его выдаёт сервер ДО первого отправленного байта;
- **молчание — это НЕ «выполняется»:** `updated_at` старше 5 мин → «нет ответа от обработки»;
  сторож через 30 мин переводит в `failed(stalled)`;
- **отказ:** причина человеческим текстом + кнопка «повторить», когда повтор законен. Пять
  пользовательских текстов на отказы по потолкам; у `user_upload_refunds` своего текста нет
  намеренно.

Обновление — опросом с разумным интервалом. Вебсокетов в неделе нет.

### 2. Экран клипов

Карточка клипа: превью, длительность, **оценка 0–99 и ТРИ объяснения** (цепкость,
самодостаточность, длина) — объяснение пустым быть не может, это условие канона. Кнопка скачивания.

**Честное число фрагментов:** нашлось меньше трёх — показываем сколько есть и говорим об этом прямо,
без «мы старались». Добор слабыми запрещён кодом фичи 5 — интерфейс не должен это маскировать.

### 3. Доступ к файлу клипа

Ровно два пути: сессия владельца видео либо гостевой код (фича 9, здесь только владелец).
**Чужой и несуществующий клип дают ОДИН `404`** — `403` подтвердил бы существование записи.
Клип не в статусе `done` — тоже `404`: файла ещё нет, но соседний готовый отдаётся как обычно.

### 4. Мобильная вёрстка — обязательна

Продукт про вертикальные клипы; смотреть их будут с телефона. Проверяется размером экрана, а не
надеждой.

## Тесты

| Страж | Внедряемый дефект |
|---|---|
| три состояния различимы | сделать «отказ» неотличимым от «выполняется» → красный |
| молчание ≠ выполняется | показать «идёт» при `updated_at` старше 5 мин → красный |
| чужой клип → `404`, не `403` | вернуть `403` → красный |
| клип не `done` → `404`, соседний готовый отдаётся | отдать файл незавершённого → красный |
| объяснение оценки непусто | принять пустое → красный |
