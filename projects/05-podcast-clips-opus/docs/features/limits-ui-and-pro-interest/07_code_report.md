# Фича 11 — limits-ui-and-pro-interest

Код реализован. Приёмка не закрыта: настоящие PostgreSQL/Redis/MinIO, обязательное
Anthropic-ревью OWN-002 и браузерный E2E в этой сессии недоступны. Ниже локальные
проверки отделены от этих пробелов; пропущенные тесты не считаются зелёными.

## Поведение

- На `/dashboard` перед загрузкой и на существующей странице записи видны остатки
  загрузок, минут и выделений/повторов. Значения читаются из БД для аккаунта сессии
  и текущих московских суток, вычитаются из настроенных потолков, ограничены снизу
  нулём. Отсутствующий счётчик означает полный остаток; ошибка БД не превращается
  в полный остаток. Обновление — каждые 30 секунд на видимой странице, при возврате
  фокуса, после загрузки и повтора. Первое выделение расходует тот же остаток, что повтор.
- Отказы загрузки, повтора и экрана прогресса используют общие пять записей текстов.
  `user_upload_refunds` отображается через `user_uploads`. Два глобальных отказа
  имеют одинаковый текст «Сервис перегружен, попробуйте позже»; машинный `scope`
  сохраняется. Числа глобальных квот и возвратов в интерфейс не передаются.
- Отказ показывает дату и время ближайшей московской полуночи. У исторического
  отказа уже прошедшая полночь отображается как «Лимиты обновились», а не обещание
  будущего обновления. `retry_after` сохраняет исходное время отказа.
- Кнопка «Нужен тариф побольше» есть в кабинете, карточке с меткой и на гостевой
  странице. Везде честный текст: «Сейчас доступен только бесплатный тариф».
  На гостевой странице анониму предлагается войти и вернуться; анонимная запись
  интереса запрещена существующей защитой API.
- Каноническая `interest.create` валидирует закрытый `source_screen` и контакт.
  По умолчанию контакт берётся из почты аккаунта сессии; API допускает валидный
  email до 254 символов. Чужой `account_id` в теле отвергается строгой схемой.
  Повтор обновляет контакт и время единственной строки; первый источник сохраняется.
  Каждое нажатие пишет существующее событие `interest` со своим источником и
  московским `day` в той же транзакции. Метка, тариф и квоты от нажатия не меняются.
- Платёжных маршрутов, форм и обещаний запуска нет. Более новый бриф имеет приоритет
  над старой формулировкой «Pro скоро» в спецификации; документы канона не изменены.

   `docker compose --project-directory . --profile test run --rm --build test`
   в настроенном тестовом окружении после проверки портов.
2. Стражи deployment seams на реальном окружении: `check-ports.cjs` и
   `check-env-wiring.sh` вернули 2 из-за отсутствующего compose-окружения;

   Первоначальный запуск с относительным путём из инструкции дал 2; исправленный
   запуск и исходная ошибка сохранены раздельно.
3. Браузерный мобильный E2E/CJM по развёрнутому адресу и реальное нажатие кнопок;
