# Постановка для Codex — фича 8 `short-link`

Готовы фичи 1–7. **337 тестов зелёные** на настоящих PostgreSQL 16, Redis 7 и MinIO. Стенд поднят и
доступен снаружи по HTTPS.

**Эта фича замыкает петлю роста продукта.** Метка на бесплатном клипе несёт адрес `/c/{code}`;
зритель видит клип в чужой ленте, набирает адрес руками и попадает к нам. Метрика недели считается
именно по этим переходам — то есть здесь измеряется, работает ли продукт как продукт, а не как
программа.

## Что построить

### 1. `GET /c/{code}` — публичный лендинг

Не редирект на файл, а **страница**: превью клипа, название продукта, приглашение попробовать.
Причина в канонe: истёкший клип (free живёт 3 дня) не должен давать битую ссылку — **лендинг
продолжает работать, даже когда файла уже нет**, и объясняет это человеческим текстом.

- код ссылки — из `clip_link`, созданного ДО рендера (ADR-004);
- несуществующий и отозванный код дают **один и тот же `404`**;
- страница отдаётся **без входа** — это внешний зритель, у него нет аккаунта;
- мобильная вёрстка обязательна: приходят с телефона, из ленты.

### 2. Учёт перехода — `link_view`

**Уникальность за сутки на `ip_prefix` обеспечивает БАЗА частичным уникальным индексом, а не код**
(V2-R12). Индекс уже есть — используй его, не пиши проверку в приложении.

- счётчик и событие пишутся **в одной транзакции** (V2-R20);
- `day` — календарные московские сутки через существующий `moscowDay` (грабля FP-001 сегодня);
- **самопереходы владельца не считаются** — это anti-fraud, а не мелочь;
- конфликт вставки И ЕСТЬ ответ «уже считали», а не ошибка.

### 3. `link_copy` — копирование ссылки владельцем

Отдельный тип события. Нужен, чтобы отличить «ссылку скопировали, но не опубликовали» от «опубликовали,
и по ней пришли»: без этого различия метрика недели необъяснима.

## Тесты, без которых фича не принимается

**Конкурентный, обязательный (четвёртый из пяти в `testing.md`):** 20 параллельных переходов по
одному `/c/{code}` с одного `ip_prefix` за сутки засчитываются как **РОВНО 1**. Последовательный
прогон зеленеет при обеих реализациях — различает только параллельный.

| Страж | Внедряемый дефект |
|---|---|
| уникальность даёт БАЗА | заменить на проверку в коде → конкурентный тест красный |
| счётчик и событие в одной транзакции | разнести → красный |
| лендинг живёт дольше файла | отдать `404` при истёкшем клипе → красный |
| несуществующий и отозванный код — один `404` | вернуть разные коды → красный |
| самопереход владельца не считается | засчитать → красный |
| `day` заполняется | убрать → красный (страж из фичи 7) |

Мутации обеими строками.
