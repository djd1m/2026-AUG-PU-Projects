# Постановка SL-006 — страж старта обязан покрывать ВСЕ форматы, а не один зашитый

Раунд SL-003 принят: проверка вместимости метки переехала на старт, мутация обеими строками,
540/540 на настоящих PostgreSQL 16, Redis 7 и MinIO. Ниже — находка ревью Anthropic (OWN-002),
сделанная после твоего раунда.

## Находка

`packages/shared/src/watermark.ts:37` — `assertWatermarkFits` вызывает
`watermarkGeometry(1080, 1920, origin, widest.repeat(length))`. Числа **зашиты**.

Размер кадра при этом живёт в другом месте и является ЗАКРЫТОЙ КАРТОЙ:
`apps/worker/src/render/format.ts:3` — `FORMAT_DIMENSIONS = { portrait: { width: 1080, height: 1920 } }`.

Сегодня в карте одна запись, поэтому страж верен. Но два места объявляют одно и то же число, и это
ровно та форма, от которой расходятся молча: в день, когда в карту добавят второй формат, страж
продолжит проверять только первый.

**Это не теоретический риск — измерено:**

| Кадр | Плита при худшем шестисимвольном коде | Доля безопасной ширины |
|---|---:|---:|
| 1080×1920 | 875 из 972 | 90,0 % |
| 720×1280 | 618 из 648 | **95,4 %** |
| 540×960 | — | **НЕ ПОМЕЩАЕТСЯ ВОВСЕ** |
| 1080×1080 | 543 из 972 | 55,9 % |

Меньший кадр пропорционально ШИРЕ, а не подобен. Причина — смешение единиц: кегль и отступ слева
берутся долей кадра, внутренние отступы плиты заданы абсолютными пикселями. На 1080 они незаметны,
на 540 съедают всё.

Значит добавление формата 540×960 или 720×1280 прошло бы страж старта и отказало на КАЖДОМ рендере —
после списанных минут, оплаченного Whisper и оплаченного выделения. Тот самый дефект, который
закрыл SL-003, вернулся бы боковой дверью.

## SL-006 · один источник размеров

Сделать: `assertWatermarkFits` проверяет **каждую** запись карты форматов, а не зашитую пару.
Карта переезжает в `packages/shared` (там уже живёт геометрия), а `apps/worker/src/render/format.ts`
читает её оттуда — чтобы источник остался ОДИН, а не стало два согласованных.

Сообщение об отказе называет, КАКОЙ формат не прошёл: при нескольких форматах «не помещается» без
имени не даёт починить.

**Страж:** добавить в карту заведомо негодный формат (подойдёт 540×960, он измеренно не проходит) —
старт обязан упасть и назвать именно его. Убрать — старт проходит. Обе строки в отчёт.

Мутация отдельно: вернуть в `assertWatermarkFits` зашитые 1080×1920 при негодном формате в карте —
старт проходит, то есть страж перестаёт стеречь. Эта мутация и есть доказательство, что правка имеет
смысл.

## Чего НЕ делать

Не «чини» пропорции метки под мелкие кадры и не добавляй форматов в карту — сегодня формат ровно
один, и менять продуктовое решение я не прошу. Задача узкая: **сделать невозможным молчаливый
пропуск формата стражем**.

`N5_PUBLIC_ORIGIN`, DNS, развёртывание — не трогать. `docs/` — только свой отчёт.
