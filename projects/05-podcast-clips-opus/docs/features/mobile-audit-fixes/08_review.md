## 2. R8: рост текста ≥ 1.8× при `html{font-size:200%}` на 390 px

Выборка прибора — `body, h1, label, p` на `/`, `/c/`, `/g/` (`textZoomRule`).

- `globals.css`: ни одного размера шрифта в px. `body 1rem`, `.intro 1.1875rem`, `.muted 0.8125rem`,
  `.auth-card label 0.875rem`, `.eyebrow`, `.text-button`, `.navigation` — все в rem → 2.0.
  Поля: `max(1rem,16px)` при 200 % дают 32 px → 2.0.
- `h1` на `/`: `clamp(2rem, 1.9rem + .4vw, 3.875rem)`. При 390: предпочтительное 30.4 + 1.56 = 31.96 px,
  это < 32, поэтому срабатывает минимум 32. При 200 %: 60.8 + 1.56 = 62.36 < 64 → 64. Отношение **2.0**.
- SSR `h1` на `/c/` и `/g/`: та же формула, максимум 2.75/2.625rem → **2.0**. `body 1.125rem`, `p`
  наследует → 2.0. `button,.download{font:inherit}` размер не сбрасывает.
- Наследования от px нет нигде. `font:inherit` у `button` и полей берёт размер от rem-предка.
- Скролл при 200 %: длинные слова переносятся (`overflow-wrap:anywhere; hyphens:auto` на
  `h1,h2,h3,p,label,button,a`); `.clips` использует `minmax(min(100%,16.25rem),1fr)`; `.cta` —
  `inline-flex` и переносится по пробелам. По расчёту горизонтального скролла нет. Подтверждение — прибор.

**Вывод по R8:** условие правки 8 выполнено. Цена — находка M1: `vw`-часть сделана настолько малой, что
на десктопе заголовки фактически не растут.
