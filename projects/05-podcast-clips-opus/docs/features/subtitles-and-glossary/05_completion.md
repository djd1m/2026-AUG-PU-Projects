# Квитанция — subtitles-and-glossary

**Требования:** FR-RENDER-005, FR-RENDER-006, FR-RESULT-004 (`docs/Specification-addendum.md`).
**Коммиты:** `69cc815`, `bc5b70c`, `9cd9f95`.

## Что сделано и почему

| Находка владельца | Причина | Исправление |
|---|---|---|
| «моргает транскрипт» | событие кончалось на конце слова, плашка исчезала в каждую межсловную паузу | события встык |
| (после исправления) подпись висела до конца клипа | «встык» тянул последнюю реплику до финала | удержание ≤ 1 с |
| «увеличь кегль и обводку» | 68 px, обводка 3 — скромно для вертикального видео | 86 px, обводка 5, тень 1 |
| английские названия кириллицей | распознаватель пишет на слух: «Велоклауд», «Виллоклауд» | словарь терминов, только в показе |
| кнопка «Повторить» серая до полуночи | экран гасил её по прогнозу квоты | решает сервер |

## Что проверено и чем

| Свойство | Чем | Итог |
|---|---|---|
| Строка помещается | отрисовка настоящим libass | 24 знака → 875 px при полезных 972; первый расчёт (26) дал 978 — переполнение |
| Подпись исчезает после речи | `tests/render-audio.test.ts`, `framing-media.test.ts` | на 6-й/8-й секунде ярких пикселей в области субтитров ноль |
| Подсказка словаря модели не работает | опыт на 30 с живого звука, с подсказкой и без | «Виллоклауда» в обоих; вариант с подсказкой дописал выдуманный текст |
| Словарь срабатывает | журнал `glossary_applied` | 13 замен «Велоклауд» → VeloCloud на прогоне |
| Переменная словаря доезжает до контейнера | `tests/wiring.test.ts` | без объявления в фикстуре — 3 красных |

## Чего фича НЕ доказывает

- Словарь покрывает только известные термины сетевой тематики. Новая тематика — новые записи.
- Читаемость на телефоне проверена только глазами владельца.
