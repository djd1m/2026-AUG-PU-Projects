## 1. Метка fail-closed — несущий инвариант

```ts
watermarkRequired(plan: unknown): boolean { return plan !== 'paid'; }
```

Сравнение **на равенство**: `null`, `''`, `PAID`, ` paid`, `premium`, число, булево — все получают
метку. Проверка вида `!== 'free'` открыла бы снятие метки опечаткой. Значение берётся **только из
базы**; поле «без метки» в теле запроса не читается вовсе.

`clip_link` создаётся **ДО** постановки задания рендера: иначе в пиксели нечего вшивать.

## 2. Порядок фильтров — это защита, а не стиль

```
масштаб → кроп 9:16 → ASS-субтитры → [музыка: не в этой фиче] → метка
```

Метка **верхним слоем** и физически не может быть перекрыта. Страж по исходнику: порядок в
`buildFilterChain` проверяется тестом, перестановка → красный.

## 3. НАЙДЕНО ИЗМЕРЕНИЕМ: метка канона НЕ ПОМЕЩАЕТСЯ в кадр

Проверено вычислением ширины (`WU-02-render.md`): при кегле 3,5 % от 1920 строка
`КлипМейкер · clipmaker.aicoding.space/c/aB3xK9` даёт 1407 px в DejaVu Bold, 1182 в Liberation,
972 в Liberation Narrow — при полезной ширине **972 px** с отступами 5 %. **Не помещается ни в одном
проверенном начертании**, и отрезается именно `/c/код` — то есть ровно то, ради чего ADR-004
существует.

**Решение координатора: метка в ДВЕ СТРОКИ.** Первая — `КлипМейкер`, вторая — `домен/c/код`. Кегль
остаётся ≥ 3,5 %, отступы соблюдаются, адрес читается целиком. Тест обязателен: расчётная ширина
каждой строки ≤ полезной ширины кадра; мутация — вернуть одну строку → красный.

Ещё две находки оттуда же, обе обязательны:

- **`font=Montserrat` подменяется МОЛЧА**: код возврата 0, ни одного предупреждения даже на
  `-v warning`, текст нарисован другим шрифтом другой ширины. Клон пишет так в трёх местах.
  **Только `fontfile=` с файлом, лежащим в образе.** Страж: в исходнике нет ни одного `font=`.
- **`amix` по умолчанию глушит речь на 6,0 дБ** — к этой фиче не относится (музыки нет), но если
  трогаешь звук, `normalize=0` обязателен.

## 4. Что построить

`packages/db` — миграция со следующим свободным номером: `clip.render_fence`, статусы клипа.

`apps/worker/src/render/*` — по таблице §0.

`apps/worker/src/workers/render.ts`:

1. `concurrency` **литералом `1`** (ADR-006, страж по исходнику);
2. резерв диска ≥ 3× размера ДО скачивания (переиспользовать проверку фичи 3, не писать вторую);
3. `watermarkRequired` из БАЗЫ до сборки фильтров;
4. рендер **дочерним процессом** — тяжёлая работа не занимает цикл событий, иначе очередь объявит
   задание зависшим через 30 с непрерывной занятости и та же работа начнётся во второй раз;
5. выгрузка в S3 по ключам канона: `clips/free/{video_id}/{clip_id}.mp4` либо `clips/paid/…`,
   превью в `thumbs/`;
6. приём результата по `render_fence`; ноль затронутых строк — `stale_attempt_result` в аудит;
7. временный каталог чистится в `finally` — и после успеха, И после отказа.

## 5. Тесты, без которых фича не принимается

| Страж | Внедряемый дефект |
|---|---|
| ADR-004 (а) метка fail-closed | `!== 'free'` вместо `=== 'paid'` → красный на `null`, `''`, `PAID`, ` paid`, `premium`, `0`, `true` |
| ADR-004 (б) `clip_link` создан ДО рендера | создать ссылку после → красный |
| метка в две строки помещается | вернуть одну строку → расчёт ширины красный |
| только `fontfile=`, ни одного `font=` | вернуть `font=` → страж по исходнику красный |
| порядок фильтров, метка верхним слоем | переставить метку перед субтитрами → красный |
| ADR-006 `concurrency` литералом 1 | заменить на переменную окружения → красный |
| резерв диска до скачивания | убрать проверку → счётчик вызовов S3 GET перестаёт быть нулём |

**Конкурентный (обязательный):** задание `render(fence=N)` доставлено дважды — только ОДИН
`UPDATE … WHERE render_fence` затрагивает строки, второй даёт ноль и `stale_attempt_result`.
Учти: в фиче 5 ровно этот класс дал blocker — два одновременных вызова прошли оба. Не повтори.
