# Постановка для Codex — фича 19 `teaser-headline`: заголовок крупно в первые секунды клипа

Готовы фичи 1–18. Решения A-2409-04 и A-2409-05 в `docs/decisions-autonomous.md` (автономный режим
владельца). Предыстория: `docs/proposals/hook-music-cta/00_proposal.md` §1.1 «окно приманки».

## Зачем

Первые 1–3 секунды решают, досмотрит ли зритель клип. Сейчас клип начинается «с полуслова». Нужен
крупный заголовок клипа поверх видео в первые **2,5 с** — как у вирусных шортсов.

## Что построить

### 1. Схема и загрузка
- Миграция `015_teaser.sql`: `ALTER TABLE video ADD COLUMN teaser boolean NOT NULL DEFAULT false`.
- `createVideoSchema`: `teaser: z.boolean().optional()`, отсутствие = `false`; повтор ключа с другим
  `teaser` → `409` (как `music`).
- `Uploader.tsx`: вторая галочка «Заголовок в начале клипа», **отмечена по умолчанию**, хранится в
  Resume и блокируется так же, как галочка музыки. Отправляется в `video.create`.
- `getRenderInput` отдаёт `v.teaser` и `c.title`.

### 2. Рендер
- Текст — `clip.title` как есть, **без кавычек** (это заголовок, не цитата). Пустой после `trim` →
  приманки нет.
- **Передача текста в ffmpeg — через `textfile=` во временном файле** в каталоге рендера (режим
  0o600), `expansion=none`. Никакой интерполяции заголовка в строку фильтра: заголовок пишет модель,
  это недоверенный ввод (прецедент — экранирование ASS).
- Шрифт — тот же `ClipMakerNarrow-Bold.ttf`, что у метки. Кегль `TEASER_FONT_SIZE = 84`.
- **Перенос по строкам — измерением**, функцией `measureText` из `packages/shared/src/watermark.ts`:
  полезная ширина = ширина кадра − 2×54 px; не больше `TEASER_MAX_LINES = 3` строк; если не
  помещается — уменьшать кегль шагом 4 до `TEASER_MIN_FONT_SIZE = 60`; не помещается и так —
  обрезать по слову с «…». Чистая функция `layoutTeaser(title, width) → { lines, fontSize }` с тестом.
- Положение: верхняя треть кадра, по центру по горизонтали, первая строка на `y = 0,16·h`;
  подложка `box=1:boxcolor=black@0.55:boxborderw=24`. Не пересекается с полосой метки (низ) и
  субтитрами (подъём снизу 500) — проверить вычислением.
- Время: `enable='lt(t,2.5)'`, плюс исчезновение за последние 0,3 с через `alpha`
  (`alpha='if(lt(t,2.2),1,max(0,(2.5-t)/0.3))'`). `TEASER_SECONDS = 2.5`.
- Порядок фильтров: кадр → субтитры → **приманка** → вспышка → метка. Метка верхним слоем.
- Субтитры в окне приманки НЕ подавляются (текст другой — заголовок, не речь).
- `renderClip` возвращает `teaser: { lines, font_size } | null`; в контракт — ТОЛЬКО при наложении:
  `teaser: { text_sha256, lines, font_size, version: 'v1' }`.
- Отказов нет: любая проблема разметки → клип без приманки + событие `{"event":"teaser_skipped"}`.

### 3. Инварианты
- `teaser=false` и `music=false` → аргументы и контракт побайтово = `tests/fixtures/music-bed/baseline.json`.
- `teaser=false`, музыка есть → побайтово эталоны `pack-shot` (`music-only.json`).
- RD-001: один `execFFmpeg` на кодирование; SL-008 — ноль вызовов до ошибки геометрии метки.

## Тесты

| Страж | Что проверяет | Дефект → ожидание |
|---|---|---|
| разметка | заголовки 34, 51, 69 знаков и `WWWW…` укладываются в ширину по `measureText`, ≤ 3 строк, кегль ≥ 60 | снять проверку ширины → красный |
| инъекция | заголовок с `'`, `:`, `\`, `%{pts}`, `[0:v]`, `;` не попадает в строку фильтра; файл содержит его дословно | интерполировать в `text=` → красный |
| окно | на настоящем ffmpeg: яркость верхней трети в t=1,0 отличается от рендера без приманки; в t=3,0 — совпадает | `lt(t,25)` → красный |
| метка цела | непрозрачная часть метки в t=1,0 совпадает с рендером без приманки | приманка после метки → красный |
| без пересечений | прямоугольник приманки не пересекает полосу метки и зону субтитров (вычислением) | `y=0,8·h` → красный |
| выключено | эталоны `baseline.json` и `music-only.json` побайтово | безусловная приманка → красный |
| схема | `teaser` без поля → false; `true` сохраняется; повтор с другим → 409; лишнее поле → 422 | снять `.strict()` → красный |
| интерфейс | галочка отмечена по умолчанию, блокируется при возобновлении, значение уходит в `video.create` | default false → красный |
| контракт | с приманкой ≠ без; без = эталон | безусловное поле → красный |

Мутации обеими строками, скрипт по образцу `tests/run-pack-shot-mutations.mjs`. Прогон — `npx vitest run`
по затронутым файлам (Docker недоступен — не повод для `failed`).
