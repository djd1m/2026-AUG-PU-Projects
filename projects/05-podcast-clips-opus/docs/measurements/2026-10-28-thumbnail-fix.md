# N5: восстановлена полная видеодорожка и превью после уплотнения пауз

Локальная приёмка 28.10.2026. Исходная версия394197e0; исправленный код
и полная сборкаd6fee35f52926c6b64fa4c79d238859548c8ddff.
Текущий публичный стенд этим изменением не обновлялся.

## Причина и исправление

Источник 5 fps резался на части до приведения к 25 fps. После сброса временных меток
части оказывались короче плана; цепочка xfade обрывала видеоряд. Аудио и длительность
MP4 оставались полными, поэтому проверка только общей длительности не находила дефект.
У третьего фрагмента четверть плановой длительности попадала за конец видеодорожки,
и создание JPEG завершалось ffmpeg_failed. У первых двух JPEG мог получиться при
уже укороченном видеоряде.

В buildCompactionGraph нормализация FPS перенесена перед trim. Изменены одна строка
графа, новый реальный media-регрессионный тест и старое буквальное ожидание порядка.
Звуковой граф, план/длительность, субтитры, метка, лимиты, публикация и права сохранены.

| Исходный диапазон | План, с | Старый граф: видеоряд в воспроизведении, с | Новый полный MP4: видео / звук, с |
|---|---:|---:|---:|
| 0–25 | 21,56 | 6,28 | 21,56 / 21,56 |
| 30–55 | 21,44 | 11,92 | 21,44 / 21,44 |
| 60–85 | 21,52 | 4,52 | 21,52 / 21,52 |

Старый граф воспроизведён на уменьшенном кадре; новые результаты получены настоящим
1080×1920 worker-пайплайном на том же200 с синтетическом исходнике и тех же сохранённых
планах. Исходные временные файлы прежнего неудачного worker уже были удалены его
обычной очисткой; их фактическая длительность задним числом не приписывается.

  и реальный JPEG. Старые VFR/A-V/audio-only тесты и 4 мутационных стража пройдены.
- Полный npm test: 1259 тестов / 131 файл / 0 пропусков; build/typecheck/lint — exit0.
- Холодное независимое ревью — без находок, с контекстом планировщика и без переписки
  кодера. Это исходниковая проверка; измеренные результаты ниже принадлежат координатору.
- Полный локальный upload→очереди→fake STT/selection→настоящий FFmpeg→S3: 3 из 3 done.
  Наблюдённое время 40,879 с — одна синтетическая точка, не производительность живых моделей/p95.
- Настоящие скачанные MP4:539/536/538 кадров,1080×1920, отдельные видео/аудиодорожки
  равны плану; кадры у конца каждого файла декодируются. Все 3 JPEG 360×640 полностью
  декодированы; выдача имеет video/mp4 и image/jpeg. Файл от кнопки UI побайтно совпал.
- Существующий Docker codex-ui-playwright: 91 проверка, 8 скриншотов; Chromium 153.0.8010.12
  и WebKit 26.6;360/900px, светлая/тёмная темы. Все 3 превью и плеера работают, предупреждения
  частичного рендера нет; реальное скачивание прошло. Браузеры Linux headless, не физический iPhone.

Изолированные тестовые БД/Redis/MinIO, fake-модели и частный HTTPS со своим сертификатом.
Платные поставщики, реальные пользователи и текущий production не затронуты. Ранее
сохранённые файлы сами не пересобираются; проверена новая обработка после исправления.

Неудачные попытки сохранены: неверный dist-путь в preflight; штатный upload429 у старого
тестового аккаунта (новый создан обычной регистрацией); промежуточные браузерные проверки
с фиксированным ожиданием/невидимым плеером и отдельной ошибкой повторного скачивания.
Финальный браузерный сценарий прокручивает плеер в видимую область и ждёт фактического
начала воспроизведения; требования не ослаблены, приложение для этого не менялось.
