## Пять причин отказа, вскрытых этой записью

Все пять — одного рода: проверка написана исходя из того, какими данные ДОЛЖНЫ быть, а не какими
приходят от настоящего распознавания.

| № | Что отвергало | Измеренная величина |
|---|---|---|
| 1 | строгая монотонность начал слов | откат **0,26 с** на слове №98 |
| 2 | доля поджатых > 1 % | **5 на 409** слов = 1,22 % |
| 3 | выход за границы записи | превышение **0,0000205 с** — двадцать микросекунд |
| 4 | один негодный фрагмент отбрасывал ВСЕ | 7 годных потеряны из-за одного |
| 5 | модели слался список всех слов | **1128 КБ ≈ 385 тысяч токенов** против 115 КБ сегментов |

Ни одна не была бы поймана набором из 580 зелёных тестов: все пять срабатывают только на настоящей
длинной записи. Это цена фикстур, построенных из ожиданий.

## Деньги: квота против фактического расхода

Списано квоты за день — **550 минут**: шесть попыток по 89 минут плюс 16 ранее. Фактически поставщику
ушло несравнимо меньше: пять из шести попыток падали на первом-втором куске за секунды, то есть
оплачено примерно по 3–6 минут звука каждая, и лишь последняя — все 88.

**Это и есть иллюстрация к разнице, объявленной в `pipeline-walkthrough.md`:** квота списывается
АВАНСОМ за всю запись, расход считается по ПОПЫТКАМ, и совпадать они не обязаны. Сегодня расхождение
составило примерно пятикратное.

Практическое следствие для владельца: при отладке суточный потолок выгорает быстрее, чем деньги.
Потолок поднят до 900 минут именно поэтому.
