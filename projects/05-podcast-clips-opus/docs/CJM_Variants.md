## Общее ядро (одинаково во всех вариантах)

Пользователь входит (почта или Telegram) → загружает файл до 2 ГБ или ссылку на VK Видео / Rutube →
сразу получает `job_id` и экран прогресса с тремя состояниями (`выполняется · успех · отказ`) →
транскрипция с таймкодами (`whisper-1` на уровне слов либо `gpt-4o-transcribe-diarize` — критерий
выбора модели здесь таймкоды, не цена) → Claude выделяет самодостаточные фрагменты 20–75 с →
ffmpeg в контейнере-воркере режет 9:16, вшивает субтитры и ставит метку на бесплатном тарифе →
пользователь видит **первый клип с оценкой и её объяснением** («хук 9/10 · мысль завершена · 41 с»),
и ровно здесь стоят кнопки «скачать / поделиться» (FR-GROWTH-001) → paywall: снять метку и
добавить минуты — платный тариф.

Ограничения недели, общие для всех вариантов (постановка 05): автопостинг, brand kit, командная
работа, распознавание лиц и авто-фрейминг НЕ входят. Файлы — том Docker. Потолки вызовов модели —
предложение к Specification: 20 минут записи на пользователя в сутки, 600 минут в сутки на всех,
счёт по попыткам; ненастроенный потолок валит запуск (`.claude/rules/model-call-cost.md`).

Метрика недели из постановки — **число опубликованных наружу клипов с меткой** — общая для всех
вариантов; каждый добавляет свою.

Варианты РАЗЛИЧАЮТСЯ growth-петлёй, а не интерфейсом.

| | A — Метка на клипе | B — Гость выпуска | C — Страница выпуска |
|---|---|---|---|
| **Growth loop** | content-driven (клип с меткой уходит в чужую ленту) | incentivized referral, двусторонний (артефакт = приглашение; стимул — контент и минуты, не деньги) | badge (публичная страница выпуска с бейджем) |
| **Aha Moment** | первый клип играет вертикально с субтитрами, рядом причина оценки | ведущий: клипы разложены по спикерам; гость: «ваши 4 момента из выпуска с Анной» | страница выпуска собралась сама: клипы, шоуноты с таймкодами, три поста |
| **Entry Hook** | эксперт-одиночка: «час записи — восемь клипов на две недели» | интервью-подкаст: гость не делится выпуском, потому что ему нечем | автор канала / подкастер без сайта: нужны шоуноты и куда поставить ссылку |
| **Paywall** | снять метку на клипе; минуты | гостю — снять метку; ведущему — минуты сверх бонуса | снять бейдж, свой адрес страницы; минуты |
| **Метрика недели** | ≥ 40 клипов с меткой наружу от ≥ 10 пользователей (по переходам с меток) | ≥ 30 % выпусков с отправленным пакетом; ≥ 50 % открыты; ≥ 8 регистраций гостей | ≥ 40 % активированных публикуют страницу; ≥ 100 уникальных посетителей |
| **Главный риск** | петля показов: конверсия зритель → регистрация неизвестна, вероятно < 1 % | держится на диаризации и на действии ведущего; бонус притягивает «фальшивых гостей» | показы бейджа ≠ регистрации (опыт N1); хостим чужой контент |
| **Переиспользование** | клон `ffmpeg.ts` (метка есть); N4 кабинет партнёра, исследование бейджа | клон STT с чанкингом; N1 `referral.ts`; N4 anti-fraud по кодам | N1 `wall.ts`, `badge.ts`; клон — страница видео |

Микро-тренды ниже — поиск 21.09.2026, номера ссылаются на раздел «Источники». Числа взяты из
вторичных сводок и на первоисточниках не перепроверялись: это сигналы для выбора петли, не
требования к продукту.

## A — Метка на клипе

| Поле | Содержание |
|---|---|
| **Aha Moment** | Через ~5 минут после загрузки первый клип играет в вертикальном плеере с субтитрами и меткой внизу слева; рядом оценка с объяснением «82 · хук 9/10 · мысль завершена · 41 с» |
| Entry Hook / сегмент | Эксперт-одиночка или автор курсов, выкладывающий раз в месяц: «час записи — восемь клипов на две недели»; лендинг открывается живым демо-клипом с меткой |
| Onboarding | Вход по почте/Telegram (код блогера необязателен, принимается по deeplink) → ссылка или файл → `job_id` и прогресс с тремя состояниями |
| Core Loop | клипы → выбрал 3–5 → скачал → опубликовал вручную в VK Клипы / Telegram / Rutube / Дзен → зритель видит метку «сделано в КлипМейкере · <домен>/c/<код>» → переходит → загружает своё |
| Paywall | «Снять метку» на каждом клипе → тариф; в неделе — тест-магазин ЮKassa из клона либо экран интереса «Pro скоро» (решение владельца) |
| Growth loop | **Content-driven**: продукт производит носитель; метка на free превращает каждый просмотр чужой аудиторией в показ бренда |
| FR-GROWTH-001 | Скачать / «отправить себе в Telegram» на карточке первого клипа, не на онбординге |
| FR-GROWTH-002 | Код блогера при входе + cookie; код сильнее cookie; хранится до покупки «снять метку» |
| FR-GROWTH-003 | Метка и есть бейдж: ≥ 3,5 % высоты кадра, подложка с контрастом, внутри safe zone сторис; снятие платно |
| FR-GROWTH-004 | Персональные коды блогеров, кабинет партнёра из N4: клики → регистрации → клипы наружу |
| Микро-тренды | 58 % открытий подкастов через короткое видео, клипы дают 20–40 % новой аудитории [1, 2]; VK Клипы 3 млрд просмотров в день, +42 % [6]; хук 1–3 с, вшитые субтитры, нативные 9:16 [3]; метка как атрибуция у CapCut внутри экосистемы TikTok [12] |
| Главный риск | Петля **показов**, не приглашений: конверсия зритель → регистрация неизвестна, отраслевого числа нет; метка, нечитаемая на телефоне, = петли нет; пользователь режет метку кропом или уходит в CapCut; @security — накрутка переходов по ссылке метки ботами |
| Проверяемая гипотеза | ≥ 40 клипов с меткой опубликованы наружу от ≥ 10 пользователей; «опубликован» = ≥ 1 внешний переход по ссылке клипа; i = клипов наружу на пользователя, conv% = переходы → регистрации, раздельно |

## B — Гость выпуска

| Поле | Содержание |
|---|---|
| **Aha Moment** | Ведущий: «Вы: 5 · Анна: 4» — клипы разложены по спикерам, кнопка «Отправить Анне в Telegram». Гость: открыл ссылку — своё лицо, свои слова, субтитры, оценка с причиной |
| Entry Hook / сегмент | Интервью-подкаст с гостями: гость не делится выпуском, потому что ему нечем; у гостя своя аудитория |
| Onboarding | Вход → загрузка → транскрипция с диаризацией (`gpt-4o-transcribe-diarize`) → экран «Кто есть кто?» (ведущий подписывает спикеров); один спикер — вариант вырождается в A, и это показывается честно |
| Core Loop | гостевая страница без входа: смотреть и скачать с меткой сразу → гость публикует → регистрируется, чтобы снять метку или загрузить свой выпуск → у него свои гости |
| Paywall | Гостю — «снять метку с ваших 4 клипов» одной покупкой; ведущему — минуты сверх бонуса |
| Growth loop | **Incentivized referral, двусторонний**: ведущему +20 минут за активированного гостя (зарегистрировался и обработал ≥ 1 своё видео с другого устройства), потолок 3 бонуса на выпуск; гостю — его клипы бесплатно |
| FR-GROWTH-001 | Двойной момент ценности: «Отправить гостю» у ведущего и «Скачать все» у гостя |
| FR-GROWTH-002 | Гость, открывший ссылку, атрибутируется ведущему (код в ссылке + cookie) до своей первой оплаты; блогерские коды независимо |
| FR-GROWTH-003 | Метка на всех клипах гостя на free; снятие платно |
| FR-GROWTH-004 | Личный код ведущего в гостевой ссылке (пользователь как микро-партнёр); коды блогеров из кабинета N4 |
| Микро-тренды | 71 % подкастеров снимают видео, 700 млн часов видео-подкастов на ТВ за месяц у YouTube [1, 4]; диаризация из коробки — постановка 05; Telegram как канал доставки, 30 % креаторов публикуются там [8, 10]; кросс-промо с гостем — базовая рекомендация RU-руководств [9] (гипотеза о силе стимула) |
| Главный риск | Держится на действии ведущего «отправить»; диаризация на 3+ спикерах ошибается — разметка обязательна; права: передача клипов с изображением гостя требует его согласия (ст. 152.1 ГК РФ), страница приватная по ссылке; @security — «фальшивые гости» ради минут |
| Проверяемая гипотеза | ≥ 30 % выпусков с отправленным пакетом; ≥ 50 % отправленных открыты; ≥ 8 регистраций гостей; i = гостей приглашено на ведущего, conv% = гостей зарегистрировалось / приглашено |

## C — Страница выпуска

| Поле | Содержание |
|---|---|
| **Aha Moment** | Страница выпуска собралась сама: 8 клипов с оценками, шоуноты с таймкодами, три поста (Telegram, VK, описание видео); кнопка «Скопировать пост для Telegram со ссылкой» |
| Entry Hook / сегмент | Автор Telegram-канала или подкастер без сайта: нужны шоуноты и куда поставить ссылку; лендинг показывает готовую страницу чужого выпуска |
| Onboarding | Вход → загрузка → пока идёт обработка, вопрос о видимости страницы: закрыта / по ссылке / публичная, по умолчанию **закрыта** |
| Core Loop | пост в канале → страница на нашем домене → посетители смотрят клипы → бейдж «сделано в КлипМейкере · сделать свой» → регистрация; клипы на странице тоже с меткой |
| Paywall | «Убрать „сделано в“ со страницы», «своя ссылка /p/имя» → тариф; fail-closed из N1: всё, что не ровно `paid`, показывает бейдж |
| Growth loop | **Badge**: артефакт живёт в описаниях и каналах ведущего, каждый посетитель видит бренд |
| FR-GROWTH-001 | «Скопировать пост со ссылкой» на экране результата; пост готов без действий пользователя |
| FR-GROWTH-002 | Переход со страницы ставит cookie-атрибуцию на её владельца до платной конверсии; код блогера — независимый fallback |
| FR-GROWTH-003 | Бейдж на странице и метка на клипах на free; правило «только одобренное публично» из N1 `wall.ts` |
| FR-GROWTH-004 | Коды блогеров + личный код владельца в CTA страницы |
| Микро-тренды | AI-саммари длинных постов в Telegram с января 2026 [10]; половина шоу выкладывает полное видео, открытия идут через клипы — нужен хаб [1, 3]; органика Rutube для видео-подкастов [9]; воронка оригинала «клип → длинное → членство» [3] |
| Главный риск | Показы ≠ регистрации (опыт бейджа в N1); трафик равен аудитории канала автора; хостим чужие записи и лица гостей — модерация, жалоба, снятие не позже 72 часов; по умолчанию закрыто → доля публичных страниц может быть низкой; @security — накрутка посетителей владельцем |
| Проверяемая гипотеза | ≥ 40 % активированных публикуют страницу; ≥ 100 уникальных посетителей страниц за неделю; i = посетителей на автора, conv% = посетители → регистрации по CTA бейджа |

## Рассмотрен и отложен: продажа студиям и агентствам (sales loop)

Суб-аккаунты, бренд-пресеты клиента, апрув по ссылке; один партнёр приводит 10–20 шоу. Прямо
упирается в «командная работа не входит» из постановки 05. В январском клоне модели `Team`,
`TeamInvite` и маршрут `/invite` уже есть, поэтому это дешёвый второй шаг после недели, а не
вариант недели. В сравнение не включён как самостоятельный вариант.

| ID | Как проявляется в вариантах |
|---|---|
| FR-GROWTH-001 | Share-CTA на экране первого клипа во всех трёх; в B добавляется «отправить гостю», в C — «скопировать пост со ссылкой» |

| FR-GROWTH-004 | Персональные коды для людей с аудиторией: блогеры (все), ведущий как микро-партнёр (B, C, D) |
| FR-GROWTH-005 (предложение) | Метка обязана быть читаемой на телефоне в VK Клипах: проверка на реальном устройстве, не в браузере; иначе loop не работает, а мы думаем, что работает |

ID не переименовываются под альтернативные петли. После выбора каждый получает happy/edge/security
сценарии в Specification; сейчас это вход к выбору, не спецификация.

## Решение владельца

**Зафиксированный выбор (2026-09-21): `{CHOSEN_CJM}` = вариант D — гибрид «A + B-лайт».**
Формулировка владельца: «A плюс B-лайт, фиксируй гибрид». Обоснование, на котором основано решение:
A обязателен по постановке и существует в любом варианте; B — самая сильная гипотеза настоящей
виральности (приглашения, а не показы), но полный B тянет диаризацию, бонусные минуты и анти-фрод;
лайт-версия проверяет обе петли за неделю почти без нового кода.

### D — Гибрид: путь A + блок «клипы для гостя» (B-лайт)

| Поле | Содержание |
|---|---|
| **Aha Moment** | Как в A: первый клип играет с субтитрами и меткой, рядом объяснённая оценка |
| Entry Hook / сегмент | Как в A: эксперт-одиночка и автор курсов; интервью-подкасты с гостями получают второй вход — «клипы для гостя» |
| Onboarding → Core Loop | Шаги A целиком. Добавляется один шаг после результата: ведущий отмечает галочкой клипы, где говорит гость, и жмёт «отправить гостю» → гость открывает страницу по ссылке без входа («Анна, ваши 4 момента из выпуска с Сергеем»), скачивает с меткой, публикует у себя → регистрируется, чтобы снять метку или загрузить свой выпуск |
| Paywall | Как в A: «снять метку» на клипе → тариф; гостю — «снять метку с ваших клипов» одной покупкой |
| Growth loop | Основной — **content-driven** (A). Вторичная тактика — гостевая ссылка (B без диаризации и без бонусных минут): та же метка, та же атрибуция, новый только адресат |
| Что из B НЕ входит | Диаризация и экран «кто есть кто» (галочки ставит человек); бонус +20 минут ведущему и, следовательно, анти-фрод «фальшивых гостей»; сортировка клипов по спикерам |
| FR-GROWTH-001 | Скачать / «отправить себе в Telegram» на карточке первого клипа (A) + «отправить гостю» на экране результата и «скачать все» на гостевой странице (B) |
| FR-GROWTH-002 | Код блогера + cookie (A); гость, открывший ссылку, атрибутируется ведущему до своей первой оплаты (B); код сильнее cookie |
| FR-GROWTH-003 | Метка на всех клипах free, включая гостевые; снятие платно |
| FR-GROWTH-004 | Кабинет партнёра из N4 для блогеров; личный код ведущего в гостевой ссылке — ведущий как микро-партнёр, только счётчики, без выплат |
| Метрика недели | Две цифры раздельно: (1) ≥ 40 клипов с меткой наружу от ≥ 10 пользователей, по переходам с меток; (2) ≥ 30 % выпусков с отправленной гостевой ссылкой и ≥ 50 % открытых. Если первая около нуля, а вторая живая — на вторую неделю поднимается полный B |
| Главный риск | Виральность A недоказуема заранее (петля показов); гостевая ссылка держится на действии ведущего; передача клипов с изображением гостя — согласие гостя фиксируется в момент отправки (чекбокс ведущего «гость согласен на публикацию», страница приватная, не индексируется); @security — накрутка переходов по метке и самопереходы ведущего на свою гостевую страницу не атрибутируются |
| Переиспользование | Клон: `ffmpeg.ts` (метка), STT с чанкингом, `llm-router.ts`, ЮKassa; N4: кабинет партнёра, события share, исследование бейджа, ADR-008; N1: `wall.ts` (страница по слагу) для гостевой страницы, `referral.ts`; N2: notifier для дайджеста. Новый код: короткая ссылка с кодом на метке, галочки «это гость», кнопка «отправить гостю», гостевая страница |

### Отвергнутые варианты (сохранены целиком выше)

| Вариант | Причина отказа |
|---|---|
| A (в чистом виде) | Не выбран как единственный: петля показов не отвечает на вопрос «есть ли у продукта настоящая виральность». Путь A целиком вошёл в D как основная петля |
| B (полный) | Не выбран на неделю: диаризация — новая внешняя зависимость и новый код разметки спикеров; бонусные минуты требуют анти-фрода; вместе это съедает неделю до первого срабатывания петли. Лайт-версия вошла в D; полный B — первый кандидат на вторую неделю, если conv% по меткам окажется около нуля |
| C | Отвергнут: показы бейджа ≠ регистрации (опыт N1), трафик равен аудитории канала автора, хостинг чужого контента тянет модерацию и снятие по требованию. Шоуноты и посты из постановки остаются в scope как выход продукта, но без публичной страницы |
| Студии и агентства | Отложен: противоречит «командная работа не входит»; заготовка в клоне (`Team`, `TeamInvite`) делает его дешёвым вторым шагом |
