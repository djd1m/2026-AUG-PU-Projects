# План на 12 часов — автономная работа (24.09.2026, старт ≈ 15:30 МСК)

Поручение владельца: «составь план на 12 часов и действуй». Режим — автономный: вопросов не задаю,
решения, которые в норме задал бы владельцу, пишу в `docs/decisions-autonomous.md` (дата, вопрос,
выбор, обоснование, откат). Останавливаюсь только перед необратимым или внешним: оплата, публикация
наружу, удаление чужих данных, порты БД.

Каждая фича — полный цикл, как 16 и 17: постановка → проверка плана (Anthropic) → код (Codex) →
ревью (Anthropic) → полный набор в образе → выкатка → живая проверка на стенде → документы
воспроизводимости (ADR, addendum, canon, REPRODUCE, roadmap, квитанция) → коммит и пуш.

## Решения, принятые заранее (детали — `decisions-autonomous.md`)

- **#18:** трек выбирается по номеру клипа в записи (`index mod N`) — клипы одной записи звучат
  по-разному, повтор рендера даёт тот же трек. Выбор модели или пользователя — нет (proposal §5.1:
  модель, судящая собственный вывод). Только альбомы Komiku с CC0 в двух источниках.
- **#19:** приманка — ДОСЛОВНАЯ строка транскрипта внутри клипа, выбирается моделью в том же вызове
  выделения (новое поле ответа, без лишнего платного вызова) и проверяется нашим кодом как подстрока
  по словам; не прошла проверку — клип без приманки, не отказ. Включается собственной галочкой при
  загрузке, по умолчанию ВКЛЮЧЕНА для новых загрузок; прежние записи не меняются.
- **Блок 4:** отдельный стек `n5-repro`, отдельная база, ключ OpenRouter тот же (расход — одна
  короткая запись, ≈ $0,01), ничего не публикуется наружу; по окончании — удаляется своим скриптом.
