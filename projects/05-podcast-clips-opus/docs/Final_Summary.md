# КлипМейкер - Executive Summary

**Версия:** 0.1 · **Дата:** 2026-09-21 · **CJM:** D — путь A + блок «клипы для гостя» (B-лайт),
решение владельца OWN-001. **Канон:** [`canon.md`](canon.md), заморожен 2026-09-21.

## Overview

«КлипМейкер» превращает одну длинную запись подкаста или интервью в 3–8 готовых к публикации
вертикальных клипов с вшитыми субтитрами и оценкой потенциала, у которой ВИДНА причина. Ведущий
загружает файл до 2 ГБ и часа полтора спустя получает клипы 9:16, короткую ссылку на каждом и — на
бесплатном тарифе — метку с адресом, которая и есть носитель роста продукта. Поверх основного пути
стоит один дополнительный шаг: ведущий отмечает моменты гостя выпуска, подтверждает его согласие и
отправляет гостю страницу без входа — так гость получает что опубликовать, а продукт получает
вторую, независимо измеримую петлю привлечения. Недели хватает на конвейер целиком; оплата,
автопостинг и диаризация спикеров сознательно отложены во вторую волну.

## Problem & Solution

**Проблема.** Эксперт с часовой записью обычно не публикует из неё ничего: нарезать самому дороже,
чем записать ещё один выпуск, а объяснения, ПОЧЕМУ конкретный момент стоит клипа, конкурентные
инструменты не дают — только число без основания. Гость выпуска после эфира остаётся вовсе без
контента: ссылка на часовой файл — плохой носитель, а резать чужую запись он не станет.

**Решение.** Конвейер «загрузка → транскрипция с таймкодами слов → один вызов модели выделения →
кроп 9:16 с вшитыми субтитрами → карточка с оценкой из трёх объяснённых компонентов», плюс гостевая
страница без входа как второй, независимый путь роста. Метка на бесплатном тарифе несёт короткую
ссылку именно этого клипа — показ измерим, а не подразумевается.

## Target Users

**Primary — Сергей, эксперт-подкастер.** Записывает час в неделю, публикует сам, монтировать не
умеет и не хочет; боль не «нарезать», а «выбрать», какой из шестидесяти минут стоит клипа.

**Secondary — Анна, гость выпуска** (нечем поделиться после эфира, входит в продукт по гостевой
ссылке без регистрации) и **Кирилл, блогер-партнёр** (нужны пять раздельных счётчиков воронки, а не
общий промокод, чтобы посчитать своё привлечение).

## MVP Features

1. **Клипы с объяснённой оценкой (FR-SELECT-001/002, FR-RENDER-001).** Один вызов модели на запись
   возвращает 3–8 самодостаточных фрагментов; каждая оценка 0–99 раскладывается на три компонента
   по 0–33 с одной фразой объяснения — число без объяснения не показывается никогда. Ценность:
   пользователь выбирает публикацию за секунды, а не пересматривает запись.
2. **Метка со ссылкой как носитель роста (FR-RENDER-002, FR-GROWTH-003).** На бесплатном тарифе
   метка вшита в пиксели и несёт короткий адрес именно этого клипа, созданный ДО рендера. Ценность:
   каждый просмотр клипа в чужой ленте — измеримый показ продукта, а не предположение о нём.
3. **Клипы для гостя (FR-GUEST-001…003, FR-GROWTH-004).** Ведущий отмечает моменты гостя,
   подтверждает согласие, отправляет ссылку на страницу без входа. Ценность: у гостя появляется что
   опубликовать, а у продукта — вторая петля привлечения, измеримая отдельно от первой.

## Technical Approach

**Architecture.** Distributed Monolith в монорепо npm workspaces, один VPS, Docker Compose за
Caddy. Семь сервисов боевого профиля: `web` (Next.js 15, tRPC, подпись ссылок), три воркера из
одного образа (`worker-stt`, `worker-llm`, `worker-video` — очереди BullMQ), `db` (PostgreSQL 16,
источник истины), `redis` (транспорт заданий), `proxy` (Caddy, единственная публичная дверь).

**Tech Stack.** OpenAI `whisper-1` для транскрипции с таймкодами слов (единственный критерий выбора
— наличие таймкодов, не цена); Anthropic Claude Sonnet 5 со structured outputs для выделения
фрагментов и оценки (схема гарантирует форму, диапазоны 0–33 и 20–75 с проверяет наш код); Cloud.ru
Object Storage в боевом профиле, MinIO в тестах; ffmpeg 7 для кропа и вшитых субтитров.

**Key Differentiators.** Объяснённая оценка (три компонента с фразой каждый, доступна на
бесплатном тарифе — у источника число платное и без объяснения); гостевая ссылка как отдельная,
независимо измеримая петля роста; честный контур RU/СНГ (VK Клипы, Telegram, Rutube, Дзен, оплата
рублями через будущую вторую волну) там, где источник недоступен для оплаты из РФ.

## Research Highlights

- `whisper-1` — единственная модель поставщика с таймкодами на уровне слов: «Use `whisper-1` when
  you need word or segment timestamps» (OpenAI, проверено 2026-09-21). Без этого нарезка невозможна
  в принципе — критерий выбора, а не предпочтение.
- Structured outputs Anthropic гарантирует ФОРМУ ответа и прямо НЕ покрывает числовые диапазоны
  («Numerical constraints … Not supported») — отсюда обязательная проверка 0–33 и 20,0–75,0 с НАШИМ
  кодом, задокументированная как решение (ADR-003, Research_Findings.md).
- BullMQ возвращает «зависшее» задание в очередь по построению («moved back to the waiting list») —
  отсюда фенс на каждой попытке как условие принятия решения об очереди (ADR-001), а не защита
  «на всякий случай».
- Конкуренты недели делятся на недоступные для оплаты из РФ западные инструменты, ручные
  видеоредакторы и российских ботов без объяснённой оценки — свободная позиция здесь не «дешевле»,
  а «оценка, которую видно и можно оспорить, плюс клипы для гостя выпуска».
- Скачивание по ссылке с VK Видео/Rutube не подтверждено документацией поставщиков (`UNCONFIRMED`)
  — требование помечено `Should` и отложено, а не реализовано на неподтверждённом допущении.

## Risks & Mitigations

| Risk | Impact | Mitigation |
|---|---|---|
| Петля показов не даёт регистраций: конверсия зрителя метки в регистрацию неизвестна и, вероятно, ниже 1 % | Высокое | Две цифры метрики недели измеряются раздельно; при нулевой первой на второй неделе поднимается полный вариант B, а не чинится метка (Solution_Strategy, R-001) |
| Метка нечитаема на телефоне в реальной ленте — петля не работает, а счётчики создают видимость работы | Высокое | Проверка НА УСТРОЙСТВЕ (FR-GROWTH-005), результат — строка в `Completion.md`, не предположение |
| Расход на внешние вызовы растёт от чужих действий, а не от нашего кода | Высокое | Потолки на пользователя и на сутки, списание ДО вызова одним атомарным оператором, счёт ПО ПОПЫТКАМ, ненастроенный потолок валит запуск процесса |
| Совместимость Cloud.ru (подписи, multipart, CORS) не равна совместимости MinIO, на которой идут тесты | Высокое | Ручная приёмка на развёрнутом стенде — условие принятия ADR-002, а не факультативный шаг |
| Передача клипов с изображением гостя без надлежащего согласия | Высокое | Согласие с версией текста и хэшем ДО создания страницы (ADR-008); приватный код, `noindex`, срок 14 дней, немедленный отзыв |
| Зависшее задание, возвращённое очередью, дописывает результат поверх новой попытки | Высокое | Фенс на каждой попытке; результат принимается только оператором с условием актуальности фенса (ADR-001), проверено тестом с двумя попытками |
| Пользователь забыл пароль — восстановления по почте в неделе нет (DEC-A-007, нет почтового провайдера в инвентаре), потеря доступа к аккаунту и клипам на всю неделю измерения | Среднее | Ручное восстановление оператором по обращению: смена `password_hash` вручную; полноценное самостоятельное восстановление — v1, вместе с почтовым провайдером |
