# Показ работы — N5 «КлипМейкер»

**Что показываем:** две реализованные фичи из двенадцати на ЖИВОМ стенде. Ничего не имитируется:
настоящие PostgreSQL 16, Redis 7, S3-хранилище и Caddy как единственная публичная дверь.

## Запуск (стенд уже поднят)

```bash
cd projects/05-podcast-clips-opus
bash scripts/demo.sh
```

Поднять заново, если остановлен:

```bash
docker compose --env-file /tmp/n5-demo.env --project-directory . --profile test --profile edge \
  up -d db redis minio web proxy
```

## Что видно в девяти шагах

| Шаг | Что доказывает |
|---|---|
| 1 | Стенд отвечает; `/health` проверяет конфигурацию И доступность базы, а не только живость процесса |
| 2–3 | Регистрация работает; повтор с тем же адресом НЕ раскрывает существование аккаунта, второй аккаунт не создаётся |
| 4 | Неверный пароль и несуществующий адрес дают одинаковый текст, код и сопоставимое время: перечислитель пользователей не работает |
| 5 | Вход выдаёт сессию; в базе только HMAC токена, сырого значения нет нигде |
| 6 | Потолок 2 загрузки в сутки на аккаунт; третья отклонена с именем ИСЧЕРПАННОГО ключа квоты, а не общим «слишком много запросов» |
| 7 | Повтор с тем же ключом возвращает ТУ ЖЕ запись и не списывает квоту дважды |
| 8 | Состояние настоящей базы после показа |
| 9 | Продукт отказался стартовать, когда публичный адрес был без HTTPS: конфигурация отказывает, а не подставляет дефолт |

## Чего показать НЕЛЬЗЯ, и это честно

- **Экранов нет.** Интерфейс появится фичей 7 из 12; сейчас всё через API.
- **Клипов нет.** Транскрипция, выделение фрагментов и рендер — фичи 4, 5 и 6.
- **Cloud.ru не подключён.** Показ идёт на MinIO: код тот же, совместимость облака этим не доказана.
- **Ключей моделей нет.** Платные вызовы понадобятся с фичи 4.

## Чем подкреплено

- 132 теста из 132 зелёные в контейнере на настоящих хранилищах, ни одного пропущенного.
- Каждая фича прошла независимое ревью моделью другого семейства: код писал Codex, проверяла Anthropic.
- Восемь дефектов найдены запуском, а не чтением, и описаны в `docs/features/*/08_review_report.md`.
