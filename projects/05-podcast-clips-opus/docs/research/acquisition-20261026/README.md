## 3.4. Воронка и события

| Шаг | Событие | Что именно наблюдается |
|---|---|---|
| Визит | n5_visit | Согласованный визит на landing, статический безопасный URL |
| Регистрация | n5_signup_success | Register и успешное защищённое продолжение, не любойHTTP200 |
| Ключевое действие | n5_first_clip_ready | Пользователь впервые в браузерном scope видит доступный готовый клип |
| Оплата | n5_payment_confirmed | Браузер получил подтверждённый статус того же intent из БД |

Это события наблюдаемой браузерной воронки. Не все посетители дают согласие,
не все плательщики возвращаются; блокировщики и закрытая вкладка могут привести
к недоучёту. Экспорт/принятие клипа к публикации не считать доказанным только
из события ready. Финансовые когорты, первые оплаты и возвраты сверять с ledger.

План и проверка: [analytics-plan.md](../../features/acquisition-analytics/analytics-plan.md),
[validation-report.md](../../features/acquisition-analytics/validation-report.md).
Код по умолчанию выключен без собственного ID. Настоящее поступление целей
в Метрику **planned для Cloud.ru РФ**, не пройдено локальными stub-запросами.
[Инструкция целевого запуска](../../features/acquisition-analytics/cloudru-launch.md).

[Единый оставшийся план реализации и запуска](../../cloudru-launch-plan.md).

## Ворота до трафика

- Код целевых30регистрационных кредитов/пакетов реализован и изолированно
  проверен; нужны целевой cutover и реальная оплата по плану запуска.
- Принять новый Yandex SpeechKit v3 STT и целевые Cloud.ru DeepSeek/S3:
  расчётные57 ₽/час (стресс62 ₽/час) не являются счётом текущего OpenRouter pipeline;
  [актуальная экономика](economics.md), [детальные статьи](../unit-economics-20261026/unit-economics-summary.md).
- Код аналитики проверен; на Cloud.ru ещё нужны собственный счётчик, цели и
  реальные события в отчётах. Согласие и отсутствиеPII проверять отдельно.
- Зафиксировать бюджет и способ учёта труда канала; не запускать расходы
  только потому, что есть расчётный сценарий.

Упражнение полностью готово лишь после целевой проверки событий. Подготовка
исследования, плана и кода сама по себе не доказывает получение целей.
