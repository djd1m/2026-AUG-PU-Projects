# N5: DeepSeek вместо Sonnet 5 для выбора клипов

Дата: 26 октября 2026 UTC. **Первый кандидат для проверки — DeepSeek V4.1 Flash-1017.** Sonnet 5 остаётся контрольной моделью. Сопоставимое качество русской нарезки пока не доказано: исследование не включало вызовы моделей, пользовательские транскрипты или изменение приложения.

## Контекст и задача

После сравнения OpenRouter с Cloud.ru владелец попросил отдельный рой оценить DeepSeek как замену Sonnet 5 именно на этапе выбора фрагментов N5. Whisper и FFmpeg в этом решении не меняются. Выбор модели и выбор территории обработки данных — отдельные решения.

Фактический вход модели — сегменты русского транскрипта и длительность записи. Все слова и их таймкоды не передаются: границы выбранных клипов корректируются локальным кодом. Комментарий исторического прогона 88 минут оценивает сегменты примерно в 39 тысяч токенов; это оценка для прежнего прогона, а не измерение токенизации DeepSeek.

Ожидаются 3–8 самостоятельных непересекающихся клипов по 20–75 секунд, русские заголовки, три компонента оценки и объяснения. Допустимы 1–2 сильных клипа, если других нет; пустой результат не является успехом. Локальный код проверяет сумму оценок, диапазоны времени и корректирует границы. Таймаут выбора — 240 секунд.

Это нельзя автоматически переносить на OpenRouter, где существуют отдельные датированные версии, включая Pro-0423. [Официальные версии](https://api-docs.deepseek.com/quick_start/pricing/), [изменения](https://api-docs.deepseek.com/updates/).

## Стоимость только выбора фрагментов

Пример: **30 000 входных токенов без кеша и 2 000 оплачиваемых выходных токенов**. Объёмы условные. Реальная токенизация, reasoning и повторные вызовы могут менять счёт. Курс расчёта — 80,5381 ₽/$; комиссии оплаты OpenRouter исключены, Cloud.ru указан с НДС 22%.

| Маршрут | Вход / выход за 1 млн токенов | Цена примера |
|---|---|---:|
| Sonnet 5 / OpenRouter | $2 / $10 | 6,4430 ₽ |
| Flash-1017 / OpenRouter, **DeepInfra standard FP8** | $0,098 / $0,294 | **0,2841 ₽**, на 95,59% дешевле |
| Pro-0813 / OpenRouter, **DeepInfra standard FP8** | $1,3 / $2,6 | 3,5598 ₽, примерно на 44,75% дешевле |
| Cloud.ru: партнёрская V4.1 Flash, точный snapshot неизвестен | 64,9406 ₽ / 194,8096 ₽ | 2,3378 ₽, примерно на 63,72% дешевле |
| Cloud.ru: локальная V4 Pro, дневной тариф, snapshot неизвестен | 183 ₽ / 732 ₽ | 6,9540 ₽, примерно на 7,93% дороже |

Выбранный исполнитель и FP8 — часть конфигурации, для которой требуется проверка качества. Наличие тарифа не подтверждает доступ в конкретном аккаунте. Партнёрская позиция Cloud.ru не подтверждает исполнение в РФ. Полная матрица, ночная акция и публичные снимки API: [pricing.md](pricing.md), [pricing-sources.json](pricing-sources.json).

При исследовании заголовочная цена страницы OpenRouter расходилась с живым API. Расчёт выше привязан к полной паре цен выбранного endpoint, а не к раздельным минимумам. [Public models API](https://openrouter.ai/api/v1/models), [Flash endpoints](https://openrouter.ai/api/v1/models/deepseek/deepseek-v4.1-flash-1017/endpoints), [тариф Cloud.ru](https://cloud.ru/documents/tariffs/evolution/foundation-models).

Экономия этого этапа не равна экономии всего продукта: распознавание речи, рендер и хранение остаются.

## Зачем нужна JSON-схема и что проверяет N5

Текущий запрос просит `json_schema` с `strict: true`. Дополнительно собственный код парсит ответ и проверяет структуру, типы, обязательные поля и ограничения фрагментов. Непарсящийся JSON или неверная структура вызывают `schema_violation`. Отдельные кандидаты с неверной длительностью, оценкой или пустым объяснением отбрасываются; годные фрагменты могут остаться. Это не полная универсальная JSON Schema валидация: часть ограничений реализована прикладными проверками, массив ограничивается при выборе принятых кандидатов.

Эта защита не гарантирует, что модель никогда не ошибается, и не доказывает нулевого числа ошибок в эксплуатации. Качество выбора и сохранение смысла не обеспечиваются одной схемой.

**Строгая схема у провайдера — полезный механизм надёжности, но не единственно возможная архитектура.** Можно принимать JSON object, сохранив локальные проверки. Это отдельное изменение текущего адаптера: нужно измерить частоту отклонений, задержку и стоимость. Нельзя принимать невалидные результаты или автоматически добавлять платные повторные вызовы ради совместимости.

В публичных метаданных OpenRouter исполнитель DeepInfra для Flash-1017 декларирует `structured_outputs`; DeepSeek для той же модели имеет `response_format`, но без этого флага. Точная схема N5 и конкретный маршрут требуют испытания. Direct Responses API документирует JSON Schema, Chat Completions — JSON mode, beta strict tools — подмножество схемы; это разные интерфейсы. [JSON mode](https://api-docs.deepseek.com/guides/json_mode/), [strict tools](https://api-docs.deepseek.com/guides/tool_calls/), [Responses](https://api-docs.deepseek.com/api/create-response/).

## Что потребуется для перехода

Сейчас allowlist N5 допускает Sonnet 5 и Gemini 3.8; provider pins также ограничены. Одной смены env недостаточно. Для будущей реализации нужны адаптированные настройки, явные ограничения reasoning/output, учёт usage и выбранный режим проверки JSON. Квоты, fencing, таймаут 240 секунд и отсутствие слепых повторов сохраняются.

Предложен ограниченный слепой A/B: восемь разнотипных записей, одинаковые сегменты для Sonnet 5 и Flash-1017, четыре дополнительных повтора — всего не более двадцати вызовов. Бюджет до $5 является предложением, а не разрешением расходов. Используются только записи, разрешённые к передаче выбранным провайдерам.

Два редактора оценивают самостоятельность начала и конца, сохранение смысла, заголовки, разнообразие и полезность, не зная модель. Отдельно измеряются JSON-ошибки, принятые кандидаты, таймкоды, выполнение инструкций, задержка и оплачиваемые токены. Оценки самой модели не заменяют человеческие. Такой малый пилот не доказывает production p95 или статистическое равенство. [Полный план и критерии](task-fit.md).
