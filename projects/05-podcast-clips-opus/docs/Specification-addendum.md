## FR-RENDER-004 · Кадр показывает человека, а не пространство между людьми

**Уточняет** FR-RENDER-001 («кроп 9:16»). Решение — ADR-009.

**Источник:** владелец на живых клипах 23.09.2026: «видеоряд ни о чём, в некоторых случаях просто
стена: сидят 2 человека, а показан не кто-то один из них, а пространство посередине».

```gherkin
Scenario: кадр следует за лицом
  Given запись с участниками, которых камера показывает по очереди
  When рендерится клип
  Then в каждом кадре клипа присутствует лицо участника
  And при смене плана камеры вырез переезжает на показанного участника не позже чем через 1,5 с

Scenario: два этажа — только если на обоих люди
  Given в клипе два участника
  When один из них присутствует меньше чем в 90 % замеров
  Then два этажа не строятся
  And показывается крупным планом тот, кто чаще в кадре

Scenario: без информации о лицах этажей нет
  Given детектор лиц недоступен или лиц не нашёл
  Then применяется центральный кроп
  And рендер клипа не прерывается
```

**Приёмка:** прогон детектора по готовым клипам даёт ноль кадров без лица (измерено: 384 с, семь
клипов, ноль).

## FR-RENDER-005 · Субтитры читаются и не мигают

**Уточняет** FR-RENDER-001 («вшитые субтитры»).

**Источник:** владелец 23.09.2026: «моргает транскрипт», «увеличь кегль и обводку».

```gherkin
Scenario: подпись не мигает между словами
  Given между словами пауза короче 1 с
  Then подпись остаётся на экране, переезжает только подсветка активного слова

Scenario: подпись не висит после речи
  Given речь закончилась
  Then подпись исчезает не позже чем через 1 с после последнего слова

Scenario: строка помещается в безопасную область
  Given строка из 24 знаков
  Then её ширина не больше 972 px при кегле 86
```

Числа: кегль 86, обводка 5, тень 1, перенос 24 знака, не больше двух строк, подъём от низа 500.
Перенос **измерен** отрисовкой (36,2 px на знак), а не выведен.

## FR-RENDER-006 · Английские названия пишутся латиницей

**Источник:** владелец 23.09.2026: «плохо, особенно когда английские слова обозначаются русскими
буквами»; в записи «Велоклауд» и «Виллоклауд» — одно и то же название.

```gherkin
Scenario: термин из словаря
  Given распознаватель вернул «Велоклауд»
  Then в субтитрах показано «VeloCloud»
  And сохранённая расшифровка не изменена
  And замена записана в журнал событием glossary_applied
```

Словарь курируемый: встроенный + `N5_GLOSSARY`. Автоматическая транслитерация **не делается**:
замена — правка сказанного человеком. Подсказка словаря модели распознавания проверена и у
исполнителя Together не работает.

## FR-TRANSCRIBE-003 · Погрешность таймкодов не отвергает запись

**Уточняет** ADR-003. Решение — ADR-010.

**Источник:** запись на 88 минут отвергнута трижды подряд строгими проверками таймкодов.

```gherkin
Scenario: слово начинается раньше предыдущего
  Given откат начала слова на 0,26 с
  Then начало поджимается к предыдущему слову, расшифровка принимается

Scenario: сегмент длиннее куска на доли микросекунд
  Given конец сегмента превышает длительность на 0,0000205 с
  Then конец поджимается к длительности, расшифровка принимается

Scenario: таймкодов нет
  Then расшифровка отвергается, как требует ADR-003
```

## FR-SELECT-003 · Негодный кандидат отбрасывается один

**Уточняет** FR-SELECT-001 (выбор 3–8 фрагментов).

**Источник:** запись на 88 минут: модель нашла семь годных фрагментов, один негодный отбросил все,
и владелец видел «самодостаточных фрагментов не найдено».

```gherkin
Scenario: один из восьми вне диапазона
  Given восемь кандидатов, один с длиной 76 с
  Then сохраняются семь
  And база повторно проверяет набор и не принимает неотсеянный
```

## FR-SELECT-004 · Модели уходят сегменты, а не каждое слово

**Источник:** замер 23.09.2026 — весь список слов 88-минутной записи весил 1128 КБ (≈ 385 тысяч
токенов), сегменты — 115 КБ. Модель вернула пустой список.

**Требование:** сообщение модели выбора фрагментов содержит язык и сегменты, но не слова. Границы
выбранных фрагментов двигаются к ближайшему слову нашим кодом (требование ADR-003 сохраняется).
Измеримо: на расшифровке в 12 916 слов сообщение меньше 200 000 байт (измерено 153 412).

## FR-RESULT-004 · Кнопка повтора не гаснет по прогнозу

**Источник:** владелец 23.09.2026: после подъёма потолка кнопка «Повторить» оставалась серой до
полуночи — экран гасил её по прогнозу обновления квоты, не заглядывая в счётчик.

**Требование:** кнопка доступна всегда, когда повтор законен; решение о квоте принимает сервер и
отвечает отказом с причиной, если места нет.

## NFR-CFG-001 · Непригодная конфигурация валит старт каждого платящего процесса

**Уточняет** V2-R06 / DEC-A-010. Находки SL-003, SL-007.

**Требование:** адрес, не помещающийся в метку, валит старт `web`, `worker-stt`, `worker-llm` и
`worker-video` — всех, кто тратит деньги, а не только тех, кому адрес нужен функционально. Иначе
платящие стадии разбирают очередь и оплачивают клипы, которые нельзя отрендерить.

## NFR-PERF-001 · Измерение

Требование «часовая запись за 20 минут p95» впервые измерено 23.09.2026: 88,4 минуты обработаны за
12 мин 39 с, в пересчёте на час ≈ 8,6 минуты. Одна точка; p95 не установлен.
`docs/measurements/2026-09-23-first-long-recording.md`.

## FR-RENDER-007 · Фоновая музыка по выбору при загрузке

При загрузке можно отметить «Добавить фоновую музыку» (по умолчанию выключено). Тогда каждый клип
записи получает подложку из закрытого каталога CC0-треков на 18 LU ниже громкости речи ЭТОГО клипа
(полоса 300–3400 Гц), без приглушения под речью. Трек из каталога 11 CC0-треков выбирается по
номеру клипа в записи (`(index − 1) mod 11`), поэтому клипы одной записи звучат по-разному. Сбой замера даёт клип без музыки, а не отказ.
Выключенная галочка оставляет рендер побайтово прежним. ADR-011, OWN-009.

## FR-SELECT-005 · Таймаут выделения по измерению длинной записи

Вызов выделения ограничен **240 с** (было 120 с). Измерено на записи 88 мин: 1:45 (23.09) и > 2:00
(24.09, оборвано). Верхняя граница — окно молчания 5 минут из `long-job-contract.md`: дольше экран
прогресса покажет «нет ответа» при живом вызове.

## FR-RENDER-008 · Финальный акцент (пэк-шот)

Если в клип смешана фоновая музыка (FR-RENDER-007), на последних 0,8 с звучит CC0-удар на
`STINGER_MARGIN_LU` ниже громкости речи (полная полоса, пиковый потолок −3 dBTP относительно пика
сэмпла) и кадр вспыхивает без текста; метка остаётся читаемой. Длительность клипа не меняется.
Сбой — клип с музыкой без пэк-шота. ADR-012.

## FR-RENDER-009 · Заголовок в начале клипа

При загрузке отмечено «Заголовок в начале клипа» (по умолчанию да) — каждый клип первые 2,5 с
показывает свой заголовок крупно (до 3 строк) в верхней трети кадра на полупрозрачной подложке.
Заголовок не является цитатой и кавычек не имеет. Сбой разметки — клип без заголовка. ADR-013.

## FR-PARTNER-004 · Блокировка кода считает людей и снимается оператором

Код блокируется, когда 50 РАЗЛИЧНЫХ аккаунтов применили его с одной подсети за 10 минут. Оператор
снимает блокировку командой с причиной; партнёр видит в кабинете дату и причину. ADR-014.

## FR-PARTNER-005 · Атрибуция переживает удаление партнёра

Удаление аккаунта-партнёра не удаляет атрибуции приглашённых им людей, а обезличивает их (статус
`partner_deleted`, без ссылки на партнёра); такой аккаунт нельзя привлечь повторно. ADR-014.
