# Независимое ревью фич 25–29 — Opus 5.5, 28.09.2026

Код фич 25–29 писал Opus 5.5 (другой агент), план и код проверял Sonnet 5 (OWN-017: OpenAI не используется).
Это второе, независимое ревью той же семьи моделей: **кросс-семейным оно не является** — хвост BACKLOG §5 п. 20
остаётся открытым до ревью моделью OpenAI.

База: `1f1edb48` (основная ветка). Код не правился. Квитанции `07_*`, `05_completion`, `08_review` прочитаны как
заявления и сверены с кодом. Проверки ревьюера:

- unit-тесты фич без БД в контейнере `mcr.microsoft.com/playwright:v1.60.0-noble` (11 файлов: theme, clip-card,
  clip-cta, clip-cta-render, clip-cta-worker, landing-demo, progress-screen, responsive-check, enums, short-link,
  retention) — `Test Files 11 passed (11)`, `Tests 198 passed (198)`;
- 8 собственных мутаций, файл восстанавливался после каждой: 7 пойманы, 1 не поймана unit-набором (фильтр срока в
  `setCta`: ловит только интеграционный тест, и не всю ветку);
- стенд `https://clipmkr.ru`, только чтение: `GET /` (тема `dark`), `GET /api/showcase/CTDUUG/thumbnail` → `302`,
  `X-Amz-Expires=900`; `GET /api/showcase/ABCDEF/file` → `404`. `/c/` не открывался: его GET пишет просмотр.

## Топ-5 находок по важности

1. **medium — надпись призыва у платного клипа отсылает к несуществующей ссылке** (`cta-overlay.ts:30,63`,
   `ffmpeg.ts:66`, `cta.ts:13-15`). Сейчас платных аккаунтов нет, но оплату делают параллельно: в момент её
   включения каждый платный клип с призывом получит в пиксели «Подписывайтесь — ссылка ниже» без метки с `/c/КОД`.
   Правится только пересборкой. Не записано ни в ADR-017, ни в BACKLOG.
2. **low — срок бесплатного клипа продублирован в шести местах** (`screen.ts:105`, `clip-file.ts:40`,
   `clip-music.ts:29`, `video-cta.ts:47-48`, `short-link.ts:61-62`, `retention.ts:90`), исключение витрины — в двух.
   Следствие уже сейчас: смена призыва/музыки у записи витрины молча не пересобирает клип лендинга.
3. **low — ветка «срок = `finished_at` + 3 сут» в `setCta` без теста** (`clip-cta-rerender.integration.test.ts:33`
   ставит `finished_at = now`); регресс, пересобирающий стёртые клипы за квоту, пройдёт зелёным.
4. **low — страж цвета фичи 25 даёт ложное срабатывание на `white-space`** (`theme.test.ts:44`) и уже заставил
   убрать `white-space:nowrap` из `.visually-hidden` (`globals.css:190`) — ослаблена доступность скрытого текста
   ленты стадий вместо починки стража.
5. **low — критерий раннера мутаций прогресса — только код возврата** (`test-progress-mutations.mjs:37`): падение
   запуска засчитывается как «мутация убита». Тот же дефект копирования репортёра остался в
   `tests/run-render-fix-mutations.mjs:9-12` (там критерий строгий, отказ будет громким).

## Что чинить первым

1. Находку 1 — **до включения оплаты**: у `paid` не рисовать надпись (или отдельный словарь без «ссылка ниже») плюс
   тест пары «paid + призыв»; записать в ADR-017. Стоит одну строку и один тест, а ошибка в пикселях необратима.
2. Находку 2 — одна функция `clipExpiresAt(row)` в `packages/shared` с исключением витрины, шесть мест на неё;
   страж по исходнику «формула `+ 3 * 86400_000` встречается ровно в одном файле». Закрывает и находку 3 тестом этой
   функции без БД.
3. Находки 4–5 — починить сами стражи (регэксп цвета с границей `-`; критерий «убита» = `failed > 0`), вернуть
   `white-space:nowrap`.
