## DEC-A-022 · Распознавание речи — `whisper-large-v3` через OpenRouter, поставщик Together закреплён

**Дата:** 22.09.2026. **Статус:** принято координатором по прямому поручению владельца
(«я сделаю и ты протестируешь и сделаешь выбор»).

**Что меняется в канонe §6 и §7.** Было: `OpenAI whisper-1`, ключ `OPENAI_API_KEY` у `worker-stt`.
Стало: `openai/whisper-large-v3` через OpenRouter, ключ `OPENROUTER_API_KEY`, поставщик закреплён
`Together` без права отката.

**Основание — измерение, а не прайс-лист** (`docs/proposals/openrouter-probe-results.md`,
прогон 22.09.2026, стоимость $0,0458):

- Таймкоды слов приходят: 12 слов из 12 с `start` и `end`, русский распознан верно. Требование
  ADR-003 выполняется — это проверялось первым, потому что без слов нарезка невозможна в принципе.
- Тайминги Together и Groq совпали **побайтово**: это одна модель у двух хостеров, выбор между ними
  ценовой, а не качественный.
- Цена за 90-минутную запись: Together $0,135 против $0,54 у `whisper-1`. **Вчетверо дешевле при
  доказанно том же результате по словам.**

**Что остаётся риском.** Проверено на 7,16 с синтетической речи. Часовой подкат с живой дикцией,
фоновой музыкой и чанкингом ≤ 25 МБ не проверялся — это делает сама фича 4 на настоящем файле.

**Обязательное условие, без которого решение недействительно.** Поставщик закрепляется явно:
`provider: { only: ['Together'], allow_fallbacks: false }`. Слова отдают только OpenAI-совместимые
хостеры; без закрепления OpenRouter выберет эндпоинт сам, и часть из них отвечает `400`. Отсутствие
закрепления в коде — дефект уровня blocker, а не стилистика.

**Форма запроса установлена ответом сервера, а не документацией:** поле называется `input_audio` и
является ОБЪЕКТОМ `{ data, format }`. Строка `audio` из документации даёт `400`.

**Откат.** Вернуться на прямой `whisper-1` — смена значения в конфигурации и ключа у `worker-stt`;
код адаптера при соблюдении границы поставщика не меняется. Цена отката — четырёхкратный рост
расхода на распознавание.

# Автономная сессия 24.09.2026 (план на 12 часов, `docs/plans/2026-09-24-12h-autonomous.md`)

## A-2409-01 · Выбор трека из библиотеки — по номеру клипа
**Вопрос:** как выбирать трек из нескольких. **Выбор:** `index mod N` по номеру клипа в записи.
**Почему:** детерминированно (повтор рендера — тот же трек), клипы одной записи звучат по-разному,
модель не судит собственный вывод (proposal music-and-stinger §5.1). **Откат:** каталог из одного
трека возвращает прежнее поведение.

## A-2409-02 · Окно приманки включено по умолчанию для новых загрузок
**Вопрос:** включать ли приманку всем. **Выбор:** своя галочка, по умолчанию включена; прежние
записи не меняются. **Почему:** текст — дословная цитата самого клипа, правовая поверхность не
растёт; польза для удержания в первые секунды. **Откат:** default false в миграции и в интерфейсе.

## A-2409-03 · Прогон REPRODUCE на этой же машине
**Вопрос:** где проверять воспроизводимость. **Выбор:** изолированный стек `n5-repro` на этой
машине, без публикации наружу. **Почему:** другой машины нет; изоляция по имени проекта, сети и
базе. **Откат:** `docker compose -p n5-repro down -v` и удаление его образов.

## A-2409-04 · Текст окна приманки — заголовок клипа, а не дословная цитата
**Вопрос:** что показывать крупным текстом в первые секунды. **Выбор:** `clip.title` — заголовок,
который модель уже пишет для каждого фрагмента и который владелец видит в интерфейсе; подаётся
как ЗАГОЛОВОК, без кавычек. **Почему:** не меняет схему ответа модели и не требует платного
повторного выделения; уже загруженные записи получают приманку простым перерендером. Отступление от
proposal hook-music-cta §1.1 («только дословная строка транскрипта») названо: заголовок пишет модель
по содержанию фрагмента, это заголовок, а не цитата, поэтому кавычки запрещены. **Откат:** галочка
«Заголовок в начале клипа» выключается; вариант с дословной цитатой — поле ответа модели + миграция.

## A-2409-05 · Приманка — своя галочка, по умолчанию включена для новых загрузок
Колонка `video.teaser boolean NOT NULL DEFAULT false` (прежние записи — без приманки), галочка в
интерфейсе отмечена по умолчанию. **Откат:** снять отметку по умолчанию.

## A-2409-06 · RT-008 — граница исключения самоперехода объявлена в ADR-007
Исключение работает для опознанной сессии; отпечатки браузера и связывание по адресу не
добавляются. Только запись, кода нет. **Откат:** удалить абзац из ADR-007.

## A-2409-07 · RT-010 — окно 900 с у превью на лендинге принято явно
Отзыв короткой ссылки не отзывает уже выданную подписанную ссылку на ПРЕВЬЮ (картинку, не файл
клипа) до 15 минут. Проксирование превью с повторной проверкой отзыва не строится: цена несоразмерна
картинке. Путь к самому файлу клипа по-прежнему ровно два (сессия владельца, гостевой код).
**Откат:** проксировать превью через `web` с проверкой статуса ссылки.

## A-2409-08 · OWN-008 — риск нескольких бесплатных аккаунтов принят ВРЕМЕННО
Суточный расход держит глобальный потолок. Ключ квоты по подсети не вводится (бьёт по людям за
одним адресом). Подтверждение почты — обязательное условие до первого реального пользователя,
вместе с переносом БД в РФ (OWN-006). **Требует подтверждения владельца**; это решение не отменяет
его права выбрать иначе. **Откат:** ничего не построено — откатывать нечего.
