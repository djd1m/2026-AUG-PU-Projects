# Канон Phase 1 — «КлипМейкер» (N5, клон Opus Clip)

Замороженный источник имён для всех документов Phase 1. Любой документ ссылается на эти
идентификаторы, не выдумывает свои. Дата заморозки: 2026-09-21. Владелец канона — координатор.
**Разморозка на Phase 2 (DEC-A-010, 2026-09-21):** по находкам валидации изменены §4 (пятый scope
`user_llm`), §5 (регистрация и отзыв гостевой страницы), §6 (`N5_PUBLIC_ORIGIN`), §7 (минуты на
аккаунт 90; измерение длительности в `worker-stt`). Хеш перепривязан в `dispatch-plan.md`.

## 1. Продукт и границы

- **Имя:** «КлипМейкер» (рабочее, унаследовано от январского клона; доступность не проверялась).
  **Клиент:** веб-приложение (Next.js) на своём домене, мобильная вёрстка обязательна.
  **Контур:** Россия/СНГ, интерфейс русский, площадки публикации — VK Клипы, Telegram, Rutube, Дзен
  (публикует пользователь вручную). **CJM:** D = путь A + блок «клипы для гостя» (B-лайт)
  ([`CJM_Variants.md`](CJM_Variants.md), решение владельца 2026-09-21).
- **Референсная кодовая база:** `djd1m/2026-jan-pu-opus-clone` (Next.js 15 + tRPC, Prisma +
  PostgreSQL 16, BullMQ/Redis, ffmpeg 7, `@clipmaker/s3`, ЮKassa). Берётся конвейер и оплата
  (спящая); механик роста в клоне нет.
- **Входит (неделя):** загрузка видео до 2 ГБ → транскрипция с таймкодами слов → выделение
  3–8 самодостаточных фрагментов → кроп 9:16 с вшитыми субтитрами → оценка потенциала с
  объяснением (три компонента) → экран клипов: плеер, скачать, короткая ссылка → метка на free с
  короткой ссылкой → «клипы для гостя»: галочки, согласие, гостевая страница без входа → код
  блогера при регистрации, кабинет партнёра со счётчиками → потолки минут и загрузок → экран
  интереса «Pro скоро» → срок хранения клипов на free.
- **НЕ входит:** автопостинг, brand kit, командная работа, распознавание лиц и авто-фрейминг,
  диаризация и сортировка по спикерам, бонусные минуты за гостя и связанный анти-фрод, приём
  денег (ЮKassa из клона — спящий код, вторая волна), выплаты партнёрам, экспорт в NLE,
  AI B-roll, дубляж, шоуноты и посты как публичная страница (текстовые шоуноты — Could).

## 4. Сущности (ровно 15) — логическая модель, физика в Architecture

`account` · `session` · `video` · `transcript` · `clip` · `clip_link` · `guest_pack` ·
`guest_pack_clip` · `growth_event` · `partner` · `partner_code` · `attribution` · `quota_counter` ·
`pro_interest` · `job_attempt`. Каждая: `id: UUID`, `created_at: Timestamp`.

Закрытые перечисления:
- `account.plan` — ровно 2: `free | paid`; всё, что не ровно `paid`, читается как `free`.
- `account.status` — ровно 3: `active | erasing | deleted`.
- `video.source` — ровно 2: `upload | url`.
- `video.status` — ровно 7: `uploading | queued | transcribing | selecting | rendering | done | failed`;
  на экране пользователя это ТРИ состояния: `выполняется` (uploading…rendering), `успех` (done),
  `отказ` (failed) с причиной и кнопкой «повторить».
- `clip.status` — ровно 4: `queued | rendering | done | failed`.
- `job_attempt.stage` — ровно 3: `stt | select | render`; `job_attempt.fence` — монотонный
  счётчик на видео; результат принимается только с актуальным fence.
- `growth_event.type` — ровно 8: `download | link_copy | link_view | guest_sent | guest_opened |
  guest_registered | code_applied | interest`.
- `attribution.source` — ровно 3: `explicit | guest_link | cookie`; `attribution.status` — ровно 4:
  `pending | activated | rejected | partner_deleted` (последний — терминальный, 24.09.2026, RT-009); `replaced_source` — то же множество или null.
- `partner_code.status` — ровно 2: `active | blocked`.
- `quota_counter.scope` — ровно 6: `user_minutes | user_uploads | user_upload_refunds | user_llm | global_minutes | global_llm`.
  `UNIQUE (scope, scope_key, day)`; предел — параметр из окружения, не колонка; списание атомарно:
  `INSERT … (used = 0) ON CONFLICT DO NOTHING`, затем `UPDATE … SET used = used + :n WHERE used + :n
  <= :limit RETURNING used` в одной транзакции — пустой результат и есть отказ (V2-R01/R03).

Переиспользование моделей клона (Prisma): `User→account`, `Video→video`, `Transcript→transcript`,
`Clip→clip`, `UsageRecord→growth_event/quota` (адаптация), `Subscription/Payment/Team/TeamInvite/
PlatformConnection/Publication` — спящие, не удаляются и не расширяются.

## 5. Маршруты (ровно 10 публичных путей) и процедуры tRPC (ровно 15)

Публичные пути (route handlers, без tRPC): `GET /health` · `GET /c/{code}` (лендинг с атрибуцией
и счётчиком перехода) · `GET /g/{guest_code}` (гостевая страница, `noindex`, без входа) ·

multipart сервером: `CompleteMultipartUpload`, `HEAD` размера, тип по первым байтам через Range-GET;

`POST /api/auth/login` · `POST /api/auth/logout` · `POST /api/auth/telegram` (Should).

Процедуры tRPC: `video.create` (заголовок `Idempotency-Key`, ответ `video_id` + подписанные
ссылки) · `video.get` · `video.list` · `video.retry` · `clip.list` · `clip.get` · `clip.markDownloaded` ·

`partner.dashboard` · `interest.create` · `account.delete`.

## 6. Сервисы compose (ровно 7 в боевом профиле, +1 в тестовом) и стек

`web` (Next.js 15, App Router, tRPC, SSR; единственный, кто подписывает ссылки для браузера; без
ffmpeg/ffprobe) · `worker-stt` (первый шаг стадии — `probe`: скачивает оригинал, `ffprobe`
длительности и звуковой дорожки, списание минут ДО первого вызова Whisper) · `worker-llm` ·
`worker-video` (три контейнера из одного образа воркера, каждый
слушает свою очередь BullMQ; `worker-video` — единственный с ffmpeg и рабочим каталогом на томе) ·
`db` (PostgreSQL 16) · `redis` (Redis 7, AOF на томе, `maxmemory-policy noeviction`, пароль без
дефолта) · `proxy` (Caddy, единственная публичная дверь, TLS, лимит частоты). Тестовый профиль
добавляет `minio` (тот же S3-код офлайн) и `test`. Хранилища без публикации портов; хостовые порты
только `${VAR:-default}`; секреты `${VAR:?…}`.
Файлы: **Cloud.ru Object Storage** (S3, регион `ru-central-1`) в боевом профиле — решение владельца
OWN-004; в тестах — MinIO. Модели — **как собрано** (правка 24.09.2026; прежняя запись называла
`whisper-1` и два отдельных ключа OpenAI/Anthropic и в код не попала): весь вывод моделей идёт через
ОДИН шлюз **OpenRouter** с одним ключом `OPENROUTER_API_KEY`. Расшифровка —
**`openai/whisper-large-v3`**, исполнитель закреплён за Together, `verbose_json`, таймкоды слов и
сегментов (DEC-A-022). Выделение — **`anthropic/claude-sonnet-5`** (`N5_LLM_MODEL`; вторая допустимая
— `google/gemini-3.8-flash`), исполнитель закреплён за Anthropic / Claude Platform on AWS,
`json_schema strict`, `require_parameters`. Локальных моделей нет. Ключи: `OPENROUTER_API_KEY`
только у `worker-stt` и `worker-llm`; `S3_ACCESS_KEY/S3_SECRET_KEY` у `web`, `worker-stt`,
`worker-video`; у `proxy` и `db` — ничего. Рендер — ffmpeg 8.1 + libass + OpenCV 4.12 (детектор лиц
YuNet, ADR-009).
**`N5_PUBLIC_ORIGIN`** — публичный origin продукта (`https://<домен>`), объявлен `${N5_PUBLIC_ORIGIN:?}`
БЕЗ значения по умолчанию у **всех четырёх** процессов (`web`, `worker-stt`, `worker-llm`,
`worker-video`, SL-007): он вшивается в пиксели метки и определяет каждую выдаваемую наружу ссылку;
отсутствие, непригодное значение или адрес, не помещающийся в метку, валят запуск
(`silent-fallbacks.md`, DEC-A-010, SL-003).

## 7. Числа канона

| Параметр | Значение |
|---|---|
| Порядок слов STT (TR-010) | Порядок слов НЕ является поводом для отказа: любой откат назад поджимается (`start` к предыдущему, `end ≥ start`), каждое исправление журналируется событием `stt_word_order_clamped`. Конечные числовые границы поджимаются в `[0, duration]` с `end ≥ start` и событием `stt_timing_clamped`; начало целиком за пределами (`start > duration`), отсутствующие и нечисловые/нефинитные таймкоды отвергаются. Решение владельца 23.09.2026 после того, как три подряд подобранных порога (строгая монотонность, 0,5 с, 10 % слов) трижды отвергли настоящую запись на 88 минут |
| Размер файла | ≤ 2 000 000 000 байт; тип по байтам (MP4/MOV/WebM/M4A/MP3) |
| Длительность записи | 2–90 мин; измеряется `ffprobe` в `worker-stt` после скачивания, ДО списания минут и ДО Whisper; `user_uploads` списан на создании; ВОЗВРАЩАЕТСЯ при отказе по свойствам файла (`too_large`, `not_media`, `no_audio`, `too_short`, `too_long`, `probe_timeout`) и НЕ возвращается при отказе по потолкам (`refused_*`) — DEC-A-014; возвратов не больше 2 в сутки на аккаунт (`user_upload_refunds`, DEC-A-015): иначе заведомо негодные файлы бесплатно занимают `worker-stt` |

| Суточный потолок минут (все аккаунты) | 600 |
| Суточный потолок вызовов LLM | 20 (один вызов выделения на запись, повтор считается); на аккаунт — 2 (`user_llm`) |
| Одновременных тяжёлых задач (рендер) | 1 на VPS |
| Клипов на запись | 3–8; длина клипа 20–75 с |
| Кадрирование (ADR-009, 23.09.2026; заменяет FR-1 «две панели по половинам») | 1080×1920. Кадр **следует за лицом**: детектор YuNet (OpenCV) раз в **0,5 с**; ведущее лицо — самое крупное из прошедших порог размера; порог = **0,4 × медиана ширины лиц этого клипа**, не ниже **0,03** кадра. Окно одиночного плана — вся высота исходника, ширина по 9:16; лицо в верхней **0,34** окна. Новый план — не чаще **1,5 с** и при сдвиге ≥ **0,06** ширины; **2** замера подряд без лица терпимы, дольше — окно в медиану найденных лиц (не в центр). Два этажа 1080×960 — только если обе группы лиц есть в ≥ **0,9** замеров и разнесены ≥ **0,15** ширины; одиночный крупный план — если самая частая группа есть в ≥ **0,5**. Нет плана (детектор недоступен) или лиц не найдено — центральный кроп. Отказ детектора рендер не валит. ASS после сборки; метка последняя. |

Трек — закрытый каталог **9** CC0-треков, каждый прослушан владельцем: Komiku «Everything is groovy» + 8 треков HoliznaCC0 (OWN-013, OWN-014); выбор `(clip.index − 1) mod 9`.
