# 05. Нарезка вирусных клипов из подкаста

> **Неделя 05** · `видео` · референс: **[OpusClip](https://www.opus.pro/) — 10M+ пользователей, ~$20M ARR**

## Простыми словами

**Проблема.** Вы записали часовой подкаст или вебинар. Внутри есть пять сильных мыслей, но целый
час никто смотреть не станет. Нарезать вручную — это вечер работы с монтажной программой.

**Что делает продукт.** Загружаете длинное видео. Система расшифровывает речь, находит куски,
которые звучат законченно и цепляюще, и нарезает их в короткие вертикальные ролики с субтитрами —
готовые к публикации. И подсказывает, у какого куска больше шансов зайти, объясняя почему.

**Зачем это людям.** Одна запись превращается в десяток коротких видео на неделю вперёд. Это
разница между «выкладываю раз в месяц» и «выкладываю через день».

**Как этим пользуются.** Записали эфир → загрузили → получили набор клипов → выбрали лучшие →
опубликовали. Час работы вместо вечера.

## Что делаем

Аналог Opus Clip: авто-нарезка длинного видео на клипы, Virality Score, 40+ ассетов из одной записи — клипы, шоуноты, посты.

**Целевой стек:** Whisper + ffmpeg в контейнере-воркере, Claude через MCP
