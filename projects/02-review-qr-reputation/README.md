# 02. Умный QR для отзывов о компании

> **Неделя 02** · `репутация` · референс: **категория review management — [NiceJob](https://nicejob.com/), [Birdeye](https://www.birdeye.com/), [Podium](https://www.podium.com/) (единого оригинала нет)**

## Что делаем

QR/ссылка ведёт на страницу оценки: позитив уходит на Яндекс.Карты и другие площадки, негатив перехватывается до публикации и уходит владельцу. Единый виджет со ссылками на все площадки, генератор QR, приём оплаты.

**Целевой стек:** роутинг по оценке, генератор QR, приём оплаты

## Механики роста (обязательный блок)

Главный продукт — не прототип, а **рост**: аудитория и выручка. В требования закладываем на этапе дизайна, а не после.

| Драйвер | Гипотеза для этого проекта |
|---|---|
| **Виральность** | Физический QR в офлайне = виральный носитель: каждый стол/чек/упаковка показывает продукт новым людям. Страница оценки брендируется и несёт ссылку на сервис. |
| **Партнёрка** | _заполняется по итогам `/research/GROWTH-MECHANICS-REQUIREMENTS.md`_ |
| **Блогеры / люди с аудиторией** | _заполняется по итогам `/research/GROWTH-MECHANICS-REQUIREMENTS.md`_ |

> Обязательный блок требований по росту: [`/research/GROWTH-MECHANICS-REQUIREMENTS.md`](../../research/GROWTH-MECHANICS-REQUIREMENTS.md)
