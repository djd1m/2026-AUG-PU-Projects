# Дизайн-система референсов: измеренные значения

Вынесено из [`01-original-walkthrough.md`](01-original-walkthrough.md) — там был превышен лимит
репозитория в 500 строк. Метод съёмки, оговорки и вердикт «почему NiceJob» — в основном файле.

Все значения получены через `getComputedStyle` в контексте страницы и чтением CSS custom
properties из `document.styleSheets`. Ни одно не взято на глаз. Дата съёмки: 2026-09-01.


### 1. NiceJob — палитра `[СНЯТО С САЙТА]`

Значения — из CSS custom properties на `:root` (`get.nicejob.com/pricing`) и из `getComputedStyle`.

| Токен | Hex | Где применяется (измерено) |
|---|---|---|
| `--color-blue-600` / `--color-electron-blue`→500 | **`#025bde`** | Заливка всех первичных кнопок (`button--primary`, `button--secondary`) |
| `--color-blue-500` | `#1874fd` | Цвет текстовых ссылок (188 текстовых узлов) |
| `--color-blue-900` / `--color-neutron-blue` | `#061e42` | Кнопка `button--tertiary`, тёмные плашки |
| `--color-blue-950` | `#00132e` | Цвет заголовков h2/h3 на светлом фоне |
| `--color-blue-50` | `#f5f9ff` | Фон чередующихся светлых секций (2-й по площади) |
| `--color-blue-100` | `#e1edff` | Фон мягких плашек/бейджей |
| `--color-gray-500` | `#364459` | **Основной цвет текста** (`body color`) |
| — | `#130a38` | **Фон тёмного героя** (тёмно-фиолетовый, 3-й по площади) |
| `--color-green-500` / `--color-atomic-green` | **`#2ce080`** | Акцент: выделенное слово в H1, бейдж «Most Popular», галочки списков |
| `--color-purple-500` | `#6f21ed` | Бейдж «14 days free», логотип-звезда |
| `--color-yellow-500` | `#ffcc00` | Звёзды рейтинга (156 узлов) |
| `--color-red-400` / `--color-fusion-red` | `#ff5851` | Ошибки/негатив |
| `--color-white` | `#ffffff` | Фон карточек и основных секций (1-й по площади) |

Полные шкалы 50…950 существуют для blue, green, yellow, red, purple — то есть система
рассчитана на переиспользование, а не на пять подобранных цветов.

### 2. NiceJob — типографика `[СНЯТО С САЙТА]`

Две семьи: **`--secondary-font-family: "Bogart", serif`** — все заголовки;
**`--primary-font-family: "Inter", sans-serif`** — весь остальной интерфейс и текст.

| Элемент | Семья | Размер | Вес | Межстрочный | Цвет |
|---|---|---|---|---|---|
| h1 (герой) | Bogart, serif | 56px | 600 | 64px (1.14) | `#ffffff` на тёмном |
| h2 | Bogart, serif | 40px | 600 | 48px (1.20) | `#00132e` |
| h3 | Bogart, serif | 20px | 600 | 36px (1.80) | `#00132e` |
| body / абзац | Inter, sans-serif | 16px | 400 | 24px (1.50) | `#364459` |
| Кнопка | Inter, sans-serif | 16px | 600 | 24px | по типу кнопки |
| Меню (header) | Inter, sans-serif | 16px | 400 | 24px | `#364459` |

`[ВЫВОД]` Приём, который стоит забрать: **гротеск для интерфейса, крупный контрастный serif для
заголовков**. Serif в SaaS для малого бизнеса читается как «сделано людьми, а не шаблоном» и
почти не встречается у конкурентов — Birdeye и Podium оба на гротесках.

### 3. NiceJob — геометрия, кнопки, контейнер `[СНЯТО С САЙТА]`

| Свойство | Значение |
|---|---|
| Ширина контейнера | `--max-content-width: 1200px` (подтверждено: `max-width:1200px` встречается 15 раз, доминирует) |
| Внутренний отступ контейнера | `--container-padding: 48px 24px` |
| Базовый зазор сетки | `--gap: 24px`; колоночный `--column-gap: 2.13%` |
| Радиус карточек | **16px** (`rounded-2xl`), рамка `1px solid #c1c1c1`, паддинг `24px`, тени нет |
| Радиус кнопок | **100px** — полная пилюля, у всех типов кнопок без исключения |
| Тень (единственная в системе) | `--elevation-one: 1px 1px 19px 0px #1874fd26` — синяя, 15% альфа |
| Высота шапки | 72px, фон `#ffffff` |
| Высота главной (1440px) | 7612px |
| Анимация | `--primary-animation-timing: ease-in-out` |

**Кнопки** — все `padding: 12px 24px`, `font: Inter 16px/600`, `border-radius: 100px`, высота 50px:

| Класс | Фон | Текст | Рамка | Где |
|---|---|---|---|---|
| `button--primary` | `#025bde` | `#ffffff` | `1px solid #025bde` | **Главный CTA «Start Free»** |
| `button--secondary` | `#025bde` | `#ffffff` | `1px solid #025bde` | Повторный CTA в секциях |
| `button--tertiary` | `#061e42` | `#ffffff` | `1px solid #061e42` | «Learn more» |
| `button--outline` | прозрачный | `#ffffff` | **`2px solid #ffffff`** | «Book a demo» на тёмном (высота 52px) |
| `button--white` | `#ffffff` | `#130a38` | `1px solid #ffffff` | CTA на цветном фоне |
| `button--link` | прозрачный | `#364459` | прозрачная | «Log In» |

**Главная кнопка целиком, для воспроизведения:**
`background:#025bde; color:#fff; border:1px solid #025bde; border-radius:100px; padding:12px 24px;
font:600 16px/24px Inter,sans-serif; height:50px;` — при подписи «Start Free» ширина 124px.

### 4. Birdeye и Podium — для сравнения `[СНЯТО С САЙТА]`

| Параметр | Birdeye | Podium |
|---|---|---|
| Шрифт (единственный) | `"Hanken Grotesk", sans-serif` — 1213 узлов из 1284 | `Graphik` в начертаниях Regular/Medium/Semibold + `Grenette` (serif) точечно |
| h1 | 52px / 500 / lh 57.2px / **letter-spacing −2.08px** | 52px (главная) и 72px (`/product/reviews`) / 500–600 / lh 1.10 |
| h2 | 32–36px / 400 | 36–46px / 500–600 |
| Body | 16px, lh `normal` | 16px / lh 24px |
| Основной текст | `#212121`, вторичный `#80878f` | `#1c1d18`, вторичный `#555c67` |
| Фон | `#ffffff`, вторичный `#f6f5f3` | **`#fafaf7`** (тёплый бежевый) — доминирует; тёмный `#18181c` в герое |
| Акцент | `#1976d2` (синий Material) | `#af4e30` (терракота) на выделенном тарифе |
| Радиус кнопок | **8px** на `/reviews`, **68px** на главной — система непоследовательна | **50px / 100px** пилюля |
| Радиус карточек | 20px, рамка `1px solid #dfdfdf`, фон `#edeeef` | **32px**, рамка `2px solid #e9e1d8`, выделенная — `2px solid #af4e30` на `#f7edea` |
| Кнопка (главная) | `#1976d2` / `#fff` / r 8px / `14px 30px` / 14px 500 | `#1c1d18` / `#fefefe` / r 100px / `12px 32px 14px` / 18px 600 |
| Контейнер | `1320px` (19 совпадений — устойчиво) | `1440px` / `1200px` — непоследовательно |
| Вертикальный ритм секций | `80px 0` и `100px 0` | `64px 80px` |

`[ВЫВОД]` Единственное, что стоит присмотреть у Podium — **тёплый небелый фон `#fafaf7`** вместо
чистого белого и крупные карточки радиусом 32px; выглядит менее «шаблонно», чем белый. У Birdeye
заимствовать нечего: радиусы кнопок различаются между страницами (8px против 68px) — система
рассогласована.
