## S3 — Площадки: диплинки и API

**Несущий раздел.** Без рабочей ссылки «оставить отзыв» продукта нет, а ситуация у трёх площадок разная —
обобщение здесь и есть источник дефекта.

| Площадка | Документированный диплинк на **форму отзыва** | Что реально доступно | API отзывов |
|---|---|---|---|
| **Google** | **ДА** | `https://g.page/r/<CID>/review` из GBP («Ask for reviews»); широко используется `https://search.google.com/local/writereview?placeid=<PLACE_ID>` | Places API (платный), `place_id` — единственное поле, которое можно хранить бессрочно |
| **Яндекс.Карты** | **НЕТ в документации** | QR + ссылка из Яндекс Бизнеса → «Промоматериалы»; ссылка на карточку/вкладку отзывов | **Нет официального API отзывов** |
| **2ГИС** | **НЕТ вовсе** | `https://2gis.ru/firm/{id}` (карточка) — единственный релевантный диплинк в документации; наклейки с QR заказываются в кабинете | Places API есть (поиск/карточка), API отзывов не документирован |

### S3.1 Google — единственная площадка, где всё честно документировано

GBP отдаёт короткую ссылку `g.page/r/XXXXXXX/review` через кнопку «Ask for reviews»; вторая
распространённая форма — `search.google.com/local/writereview?placeid=`
([Wiremo](https://wiremo.co/blog/how-to-get-your-google-review-link/),
[EmbedSocial](https://embedsocial.com/blog/google-review-link/)). `place_id` берётся программно через
Places API, и это **единственное поле, которое разрешено хранить бессрочно** — остальные данные Places
кэшировать нельзя
([Google](https://developers.google.com/maps/documentation/places/web-service/usage-and-billing));
тариф: IDs Only бесплатно, Pro $32/1000, Enterprise $35/1000
([Woosmap](https://www.woosmap.com/blog/google-places-api-pricing), [SafeGraph](https://www.safegraph.com/guides/google-places-api-pricing/)).
Для РФ Google — **третья** по значимости площадка, поэтому её удобство не спасает.

### S3.2 Яндекс.Карты — диплинка нет, но есть санкционированный QR

- **«Промоматериалы»** кабинета Яндекс Бизнеса, дословно: *«В QR-код зашифрована ссылка на профиль вашей
  организации в Картах и форма для оценок и отзывов в нём»* — плюс макеты визиток, пирамидок и PNG с QR
  ([Яндекс Бизнес](https://yandex.ru/support/business-priority/ru/manage/promo)).
- Официальная URL-схема Карт для веба есть, но **параметров формы отзыва в доступной документации нет**
  ([Клуб API Карт](https://yandex.ru/blog/mapsapi/kak-sformirovat-ssylku-na-yandeks-karty)); **API отзывов
  у Яндекса тоже нет** — только виджет на сайт ([Клуб API Карт](https://yandex.ru/blog/mapsapi/42108),
  [MyReviews](https://myreviews.ru/yandex-biznes-otzyvy)).
- `[H]` ⚠️ contested: параметр `?add-review=true` к `yandex.ru/maps/org/<slug>/<oid>/reviews/` кочует по
  блогам, но **ни в одном первоисточнике мы его не нашли**. Фольклор до ручной проверки.
- Лицензия **API Поиска по организациям** — только стандартная, данные **запрещено сохранять и изменять**
  ([Яндекс](https://yandex.ru/dev/maps/geosearch/)): ID организации получить можно, кэш «своей базы
  точек» на этом строить нельзя.

### S3.3 2ГИС — хуже всего

Документация диплинков даёт исчерпывающий список сценариев: запуск приложения, поиск, карточки (фирм,
мест, остановок, маршрутов, входов в метро), избранное, проезд, маршрут, ведение по маршруту.
**Действия «оставить отзыв» в списке нет.** Карточка фирмы — `https://2gis.ru/firm/{id}`, рекомендуется
https-форма ради fallback на веб
([Помощник 2ГИС](https://help.2gis.ru/question/razrabotchikam-zapusk-ideystviya-vmobilnom-prilozhenii-cherez-deeplink)).
**Встроенного генератора QR в кабинете 2ГИС нет**, но брендированные наклейки заказываются через
кабинет/менеджера, и *«все промоматериалы содержат QR-код, который приведёт пользователя в форму, где
можно оставить отзыв»* ([Помощник 2ГИС](https://help.2gis.ru/question/kak-rabotat-s-otzyvami-klientov-instrukciya-dlya-kompaniy),
[VICTORY group](https://victoryagency.ru/blog/reputation/kak-sdelat-qr-kod-na-otzyvy-v-2gis)).
Places API 2ГИС умеет искать организацию по названию, адресу, телефону, ИНН и отдавать объект по ID
([docs.2gis.com](https://docs.2gis.com/en/api/search/places/overview)) — но это про поиск, не про отзывы.

## S6 — Регуляторные первоисточники

Проверялось звено за звеном, потому что README проекта утверждал, что gating «запрещён правилами площадок
и законом». Реальность мозаичная.

| Кто | Запрещает ли гейтинг | Дословно / точно |
|---|---|---|
| **Google** | **ДА, прямо** | *«Discourage or prohibit negative reviews, or selectively solicit positive reviews from customers»* — запрещено; также запрещено *«require or pressure users to leave ratings or write reviews while on the premises»*. Санкции: удаление контента, при системности — от приостановки привилегий аккаунта до его прекращения — [Google Maps UGC Policy](https://support.google.com/contributionpolicy/answer/7400114?hl=en) |
| **Яндекс** | **НЕТ прямого запрета** | Запрещены накрутка (*«автор не взаимодействовал с компанией»*) и вознаграждение за положительный отзыв (*«не оставляйте только положительный комментарий ради бонуса»*), запрещено *«предлагать скидки за положительные комментарии»*. **Явно разрешены** прямые ссылки, QR и промоматериалы — [Яндекс, правила отзывов](https://yandex.ru/support/reviews/ru/rules), [Яндекс Бизнес](https://yandex.ru/support/business-priority/ru/reviews/get-and-promote) |
| **2ГИС** | **НЕТ прямого запрета**, при этом ⚠️ **сам продаёт гейтинг** | В справке: запрещено *«поощрять клиентов только за положительные отзывы»*, запрещены накрутка и требование писать отзыв на устройствах компании — [Помощник 2ГИС](https://help.2gis.ru/question/kak-rabotat-s-otzyvami-klientov-instrukciya-dlya-kompaniy). И одновременно 2ГИС продаёт «Отзывы Про» с маршрутизацией по оценке — [reklama.2gis.ru/reviewpro](https://reklama.2gis.ru/reviewpro) |
| **FTC (США)** | **Косвенно** | 16 CFR Part 465 состоит из: 465.2 фейковые отзывы · 465.4 покупка положительных/отрицательных · 465.5 инсайдерские · 465.6 подконтрольные компании сайты отзывов · 465.7 подавление отзывов · 465.8 фейковые индикаторы влияния. **Отдельного пункта «review gating» в тексте правила нет** — [eCFR / Cornell LII](https://www.law.cornell.edu/cfr/text/16/part-465). Штраф: ⚠️ contested — источники дают **$51 744** и **$53 088** за нарушение (ежегодная индексация). Правило действует с 21.10.2024. **К российскому заведению неприменимо.** |
| **РФ, закон** | **Прямого запрета гейтинга нет** | Накрутка квалифицируется как недобросовестная конкуренция (135-ФЗ) / недостоверная реклама; ст. 14.33 КоАП — штраф юрлицу **100 000–500 000 ₽** — [work24](https://work24.ru/spravochnik/povyshenie-kvalifikacii/teksty/otzyvy/nakrutka-otzyvov-chto-eto-riski-i-posledstviya-dlya-biznesa), [vitvet](https://vitvet.com/articles/135_fz/narushenie_135_fz_o_zawite_konkurencii/) |
