## Boundary assessment

The global runtime promise shares one pool/password service across routes. The process admission guard precedes lazy initialization; durable fixed-cardinality admission completes before reading bodies or entering credential work. The fixed unknown-source bucket is the accepted pilot behavior; untrusted forwarding headers cannot manufacture trusted source identity. Body cancellation does not wait indefinitely for a hostile producer or release native KDF capacity before actual completion.

SQL functions use schema-qualified, narrow SECURITY DEFINER interfaces with fixed search_path and revoked PUBLIC/helper privileges. The application has no added protected-table DML/read authority. Composite constraints bind membership, grant, partner, asset and policy to their program. Transactions couple acceptance, consent, assets, projections, immutable facts and grant/invitation consumption. Preliminary authentication does not replace post-lock current-session/issuer checks. No client-selected actor/role escalation, cross-program data-return path or activation override was found.

The UI uses the frozen request/response fields, preserves exact terms text and clears consent after a terms-changed/refetch result. Raw grant tokens are transient handoff state, not URL/storage state; sessions are not serialized into ordinary JSON. All nineteen non-health routes are dynamic Node handlers. This slice adds no live bootstrap endpoint, N1 call, financial operation, referral redirect, tax workflow or manual transfer implementation.

The compose change attaches only the web service to an own-namespace ingress bridge with loopback publication; database/test services remain on the internal private network with no DB published port. Infrastructure checks and the thirtieth mutation enforce this boundary. The canon adapter pins the upstream checker SHA and gives it a temporary unit-section copy, retaining duplicate/missing-unit/hash failures and cleaning temporary data. The later inherited-stdio/60-second-timeout change was inspected and its six adapter tests independently passed.
