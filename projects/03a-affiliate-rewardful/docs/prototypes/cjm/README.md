# N3a — HTML CJM для выбора

Статус: варианты подготовлены для обсуждения; ни один не выбран. PRD и реализация не начаты.

Откройте [общее сравнение и прототип](index.html) или конкретный вариант:

- [A — Через вознаграждение](variant-a.html): владелец настраивает программу, партнёр рекомендует N1, видит комиссию; рост через собственную партнёрскую программу платформы.
- [B — Через видимый бренд](variant-b.html): публичная страница программы Proofwall, самостоятельное вступление, обнаружение платформы по badge на странице программы.
- [C — Через сопровождение](variant-c.html): совместный запуск с владельцем, проверка пути оплаты и сверка, затем ручной расчёт и кейс.

Каждый HTML автономен: скрипты, стили и шрифты встроены. Можно скачать один файл и открыть локально, без установки и сервера. Интернет для работы макета не требуется.

## Как посмотреть

1. Переключайте A/B/C и шаги 1–6. Справа — сегмент, рост, момент ценности и риск. Под экраном — задача шага и ощущение пользователя.
2. В A на шаге 3 нажмите «Показать подтверждённую оплату». Это включает пример начисления, а не реальный платёж.
3. На шаге 4 попробуйте возврат и продление; на шаге 5 переключите сентябрь/октябрь. Сентябрь выплачивается 5 октября, октябрь — 5 ноября.
4. Скачайте демо-таблицу CSV. Она не помечает выплату выполненной. Ручная отметка в примере требует отдельного подтверждения.
5. Откройте «Сравнить A / B / C». Через «Собрать сочетание» можно подготовить текст гибридного варианта.
6. Сообщите выбранный вариант или сочетание в чате. Кнопки HTML лишь подготавливают текст выбора, ничего не отправляют и не разрешают переход к PRD.

## Границы демонстрации

N1 — первая интеграция, ЮKassa — платёжный провайдер. N2 — только донор кода. Выплаты выполняет владелец вручную каждого 5-го числа за предыдущий месяц, без обязательного hold 30–45 дней на каждое начисление.

Все события в HTML демонстрационные. Пример: оплата 990 ₽, комиссия 20% = 198 ₽; частичный возврат 330 ₽ уменьшает комиссию на 66 ₽; остаток 132 ₽. Ставка 20% не утверждена. Налоговые удержания не моделируются. N1 имеет ручное продление на 30 дней; автоматическая подписка и достоверный партнёрский MRR не заявляются.

Состояние хранится в памяти страницы и сбрасывается при перезагрузке. Каждый вариант имеет отдельное состояние. Прямая навигация по шагам разрешена для сравнения; она не является моделью production-авторизации.
