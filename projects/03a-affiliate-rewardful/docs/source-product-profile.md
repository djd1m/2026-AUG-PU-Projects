# N3a — профиль визуального источника

Источник: Rewardful, https://www.rewardful.com/.
Дата составления: 2026-09-09. Дата использованной съёмки: 2026-09-08.

**Статус новой съёмки:** НЕ ИЗМЕРЕНО.
**Причина:** no-browser-mcp — внешний навык clone-website и его браузерный MCP не обнаружены среди доступных инструментов. Локальный Firefox применяется для проверки N3a, не выдаётся за запуск clone-website.
**Происхождение визуальной основы:** исторический локальный исследовательский снимок предыдущего дня, просмотренный координатором. Это не новая съёмка живого Rewardful.

Использованы материалы старого N3:

- `../../03-affiliate-rewardful/docs/source-product-profile.md`;
- `../../03-affiliate-rewardful/docs/discovery/screenshots/rewardful-home.png`;

В снимке зафиксированы Rubik, белая основа, slate-текст, синий CTA #0087ee с радиусом 5 px, двухколоночный hero. В N3a эти свойства служат исходной визуальной системой; CTA затемнён до #0074cf для читаемости. Шрифты поставлены с OFL. Закрытые кабинеты Rewardful не измерены: auth-required. Их порядок экранов не копируется и не заявляется подтверждённым.

Авторские экраны N3a разделяют выбор CJM и демонстрационный интерфейс, явно показывают роли владельца, партнёра и клиента N1. Три growth-гипотезы сохраняют общий финансовый сценарий: месячный реестр и ручная выплата 5-го числа.

| Черновой ID | Наблюдение / проектное решение | Основание |
|---|---|---|
| FR-LOOK-001 | Rubik, slate text, белый фон и синий основной CTA | Исторический DOM/CSS снимок |
| FR-LOOK-002 | Hero с текстом слева и продуктовым примером справа, одна колонка на мобильном | Исторический screenshot + авторская адаптация |
| FR-LOOK-003 | Раздельные роли, начисление отдельно от выплаты | Авторский сценарий текущего N3a |
| FR-LOOK-004 | Кликабельные варианты, сравнительная таблица, заметки CJM, черновик сочетания | Требование HTML checkpoint |

Это вход для обсуждения CJM. Specification/PRD по указанию владельца не создаются; отсутствие связей с ними не считается успешно пройденной валидацией.
