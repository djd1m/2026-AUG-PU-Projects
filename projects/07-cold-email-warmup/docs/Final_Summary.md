# Final Summary — Грелка (N7 · Instantly-клон)

## Грелка — Executive Summary

Грелка — веб-сервис холодной email-рассылки с сетевым прогревом. Владелец подключает свои ящики по
SMTP/IMAP, ящики греются в общем пуле со явным согласием всех участников, health-дашборд доказывает
рост репутации домена, кампании идут с ротацией, лимитами и полным антиспам-контуром (отписка
RFC 8058 ≤ 48 ч, глобальный стоп-лист, автопауза жалоб, согласие на действие от имени). Тарифы
flat (Free/1 490 ₽/4 900 ₽ + $-контур), платежи — ЮKassa и Stripe, партнёрские коды с атрибуцией
до оплаты. Клон механики Instantly, отличия: комплаенс by design, RU UI/платёж, честные потолки.
Постановка: N7 курса; сетевой эффект — единственный «подлинный» из 8 проектов (и самый рискованный:
пул обязан засеяться).

## Problem & Solution

Письма с нового домена не доходят (58 % ответов теряется уже на первом письме), инструменты дороги
и глухи к правому полю; решение — общая сеть прогрева с honest-показом + комплаенс как ядро.

## Target Users

- Primary: соло-продавец B2B (S1) — старт дёшев, письма доходят, здоровье видно.
- Secondary: агентство (S2) — канал через партнёрский код; полный агентский воркспейс — v1.0.

## MVP Features

1. **SMTP/IMAP-ячщики + общий пул прогрева** — сетевой эффект с первого дня (сид 25).
2. **Кампании со ротацией и pre-flight** — запускается только при явном согласии; стоп при ответе.
3. **Health-дашборд + публичная статистика сети** — момент ценности и витрина честного продукта.

## Technical Approach

Архитектура: разделённый monolith (Fastify API + 3 worker-контейнера, BullMQ/Redis, PostgreSQL 16),
Caddy TLS, Compose deploi. Секреты — AES-256-GCM envelope. Доноры: N1 (ЮKassa+tariff+агентские
выплата), 03a (auth, referral), N6 (packages/queue). Ключи и алгоритмы — Specification/Pseudocode;
AD-001..006 — ADR.md.

## Research Highlights

1. Прогрев — отдельный товар за $500–1000/мес у источника (пул — актив, не фича).
2. Правила Gmail/Yahoo/Microsoft 2024–2025: TLS, авторизация, спам-рейт < 0,3 %, одна-клика отписка.
3. Кейс GMass (Google закрыл сеть 2023) и линия Apollo: warmup без комплаенса умирает.
4. «Unlimited»-магия: у Smartlead — Fair Use-потолки с 2026-02; честно показать потолки.
5. Канал RU→мир: RU-инструмента нет; доноры платёжки есть.

## Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Пул не нагоняет 25 | seed-план из брифа; метка «сеть разогревается»; согласие всех |
| SMTP AUTH ограничения Workspace | диагноз в UI, план OAuth v2.0 |
| Утечка секретов | envelope + audit + TLS-only + запрет plaintext логов |
| RU реклама без согласия | предупреждения, стоп-лист, отписка; знак согласия в UI |
| Абьюз платформы | fail-closed потолки, автопауза, лимит аккаунта |
