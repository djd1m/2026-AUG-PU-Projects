# Narrow primary protocol preparation for F09

Read-only preparation while the independent F08 writer runs; no F09 PLAN/implementation or runtime acceptance. Read2026-10-06. No provider connection, credentials, send, install or spend. F09 still requires /next→/go→full feature and exact accepted F08 source before dependent code.

[SMTP RFC5321 §4.2.5](https://www.rfc-editor.org/rfc/rfc5321.html#section-4.2.5) places acceptance responsibility at positive completion after end-of-DATA. [§4.5.3.2](https://www.rfc-editor.org/rfc/rfc5321.html#section-4.5.3.2) specifies command-specific timeout behavior and recommends ten minutes for the final DATA response; premature timeout can cause duplicates. **N7 design implication:** a shorter resource/SLO deadline must be documented as a bounded application policy, never interpreted as definite rejection after submission; preserve unknown_delivery and no blind retry. F08 authentication-only deadlines do not establish F09 sending policy.

[IMAP RFC9051 §2.3.1.1](https://www.rfc-editor.org/rfc/rfc9051.html#section-2.3.1.1) binds stable message identity to mailbox, UIDVALIDITY and UID; sequence positions are not equivalent. [EXAMINE](https://www.rfc-editor.org/rfc/rfc9051.html#section-6.3.3) provides read-only selection; [BODY.PEEK](https://www.rfc-editor.org/rfc/rfc9051.html#section-6.4.5) avoids implicit Seen marking. [APPEND](https://www.rfc-editor.org/rfc/rfc9051.html#section-6.3.12) allows caller-supplied internal dates. **N7 implications:** generation resets and incomplete scans must remain fail-closed; prefer read-only bounded fetches, and do not promote INTERNALDATE to trusted arrival without independent provenance.

Still unestablished: actual accepted connector API/source, advertised IMAP4rev1 versus rev2 compatibility, exact bounded UID cursor/range algorithm, literal framing/backpressure/cancellation, partial-message behavior, SMTP safe-versus-unknown failure mapping, provider capabilities and live-account authorization. These belong to the F09 source-bound plan and real local protocol fixtures, not a claim of protocol conformance here. Do not reopen broad donor/competitor research.
