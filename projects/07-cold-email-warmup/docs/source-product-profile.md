# Source product profile

Источник: Instantly.ai / Smartlead; дата 2026-10-02.

**Статус съёмки:** НЕ ИЗМЕРЕНО — no-browser-mcp
**Статус съёмки (путь):** НЕ ИЗМЕРЕНО — no-browser
**Происхождение:** не снято

На старте доступный Docker context не содержал browser runtime. Владелец разрешил
корневому координатору создать общий Docker Playwright; endpoint ожидается.
Help Center прочитан как продуктовый источник, но не изображает живую визуальную
съёмку. Login/authenticated competitor flow не обходится.

FR-LOOK seed не создаётся из воображения. До browser capture три CJM используют
явно обозначенный авторский B2B fallback: спокойная рабочая консоль, различимые
состояния, ограниченные акценты. Логотипы, код, CSS и фирменные значения конкурента
не копируются. После доступности browser: one-page public capture либо named
blocked outcome; несколько страниц только после robots.txt, без логина.
