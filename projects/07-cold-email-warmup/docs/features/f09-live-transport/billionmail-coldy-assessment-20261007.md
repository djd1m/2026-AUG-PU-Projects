# BillionMail и Coldy: границы применимости к N7

Проверка официальных источников: 2026-10-07. Исследование не меняет утверждённый scope и текущие AC; новые сервисы и провайдеры не запускались.

BillionMail имеет смысл оценивать как отдельный mailhost для собственных ящиков warmup/cohort. N7 подключается к ящикам через SMTP submission и UID-чтение IMAP; он не реализует сервер хранения почты/MTA. В официальном [compose](https://github.com/Billionmail/BillionMail/blob/dev/docker-compose.yml) присутствуют Postfix, Dovecot, Rspamd, Redis, PostgreSQL и Roundcube; по умолчанию опубликованы web/mail ports, core получает Docker socket. Поэтому готовый стек требует отдельной оценки инфраструктуры и доступа. Он не исправляет текущую ошибку cadence F11 с повторными EXAMINE и fair HEADER turns. Миграция или запуск сейчас не назначены; оценка «35–40% покрытия» количественно не проверена.

[LICENSE](https://github.com/Billionmail/BillionMail/blob/main/LICENSE) содержит AGPLv3. Section0 различает сетевое взаимодействие и передачу копии; section13 требует предложения Corresponding Source пользователям модифицированной версии при соответствующем удалённом взаимодействии. Из этих положений не следует категорический запрет любого закрытого SaaS. Для отдельной интеграции стандартными SMTP/IMAP необходима оценка конкретной границы лицензирования; наличие отдельной коммерческой лицензии не подтверждено.

Позднее можно ограниченно сравнить зрелые SMTP/IMAP-клиенты [Nodemailer](https://nodemailer.com/smtp/) и [ImapFlow](https://imapflow.com/) с native F09. Прежний выбор native ограничивал зависимости и загрузки, а не доказал несовместимость библиотек. Любая замена должна сохранить submitting fence, unknown_delivery hold, UID/owner/generation fences, лимиты, bounded I/O, SSRF и точную публикацию результата после закрытия операции.

[Coldy](https://coldy.ai/) служит дополнительным конкурентным ориентиром для РФ: сайт заявляет подключение корпоративных почт, прогрев, цепочки, AI-персонализацию получателей, обработку ответов в интерфейсе и передачу лидов в CRM. Это маркетинговые заявления, а не наши измерения качества или AI-ответа быстрее пяти минут. База компаний, enrichment и CRM не добавлены в scope N7. Текущий critical path остаётся F11 → F12 → F13 → F14 с обязательными проверками; живой pilot и расходы требуют своих разрешений.
