# Решение по локальному прототипу почтовых библиотек

На 2026-10-07 независимое ревью завершено: **ImapFlow FAIL, Nodemailer INCONCLUSIVE**. Замена рабочего транспорта N7 не принята. Отрицательный эксперимент завершён и сохранён отдельно от production-кода.

Источник — `530a73fb5498ae873d48e4b05176946bee1734a4`, ровно восемь файлов [эксперимента](../../../experiments/mail-library-prototype/README.md). Закреплены ImapFlow2.2.6 и Nodemailer10.0.15; lockfile принадлежит эксперименту. Главные зависимости, транспорт, схема БД и публичный F08 preview не изменены. Установка и испытания были разрешены только локально; внешние SMTP/IMAP/OpenAI и платежи не выполнялись.

| Проверка | Подтверждённый результат |
|---|---|
| IMAP literal | Публичный лимит отвергает отдельные враждебные literals до накопления; это не доказывает общий лимит сессии. |
| IMAP aggregate | Завершённый ответ 1,134,545 байт превышает 1,048,576: FAIL. `maxResponseSize` сбрасывается между ответами. Совокупный pending≤128KiB не установлен. |
| IMAP AUTH | Поддержанный выбор AUTH=PLAIN сам по себе не исключает LOGIN fallback при отсутствии SASL capability: FAIL общей границы. |
| SMTP | Наблюдаемые до/после-DATA исходы консервативны; полный final250 отделён от unknown_delivery. Новая pin/endpoint-negative проверка и часть cancellation/slow-input матрицы отсутствуют: INCONCLUSIVE. |
| Cleanup harness | Фallback SIGKILL задан через7s, последующее ожидание exact exit/close не ограничено вторым5s сроком. Полный lifetime PASS отсутствует. Все39 наблюдаемых сценариев фактически закрылись; это не проверка fallback. |

Семь wrapper-тестов прошли с native0; это не приёмка совместимости. Ревью сопоставило62 hashes и39 сценариев, проверило отсутствие их PID и финальных сокетов. У ревьюера не было авторского чата, отчёта или receipt-оракула; использованы пакет планировщика, замороженный код и объективные результаты.

Сохранены [независимое ревью](client-library-assessment-20261007/prototype-review.md), [машинный verdict](client-library-assessment-20261007/prototype-review.json), [seal](client-library-assessment-20261007/prototype-final-seal.json) и [запись моделей/стадий](client-library-assessment-20261007/prototype-run.json). Прототип опубликован в отдельной ветке `work/n7-mail-library-prototype-20261007`; PR не создан. Точное время push не измерялось, подтверждение root —07:30:26UTC.

Профиль `model-routing-econom`: запрошены Sol6.1/HIGH для планирования и независимого ревью, Sol6.1/MEDIUM для реализации. Фактические host model/effort, токены и стоимость недоступны; они остаются null. Экономия не измерена.

Решение: сохраняем native-транспорт. Новый ограниченный эксперимент возможен при доказуемом публичном enforcement общего receive/AUTH и полной SMTP/cancellation матрице; private parser hooks или ослабление границ не разрешены этим результатом. Текущий F11 отдельно остаётся непринятым и продолжает собственную нормативную диагностику.
