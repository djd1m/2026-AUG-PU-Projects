## F09-V1 — lifetime evidence (checked2026-10-06)

Opened exact primary Node22.20.0 contracts: [timers](https://nodejs.org/download/release/v22.20.0/docs/api/timers.html#scheduling-timers), [ChildProcess exit](https://nodejs.org/download/release/v22.20.0/docs/api/child_process.html#event-exit), [killed](https://nodejs.org/download/release/v22.20.0/docs/api/child_process.html#subprocesskilled), and [socket close](https://nodejs.org/download/release/v22.20.0/docs/api/net.html#event-close_1). The child exit event means the process ended; `killed` means a signal was sent and is not termination evidence. Socket close documents fully closed connection; timers cannot promise execution while an owner is suspended. N7 inference: expiry/deadline cannot release another owner's still-open socket. Use exact child identity and exclusively owned, unshared socket descriptors for process-exit closure proof, or sealed-operation local close acknowledgement for every underlying handle. Raw/TLS wrappers must be reconciled to their underlying descriptor; a protocol response or destroy request is insufficient. Missing proof fails closed. These documented primitives support the prospective bounded lifetime guard, not an already-tested recovery claim. Cross-host termination attestation is not implemented by this plan; absent authoritative proof the occupied slot stays blocked.
