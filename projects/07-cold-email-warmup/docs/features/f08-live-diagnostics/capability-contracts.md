# F08 — pinned capability contract and selection

Inspected2026-10-06. Selected smallest F08 approach: native Node22.20.0 (existing Dockerfile runtime) with a deliberately finite auth-only state machine and explicit custom limits. No SMTP/IMAP npm package is selected or installed. Native TLS implements crypto/certificate verification; N7 implements protocol framing/admission/deadline/cancellation, which remain unverified until real fixtures. This is not a general SMTP/IMAP library and cannot provide F09 DATA or UID semantics.

## Required implementation contract

The only peer connector exposed in production takes validated endpoint+signal; no proxy/redirect/reconnect/alternate-address fallback. DNS result validation occurs on every attempt before socket creation. Test seam may map synthetic public endpoint to local fixture address and CA only through an explicit test constructor unreachable from runtime env/HTTP; it retains original hostname validation and production state parser. Success fixtures must use actual local TLS with validated synthetic SAN; invalid CA/hostname/downgrade fixtures must fail. No tls.rejectUnauthorized=false anywhere.

Fixed operation limits:2 requests/process,1/mailbox,2 protocols/request,30s shared absolute deadline, each phase≤10s,65536 received bytes/protocol,8192 bytes/line, no queue/retry. Check bytes before concat/decoding; literal markers/unknown protocol states fail closed; never install raw protocol logging. Results enum-only, independent SMTP/IMAP, gate/config/revision bound. Adapter finite command methods make message commands unavailable.

Readiness: API/source contracts are established; custom guard correctness and production adapter behavior are still PENDING runtime witnesses. No authorized external account was contacted and no claim of live_provider verification exists. F09 send/UID behavior and real-provider auth support beyond password PLAIN remain outside F08. If required PLAIN provider is unsupported, report unsupported and keep gate closed; do not quietly expand scope or downgrade TLS.
