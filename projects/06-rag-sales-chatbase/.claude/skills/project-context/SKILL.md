# project-context — N6 «Суфлёр»

Источники: `docs/PRD.md`, `docs/Specification.md` §1/§5/§7/§8, `docs/canon.md`,
`docs/Research_Findings.md`, `docs/Solution_Strategy.md`, `docs/decisions-autonomous.md`.
При расхождении прав канон; числа здесь — цитаты канона на 25.09.2026, а не второй источник.

## Продукт в одном абзаце

Владелец сайта вставляет адрес сайта и PDF; через минуты у него бот, который отвечает посетителям
только по этим материалам, в каждом ответе показывает источник, а когда ответа нет — честно говорит
«не знаю» и даёт контакт компании. Бот ставится одним `<script>` на сайт клиента; на бесплатном плане
несёт бейдж «Работает на Суфлёре» — каждый клиент бесплатно раздаёт нам показы. Гипотеза недели:
малый бизнес РФ поставит бесплатного бота с бейджем, если путь «URL → живой бот с источником»
занимает минуты и не требует регистрации до первого ответа (PD-CORE-002).

## Персоны

- **Ольга, владелица онлайн-школы** (S1, PD-SEG-001): сайт на Tilda, 3–5 тыс посетителей/мес,
  вопросы о ценах вечером; боится, что бот «наврёт» ученикам. Поставит бесплатно с бейджем.
- **Денис, веб-студия** (S2, PD-SEG-002): 20 клиентов просят «чат с ИИ»; собрать бота за минуты,
  передать клиенту, получать доход с продления — нужен кабинет с несколькими ботами.
- **Посетитель чужого сайта:** не знает о продукте, хочет быстрый ответ; видит бейдж.
- **Анти-персоны:** контакт-центр (нужна передача оператору), e-com с 10 000+ SKU, «бот-продавец,
  обещающий скидки» — продукт принципиально не говорит того, чего нет в материалах.

## Путь CJM H (временно, A-N6-008)

Лендинг с ОДНИМ полем URL → «Читаем сайт: k из ≤ 20 страниц» → предпросмотр: макет страницы +
живое окно бота → вопрос → ответ с цитатой и ссылкой → CTA «поставить на сайт» → регистрация
сохраняет бота (claim) → контакт для «не знаю» → домены → код `<script>` + список CSP-директив →
виджет на сайте → первый ответ посетителю → установка засчитана → демо-страница `/b/{slug}` →
сводка «ответил / не знал». Ветки: код партнёра `/r/{code}`, кабинет студии с переносом бота
клиенту, экран интереса вместо оплаты.

## Словарь

| Термин | Значение здесь |
|---|---|
| Фрагмент | кусок текста страницы или PDF ≈ 500 токенов (потолок 600, перекрытие 80) с контекстом «заголовок › раздел» и ссылкой на источник |
| Плашка источника | строка под ответом «Источник: <страница> ↗»; владельцу в предпросмотре — развёрнутая цитата |
| «Не знаю» | ответ без вызова модели, когда нет фрагмента со сходством ≥ 0.40, либо когда модель сослалась на фрагмент вне контекста |
| Установка | внешний origin из списка бота (≠ `N6_PUBLIC_ORIGIN`), запросивший конфигурацию И получивший ≥ 1 ответ посетителю |
| Бейдж | «Работает на Суфлёре» на плане free; ссылка `/?from=<домен>&utm_source=badge` |
| Предпросмотр | бот `draft` без аккаунта, ≤ 20 страниц, живёт 24 ч до claim |
| Задача индексации | `index_job`: идентификатор до работы, `queued/running/done/failed`, 11 причин отказа |
| Студия | план `studio`: до 10 ботов, перенос бота клиенту одноразовой ссылкой на 7 дней |

## Границы недели (канон §1)

**Входит:** краулинг сайта в пределах хоста + PDF, чанкинг, эмбеддинги 1536 в pgvector, чат с
источником в каждом ответе, «не знаю» + контакт, предпросмотр до регистрации, виджет, бейдж,
установки, демо-страница (noindex), коды партнёров, кабинет студии с переносом, потолки платных
вызовов, экран тарифов и интереса.
**Не входит:** передача оператору, мультиязычность, аналитика диалогов, CRM, обучение на диалогах,
выбор модели, OCR, рендер JS-сайтов, скриншот сайта, white-label, приём денег, выплаты партнёрам,
рассылки, стриминг, сброс пароля.

## Метрики недели (Specification §8)

≥ 15 установок на внешних доменах (гипотеза A-N6-005) · доля `unknown` ≤ 35 % при n ≥ 100 ·
«URL → первый ответ в предпросмотре» p50 ≤ 5 мин · i (клики по бейджу на 1000 показов) ≥ 3 ·
conv% (пришедшие по бейджу → первый ответ своего бота) ≥ 5 % при n ≥ 30 · ответов без ссылки на
фрагмент — 0 · выдуманных на наборе 20 «вне базы» — 0 из 20 (ручное измерение).

## Seeding (FR-GROWTH-007)

Группы с кодами: `seed-net` (сеть владельца курса, 10–15), `seed-studio-<имя>` (3–5 студий × 3
клиента, план `studio` назначает оператор), `seed-dogfood` (сайты N1–N5). Отчёт по когортам:
регистрации → установки → ответы.

## Конкуренты (PD-INSIGHT)

Jivo — ИИ-модуль 12 990 ₽ за 2000 диалогов, Carrot quest — 12 000 ₽ за 1000 вопросов: без
бесплатного входа и без источника в каждом ответе. Chatbase ушёл в enterprise, бейдж снимается
аддоном $99/мес. Бренд источника в интерфейсе, данных и бейдже не используется; числа с его сайта не
переносятся.
