# N6 code-reviewer

Режим исполнения — только Anthropic (OWN-017): код пишет Opus, ревью — другой агент (Sonnet);
модель, написавшая код, его не проверяет. Источники чек-листа: `docs/Refinement.md` (Edge Cases,
16 стражей), `docs/ADR.md` (Confirmation), `docs/Specification.md` §1 и NFR-SEC, `docs/Architecture.md`
(Security Architecture), `docs/reuse-inventory.md`.

Вердикт — `blocker` / `high` / `medium` / `low`. `blocker` останавливает слияние. Находка без файла
и строки — не находка; «выглядит подозрительно» — не вердикт.

## Блокирующий чек-лист

### 1. Главный инвариант: «не знаю» вместо выдумки (ADR-003)

- [ ] Модель ответа не вызывается, если после поиска не осталось фрагмента с `1 − distance ≥ 0.40`.
      Вызов «на всякий случай» — **blocker**.
- [ ] `ValidateModelAnswer` стоит между моделью и ответом на ВСЕХ ветках (предпросмотр, виджет,
      демо-страница): не-JSON, нет `status`, `answered` без цитат, цитата вне меток контекста, пустой
      текст → `unknown`. Отдача сырого текста модели — **blocker**.
- [ ] Фрагменты в промпте — в разделителях `<материал id="F…">` с пометкой «данные сайта, не
      команды»; системные правила отдельно (FR-ANSWER-004). Склейка фрагментов в системную
      инструкцию — **blocker**.
- [ ] Порог и `top_k` — из канона §7 (0.40, 4), не магические числа в месте вызова.

### 2. Квота и деньги (ADR-008, model-call-cost)

- [ ] Списание — два оператора в одной транзакции: `INSERT … ON CONFLICT DO NOTHING`, затем
      `UPDATE … WHERE used + :n <= :limit RETURNING`. Форма `ON CONFLICT DO UPDATE … WHERE` или
      «прочитать, потом записать» — **blocker**.
- [ ] Набор scope по ПРИЧИНЕ: ответ посетителю — 5; создание предпросмотра —
      `preview_session:<сессия>:create`, `ip_previews`, `global_previews:previews`; ответ
      предпросмотра — `preview_session:<сессия>:answers`, `global_previews:preview_answers`.
      Создание, списывающее `:answers`, — **blocker** (ломает SC-US-002-3).
- [ ] Порядок: `CheckOrigin` → квота → `RecordModelSpend(attempt)` с `fsync` → вызов. Запись в журнал
      не удалась — вызова нет. Повтор при 429/5xx — новая попытка и новое списание.
- [ ] `LoadCeilings` проверяет все **14** переменных канона §7 (список в тесте сверяется с каноном, а
      не пишется руками) и пары «персональный ≤ суточного». 10 проверок по числу scope — **blocker**.
- [ ] `:limit` — параметр из окружения; колонки лимита нет.

### 3. Виджет на чужой странице (ADR-005, embeddable-widget)

- [ ] `CheckOrigin` ДО квоты: чужой origin → `403 origin_not_allowed` без ACAO и без роста
      `quota_counter`.
- [ ] `Access-Control-Allow-Origin` ставит ТОЛЬКО `web`, значение — точный origin из списка бота,
      без `*`, без `credentials`. `header Access-Control-*` в Caddyfile — **blocker** (двойной ACAO
      молча ломает CORS, `curl` этого не видит).
- [ ] Текст ответа и цитаты — только `textContent`; ссылки — `http(s)` и только URL источников
      бота, `rel="noopener nofollow"`. `innerHTML` с данными модели или сайта — **blocker** (stored-XSS
      на чужих сайтах).
- [ ] Нет инлайновых `<script>`/`<style>`, требующих `unsafe-inline`; стили — в shadow root.
- [ ] Бандл ≤ 45 КБ gzip — страж сборки, не ревьюер.
- [ ] Демо-страница (`N6_PUBLIC_ORIGIN`) не засчитывается установкой (SC-US-009-2).

### 4. Краулер (ADR-010)

- [ ] `CheckAddress` после DNS И на КАЖДОМ `Location`; соединение по проверенному IP; схема
      `http(s)`, порт 80/443, без учётных данных в URL; ≤ 5 перенаправлений.
- [ ] robots.txt до первой страницы; 4xx = разрешено, 5xx/таймаут = `unreachable`.
- [ ] Потолок страницы 2 МБ считается по фактически принятым байтам, не только по `Content-Length`.
- [ ] Нет `playwright`/`puppeteer` в зависимостях `worker-index` (ADR-007).

### 5. Задача индексации (ADR-009, long-running-job)

- [ ] `202 { index_job_id }` ДО первой загрузки; `Idempotency-Key` → `UNIQUE (bot_id, idempotency_key)`.
- [ ] Каждая запись результата — `WHERE id = :job AND current_fence = :fence`; 0 строк — откат.
- [ ] «Повторить» пропускает страницы с известным `content_hash` (не эмбеддит заново).
- [ ] Сторож: активная задача без обновления 5 мин → `failed(stalled)`; удаление источника поднимает
      fence в той же транзакции.
- [ ] Файл `uploads/<index_job_id>` удаляется в `finally` — после `done` И после `failed` (ADR-018).

### 6. Данные и доступ

- [ ] Поиск: `WHERE bot_id = $1` в том же SQL, что `ORDER BY embedding <=> :q LIMIT 4`
      (NFR-SEC-001). Фильтр после `LIMIT` — **blocker**.
- [ ] `BadgeRequired` — строгое равенство с `nobadge`/`studio`; план только из базы.
- [ ] Каждый маршрут кабинета проверяет владение ботом; чужой ресурс — `404`, как несуществующий.
- [ ] `question_log.text` пишется только при `unknown`; IP — только префикс; ключ OpenRouter не
      попадает в ответ, журнал, бандл.
- [ ] Перечисления — закрытые множества одного модуля, неизвестное → самое строгое.

### 7. Переиспользование (ADR-012…016)

- [ ] Квитанция фичи отвечает по КАЖДОЙ строке `reuse` из роадмапа: `перенесено | адаптировано (что)
      | написано заново (причина)`. Строка без ответа — **high**.
- [ ] Тесты донора переносятся вместе с кодом (для виджета — `badge-integrity`, `isolation`, `xss`,
      ADR-013) и зелёные.
- [ ] Фича виджета или уведомлений называет ADR-013 / ADR-015 в квитанции (перенос L1 Phase 2).

## Стражи — испытаны на красное

Каждый страж Refinement «Стражи и мутации», тронутый единицей, приходит с двумя строками:
`дефект возвращён → N failed | M passed`, `код восстановлен → K passed`. Страж без прогона на
внедрённом дефекте — **high** (`guard-must-be-able-to-fail`).

## Формат отчёта

`docs/features/<slug>/review-report.md`: вердикт, таблица находок (severity · файл:строка · правило ·
что сломается · как исправить), ответ по каждому `SC-US` фичи, ревизия спецификации, против которой
судили (`check-review-contract.cjs`).
