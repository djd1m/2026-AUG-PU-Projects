## 2. Ждут решения владельца

1. **Риск ответов бота (A-N6-030) — главный.** Проверка цитат не сверяет текст ответа с фрагментом: модель может
   процитировать настоящий прайс и дописать выдумку. До решения ответ показывается посетителю только у бота с отметкой
   владельца «проверен» (A-N6-035); отметку снимает любой новый фрагмент (A-N6-036). Предложение исполнителя: (а) каждое
   число, ₽, % и срок из ответа обязаны встречаться в процитированном фрагменте, иначе «не знаю»; (б) непроверенному
   боту показывать только фрагмент-источник.
2. **152-ФЗ** — вопросы посетителей уходят модели за рубеж; секция доверия НЕ обещает «данные в РФ».
3. **Название** — рабочее «Суфлёр» (A-N6-003); предложено «Сноска» (snoska.ai/.io свободны, .ru и товарный знак не
   проверены). Домен стенда — `sufler.aicoding.space` (A-N6-042).
4. **Свой ключ OpenRouter для N6** — стенд работает на ключе стенда N5 (A-N6-019, A-N6-037); ротация — `.claude/rules/secrets-management.md`.
5. **Вариант CJM** — временно принят гибрид H (A-N6-008).
6. **Модели** — Haiku 4.5 и `openai/text-embedding-3-small` через OpenRouter (A-N6-010, A-N6-019) — подтверждены живыми
   вызовами на стенде 26–27.09.
7. **Цены и метрика недели** — гипотезы: 0 / 990 / 4 900 ₽ (подтверждены владельцем для оплаты, A-N6-040), 15 виджетов
   на внешних доменах (A-N6-004/005).
8. **Чат владельца делит лимит ответов с посетителями** (A-N6-033); баннер месяца это называет.
9. **Отказ от HNSW** в пользу точного перебора внутри бота (A-N6-028; индекс снят миграцией 008, A-N6-051) — пересмотреть
   при росте числа ботов.

### 3б. Принятый риск фичи 17 (решение владельца 27.09: «узкое ревью, затем влить»)

Восемь полных ревью удаления аккаунта (все D по шкале «любая high — D») и узкое ревью последней правки (C по области
коммита; обе находки закрыты резервированием префикса `erased:`). Остаток принят владельцем: редкие конкурентные гонки
вокруг стирания (удаление ↔ оплата / выплата / приём приглашения / разморозка), не воспроизводимые последовательными
тестами без барьера; свободный текст оператора в полях, не перечисленных в стражах (новые поля обязаны обезличиваться
стиранием — проверять при каждой миграции). Независимого полного ревью после восьмого круга не было.
