## Последствие для данных и стоимость

`content_hash` = sha256(заголовок + текст) меняется только у страниц, где был стык соседних элементов без пробела (у
современных сайтов на карточках и flex/grid — у большинства). Следующее «Обновить» переэмбеддит такие страницы ОДИН раз.
Автоматического переэмбеддинга нет: старые фрагменты работают, пока владелец не нажмёт «Обновить» (или «Повторить»).

| Оценка | Число |
|---|---|
| сайт 50 страниц (замер стенда 26.09, info.cern.ch) | 32 981 токен эмбеддингов |
| цена `openai/text-embedding-3-small` | $0,02 за 1 млн токенов → ≈ $0,0007 за такой сайт |
| потолок серии free (A-N6-050) | 500 000 токенов → ≤ $0,01 на источник |

Попутные последствия переиндексации (существующее поведение, правкой лишь задействуется чаще): новые фрагменты получают новые
UUID — в `question_log.cited_chunk_ids` старых вопросов остаются идентификаторы удалённых фрагментов; новый фрагмент снимает
отметку «Я проверил ответы бота» (миграция 004, A-N6-036) — владелец отмечает заново.
