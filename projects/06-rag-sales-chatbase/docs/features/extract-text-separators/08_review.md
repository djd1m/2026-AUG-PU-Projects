**Заявления плана, не подтверждённые кодом**

- Уступка HTML шире «посимвольной анимации»: `<span>1</span><span>.5</span>` становится `1 .5`; `<span>1</span><span>000</span>` — `1 000`. Разделяются также части ссылок и ruby (`漢 かん`). Последствия для чисел нельзя считать заведомо безопасными.
- Склейки устранены не полностью: `<span>А</span>&shy;<span>Б</span>` даёт `АБ`. Текстовый токен сбрасывает флаг, затем декодирование удаляет `&shy;`.
- Выбор `main/article` может измениться: воспроизведён переход с 199 до 200 символов за счёт вставленного пробела, после которого внешний текст исключается. Константа порога сохранена, результат выбора — нет.
- Геометрия не восстанавливает порядок чтения колонок: элементы разных колонок на одной высоте соединяются пробелом. Нулевая ширина принимается как достоверная геометрия; её точность для реальных документов **не подтверждена**. Без геометрии сохраняется прежняя склейка, как и заявлено.
- Последствия обновления не ограничиваются расходом на эмбеддинги. `packages/db/src/chunks.ts:51` удаляет прежние фрагменты, вставляя новые UUID. Исторические `question_log.cited_chunk_ids` сохраняют уже отсутствующие идентификаторы. Это существующее поведение переиндексации, которое правка массово задействует. Миграция `004_verified_reset.sql:7` также снимает отметку проверки ответов.
- Нарушения текущей проверки цитат не обнаружено: она проверяет метки полученного контекста, а excerpt берётся из найденного фрагмента. Дедупликация остаётся по хэшу извлечённого текста; утверждение «у каждой страницы меняется хэш» неверно — только при изменении результата извлечения.
