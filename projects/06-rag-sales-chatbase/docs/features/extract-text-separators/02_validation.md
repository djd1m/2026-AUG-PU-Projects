# 02 — Самопроверка плана `extract-text-separators`

Независимого валидатора нет (исправление дефекта, тир M); самопроверка по INVEST/SMART и правилам репозитория.

| Проверка | Итог |
|---|---|
| Каждый AC проверяем детерминированно | да: AC-1…AC-8 — unit/страж по исходнику, AC-9 — прогоны |
| Тест СНАЧАЛА красный | обязателен для AC-1, AC-2, AC-5, AC-6 (фиксирует дефект); AC-3, AC-4 — охрана от перелечивания, зелёные и до |
| Числа канона не меняются | да: пороги текста и пределы PDF не трогаются |
| Перекрёстное чтение (complexity-router M п.3) | Specification FR-SOURCE-001/003 (текст страницы и PDF — источник фрагментов и цитат) и Architecture (извлечение без DOM, дочерний процесс PDF) прочитаны; правка не меняет их контрактов |
| Разделяемый ресурс | нет: чистые функции извлечения; побочный эффект — смена `content_hash` → один переэмбеддинг при «Обновить» (оценка в квитанции) |
| Страж умеет падать | мутации U5, включая «сборка не копирует модуль PDF» |
| Цена правила | посимвольно разрезанное соседними элементами слово разрежется пробелом — записано в плане как принятая цена |

Вердикт: 🟢 к реализации.
