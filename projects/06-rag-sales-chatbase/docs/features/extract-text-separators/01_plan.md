## Дефект (стенд 26.09, BACKLOG §3а)

Цитата источника предпросмотра `https://aicoding.space/`: «целиком5 курсов health-advisorПодготовка к разговору с врачом».
Разметка страницы `/courses/` (снята 27.09):

```html
<span class="d" style="flex:1">как выглядит собранное на этом харнессе целиком</span><span class="d">5 курсов</span></div>
<a class="crs" href="/courses/health-advisor/"><span …>health-advisor</span><span class="sg" …>Подготовка к разговору…</span>
```

Соседние элементы разделены только CSS (flex/grid) — пробела между тегами в разметке нет. `extract-text.ts` режет текст
лишь на блочных тегах (`BLOCK`), а `span`/`a` строчные → текст соседних элементов склеивается.

PDF (`extract-child.mjs`, `pageText`): элементы `getTextContent` склеиваются без разделителя, перевод строки — только по
`hasEOL`. Слова в соседних элементах одной строки (ячейки таблицы, смена шрифта, колонки) слипаются тем же образом.

## Решение

**HTML — граница элементов.** Если открывающий тег идёт сразу за закрывающим, без текста между ними (`</span><span>`,
`</a><a>`, `</span></a><a><span>`), это граница двух соседних элементов — в текущий буфер (или текст заголовка) ставится
пробел. Слово, разрезанное строчным тегом, остаётся целым: `<b>при</b>мер` (за закрывающим — текст), `при<b>мер</b>`
(перед открывающим — текст) → «пример». Блочные теги по-прежнему закрывают блок. Известная цена правила: слово,
целиком собранное из соседних элементов без текста между ними (`<span>при</span><span>мер</span>` — посимвольная
анимация), разрежется пробелом; это редко и безопаснее склейки двух разных слов.

**PDF — геометрия.** Разделитель между элементами из их положения (`transform[4..5]`, `width`, высота шрифта из
`transform`): сменилась строка (сдвиг по вертикали больше половины высоты шрифта) без `hasEOL` → перевод строки; на той
же строке зазор больше доли высоты шрифта → пробел; перекрытие или стык без зазора → без разделителя (кернинг внутри
слова). Функция выносится в чистый модуль `apps/worker/src/pdf/page-text.mjs` (дочерний процесс исполняется при
импорте); сборка воркера копирует его рядом с `extract-child.mjs`.

**Числа не меняются:** `CRAWL_MIN_TEXT_CHARS`, `PDF_MIN_PAGE_TEXT_CHARS`, доли и пределы — как в каноне.

## Изменено по ревью (08_review.md)

Геометрия PDF снята: pdfjs уже расставляет разделители, своя эвристика портила повёрнутый текст, индексы и RTL; склейка PDF
прежняя, байт в байт. AC-6 заменён проверкой «склейка прежняя», AC-7 — регрессионный. Граница HTML не ставится перед тегами
без текста (RAW, `title`, VOID, SKIP), `&shy;` не сбрасывает границу. Хэш меняется только там, где изменился результат
извлечения, а не у каждой страницы.

## Последствие для данных (для квитанции)

`content_hash` = sha256(заголовок + текст) изменится у страниц, где был стык элементов (практически у всех современных
сайтов). «Обновить» после выката: такие страницы считаются изменёнными → переэмбеддинг один раз. Оценка — в квитанции.
Автоматического переэмбеддинга нет: старые фрагменты работают, пока владелец не нажмёт «Обновить».
