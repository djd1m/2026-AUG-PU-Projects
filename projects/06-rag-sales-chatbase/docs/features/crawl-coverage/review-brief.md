## Дефект, который чинится

Стенд 28.09: бот для сайта на плане free (предел 50 страниц). Обход закрылся `done`, `pages_done = pages_total = 50`.
В sitemap.xml ~57 адресов: главная, «обо мне», контакты, мастерская, лента блога, 42 курса, записи блога — в этом порядке.
Очередь была FIFO → прочитаны 42 курса, ни одной записи блога; владелец видел «50 из 50», как будто сайт прочитан целиком.

## Ограничения, которые НЕЛЬЗЯ было менять

Лимиты, паузы (1 с, 1 поток), потолок запросов `2 × бюджет + 10`, бюджет времени, SSRF-проверки (`CheckAddress` после DNS
и на каждом перенаправлении), robots.txt до первой страницы (ADR-010). Экран тарифов не трогать.

## Вопросы (ответь на каждый)

1. Корректность: может ли новый порядок нарушить ограничения выше (лишние запросы, обход вне хоста, обход robots)? Может ли
   `Frontier` потерять или задвоить адрес, зациклиться, сломать «корень — первым»?
2. Честность числа: `pagesKnown` = прочитанные + очередь (+ страница, остановленная бюджетом эмбеддингов). Где число может
   быть ЛОЖНЫМ (завышено/занижено) так, что владелец будет введён в заблуждение? Верно ли `GREATEST(..., pages_done)`?
3. Схема и состояния: CHECK миграции 012, сброс `unread_sample` при аренде и «Обновить», инвариант «только у усечённой».
   Есть ли путь, где `completeIndexJob` упадёт на CHECK (например, `coverage` без `truncated`) и задача зависнет?
4. ПДн/безопасность: `unread_sample` — только путь; может ли туда попасть что-то чувствительное или вредное для экрана
   (XSS — React экранирует; длина; управляющие символы)?
5. Экран: текст пометки для `page_budget`/`crawl_limit`, определение тарифа по `pages_done`; регресс для прежних пометок
   (`embed_budget`, `series_embed_budget`) и для экрана предпросмотра (там `truncated` теперь бывает `page_budget`).
6. Тесты: доказывают ли они AC-1…AC-8 плана, или какой-то зелёный при сломанной реализации?

## Формат ответа

Первая строка — `Оценка: A|B|C|D` (A — можно вливать; D — блокер). Затем находки списком: `[high|medium|low] файл:строка —
что не так — как проверить — что предлагается`. Не выдумывай: если не уверен — пометь «гипотеза». Пустой ответ недопустим.
