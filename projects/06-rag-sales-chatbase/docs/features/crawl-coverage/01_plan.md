## Дефект (стенд 28.09, БД и журнал прокси сайта)

Бот для `https://aicoding.space` (план free): обход `done`, `pages_done = pages_total = 50`, 1482 фрагмента. На сайте ~57
адресов в `sitemap.xml` (главная, «обо мне», контакты, мастерская, лента блога, 42 курса, 13 записей блога). Прочитаны
42 курса и лента блога — ни одной записи блога. Причины две и независимы:

1. **Порядок.** Очередь FIFO: `sitemap.xml` перечисляет сначала страницы верхнего уровня, потом 42 курса, записи блога — в
   конце. С пределом 50 один раздел вытеснил все остальные. sitemap читается (проверено `curl` 28.09: `urlset`, 63 `<url>`
   с `lastmod`), но `lastmod` не использовался.
2. **Итог.** Остановка по `PAGES_BY_PLAN` давала `stoppedBy = 'page_budget'` только в журнал; задача закрывалась `done` без
   пометки, а `pages_total = min(бюджет, прочитано + очередь)` = 50. Владелец видел «50 из 50» — «прочитан целиком».

## Решение

| Часть | Что | Где |
|---|---|---|
| Порядок | очередь по кругу между разделами (первый сегмент пути; корень и файлы верхнего уровня — раздел главной); внутри раздела — адреса sitemap по `lastmod` убыв., затем прочие в порядке обнаружения | `apps/worker/src/crawl/frontier.ts` (новый), `crawl-site.ts` (`sitemapEntries`) |
| Итог обхода | `CrawlResult.pagesKnown` = прочитанные + оставшиеся в очереди (+ страница, на которой остановил бюджет эмбеддингов); `unreadSample` — до 5 путей, по кругу между разделами, без параметров запроса | `crawl-site.ts`, `frontier.ts` |
| Пометка | `truncated_by` += `page_budget` (предел страниц тарифа/предпросмотра), `crawl_limit` (потолок запросов или времени обхода); бюджет эмбеддингов главнее | `packages/rag/src/enums.ts`, `site-processor.ts` |
| Схема | миграция `012_crawl_coverage.sql`: CHECK расширен; `index_job.unread_sample text[]` (1–5, только у усечённой) | `packages/db/migrations/` |
| Запись | `completeIndexJob(…, truncated, coverage)`: `pages_total = GREATEST(известные, pages_done)`, `unread_sample`; сброс при новой аренде и «Обновить» | `packages/db/src/index-jobs.ts`, `sources.ts` |
| Экран | лента источника: «Прочитано 50 страниц из ≥ 58 известных — предел тарифа «Бесплатный» — 50 страниц (платные тарифы — до 300). Бот не знает того, что есть только на непрочитанных страницах. Не прочитаны, например: … и другие.» | `SourceTruncationNotice.tsx` (новый), в `CabinetViews.tsx` — одна строка + импорт |

Не делается: экран тарифов/апгрейда; источник «llms-full.txt» (в BACKLOG как предложение); чтение вложенных sitemap
(`sitemapindex`) и директивы `Sitemap:` robots.txt (BACKLOG).

## Критерии приёмки

- **AC-1** Фикстура «42 курса + 10 записей блога + 5 прочих», предел 50: прочитаны все 5 прочих, все 10 записей блога, 35
  курсов; корень — первым.
- **AC-2** Внутри раздела свежие по `lastmod` раньше; без даты — после датированных; непригодная дата — как без даты.
- **AC-3** Остановка пределом → `done`, `truncated_by = page_budget`, `pages_total` = известные (58 на фикстуре), до 5
  непрочитанных путей без параметров запроса; обход без остановки — без пометки, `pages_total = pages_done`, примеров нет.
- **AC-4** Экран владельца (`readIndexJob`, `readBotCabinet`) получает пометку, известные и примеры; лента — текст AC-6.
- **AC-5** «Обновить» и новая аренда сбрасывают пометку и примеры.
- **AC-6** Лента: `page_budget` — «Прочитано N из ≥ M известных — предел …», примеры `<code>`, «и другие» при остатке;
  `crawl_limit` — свой текст; бюджет эмбеддингов — прежний текст; axe/R1/R2/R5/R8 на 320 и 390, две темы, Chromium+WebKit.
- **AC-7** БД: CHECK принимает 4 значения, отвергает прочие; `unread_sample` — 1…5 и только при пометке.
- **AC-8** Мутации: FIFO → красный; «50 из 50» → красный; `lastmod` проигнорирован, `pages_total` = прочитанным, «Обновить» не
  сбрасывает, параметры в примерах → красный; экран без новой пометки → красный браузер.
