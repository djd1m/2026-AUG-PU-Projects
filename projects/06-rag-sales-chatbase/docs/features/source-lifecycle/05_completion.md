## Что доказано и чем

- **SC-US-014-1:** сайт из 5 страниц, 3 изменились → «Обновить» → ровно 3 вызова шлюза эмбеддингов, та же задача
  (`index_job_id`), 2 серии в `job_attempt`, одна задача у источника; без изменений — 0 вызовов (интеграционный тест).
- **SC-US-014-2:** удаление → 0 страниц, фрагментов и задач источника; `searchChunks` бота не возвращает его фрагментов,
  соседний источник цел; чужой, несуществующий и повторный — `null`/404. Ядро ответа отдельно не вызывалось — доказано
  на поиске, которым пользуется ядро.
- **Гонки:** удаление и «Обновить» параллельно с воркером, держащим строку задачи и вставляющим страницу и фрагмент (с
  триггером снятия отметки), — обе стороны завершаются, без `deadlock detected`; опоздавшая запись страницы после
  удаления — `StaleAttemptError` и 0 фрагментов; 30 одновременных запусков при остатке 5 → ровно 5 задач.
- **Уборка:** исчезнувшая страница удаляется после полного обхода; при 500 другой страницы, сбое sitemap — не удаляется;
  404 — удаляется; переехавшая неизменная страница получает новый адрес без переэмбеддинга; `chunks_done` = фрагментам.
- **Предел запусков:** 20 в сутки МСК, вчерашние не считаются, повтор с тем же Idempotency-Key не тратит; «Обновить»,
  «Повторить» по id, сайт и PDF (до тела — 429 без чтения тела, в транзакции — 429 с удалением принятого файла).
- **Бюджет серии:** сверх предела — `quota_refused` до вызова шлюза; новая серия (и через `retryIndexJob`) — с нуля;
  предпросмотр платит своим бюджетом; «Обновить» сохранённого предпросмотра снимает его бюджеты.
- **Предел фрагментов:** 300 на страницу, `chunks_dropped` у страницы; запись > 300 — отказ; в обработчиках предел стоит ДО
  эмбеддинга (страж по исходнику и мутация).
- **HNSW:** индекса нет, `chunk_bot` на месте; поиск 5 001 фрагмента одного бота < 500 мс (прежний тест).
- **Кабинет (браузер, контейнер Playwright, обе темы, правила прибора и axe):** «Обновить» только у готового сайта,
  «Повторить» у отказавшего, «Удалить» у каждого из 6 источников; подтверждение удаления с последствием, «Удалить» и
  «Отмена» только у выбранного; ошибка предела запусков у своего источника; строка об обрезанных страницах.

## Ответ по строкам reuse

ADR-016 «переиндексация — донора нет» — **подтверждено поиском**: N1 импорт — CSV отзывов; N5 — повтор под `FOR UPDATE`
(`video-retry.ts`) и суточные слоты (`quota.ts`) **адаптированы** (блокировка строки бота, отказ слот не возвращает);
мягкое удаление N5 (`deleted_at`) **не взято** — оставило бы фрагменты в поиске.

## Что НЕ доказано

- Стенд: маршрут `DELETE` и «Обновить» в работающем Next и через дверь Caddy не прогонялись (стенд держит координатор).
- Браузер: интерактив (щелчок «Удалить» → подтверждение → запрос; синхронизация отметки после `router.refresh()`; сообщение
  при 404) — только разметкой состояний и стражами по исходнику, без щелчков.
- Справедливой очереди воркера по ботам нет; предпросмотр не пишет запуск (свои квоты).
- NFR-SCALE-001, CL+TE через Caddy, сверка токенов — перенесены (выше).
- Повторного ревью исправлений не было; валидация плана — самопроверка.
