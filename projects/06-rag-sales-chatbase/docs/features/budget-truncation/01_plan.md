# 01 — План: `budget-truncation` (исправление дефекта стенда)

Дата: 2026-09-26 · Основа: `76c4b4f6` (фичи 12–16 влиты) · Тир: **L** (`scripts/complexity-router.sh`, код 1: миграция схемы).
Деньги не затронуты: потолки расхода по-прежнему отказывают ДО вызова; меняется только исход задачи при исчерпании её
СОБСТВЕННОГО бюджета. FR: FR-INDEX-002, FR-LIMIT-002, FR-LIMIT-003. SC: SC-US-001-1, SC-US-001-3. Правила:
`long-running-job.md`, `model-call-cost.md`, `honest-configuration.md`, `guard-must-be-able-to-fail.md`.

## Дефект (наблюдение на стенде 26.09, задача `ea9150dc…`)

Предпросмотр `https://aicoding.space/` прочитал 10 страниц, записал 83 фрагмента; следующая пачка (оценка 13 839 токенов)
не влезла в `index_job.embed_budget` = 40 000. `embedBatch` бросил `StepFailure('quota_refused')` → ВСЯ задача `failed`.
Человек увидел «Бюджет предпросмотра исчерпан. Предпросмотр читает до 20 страниц…», хотя прочитано 10, и бота с
прочитанным не получил. Тот же путь у задач аккаунта с `index_job.series_embed_budget` (500 000 на free): крупный сайт
падает целиком, хотя всё прочитанное уже записано.

## Решение

| Предел | Чей | Исход при исчерпании |
|---|---|---|
| `index_job.embed_budget` (предпросмотр, 40 000) | задачи — объявленный размер предпросмотра | **усечение**: обход останавливается, задача `done` с `truncated = 'embed_budget'` |
| `index_job.series_embed_budget` (500 000 / 1 000 000) | серии источника | **усечение**: `done` с `truncated = 'series_embed_budget'` |
| `account_embed_tokens`, `global_embed_tokens` | внешние потолки расхода | **отказ** `quota_refused`, как было (model-call-cost: предел — отказ) |
| любой собственный, но прочитано 0 страниц | — | **отказ** `quota_refused` (не пустой `done`, SC-US-001-3) |

Усечение — не деградация: платных вызовов сверх объявленного бюджета нет, модель «поменьше» не зовётся; бюджет задачи и
есть объявленный размер работы. Три состояния задачи различимы: усечённый `done` — готово с пометкой, не «выполняется» и
не отказ.

## Критерии приёмки

| AC | Утверждение | Доказательство |
|---|---|---|
| AC-1 | Предпросмотр: 3 страницы влезают в бюджет, 4-я нет → задача `done`, `truncated='embed_budget'`, `pages_done=3`, фрагменты 3 страниц, 4-я не записана ни одним фрагментом | integration (подменный шлюз, настоящий Postgres) |
| AC-2 | Страница, не влезшая в остаток, не оплачивается: попыток шлюза за неё 0, строк `attempt` 0 | integration |
| AC-3 | Бюджет серии аккаунта — то же усечение, `truncated='series_embed_budget'` | integration |
| AC-4 | Внешний потолок (`account_embed_tokens` / `global_embed_tokens`) — отказ `quota_refused`, как раньше | integration |
| AC-5 | Бюджет кончился на первой странице (0 записано) → `failed(quota_refused)`, не пустой `done` | integration |
| AC-6 | «Обновить» усечённого источника: новая серия, `truncated` сброшен; неизменные страницы не переэмбеддятся (content_hash) | integration |
| AC-7 | PDF: лист, не влезший в собственный бюджет, останавливает ИНДЕКСАЦИЮ листов (разбор документа выполняется целиком заранее, дочерний процесс 30 с / 100 листов); `done`+`truncated`; 0 листов → отказ | integration (бюджет предпросмотра, подменный разбор) |
| AC-8 | API `GET /api/index-jobs/{id}` и `/api/preview/{id}` отдают `truncated`; неизвестное значение колонки → как отсутствие усечения не читается — `CHECK` в БД, разбор закрытым набором | unit |
| AC-9 | Экран предпросмотра в усечённом `done`: чат доступен, пометка «Прочитано N страниц…» видна; лента кабинета — «сделано» с пометкой | браузер (Playwright, Chromium + WebKit — движки прибора), разметка компонентов |
| AC-10 | Страж: вернуть `throw new StepFailure('quota_refused')` на собственном бюджете → AC-1/AC-3 красные | мутация |

## Бюджет 40 000 и 20 страниц — вопрос владельцу, не правка

Числа — канон §7 и Specification FR-LIMIT-002 (решение владельца). Замер на стенде: одна пачка aicoding.space — 13 839
токенов; 83 фрагмента на 10 страницах — в среднем ≈ 8 фрагментов ≈ 3 000 токенов на страницу; при пределе 300 фрагментов
на страницу одна страница может стоить до ~150 000 токенов. 40 000 ≈ 13 страниц такого сайта, а не 20. Предложение
(не применяется): 120 000 токенов (≈ 20 страниц по 6 000 с запасом); цена эмбеддингов `text-embedding-3-small`
≈ $0,02 за 1 млн токенов — ≈ $0,0024 за предпросмотр при `global_previews` 200/сутки ≈ $0,48/сутки худшего дня.
