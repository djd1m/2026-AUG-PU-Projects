# Карта переиспользования — `widget-runtime-and-badge` (ADR-013, донор N1)

Донор: `projects/01-testimonials-senja` (N1 «Proofwall», виджет отзывов). Ответ по КАЖДОЙ строке `reuse`
roadmap и ADR-013: `перенесено | адаптировано (что) | написано заново (почему)`. Строка происхождения стоит в
шапке каждого файла.

| Строка reuse (ADR-013) | Источник N1 | Куда в N6 | Ответ |
