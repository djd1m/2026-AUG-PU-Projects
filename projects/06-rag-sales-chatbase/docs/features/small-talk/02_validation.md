# 02 — Самопроверка плана `small-talk`

Независимого валидатора нет (изменение по решению владельца, образец фич 13–16); самопроверка по INVEST/SMART и правилам.

| Проверка | Итог |
|---|---|
| Каждый AC проверяем детерминированно | да: AC-1…AC-5, AC-8 — unit/integration, AC-6 — браузер, AC-7 — мутации, AC-9 — прогоны |
| ADR-003 (модель только при фрагменте ≥ 0.40) | не ослаблен: шаблон — константа кода, модель на светской реплике не зовётся вовсе; страж — мутация «модель вызвана» |
| Инъекция через реплику | правило «вся реплика из словаря»: посторонний глагол («игнорируй») делает реплику вопросом → порог ДО модели |
| Стоимость (model-call-cost) | новых платных вызовов нет; светская реплика — 0 вызовов, 0 списаний; строки контракта не меняются, добавлен абзац |
| Разделяемый ресурс | пул БД: на реплику 1 SELECT заголовков (≤ 30 строк, индекс нет — `page` бота мала) и 1 INSERT журнала; предел — дверь 30/мин на IP, как у любого вопроса. Квота не трогается |
| 152-ФЗ | `small_talk` без текста; CHECK `question_text_only_unknown` не меняется |
| Перекрёстное чтение | Specification FR-ANSWER-003/005, ADR-003, Architecture (ответ в `web`), canon §4 — правки на месте |
| Параллельные фичи | `widget-ask-handler.ts` — одна ветка `case`, ворота `not_verified` не тронуты; миграция 013 ДОБАВЛЯЕТ значение к текущему CHECK |
| Цена правила | распознаватель — словарь: реплика вне словаря («хаюшки») получит «не знаю по сайту», а не приветствие; ошибка в эту сторону безопаснее ложного шаблона на вопрос |

Вердикт: 🟢 к реализации.
