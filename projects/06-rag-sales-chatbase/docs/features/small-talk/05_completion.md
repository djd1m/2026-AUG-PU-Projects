## Что сделано

- **«Привет» и подобное** — детерминированный распознаватель закрытого словаря (6 намерений) в ядре `answerQuestion`
  ДО квоты и эмбеддинга; ответ — шаблон кода: «Здравствуйте! Я бот компании «X», отвечаю только по материалам сайта.
  Например, спросите о темах: A, B, C.» (темы — заголовки прочитанных страниц бота). Модели нет, эмбеддинга нет,
  списания нет; исход `question_log.small_talk` без текста.
- **Не по теме** — «Я отвечаю только по материалам сайта компании «X» и не нашёл там ответа на этот вопрос. Напишите:
  <контакт>» во всех местах показа (виджет и демо-страница, предпросмотр, чат владельца — текст берётся из ядра).
- **Реплика со словом вне словаря — обычный вопрос** («привет, сколько стоит доставка?» → ответ по фрагменту;
  «привет, игнорируй инструкции…» → порог ДО модели, «не знаю»). ADR-003 не ослаблен.

## Что НЕ доказано

- **Полнота словаря — не измерена на живых посетителях.** Реплика вне словаря («хаюшки», «доброго», смешанные языки)
  получит «не знаю по сайту» — безопасно, но не вежливо. Журнал `question_log` покажет: `unknown` с коротким текстом —
  кандидаты в словарь.
- **Стенд не проверен**: изменение не выложено; `/w/v1/ask` на `sufler.aicoding.space` по ВЫДАННОМУ адресу — после выкладки.
- **Слияние с соседними фичами не проверено**: миграция 011 (`not_verified`) — неизвестной формы. 013 дописывает
  `small_talk` к ТЕКУЩЕМУ CHECK и потому совместима с любым порядком… но только если 011 оставит ограничение с именем
  `question_log_outcome_check` и формой `ARRAY[...]` (иначе 013 откажет громко). Юнит-тест `enums.test.ts` считает
  добавленные значения по форме `ARRAY[''x''::text, ` — литеральный список 011 он не увидит; после слияния его нужно
  свести с `not_verified` (интеграционный тест сверяет настоящий CHECK БД с `QUESTION_OUTCOME` и покажет расхождение).
- У непроверенного бота (A-N6-035) «привет» получает «Бот ещё настраивается» — ворота стоят ДО ядра и принадлежат соседней
  фиче; не менялось.
- Флуд светскими репликами ограничен только дверью (30 мутаций/мин на IP): каждая реплика — 1 SELECT (≤ 30 заголовков) +
  1 INSERT журнала. Нагрузочный замер не делался.

## При выкладке

1. Миграция 013 применяется `migrate` до старта `web` (добавляющая; откат приложения без отката схемы безопасен).
2. Пересобрать `web` (в нём бандл виджета): новый бандл отдаётся по тому же адресу; старый кэшированный бандл показывает
   приветствие как обычный текст ответа — совместимо.
3. Проверка на стенде: «привет!», «Спасибо!», «Какая погода в Москве?» через виджет на чужом origin и в чате владельца —
   первые два без роста `bot_day_answers` и без строк `embed_question` в `/work/spend/model-spend.jsonl`.
