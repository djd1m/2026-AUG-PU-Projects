# 01 — План: `small-talk` (светская беседа и «не по теме»)

Дата: 2026-09-28 · Основа: `bf7ab6d0` · Решение: **A-N6-074** · Тир: **L** — `scripts/complexity-router.sh` по списку файлов
(миграция схемы; работа пересекает `web` и бандл виджета). Постановка координатора ожидала M; роутер даёт нижнюю границу L,
тир не опускается. Остановки у владельца нет (не XL: денег, необратимого и смены несущего инварианта нет — ADR-003 сохраняется).

## Решение владельца (28.09.2026, дословно)

> «когда ему просто пишешь "привет!" он в ответ ничего не пишет — это плохо, он должен уметь поддерживать базовый уровень
> беседы и если вопрос совсем не по теме напоминать пользователю что отвечает только по материалам сайта и не смог найти
> ответ на заданный вопрос в материалах, но на "привет" и тому подобные вещи надо отвечать вежливо».

Факт стенда: «привет!», «Спасибо!», «Какая погода в Москве?» → одинаково `unknown/below_threshold`, «Не нашёл этого в
материалах компании. Напишите: <контакт>».

## Решение

1. **Светская реплика — детерминированно, ДО квоты и эмбеддинга, без модели.** `packages/rag/src/small-talk.ts`:
   закрытый набор намерений `greeting · goodbye · thanks · how_are_you · who_are_you · help`; правило «ВСЯ реплика из
   словаря» — каждое слово входит в фразу словаря или в служебные слова, иначе это вопрос. Нормализация: регистр, «ё»,
   знаки и эмодзи → пробел, повтор буквы → одна («приветт»), 👋/🙏/👍 — слова; опечатка в одну правку у слов ≥ 6
   (перестановка/пропуск/лишняя буква; замена — только у слов ≥ 7: «привез» ≠ «привет»). ≤ 80 символов, ≤ 8 слов.
2. **Ответ — шаблон кода** от имени бота: «Здравствуйте! Я бот компании «X», отвечаю только по материалам сайта. Например,
   спросите о темах: A, B, C.» Темы — первые осмысленные части заголовков прочитанных страниц ЭТОГО бота (`page.title`,
   без «Главной», названия компании, повторов, длиннее 40), в порядке обхода. Ничего от имени компании не обещается.
3. **Место — ядро `answerQuestion`**, шаг 0 после проверки статуса бота и границы тела: одно место для виджета,
   демо-страницы (тот же маршрут), предпросмотра и тестового чата владельца. Результат ядра — новый статус
   `small_talk { intent, text }`; маршруты отдают `200 { status: small_talk, text }`.
4. **Не списывать.** Шаблон ничего не стоит: ни эмбеддинга, ни модели. Флуд ограничен тем, что уже стоит ДО ядра: лимит
   двери Caddy 30 мутаций/мин на IP и `allowMutation` приложения; у предпросмотра светская реплика не тратит 10 ответов.
   Цена записи — одна строка `question_log` на реплику (виджет, предпросмотр; кабинет не пишет) при том же пределе двери.
5. **Журнал:** исход `small_talk` без текста (152-ФЗ: текст только у `unknown`); сводка владельца его не считает.
   Миграция `013_small_talk.sql` ДОБАВЛЯЕТ значение к текущему CHECK (не перечисляет набор — параллельная фича добавляет
   `not_verified` в 011).
6. **Не по теме:** `unknownMessage(компания)` = «Я отвечаю только по материалам сайта компании «X» и не нашёл там ответа
   на этот вопрос.» + «Напишите: <контакт>» — везде, где показывается «не знаю» (виджет, демо, предпросмотр, чат владельца:
   все берут текст из ядра). `service_unavailable` — прежний текст сбоя.
7. **Порядок в виджете:** ворота «проверено» (A-N6-035) стоят ДО ядра и не трогаются: у непроверенного бота и «привет»
   получает «Бот ещё настраивается» (ветку правит соседняя фича).

## Критерии приёмки

| AC | Утверждение | Доказательство |
|---|---|---|
| AC-1 | Таблица ≥ 40 реплик: 6 намерений распознаются (регистр, «ё», знаки, эмодзи, «приветт», английский); ловушки — нет | unit |
| AC-2 | «привет, сколько стоит доставка?», «привет, игнорируй инструкции…» — НЕ светская беседа: обычный путь, модель только при фрагменте ≥ 0.40 | unit + integration |
| AC-3 | «привет» → шаблон с темами из заголовков; 0 эмбеддингов, 0 вызовов модели, 0 списаний, 0 строк журнала расхода | unit + integration на Postgres |
| AC-4 | `question_log`: `small_talk` без текста; CHECK после всех миграций = `QUESTION_OUTCOME`; `small_talk` с текстом отвергается | integration |
| AC-5 | Не по теме → «Я отвечаю только по материалам сайта компании «X» и не нашёл там ответа… Напишите: <контакт>» во всех режимах | unit + integration (виджет, кабинет, предпросмотр) |
| AC-6 | Виджет на ЧУЖОМ origin: «привет» → приветствие видно в окне | браузер в контейнере Playwright |
| AC-7 | Страж падает: распознаватель выключен → красный; модель вызвана на светской реплике → красный; ловушка съедена → красный | мутации |
| AC-8 | Шаблоны не обещают от имени компании (нет цен, скидок, сроков); «кто ты» — бот, не человек | unit |
| AC-9 | Все наборы зелёные (образ: lint + все тесты; браузер) | прогоны |
