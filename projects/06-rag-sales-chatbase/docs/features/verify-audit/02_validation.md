## Сверка — найдено

1. **Двойной клик на баннере.** Баннер исчезает после отметки, и второй клик попадает в то, что под ним — источники с
   «Обновить» без подтверждения; «Обновить» снимет отметку новыми фрагментами. Добавлен AC-11.
2. **Старая вкладка после выкладки.** Прежний бандл шлёт `{ verified: !verified }` — снятие без подтверждения прошло бы.
   Отсюда AC-6 (сервер требует `confirm: true`); установка отметки `confirm` не требует — старая вкладка ставит как раньше.
3. **Стирание аккаунта:** события уходят каскадом вместе с ботом (ПДн в них нет) — реестр `tests/account-erasure` получает
   строку `erase`; служебный список таблиц — `bot_verification_event`.
4. **Рост журнала:** событие только на ПЕРЕХОДЕ; переходов не больше, чем действий владельца и вставок фрагментов после
   отметки (одна строка на оператор вставки при стоящей отметке). Предел не нужен.
