## Чего фича НЕ доказывает

1. **Фрагментов и эмбеддингов нет** (`chunk-embed`): страница PDF пишется в `page` с `content_hash` БЕЗ текста и
   фрагментов; задача закрывается `done`. Текст страницы живёт только в памяти воркера на время задачи, файл после
   неё удаляется — значит `chunk-embed` ОБЯЗАН резать и эмбеддить в той же транзакции страницы
   (`pdf-processor.ts`), иначе после `done` восстановить текст будет не из чего. «Ответ ссылается на «прайс.pdf,
   с. 3»» (SC-US-004-1 целиком) — не доказан.
2. **«Повторить» PDF после завершения даёт `failed(internal)`**: файл удалён по ADR-018. Маршрута «Повторить» всё
   ещё нет; экран обязан предлагать новую загрузку, а не повтор (A-N6-027 п.7).
3. **Закрытый список причин не расширен** (A-N6-027 п.3): таймаут и нехватка памяти показываются как
   `too_large`, пароль — как `no_text_layer`. Подробный код — только в журнале воркера. Постановка называла
   `pdf_timeout` отказом задачи — в БД такой причины нет.
4. **Пределы разбора — числа агента** (30 с, 384 МБ RSS, 256 МБ кучи, 2 млн символов), не канон; на VPS не
   мерились, память контейнера `worker-index` не ограничена compose. Замер RSS опрашивается каждые 25 мс — всплеск
   между замерами может превысить 384 МБ.
5. **Тело загрузки держится в памяти `web`** (до 10 МБ + 64 КиБ на запрос, плюс копия при склейке); одновременные
   загрузки умножают это. Ограничены только дверью (30 мутаций/мин на IP) и сессией.
6. **Сирота при гибели воркера:** если процесс `worker-index` убит, дочерний разбор живёт до конца своей работы
   (таймаут исполняет родитель); в контейнере его убирает перезапуск контейнера, вне контейнера — нет.
7. **Реальных PDF не было**: все документы собраны в тесте (Helvetica, `/Differences`). Встроенные шрифты,
   CID/Identity-H, сжатые потоки объектов (PDF 1.5+), реальные прайсы на кириллице и сканы — не прогонялись; кириллица
   проверена одним способом кодирования.
8. **Добавление сайта этим маршрутом не подключено**: JSON `{ url }` → `422`; `CheckAddress` в `web` не вызывается
   (пункт 1 квитанции `crawler` остаётся открытым).
9. **`npm audit --omit=dev` не чист**: 1 high + 1 moderate (`next` → `postcss`) — были до фичи; pdfjs новых не
   добавил. Security «Pre-Deployment» требует ноль high — открыто.
10. **Стек целиком не поднимался**: связка Next ↔ `bullmq` (`serverExternalPackages`) проверена только сборкой;
    постановка в очередь из `web` в живом процессе не выполнялась. `check-job-contract.cjs` → **2** (`not-deployed`).
11. **Независимого ревью не было** (ни Sonnet 5, ни cross-family).
