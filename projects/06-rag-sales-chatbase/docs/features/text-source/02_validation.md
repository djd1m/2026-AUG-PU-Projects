# 02 — Валидация плана: `text-source`

Самопроверка исполнителя (как у `crawl-coverage`): отдельного агента-валидатора не было; независимую проверку несёт ревью
Codex (`08_review.md`). Вердикт: 🟢 READY с оговорками ниже.

| Проверка | Итог |
|---|---|
| AC проверяемы тестом, у каждого — набор | AC-1/2/3/6 — `tests/text-source.test.ts`; AC-4/5 — `tests/text-source.integration.test.ts`; AC-7 — `tests/browser/text-source.test.ts`; AC-8 — `scripts/test-text-source-mutations.mjs` + браузерная мутация |
| Порядок операций (ADR-010) | форма адреса → robots.txt (через `CheckAddress`) → файл через `safeGet` (`CheckAddress` после DNS и на каждом шаге, соединение по проверенному IP) → тип по заголовку ДО тела → размер по заявленному и принятому → тип по содержимому → разбор → эмбеддинги (квота ДО вызова). В web — `CheckAddress` ДО записи |
| Второй реализации проверок нет | `safe-get.ts`, `robots.ts`, `check-address.ts` вызываются, не копируются; меняется только `inScope` (может быть асинхронным) |
| Разделяемые ресурсы | тело файла ≤ 2 МиБ в памяти воркера (как страница краулера), один поток (`concurrency 1`); транзакции — по одной на раздел, сеть (эмбеддинги) вне транзакции; соединение пула не держится на время загрузки |
| Деньги | эмбеддинги — прежний `EmbedAndStore` (квота + бюджет серии на КАЖДУЮ попытку); предел разделов (50/300) ДО эмбеддинга; неизменный раздел — 0 вызовов |
| Три состояния задачи | идёт «k из N разделов файла» / готово (с пометкой `page_budget` при пределе) / отказ с причиной из закрытого набора (+ `not_text`) |
| Закрытые наборы расширены, не заменены | DO-блок дописывает значение к ТЕКУЩЕМУ `ARRAY[…]`; ограничение без `ARRAY[…]` — отказ миграции; `enums.test.ts` сверяет 001 + дописанное с кодом, интеграционный тест — действующий CHECK базы |
| ПДн | в журнал — только счётчики и код отказа (ни адреса, ни текста файла) |

Оговорки (не блокеры): предел 2 МиБ при файле aicoding.space 1 917 396 байт — запас 9 %; плашка ведёт на `файл#якорь`, а не на
страницу сайта (решение владельца «не выдумывать»); Markdown, начинающийся с HTML-тега, — `not_text` (fail-closed).
