## Что доказано и чем

- **AC-1** разбор: `#`/`##` — разделы, `###` — `context_path`, блок кода не делит, пустой `#` не раздел, якоря уникальны
  (в т.ч. «A, A, A-1»), 20 000 одинаковых заголовков — 0,4 с.
- **AC-2** 12 адресов Refinement (петля, 10/8, 172.16/12, 192.168/16, метаданные 169.254.169.254, CGNAT, 0.0.0.0, `::1`,
  ULA, link-local, имя → 10.0.0.5, перенаправление → 127.0.0.1) — `blocked_address`, соединений только с проверенным
  публичным адресом, файл не запрошен; схема/порт/учётные данные — отказ без DNS; robots запрет — файл не запрошен; robots
  5xx — `unreachable`; перенаправление на запрещённый путь — ни своего, ни `www.`-варианта — не запрошено.
- **AC-3** `text/html` — `not_text`; `text/plain` с HTML в начале (включая `<div>`, 3000 пробелов перед `<html>`) — `not_text`;
  JSON — `not_text`; ровно 2 МиБ — принят; +1 байт по заявленному и потоком — `too_large`; 404 — `unreachable`.
- **AC-4** на настоящем Postgres: `done`, строки `page` `…/llms-full.txt#раздел-N`, `context_path` «Компания › Раздел 2 ›
  Подробности», `content_bytes`/`content_sha256`; кабинет видит `text`; 55 разделов на free — `page_budget`, 50 из 55, пять
  примеров `путь#якорь`, раздел 51+ не эмбеддится. Отказы `not_text` / `too_large` / `blocked_address` — без эмбеддингов.

## Что НЕ доказано

- **На стенде не прогонялось** (стенд, основное дерево и прокси не трогались): настоящий `https://aicoding.space/llms-full.txt`
  не индексировался. Вывод о нём — из замера `curl` 28.09 (1 917 396 байт, `text/plain; charset=utf-8`, robots `Allow: /`,
  `#` — 5, `##` — 54, `###` — 576) и фикстур. Ожидаемо на free: ≈ 55 разделов → 50 прочитано, `page_budget`; бюджет серии
  500 000 токенов может усечь раньше (`series_embed_budget`) — сколько токенов даст файл, не измерено.
- **Запас по размеру 9 %:** файл вырастет на ~180 КБ — отказ `too_large` (владелец увидит «Файл больше 2 МБ»).
- Совместимость с миграцией 014 соседа не проверена (её нет в основе): 015 не трогает `question_log`/`bot` и дописывает к
  текущему набору, но совместный прогон — при сведении.
- Конкурентный тест фенса записи `content_bytes` не выполнялся (порядок «прогресс с фенсом → запись» в одной транзакции — по
  коду и ревью).
- Отправка формы в браузере (`TextSourceAdder` → запрос → обновление списка) не проверена браузером: набор рендерит разметку;
  маршрут проверен unit-тестом обработчика.
- Плашка ответа ведёт на `файл#якорь`: файл открывается, но якоря в `.txt` браузер не прокручивает — посетитель видит начало
  файла. Адрес страницы из строки `Адрес:` раздела не используется (решение «не выдумывать»; кандидат в BACKLOG).
- Markdown, начинающийся с HTML-тега (например README с `<p align="center">`), — `not_text` (осознанная цена).
