## Риски плана

- **Тома PDF.** Файл `uploads/<index_job_id>` удаляется после done и failed (ADR-018), но задача, убитая посреди работы,
  может оставить файл; шаг 2 сторожа удаляет каталог задачи явно, `deleted` — только после (N4 RV-02).
- **Надгробная строка `account`.** Физически строка не удаляется (ссылки `commission_entry … RESTRICT` и платежи);
  уникальность почты освобождается подменой `email → deleted:<id>`. Проверка: регистрация на ту же почту после `deleted` (AC-5).
- **Сторож один на платформу.** Стирание большого аккаунта (1 млн фрагментов) — пачками через `deleteSource`, без длинной
  транзакции; замер — вне теста (NFR-SCALE-001 перенесён фичей 16).
- **Самопроверка.** Независимого валидатора не было; ревью Codex — после реализации.
