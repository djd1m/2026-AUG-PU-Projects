### Что работает (проверено на стенде по выданному адресу)

- **Предпросмотр до регистрации:** адрес сайта → бот за ~15–25 с; при исчерпании бюджета — честное усечение
  «Прочитано N страниц» (aicoding.space: 15 из 20 при бюджете 120 000, A-N6-053); ответ НАСТОЯЩЕЙ модели с плашкой
  источника.
- **Кабинет:** боты, источники (сайт/PDF) с лентой стадий, «Обновить» без повторной оплаты неизменных страниц,
  удаление источника с фрагментами, тестовый чат, отметка «Я проверил ответы бота», баннер лимита.
- **Виджет на чужом сайте:** один `<script>`, Shadow DOM; на чужом origin под строгим CSP и враждебным CSS в Chromium,
  Firefox и WebKit — ответ с источником, стили хозяина не задеты; origin вне списка — 403 (`check-embed-contract` → 0).
- **Долгая задача индексации:** три состояния по `index_job_id`, повтор с тем же ключом — та же задача
  (`check-job-contract` → 0).
- **Демо-страница `/b/{slug}`**, вход по бейджу `/?from=`, сводка «ответил / не знал».
- **Тарифы 990 / 4 900 ₽ и оплата ЮKassa** — код готов и протестирован на поддельном провайдере; стенд в режиме `off`
  (экран интереса) до магазина владельца.
- **Партнёры и студии:** `/r/{код}` с подписанной cookie 30 дней, анти-накрутка, комиссия 20 % / 12 мес / холд 30 дн,
  выплаты от 1 000 ₽ командой оператора, кабинеты, передача бота клиенту.
- **Удаление аккаунта по 152-ФЗ:** запрос с паролем → сессии, боты и виджет гаснут сразу; сторож стирает после тихого
  часа (≤ 72 ч); почта → `deleted:<id>`; платёжные записи — 5 лет обезличенно; деньги партнёра — долг, не сгорают.

## Исходное резюме Phase 1 (25.09.2026)

Дата: 2026-09-25 · Phase 1 (sparc-prd-mini, AUTO, владелец спит) · CJM H — временно (A-N6-008).

## Overview
«Суфлёр» — клон Chatbase для малого бизнеса РФ: адрес сайта и PDF превращаются в бота, который
отвечает посетителям только по этим материалам, под каждым ответом показывает источник и говорит
«не знаю» с контактом компании, когда ответа нет. Бот ставится на сайт одной строкой `<script>`.
Бесплатный план несёт бейдж «Работает на Суфлёре» — это основной канал роста. Вектора живут в нашем
Postgres (pgvector), модели — через шлюз OpenRouter.

## Problem & Solution
**Проблема:** вопросы посетителей приходят, когда ответить некому; ответы уже есть на сайте и в
прайсе. РФ-конкуренты продают ИИ модулем за 12–13 тыс ₽/мес без бесплатного входа.
**Решение:** путь «URL → живой бот» до регистрации, ответ со ссылкой на фрагмент, двойной барьер
против выдумки (порог сходства до модели + проверка цитат после), бейдж на free.

## Target Users
**Primary:** владелец малого бизнеса с сайтом (S1). **Secondary:** веб-студии, ставящие сайты
клиентам (S2) — канал с мультикабинетом и переносом бота.

## MVP Features
1. **Бот из сайта и PDF с источником в каждом ответе** — доверие владельца: бот не врёт от его имени.
2. **Предпросмотр до регистрации + виджет одним тегом** — время до ценности ≤ 5 мин (p50).
3. **Бейдж, демо-страница, коды студий** — петля роста и канал с первого дня.

## Technical Approach
- **Architecture:** Distributed Monolith, 6 сервисов compose (`proxy`, `web`, `worker-index`, `db`,
  `redis`, `migrate`) на одной VPS.
- **Tech Stack:** Next.js 15, Node 22, Postgres 16 + pgvector 0.8.6 (`vector(1536)`, HNSW), Redis 7.4 +
  BullMQ, Caddy 2.8; OpenRouter: `openai/text-embedding-3-small`, `anthropic/claude-haiku-4.5`.
- **Key Differentiators:** «не знаю» вместо выдумки как @security-инвариант; бесплатный вход с
  бейджем, снятие бейджа — видимая строка плана; студии с переносом бота клиенту.

## Research Highlights
1. Chatbase: $10M ARR (03.2026), бейдж снимается аддоном $99/мес, white-label только Enterprise [F/S].
2. Jivo 12 990 ₽ за 2000 диалогов, Carrot quest 12 000 ₽ за 1000 вопросов — ИИ как дорогой модуль [F].
3. Посетители кликают на источник в AI-ответе ≈ 1 % визитов — плашка компактна, цитата — владельцу [S].
4. OpenAI API не обслуживает РФ; OpenRouter отдаёт `text-embedding-3-small` ($0,02 за 1 млн токенов) —
   маршрут эмбеддингов через шлюз, запасной путь назван (ADR-002) [F].
5. pgvector индексирует HNSW только до 2000 измерений у `vector` — 1536 проходит, 3072 нет [F].
