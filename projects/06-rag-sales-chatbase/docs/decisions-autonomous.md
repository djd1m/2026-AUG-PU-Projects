# N6 — решения, принятые без владельца

Режим: владелец спит, конвейер идёт автономно (память «Автономия, когда владелец ушёл»). Здесь
каждое решение, которое по регламенту принимает человек, но было принято агентом, — с причиной и
условием отмены. Необратимого ничего не делалось: нет коммитов, нет внешних действий, нет денег.

Исполнитель: Claude Opus 5.5 (агент Phase 0 / 0.5). OpenAI/Codex как исполнители не вызывались
(OWN-017: только Anthropic с 25.09.2026).
