# Стандарты реализации ClipMkr (05a)

Сначала прочитать `.claude/rules/coding-style.md` и нужный алгоритм в `docs/Pseudocode.md`. Для
изменений схемы, транзакций, границ доверия и внешних вызовов дополнительно
`.claude/rules/security.md`, `docs/Architecture.md`/`docs/Architecture-compose.md` и применимый
ADR. Для любого изменения admission/quota/spend — `.claude/agents/cost-guard.md` ОБЯЗАТЕЛЬНО.

## Девять обязательных образцов

1. **Внешнее значение разбирается из `unknown` через схему**, а не приводится типом. Относится к
   телу HTTP-запроса, ответу STT/LLM-провайдера и результату `ffprobe`.
2. **Диапазоны проверяет наш код после разбора.** OpenRouter structured outputs гарантируют тип и
   форму, но Anthropic НЕ поддерживает `minimum`/`maximum`/`multipleOf`/`minLength`/`maxLength` в
   этих схемах (ADR-005 п.4) — их проверяет код: `confidence` не запрашивается вовсе (модель
   отвечает индексами), баллы 0–40/0–40/0–20, ≤ 10 фрагментов, длина строк.
3. **Фрагмент задаётся индексами `start_unit`/`end_unit`, не миллисекундами.** Модель не может
   выдумать таймкод — миллисекунды считает код из уже известных границ единиц транскрипта.
4. **Разделяемый ресурс правится ОДНИМ оператором.** Резерв потолка, идемпотентный ключ, аренда
   рендера — `INSERT … ON CONFLICT …` и условная проверка `RETURNING`. Никакого «прочитать, потом
   записать»: две попытки приходят ОДНОВРЕМЕННО, обе видят свободный остаток, обе не должны
   пройти обе.
5. **Транзакция не держит внешний вызов.** Резерв потолка закрывается ДО обращения к OpenRouter/
   S3; факт стоимости пишется короткой транзакцией ПОСЛЕ ответа.
6. **Владение резолвится на сервере** из сессии; чужой ресурс отвечает `404`, тем же ответом, что
   и несуществующий.
7. **Закрытые перечисления — union-типы.** Значение вне набора трактуется как самое строгое:
   `account.plan` → `free`, `account.role` → `user`, статус вне закрытого списка — недопустимое
   состояние, не дефолт «на всякий случай».
8. **Отсутствие числа показывается как отсутствие.** `unmatched`/цитата без совпадения —
   «компонент без балла»; ноль знаменателя метрики — «нет данных», не `0%`.
9. **Внешний сервис — за адаптером.** У `Transcriber` и `SelectionModel` — боевая и запасная
   реализация (`OpenRouterTranscriber`/`OpenAiTranscriber`), у `PaymentProvider` — фейк и два
   боевых (v1). Тесты не ходят в интернет боевыми ключами; живой режим включается ключом и
   помечается отдельно.

## Порядок шагов в конвейере (принадлежит защите, не удобству)

`POST /api/videos` → `…/complete` (`EnqueueScan`-аналог, «Завершение загрузки»):

```
подтверждение почты → лимит частоты → размер ≤ 2 ГБ → РЕЗЕРВ лимита загрузок (на POST /api/videos,
НЕ на complete, VT-17) → выдача подписанных ссылок → PUT частей браузером → complete
(Idempotency-Key) → HeadObject + magic bytes → job (running, transcribing) → 202 {job_id}
```

«Транскрипция куска» (шаг 1 — ВОРОТА ДОПУСКА, VA-01): `IF c.attempt_count = 0 AND нет отметки
допуска THEN admit_stt(job_id)`; отказ → `RETURN`. Это единственное место, где резервируется
STT — «Повтор задачи» ПОЛАГАЕТСЯ на эти ворота, а не проверяет их сам.

«Допуск STT» (шаг 2a — ВЫПОЛНИМОСТЬ LLM, до резерва STT самого): `est_kop ←
llm_reserve_kop(video.duration_ms, LLM_EST_CHARS_PER_SEC)`; `est_kop > LIMIT_LLM_KOP_JOB` →
`quota_user` немедленно; иначе сверить остатки автора/сервиса. Пройдено → шаг 3 резервирует
секунды STT (два разных счётчика — персональный по записи, глобальный по провайдеру,
плюс пул новичка при `is_newbie`).

«Выбор фрагментов LLM», шаг 7: проверить `finish_reason == 'length'` ДО `JSON.parse` — обрубленный
ответ иначе бросает исключение разбора и уходит в обычный повтор BullMQ с тем же `max_tokens`
(V3-11а).

## Единицы, время, имена

Мс — позиция/длительность клипа. Секунды — счётчики STT (две разные формулы, см.
`coding-style.md`). Копейки — деньги (целое, без плавающей точки). Граница суток для ВСЕХ
счётчиков — `msk_day(now())` в момент попытки, не `job.created_at` (VT2-11). Имена — из
`docs/canon.md`, переименование фиксируется в плане фичи.

## Миграции

Prisma-схема канона §4: `account`, `email_token`, `refresh_token`, `video`, `job`,
`transcript_chunk`, `clip`, `quota_counter`, `spend_ledger`, `event`, `publication`, `partner`,
`attribution`, `audit_log`. Уникальность и потолки — база, не код. Частичные уникальные индексы
под `event` — четыре штуки (см. `coding-style.md`), не общий уникальный индекс на всю таблицу.

## Перед тем как назвать команду

Точные версии, пути workspace и npm-скрипты фиксирует фича `foundation-auth` и подтверждает
исходник. До этого команда из документа — предложение, а не факт.
