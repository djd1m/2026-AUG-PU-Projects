## Продукт и актёры

ClipMkr превращает длинную русскоязычную запись (подкаст, интервью) в короткие вертикальные клипы
1080×1920 с вшитыми субтитрами-фразами (подпись говорящего), объяснимой оценкой потенциала (хук,
завершённость, длина — и почему) и полупрозрачным знаком `clipmkr.ru` на бесплатном плане. Рост —
content-driven: клип со знаком публикует сам автор, зритель видит знак и приходит (CJM Variant A,
OWN-05A-001). **Оценка потенциала не создаёт виральность** — это предсказательный инструмент для
автора, не механизм роста; продукт растёт за счёт опубликованного клипа со знаком, не за счёт
скора (PRD §2.3, постановка).

| Актёр | Кто это | Что делает |
|---|---|---|
| Подкастер (первичная персона) | ведущий аудио/видео-подкаста, выпуски 40–120 мин | загружает выпуск, смотрит клипы с объяснением, публикует со знаком |
| Эксперт/автор вебинаров (вторичная) | совмещает роль спикера и маркетолога | знак неприемлем при платном продвижении — вероятный покупатель снятия знака, его клик fake-door — сигнал спроса |
| Зритель знака | увидел клип на чужой площадке | по адресу со знака или по ссылке в подписи находит продукт |
| Оператор | владелец продукта | проверяет ссылки на публикации, выдаёт коды партнёрам и роль, смотрит расход |

**Анти-персоны недели** (для кого неделя НЕ делается, PRD §3.3): SMM-агентство (нужны командные
тарифы), стример с 3–6-часовыми эфирами (выпуск длиннее 120 мин), автор, которому нужен
автопостинг по расписанию.

## Словарь, который не пересогласовывается

| Термин | Значение |
|---|---|
| Клип | отрендеренный вертикальный фрагмент 20–90 с |
| Знак (watermark) | текст `clipmkr.ru`, вшитый в пиксели каждого кадра на плане `free` |
| Момент ценности | автор досмотрел первый клип до 50 % или до конца (`clip_viewed`) |
| Paste-back | ссылка на пост с клипом, которую автор вернул в продукт |
| Fake-door | экран плана «без знака» (2-я очередь): клик фиксирует спрос, оплаты нет |
| `i` | подтверждённые внешние клипы на активированного автора |
| `conv%` | доля активированных авторов с ≥1 подтверждённой публикацией; при n < 30 — «k из n» |
| Активированный автор | автор с ≥1 `clip_viewed` |
| Новичок | аккаунт младше 24 ч без `account.beta_at` (OWN-05A-016) — квота 30 мин, не 120 |
| Попытка | ОДИН вызов модели, включая эскалацию/повтор куска, таймаут и отказ провайдера |
| `unmatched`/`speaker_map_confident=false` | недостаточная уверенность: позиция исключается из итога / подпись спикера не печатается — а не заменяется угадыванием |

## Границы недели (первая очередь, ядро)

**Входит** (PRD §1.2, OWN-05A-014): регистрация email+подтверждение; загрузка ≤ 2 ГБ/≤120 мин,
≤3/сутки; транскрипция с диаризацией; выбор 0–10 фрагментов LLM; объяснимая оценка; рендер со
знаком; скачать/поделиться + подпись к посту со ссылкой; paste-back с ручной проверкой оператором;
`/admin/publications`, `/admin/metrics`; партнёрские коды (`ops partner-add`), расход (`ops
spend-today`), сброс пароля (`ops reset-link`), отметка беты (`ops beta-add`); потолки расходов.

**2-я очередь** (не блокирует метрику недели): веб-страница сброса пароля на `/admin/users`,
`/admin/partners`, `/admin/spend`, экран fake-door (`/plans`, `POST /api/fakedoor`).

**НЕ входит вовсе** (PRD §1.2): автопостинг, brand kit, командная работа, распознавание лиц/
автофрейминг, шоуноты и посты, настоящая оплата, выплаты партнёрам, `invite_code`, загрузка по
URL, аудио без видео, редактор границ клипа, публичные страницы клипов, калькулятор объёма,
отзывы на лендинге, караоке-субтитры (OWN-05A-003), размытый фон и ручной сдвиг кадра
(OWN-05A-008).

## Метрика недели и числа канона

**Метрика недели** (OWN-05A-002): ≥ 5 уникальных клипов со знаком в статусе `confirmed` на 7-й
день от ≥ 3 разных авторов (считается по `min(accounts, channels)`, V3-18). Считается из НАШЕЙ БД
(`publication`), не из внешнего API площадки. `i` и `conv%` — рядом, без цели (n < 30).

Девять потолков (canon §6): 120 мин STT/автор/сутки (30 мин новичку первые 24 ч, пул новичков
≤ 750 мин); 3 загрузки/автор/сутки; 50 ₽ LLM/автор/сутки, 24 ₽/задача; 1500 мин STT и 300 ₽ LLM на
сервис в сутки. Выполнимость LLM проверяется на допуске, ДО оплаты STT (OWN-05A-012). Себестоимость
часа — ориентир 40–100 ₽/час (R1 M4.A), не измерено.
