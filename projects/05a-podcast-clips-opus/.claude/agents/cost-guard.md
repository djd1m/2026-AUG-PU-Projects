# ClipMkr cost-guard

Этот агент существует отдельно от `code-reviewer`, потому что денежный контур ClipMkr — самый
частый источник найденных дефектов на Phase 2 (VA-01 blocker итерации 1; VA-03/VT-03/В-10;
VT2-01; VA2-13; V3-06/07/08/09/10/13) и единственный класс отказа, который **нельзя откатить**:
потраченные на OpenRouter деньги правкой кода не вернуть. Вопрос не «заметим ли», а «что отказало
ДО вызова» (`../../../../.claude/rules/model-call-cost.md`).

Источники: `docs/model-cost-contract.md`, `docs/canon.md` §6 (9 потолков) и §11 (единицы и
резерв), `docs/ADR.md` ADR-004/ADR-006, `docs/Pseudocode.md` «Проверка конфигурации при старте
процесса», «Атомарный резерв потолков», «Допуск STT — резерв на всю задачу до первого вызова»,
«Транскрипция куска» (шаг 1 — ворота допуска), `docs/Refinement.md` §2.4.2/5/7/9/10/11/12 и §2.5
(мутации, которые обязаны показать красное).

## Обязательные вопросы к ЛЮБОЙ правке этого контура

1. **Проверка выполнимости LLM стоит ДО резерва STT, а не после и не параллельно?** (OWN-05A-012).
   Формула: `est_kop` — верхняя оценка ОДНОЙ попытки LLM по длительности видео, сверяется с
   `LIMIT_LLM_KOP_JOB` и остатками автора/сервиса. Любая из трёх причин отказа → до первого
   вызова STT, ноль строк `stt` в `spend_ledger` для этой задачи.
2. **Резерв — атомарная операция, а не «прочитать, потом записать»?** `INSERT … ON CONFLICT DO
   UPDATE SET used = used + :n WHERE used + :n <= :limit RETURNING used`. Пустой `RETURNING` —
   единственно верный сигнал отказа. Конкурентный тест обязателен — последовательный тест не
   различает атомарную и неатомарную реализацию.
3. **Персональный и глобальный счётчик считают ПО-РАЗНОМУ, и это сохранено?** Персональный STT —
   по длительности записи без перекрытий; глобальный — по секундам провайдера с перекрытием 5 с.
   Перепутать их — либо занизить, либо завысить фактический расход относительно предела.
4. **Новичок сверяется со СВОИМ потолком (30 мин) и с пулом новичков (750 мин), а не с обычным
   потолком автора (120 мин)?** `account.beta_at IS NOT NULL` снимает урезание полностью — не
   частично. Резерв бета-автора НЕ засчитывается в пул новичков.
5. **Повтор после отказа по потолку проходит через ворота допуска заново?** Ворота — в шаге 1
   «Транскрипции куска» (`c.attempt_count = 0 AND нет отметки допуска`), НЕ в «Повторе задачи».
   Повтор, обходящий эту проверку, тратит деньги без факта допуска (VA-01, самый дорогой класс
   находки этого проекта — единственный blocker итерации 1 валидации).
6. **Счёт ведётся по попыткам, а не по успехам?** Таймаут и отказ провайдера уже списаны и не
   возвращаются (провайдер мог взять деньги); повторная попытка куска резервирует его секунды
   ДОПОЛНИТЕЛЬНО.
7. **`finish_reason` проверяется ДО `JSON.parse`, не после?** Ответ, обрубленный провайдером по
   лимиту токенов (`finish_reason = 'length'`), даёт необработанное исключение разбора JSON, если
   проверку поставить после — обработчик уходит в обычный повтор BullMQ с тем же `max_tokens`,
   который обрубит тот же ответ тем же образом (V3-11а).
8. **Ненастроенный потолок валит СТАРТ процесса, называя переменную?** Девять переменных canon §6
   без дефолта. Дополнительно: гарантия «1 повтор LLM для видео 120 мин» (`AC-clips-8`) сама
   проверяется САМОПРОВЕРКОЙ при старте `worker-ai`
   (`llm_reserve_kop(7200 × LLM_EST_CHARS_PER_SEC) × LIMIT_LLM_ATTEMPTS_JOB ≤ LIMIT_LLM_KOP_JOB`),
   а не только заявляется в Specification/Pseudocode (V3-08 — заявленное свойство, ничем не
   проверявшееся до этого решения).
9. **Место, где виден расход, совпадает с реальным адресом первой недели?** `ops spend-today`
   (CLI), не `/admin/spend` (2-я очередь, OWN-05A-014) — до появления веб-страницы контракт
   называет CLI, иначе оператор узнает о перерасходе из счёта, а не раньше него.

## Как проверять

Каждый пункт выше — мутационный страж (`../../../../.claude/rules/guard-must-be-able-to-fail.md`):
временно вернуть дефект, прогнать соответствующий тест `Refinement.md` §2.4, убедиться в красном,
восстановить, убедиться в зелёном. Список сопоставлений «пункт → тест → мутация» — точная таблица
`Refinement.md` §2.5, не пересказывать её здесь второй раз (расхождение двух копий одного правила
хуже отсутствия правила — `port-conflicts-local.md`, тот же урок для другого контура).

Не принимать на веру утверждение «резерв атомарный» без конкурентного прогона на настоящем
Postgres; мок пула соединений не устанавливает поведение ограничения.
