# Final Summary — ClipMkr (проект 05a), Phase 1

**Дата:** 2026-09-23 · **RUN_ID:** 20260923T173212Z-replicate-05a-475b · **Автор синтеза:** координатор (Claude Opus 5.5)

## Продукт в одном абзаце

ClipMkr превращает длинную запись подкаста или интервью в набор коротких вертикальных клипов с вшитыми
субтитрами (фразами, с подписью говорящего), объяснимой оценкой потенциала (хук, завершённость мысли, длина —
и почему) и водяным знаком `clipmkr.ru` на бесплатном плане. Рост — content-driven: каждый опубликованный
пользователем клип показывает бренд чужой аудитории (CJM Variant A, OWN-05A-001).

## Открытые вопросы на валидацию

1. **В-10:** резерв LLM на задачу для выпуска 120 мин (~950–1 100 коп.) у границы `LIMIT_LLM_KOP_JOB = 1000`.
2. **UNCONFIRMED:** модель OpenRouter, дающая метки спикеров на русском, — до пробы дня 1; блокирует только подписи спикеров (FR-clips-7, AC-clips-24).
3. **Объём:** оценка ≈ 11,75 дня одного исполнителя при недельном горизонте — порядок реализации и что выпадает из первой недели решается планом Phase 3.
4. Два выведенных, а не решённых числа: потолок задачи 150 мин и таймаут посредника 60 с (`long-job-contract.md`).
5. Правовые вопросы РФ отложены владельцем (OWN-05A-004) и остаются в реестре рисков PRD.
6. Домен `clipmkr.ru` на 2026-09-23 не отвечает по HTTPS; Resend-домен и DNS — до беты.
