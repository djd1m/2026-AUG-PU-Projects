## Решения, принятые мной (для проверки на СТОП 2)

1. Регистрация по email обязательна до загрузки: без неё персональный потолок расходов не к чему привязать и нельзя различить «≥3 автора». Подтверждения email на неделе нет; обход через новые аккаунты упирается в глобальный суточный потолок; сброс пароля делает оператор.
2. Кнопки «Скачать/Поделиться» активны сразу, после `clip_viewed` только выделяются (в прототипе CJM были заблокированы до просмотра). «Поделиться» = Web Share API с файлом; где отправка файла не поддерживается, остаётся только «Скачать».
3. Оценка: хук 0–40 и завершённость 0–40 (LLM, с цитатами), длина 0–20 (код, детерминированно). Цитаты сверяются с текстом фрагмента; без проверенного объяснения итоговое число не показывается.
4. Подставные моменты донора (`generateFallbackMoments`) запрещены: после двух невалидных ответов задача получает `failed/selection_failed`.
5. Исходник 16:9 вписывается по ширине, поля заполняются размытой копией кадра, центр-кроп не используется (он срезал бы собеседника). Раскладка: знак y=200, видео y 420–1028, субтитры y 1100–1460, x 80–900.
6. Знак: непрозрачная плашка ≥0,85, 1–4 % площади, кегль 44–52 px; расхождение с R2 (5–10 %, прозрачность 30–60 %) объявлено. Читаемость проверяет OCR после перекодирования в 720×1280 1,5 Мбит/с, порог ≥9/10.
7. Адрес со знака ведёт на путь `/w`: так переходы по знаку отделяются от прочих визитов (сигнал C из R2).
8. Paste-back: закрытый список хостов, `instagram.com` исключён (38-ФЗ, CJM-R-11); сервер ссылки не открывает (нет SSRF и внешней зависимости), проверяет оператор; перепроверка на 7-й день.
