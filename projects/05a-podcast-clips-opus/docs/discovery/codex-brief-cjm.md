### 2. `docs/CJM_Variants.md` — варианты CJM
- **Не менее 3, рекомендую 4 варианта.** Каждый — раздел `## Variant X: <название>`.
- Варианты ОБЯЗАНЫ различаться по growth loop (один из: badge / content-driven / incentivized referral /
  sales / network effect). Три варианта с одним loop — дефект. Основной loop постановки — content-driven
  (watermark на free); он должен быть хотя бы в одном варианте, остальные — честные альтернативы.
- Для каждого варианта — таблица полей (строки начинаются `| **Поле** |`):
  `Aha Moment` (конкретное событие) · `Entry Hook` (сегмент + боль) · `Onboarding → Core Loop → Paywall`
  (последовательность экранов) · `Growth loop варианта` · `Как ложатся FR-GROWTH-001..004` (момент share-CTA,
  где живёт watermark/badge, где партнёрский код) · `Микро-тренды` (2–4, со ссылкой из R2) ·
  `Метрика недели и целевое число` · `Что берём из январского клона` · `Главный риск` (честно, включая
  «этот вариант не даёт виральности»).
- Во всех вариантах соблюдать: оценка потенциала клипа показывает ПОЧЕМУ (хук, завершённость мысли,
  длина); оценка НЕ создаёт виральность продукта — это predictive-инструмент; момент ценности = пользователь
  посмотрел первый готовый клип, кнопка «скачать / поделиться» ровно там; watermark читаем в 9:16 на
  мобильном экране (позиция — из safe zones R2, помечена как неподтверждённая на живом UI).
- Scope недели не расширять: автопостинг, brand kit, команды, распознавание лиц — НЕ входят ни в один вариант.
- Итог: сравнительная таблица вариантов + раздел `## Рекомендация исполнителя` (какой и почему, с оговоркой:
  выбор делает владелец) + раздел `## Зафиксированный выбор` с текстом `{CHOSEN_CJM}: ОЖИДАЕТ ВЫБОРА ВЛАДЕЛЬЦА`.
- Метрика недели: в постановке нет целевого числа. Предложи число для каждого варианта (R2 даёт отправную точку)
  и пометь как предложение, требующее утверждения.

### 3. `docs/CJM_Variants.html` — кликабельный прототип (один самодостаточный файл)
- Один HTML-файл, CSS и JS внутри. Внешних скриптов нет (можно Google Fonts через `<link>`). Работает офлайн.
- `<title>` — короткое имя 2–4 слова.
- Цвета — CSS-переменные на `:root`; тёмная тема через `@media (prefers-color-scheme: dark)` под
  `:root:not([data-theme="light"])` и дублем `:root[data-theme="dark"]`; явный фон у `body`.
- Работает на ширине телефона: поле 16px по бокам, без горизонтальной прокрутки страницы.
- Функции: переключатель вариантов (вкладки A/B/C/D); для каждого варианта 6 экранов по шагам CJM
  (лендинг → загрузка → прогресс обработки → **первый готовый клип (Aha) с кнопкой скачать/поделиться** →
  paywall/снятие watermark → share/партнёрский экран); оверлей CJM (стадия, AARRR, FR-GROWTH на экране);
  сравнительная таблица; конструктор «собрать свой» (выбрать блок из каждого варианта); итоговая карточка
  выбора, которая формирует текст вида «Aha от A, paywall от C, loop от B» для копирования владельцу.
- На экране клипа — макет вертикального плеера 9:16 с вшитыми субтитрами (караоке-стиль из R2) и
  watermark в рекомендованной зоне; карточка оценки потенциала с разбором ПОЧЕМУ по трём критериям.
- Облик: закономерности из `docs/source-product-profile.md` (шаг отступов, шкала шрифтов, плотность,
  порядок экранов). НЕ переносить значения бренда Opus Clip (его точные цвета, шрифт, логотип, название) —
  это чужие товарные знаки. Свою палитру подписать в подвале: «палитра своя; закономерности — из профиля источника».
- Тексты интерфейса — на русском. Имя продукта — рабочее, придумай нейтральное (не «Opus»).
