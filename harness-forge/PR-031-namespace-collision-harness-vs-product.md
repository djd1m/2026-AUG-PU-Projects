# PR-031: Пространство имён конвейера сталкивается с именами генерируемого продукта

**Класс:** коллизия имён без предупреждения · **Приоритет:** P2 · **Найдено:** 2026-09-01, проект 02

## Наблюдение

Конвейер владеет пространством имён slash-команд: `/replicate`, `/feature`, `/go`, `/plan`,
`/start`, `/run`, `/next`, `/docs`, `/deploy`, `/harvest`, `/myinsights`.

Генерируемый продукт естественным образом использует те же короткие имена для **URL-путей**:
`/go`, `/start`, `/next`, `/docs` — обычные редиректы, точки входа и разделы. Ничто об этом
не предупреждает ни при генерации, ни при ревью.

## Как это выглядело

Архитектура проекта 02 вводит редирект `GET /go/:slug/:platform` — гость уходит на выбранную
площадку через наш маршрут, чтобы поддавалась счёту доля выбравших публичную дверь.

В документах он **десять раз в пяти файлах** написан голым: `` `/go` ``. Владелец продукта,
читая отчёт, спросил прямо: «под `/go` подразумевается команда p-replicator?»

Вопрос закономерный: `/go` в этом репозитории **действительно** команда — «intelligent feature
implementation router» из `.claude/commands/go.md`. Два разных объекта, одно имя, разные
пространства, и ни одной пометки.

Побочно и показательно: при фиксации правки `bash` попытался **исполнить** `/go` из текста
коммит-сообщения и вернул `No such file or directory`. Коллизия задевает не только читателя.

## Почему это дороже, чем опечатка

| Кто читает | Что понимает |
|---|---|
| Владелец продукта | «речь о команде конвейера» — и теряет нить архитектурного разбора |
| Агент следующей фазы | может исполнить команду вместо ссылки на маршрут |
| Автор через полгода | ищет `/go` в `.claude/commands/`, не находит связи с продуктом |

Ущерб не в поломке, а в **тихой потере смысла**: документ читается, но понимается неверно, и
это не проявляется ошибкой.

## Что предлагается

**1. Перечень зарезервированных имён в конвейер.** Список команд пакета известен на момент
генерации. Проверка «путь продукта совпадает с именем команды» — один `grep` по таблице
маршрутов, то есть слой 1.

**2. Соглашение в навык документирования.** Путь продукта пишется в полной форме —
`GET /go/:slug/:platform`, а не `` `/go` ``. Полная форма однозначна сама по себе и не требует
знания контекста.

**3. Предупреждение при совпадении, а не запрет.** Запрещать продукту иметь путь `/go`
неправильно — это хорошее имя для редиректа. Достаточно, чтобы генератор один раз сказал:
«путь `/go` совпадает с именем команды конвейера; в документах пишите полную форму».

## Способ проверки

```
Сгенерировать проект с маршрутом, чьё имя совпадает с командой пакета.
Отсутствие предупреждения — воспроизведение дефекта.
```
