## Принцип, по которому оформлены заявки

Из корневого `CLAUDE.md` — **лестница стоимости обнаружения**. Каждая проверка должна жить
на самом сильном слое, который способен её выразить:

```
1. CI / детерминированный тест     ← сюда стремимся
2. всегда-загружаемое правило
3. gate фазы пайплайна
4. суждение скилла
5. память агента                   ← отсюда уходим
```

Общая черта всех найденных дефектов: проверка живёт на слое 4–5 («модель вспомнит»), где
её пропуск **не оставляет следов**. Пайплайн проходит зелёным, артефакт просто отсутствует.
