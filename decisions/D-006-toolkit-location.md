# D-006: Куда Phase 3 пишет тулкит проекта

**Дата:** 2026-08-26 · **Статус:** подтверждено владельцем

## Контекст

Phase 3 пайплайна `/replicate` генерирует **проектные** артефакты Claude Code: `CLAUDE.md`,
агентов, правила, скиллы, `feature-roadmap.json`. По умолчанию она пишет в `.claude/` от корня.

Но в этом репозитории **восемь проектов**, а корневой `.claude/` уже занят общим тулкитом:
174 скилла, 160 команд от p-replicator, feature-adr и ruflo.

## Варианты

| Вариант | За | Против |
|---|---|---|
| A. Корневой `.claude/` | Claude Code подхватит автоматически | Артефакты 8 проектов смешаются; следующий `/replicate` перезапишет предыдущий |
| **B. `projects/<проект>/.claude/`** ← выбрано | Изоляция; соответствует правилу «работа только внутри папки проекта» | Claude нужно запускать из папки проекта |

## Решение

**Тулкит проекта живёт в папке проекта.** Claude Code запускается из неё же:

```bash
cd projects/01-testimonials-senja
claude
```

Формулировка владельца: *«если это установка кастомных инструментов для claude, то возможно
имеет смысл их ставить прямо в папку проекта и клод запускать в папке проекта»*.

## Обоснование

Проектные артефакты по определению относятся к одному проекту: `feature-roadmap.json` со списком
фич Senja-клона бессмыслен для клона Cal AI. Восемь таких наборов в одной папке неизбежно
передерутся — причём молча, при следующем прогоне `/replicate`.

Изоляция стоит одной команды `cd`.

## Что остаётся в корне

Общий тулкит: скиллы p-replicator, feature-adr, ruflo, команды `/replicate`, `/feature`,
правила репозитория, `scripts/check-pipeline-gaps.sh`. Он **общий для всех восьми** и
дублировать его в каждую папку не нужно.

## Открытый вопрос

Подхватятся ли проектные скиллы, если Claude запущен из корня репозитория. Claude Code
поддерживает directory-scoped скиллы (показываются с префиксом пути), но на этом репозитории
это не проверялось. Практическая рекомендация — запускать из папки проекта, тогда вопрос не встаёт.

## Как переиграть

Перенести содержимое `projects/<проект>/.claude/` в корневой `.claude/` с переименованием,
чтобы избежать коллизий между проектами.
