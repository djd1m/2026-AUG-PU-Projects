# Журнал развилок

Решения, принятые **без участия владельца** — когда ответа не было в течение ~5 минут,
а работа блокировалась. Каждое можно переиграть: указано, что править и во что это обойдётся.

**Формат ID:** `D-NNN`. **Статус:** `принято мной` · `подтверждено владельцем` · `переиграно`.

| ID | Тема | Решение | Статус |
|---|---|---|---|
| [D-001](D-001-metric-target.md) | Целевое число метрики недели | 10 сайтов | принято мной |
| [D-002](D-002-value-moment.md) | Семантика момента ценности | на каждый новый домен | **переиграно владельцем** |
| [D-003](D-003-object-storage.md) | Хранилище видео | MinIO как сервис compose | принято агентом |
| [D-004](D-004-rate-limit-store.md) | Счётчики anti-fraud | таблица Postgres, не Redis | принято агентом |
| [D-005](D-005-tls-termination.md) | TLS-терминация | Caddy (ADR-007) | принято агентом |
| [D-006](D-006-toolkit-location.md) | Где живёт тулкит проекта | в папке проекта | **подтверждено владельцем** |

## Правило

Развилка попадает сюда, если:
- решение меняет продукт или архитектуру, а не оформление;
- у него есть разумная альтернатива, которую можно было выбрать;
- владелец его не подтверждал явно.

Мелкие технические выборы без альтернатив сюда не пишутся — иначе журнал станет шумом.
